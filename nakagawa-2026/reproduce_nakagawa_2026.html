Reproducing Nakagawa et al. (2026) from dandiset 001968¶

Paper. Nakagawa T, Xie JL, Park K, et al., Igarashi KM (2026). Early dopamine disruption in the entorhinal cortex of a knock-in model of Alzheimer's disease. Nature Neuroscience. doi:10.1038/s41593-026-02260-w. The claims file was written from the version of record (Europe PMC, PMC13246448) with its Extended Data legends and the supplement (Supplementary Figs. 1 to 11, Tables 1 to 4), and from the Methods of ref. 16 (Lee et al. 2021) for the steps the paper describes "as previously described".

Dandiset. DANDI:001968, version 0.260914.1316. The paper cites no DANDI version (its data statement points to the lab's web page, which holds only a hippocampal spike set of an earlier paper, three linear-track MATLAB scripts and a headplate file). Of the two published versions, 0.260913.1518 holds a single unit file and 0.260914.1316 all 3855 files; the latter is the most recent and is pinned. The draft has the same asset count and size.

What the dandiset holds. 3813 unit files (one sorted LEC unit each: spike times, a source mean rate, and a source file name carrying strain label, date, odor set, an RS or FS class label and tetrode) from 27 tetrode mice, and 41 photometry sessions from 10 mice (one z-scored trace per trial with its odor and action codes, and the source's per-odor block means). There are no trial, odor or lick times for the unit sessions, no waveforms, no histology, and no behaviour of mice other than the photometry mice. No file states genotype, age group or treatment; these come from the paper's Supplementary Table 2 and Supplementary Fig. 2a (link claims below).

The helper module lecda.py loads the files and holds the measures; its docstring says where each parameter comes from. Two choices rest on assumptions checked in the data check: the photometry traces are sampled at 1 kHz with the cue at sample 1000, and the odor codes 1 to 4 are Odor-A, Odor-B, Odor-1 and Odor-2. A third, the unit of the photometry statistics, is set out before the photometry claims: the mean over a mouse's sessions stands in for the paper's hemispheres.

Photometry: common table¶

Per session, odor and timepoint, the window means of the block's trial-averaged z-scored signal (helper, block_table). Units of analysis: the paper's are hemispheres (10 WT, 8 APP-KI), which the files do not identify (one signal per session file, no fiber or location metadata; data check). The Fig. 4d legend gives F(4,80) for 10 + 8 hemispheres and five timepoints, which leaves one value per hemisphere and timepoint: a hemisphere's sessions are pooled, not counted apart. The adopted reading, an assumption, is therefore the mean over a mouse's sessions (M; 5 WT and 5 APP-KI mice), the nearest pooled unit the files allow. It has fewer units than the paper's 18, and with 5 units a two-sided signed-rank test cannot reach p < 0.05 (its smallest p is 0.0625). Sessions as units (S; 11 WT and 30 APP-KI sessions) are run as a variant: they count repeated recordings of one hemisphere as independent, giving 195 residual degrees of freedom against the paper's 80. Where the two readings give different outcomes, this is said in the conclusion.

Against the precue, the Wilcoxon signed-rank test is adopted (Supplementary Table 1). It is paired; the rank sum test the Results name compares window means with precue means that are near 0 by the z-scoring, so it is not paired, and it is shown as a variant. A session whose T5 performance is undefined under a reading (00266_20190405 under B1) is counted neither as correct nor as an error.

def precue_tests(df):
    """Window G2 against the precue per unit: Wilcoxon signed-rank (paired, the test adopted)
    and rank sum (a variant; it compares window means with precue means that are near 0 by
    the z-scoring, so it is not a paired test)."""
    if len(df) < 2:
        return np.nan, np.nan
    sr = stats.wilcoxon(df.G2, df.pre).pvalue if len(df) > 1 else np.nan
    rs = stats.ranksums(df.G2, df.pre).pvalue
    return sr, rs

def strain_time(df, odor, window, unit):
    u = lecda.per_unit(df, "session" if unit == "S" else "mouse")
    v = u[(u.odor == odor) & u["T"].isin(TS)].rename(columns={window: "y"})
    table, tk = lecda.two_way(v, "strain", "T")
    same = tk[[a[1] == b[1] for a, b in zip(tk.a, tk.b)]].copy()
    same["T"] = [a[1] for a in same.a]
    # diff is a - b; report WT minus APP-KI
    same["WT - APP"] = [d if a[0] == "WT" else -d for a, d in zip(same.a, same["diff"])]
    n = v.groupby("strain").unit.nunique().to_dict()
    return table, same, n

Reproducing Kyzar et al. (2024) from dandiset 000469¶

Paper: Kyzar, Kamiński, Brzezicka, Reed, Chung, Mamelak & Rutishauser (2024), "Dataset of human-single neuron activity during a Sternberg working memory task", Sci Data 11, 89, doi:10.1038/s41597-024-02943-8.

Dataset: DANDI:000469, version 0.240123.1806 (doi:10.48324/dandi.000469/0.240123.1806). The paper cites the dandiset without a version (ref. 46, "Kyzar M, 2023, DANDI Archive"), so the most recent published version is pinned. The four published versions (0.231213.2047, 0.240122.1800, 0.240122.1812, 0.240123.1806) and the draft list the same 41 assets with the same asset identifiers and sizes, so the choice does not change the data read; the cell below checks this against the archive.

Text the claims file was written from: the version of record (Europe PMC, PMC10796636), with Methods, Technical Validation, legends and Tables 1 to 3; the paper has no supplement. The claims file also read the paper's code, github.com/rutishauserlab/workingmem-release-NWB at commit f8594e0. Where a method detail below is taken from that code, the helper module sternberg.py cites the file.

The spikes are checked against the trial clock with a contrast between conditions: the fraction of units whose response 200 to 1000 ms after image onset differs between images, with the onsets shifted by -2 to +2 s.

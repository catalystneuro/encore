Reproducing Economo et al. (2018) from dandiset 000006¶

Paper. Economo MN, Viswanathan S, Tasic B, et al. (2018). Distinct descending motor cortex pathways and their roles in movement. Nature 563, 79-84. doi:10.1038/s41586-018-0642-9. The paper is not open access and has no copy in PubMed Central, so the claims and criteria were written from its abstract only. Its public Data availability statement was read to find the linked data and code. After the first round of verification, the public legends of Extended Data Figs 5 to 10 were read for the number of units the paper used (61 PTupper, 69 PTlower) and for the single-unit decoding measure of Extended Data Fig. 9; both are used in variants only, and the criteria were not changed.

Dandiset. DANDI:000006, version 0.220126.1855. The paper cites no DANDI version (it points to CRCNS and Figshare). This is the only published version, and it is pinned for that reason. The draft holds the same 53 files with the same sizes; it differs only in metadata added later (ORCID, affiliations, funders, anatomy terms and a link to the DataLad source), none of which the analysis uses.

What the dandiset holds. Spike-sorted units from silicon probe recordings in the anterior lateral motor cortex (ALM) of 12 mice in a delayed response task (lick left or right after a go cue, depending on the position of a pole presented in the sample epoch), with trial tables and lick times. Tagged pyramidal tract (PT) units carry the label PTupper (8 mice) or PTlower (4 mice). The single-cell and bulk RNA-seq, the anatomy and the axonal reconstructions of the paper are not in it.

Code read. The paper's Data availability statement points to the Figshare record doi:10.25378/janelia.7007846 (version 1). Its Ephys.zip holds the MATLAB analysis code (defineDataset.m, loadAndProcessData.m, simplePlots.m, Projections.m, CDCorrelation.m, decodingAccuracy.m, VarianceExplained.m and helpers) and the processed data it reads. The code names the PTlower animals "MP" (medulla-projecting) and the PTupper animals "TP" (thalamus-projecting), and fixes the epochs, the trial and unit selection and the selectivity test used here (see alm.py). The processed data are read in the data check, to show how the files' spike times were built and which of the paper's units the dandiset holds, and in variants that rerun the tests on the paper's 61 and 69 units.

The files match the archive's summary: 53 files and 12 mice. Each mouse has only one tagged type: PTupper in 8 mice and PTlower in 4, so the type comparison is also a comparison between animals. The code's grouping of animals into "MP" and "TP" (defineDataset.m) puts the four PTlower mice in "MP" (medulla-projecting) and the eight PTupper mice in "TP" (thalamus-projecting). That is how the types are linked to projections here; the files themselves do not name the projection target. Tagged units are exactly the units with ids above 1000. Unit quality has a mix of vocabularies (single, Excellent, Good, Fair, Poor) and some empty values ([], 0, blank), which are not described. Sex is U and genotype empty in every file, and the session start times are at midnight. 34 files hold only the tagged units of the session (1 to 4 units), with no unidentified units, and electrode positions are all zero.

The trial table holds start_time on the session clock and pole_in_time, pole_out_time and cue_start_time in seconds from the trial start, as the dandiset's layout implies but does not state. The pole comes in 2.5 s before the go cue and starts to leave 1.5 s before it in nearly all trials, so the code's epochs (sample from -2.5 s, delay from -1.3 s) fit the events. The trials where the delay is not 1.5 s are nearly all early-lick trials, which are left out. stop_time is NaN throughout, so trials have no stated end. Consecutive trial starts are a median 6.4 s apart (5.4 to 7.9 s from the 1st to the 99th percentile), while the go cue comes 6.3 to 8.5 s after the start, so on the file's clock a trial's go cue often falls after the next trial's start. Photostimulation was flagged on 2 trials only, and is_good is false for 651 trials; the code does not use is_good (a variant below drops those trials).

# Clock of the licks: first lick in the 2 s after the go cue, against the trial's direction,
# with the true labels and with each trial given the label of the next trial.
rows = []
for s in sessions:
    t = s["trials"]
    left, right = np.sort(s["licks"]["left"]), np.sort(s["licks"]["right"])
    for shift in (0, 1):
        labels = np.roll(t.type.to_numpy(), -shift)
        for i, c in enumerate(t.cue_abs.to_numpy()):
            fl = left[np.searchsorted(left, c, "right")] if np.searchsorted(left, c, "right") < len(left) else np.inf
            fr = right[np.searchsorted(right, c, "right")] if np.searchsorted(right, c, "right") < len(right) else np.inf
            first = min(fl, fr)
            side = "none" if first - c > 2 else ("left" if fl < fr else "right")
            rows.append({"shift": shift, "response": t.response.iloc[i],
                         "first lick": "none" if side == "none" else ("trial side" if side in labels[i] else "other side"),
                         "latency": first - c if side != "none" else np.nan})
licks = pd.DataFrame(rows)

print("First lick after the go cue, true labels (shift 0) and labels of the next trial (shift 1):")

# Per unit: selectivity p-value and d' in each epoch (correct trials, left against right).
def unit_table(recs):
    rows = []
    for r in recs:
        if not r["included"]:
            continue
        row = {"subject": r["subject"], "session": r["session"], "id": r["id"], "cell_type": r["cell_type"],
               "depth": r["depth"]}
        for name, rates in r["rates"].items():
            row[f"p {name}"] = alm.ranksum_p(rates, r["is_right"])
            row[f"d {name}"] = alm.dprime(rates, r["is_right"])
        rows.append(row)
    return pd.DataFrame(rows)


def shuffle_fraction(recs, cell_types, epoch, rng, n=1000, threshold=alm.SELECTIVITY_P):
    # Fraction of included units of `cell_types` selective in `epoch`, and its null from
    # shuffling each unit's trial labels.
    obs, null = [], []
    for r in recs:
        if not r["included"] or r["cell_type"] not in cell_types:
            continue
        rates, right = r["rates"][epoch], r["is_right"]
        obs.append(alm.ranksum_p(rates, right) < threshold)
        null.append(alm.shuffled_ranksum_p(rates, right, alm.label_shuffles(len(right), n, rng)) < threshold)
    obs, null = np.array(obs), np.array(null).mean(axis=0)
    return obs.mean(), obs.sum(), len(obs), null, alm.null_p(obs.mean(), null)

def similarity_test(recs, cell_type, rng, n=1000):
    # Cosine similarity of sample and late delay d' over included units of a type, and its null
    # from shuffling each unit's trial labels (the same shuffle for both epochs).
    d_s, d_l, null_s, null_l = [], [], [], []
    for r in recs:
        if not r["included"] or r["cell_type"] != cell_type:
            continue
        right = r["is_right"]
        perms = alm.label_shuffles(len(right), n, rng)
        d_s.append(alm.dprime(r["rates"]["sample"], right))
        d_l.append(alm.dprime(r["rates"]["late delay"], right))
        null_s.append(alm.shuffled_dprime(r["rates"]["sample"], right, perms))
        null_l.append(alm.shuffled_dprime(r["rates"]["late delay"], right, perms))
    d_s, d_l = np.array(d_s), np.array(d_l)
    null_s, null_l = np.array(null_s), np.array(null_l)
    null = (null_s * null_l).sum(axis=0) / (np.linalg.norm(null_s, axis=0) * np.linalg.norm(null_l, axis=0))
    obs = alm.cosine(d_s, d_l)
    return obs, null, alm.null_p(obs, null), d_s, d_l

def mcnemar_table(table, cell_type, first, second, threshold=0.01):
    t = table[table.cell_type == cell_type]

    p = alm.mcnemar_one_sided(int((a & ~b).sum()), int((~a & b).sum()))
    return a.mean(), b.mean(), int((a & ~b).sum()), int((~a & b).sum()), len(t), p

def bootstrap_similarity(recs, cell_type, rng, n_boot=100):
    pool = [r for r in recs if r["included"] and r["cell_type"] == cell_type]
    animals = sorted({r["subject"] for r in pool})
    out = []
    for _ in range(n_boot):
        chosen = rng.choice(animals, len(animals), replace=True)
        cand = [i for a in chosen for i, r in enumerate(pool) if r["subject"] == a]
        picks = rng.choice(cand, len(pool), replace=True)
        d_s, d_l = [], []
        for i in picks:
            r = pool[i]
            right = r["is_right"]
            idx_l = rng.choice(np.flatnonzero(~right), (~right).sum())
            idx_r = rng.choice(np.flatnonzero(right), right.sum())
            idx = np.r_[idx_l, idx_r]
            lab = np.r_[np.zeros(len(idx_l), bool), np.ones(len(idx_r), bool)]
            d_s.append(alm.dprime(r["rates"]["sample"][idx], lab))
            d_l.append(alm.dprime(r["rates"]["late delay"][idx], lab))
        out.append(alm.cosine(np.array(d_s), np.array(d_l)))
    return np.array(out)

How the analysis differs from the paper's. The claims and their criteria were written from the abstract only, so they and the tests of significance are this attempt's; the paper's own statistics are unknown. The public Extended Data legends 5 to 10, read later, are used in variants only. The epochs, trial selection, unit inclusion and selectivity test follow the paper's code on Figshare. Epoch rates are spike counts over the epoch, where the code averages a causally smoothed PSTH. Spikes are counted on the file's clock, where some spikes of one trial fall into the next trial's early epochs; the code worked on spikes already assigned to trials. Leaving out the spikes that the stored order shows to overlap changes no outcome. The tests of chance (label shuffles), of change between epochs (McNemar) and between types (Fisher) are choices made here. The dandiset holds 44 of the paper's 61 PTupper and 56 of its 69 PTlower units; variants rerun every test on the paper's 130 units from its processed data and give the same outcomes.

What was found about the dandiset.

  • It holds the electrophysiology only: the transcriptomic, anatomical and axonal data behind four of the abstract's findings are elsewhere (GEO GSE119182 and the Figshare record).
  • Spike times are not sorted in 1120 of 1149 units. They were written as trial start + go cue time

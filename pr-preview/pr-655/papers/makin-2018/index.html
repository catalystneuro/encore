Makin et al. 2018 · Journal of Neural Engineering

Superior arm-movement decoding from cortex with a new, unsupervised-learning algorithm.

doi:10.1088/1741-2552/aa9e95 · paper key makin-2018

Datasets

  • DANDI:000129

Most of Makin et al.'s main findings could not be tested here, because the dandiset holds one session where the paper used 49, and every claim that needs a test across sessions is blocked. On that one session the rEFH decoder's advantage at velocity and acceleration held, and so did the weak effect of a Kalman filter on KFlatent and the rising advantage with bin width. The rEFH's dynamic gain for position (4.45 dB against about 3) did not match, nor did position being the best-decoded variable for the rEFH, nor the losses in the figure 8 variants. The velocity-boost ratio (1.92 against the required 2) flips with the kinematics reading the Methods and code disagree on. The file has sorted units only, which probably explains the low unit count (111 against 171 to 413).

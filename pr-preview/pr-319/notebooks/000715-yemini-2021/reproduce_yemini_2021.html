Dandiset. DANDI:000715, version 0.241009.1514 (doi:10.48324/dandi.000715/0.241009.1514). The paper cites no DANDI version (its data statement points to Zenodo). There are four published versions (0.240424.1847, 0.240611.1953, 0.240614.1942, 0.241009.1514) and the draft; all list the same ten assets with the same asset and blob identifiers and sizes, so their content is identical. The most recent published version is pinned.

What the dandiset holds. Ten NWB files, each one worm head: a five-channel volume and the hand-annotated neurons (one centre voxel and one name per neuron). The data check below shows that these are the heads of the paper's ten atlas worms (otIs669), whose head and tail volumes are also on Zenodo (doi:10.5281/zenodo.3906530); the tails are not in the dandiset. The files' own metadata say otherwise (strain OH16230, a spinning disk confocal, a microfluidic chip).

Outside inputs. The NeuroPAL colors of each neuron, from data.mat of the paper's Optimal_Coloring code (github.com/Eviatar/Optimal_Coloring at 990c597), for ms2-neuropal-color-violations (and the reporter table of the same file for fig7de, in optimal_coloring.ipynb). The ganglion of each neuron, from the CELL_ID neuron tables (Data/NeuroPAL/herm_data.mat at d9f5df9), for the head part of fig7bc-ventral-ganglion-lowest.

The statistical atlas (MS1 Algorithm 4)¶

The atlas is fit on the named neurons: position (um) and the R, G, B landmark colors (mNeptune2.5, CyOFP1, mTagBFP2) read from the z-scored volume. Algorithm 4 as written alternates an affine regression of the atlas means on each worm (equations 4.15 and 4.16) with the moments of the aligned worms (equations 4.13 and 4.14) until the change is below a tolerance. On these data it does not converge: the atlas is defined only up to an affine map, and the regression shrinks it along its minor axes at every alternation (table below). The paper does not say how this was avoided. The atlas here keeps the gauge of the initial worm (after each update the atlas is mapped back, by the affine map that best fits its means to the initial worm's neurons) and stops after npl.ATLAS_ITER = 20 alternations, where the position block has settled. This is an assumption; the results are shown under other choices.

def atlas_summary(names, mu, sigma):
    coeff, m = npl._pca(mu[:, :3])
    P = (mu[:, :3] - m) @ coeff
    sd = np.sqrt(np.einsum("ai,nab,bi->ni", coeff, sigma[:, :3, :3], coeff))
    csd = np.sqrt(np.diagonal(sigma[:, 3:, 3:], axis1=1, axis2=2))
    return P.max(0) - P.min(0), np.median(sd, 0), np.median(csd, 0)

def ollr_olll(names, mu, sigma):
    sd, coeff = axis_sd(mu, sigma)
    out = {}
    iR, iL = names.index("OLLR"), names.index("OLLL")
    out["a_sd_ratio"] = sd[iR, 0] / sd[iL, 0]
    out["b_var_ratio"] = out["a_sd_ratio"] ** 2
    r50 = np.sqrt(stats.chi2.ppf(0.5, 2))
    for plane, keep, q in (("axes_1_2", [0, 1], 2), ("axes_1_3", [0, 2], 1)):
        ext = []
        for i in (iR, iL):
            S = coeff.T @ sigma[i, :3, :3] @ coeff            # covariance in the principal frame
            Spp = S[np.ix_(keep, keep)]
            Spq = S[np.ix_(keep, [q])]
            cond = Spp - Spq @ Spq.T / S[q, q]                 # conditional 2-D covariance in the plane
            ext.append(2 * r50 * np.sqrt(cond[0, 0]))          # AP extent of the 50% contour
        out[f"c_extent_ratio_{plane}"] = ext[0] / ext[1]
    out["sd_OLLR_um"], out["sd_OLLL_um"] = sd[iR, 0], sd[iL, 0]
    return out

Leave-one-out identification (MS1 Algorithm 5)¶

For each held-out worm the atlas is fit on the other nine and the worm's named neurons are identified. Two alignments are run, as the claims file asks: Algorithm 5 as written (identity start on the positions as given) and the CELL_ID global alignment (principal axes and a search of rotations). A third run aligns the held-out worm with its true correspondences; it is not the paper's method and only bounds what the atlas and the colors allow.

The files carry no orientation of the worm. The subject names end in LR (imaged in left-right view) or DV (dorsal-ventral view), and the alignment by true correspondences (next cells) shows that the five DV heads are stored rotated by about 90 degrees about the long axis relative to the five LR heads. Algorithm 5's identity start cannot undo this, and the CELL_ID rotation search does not search rotations: as in CELL_ID, the principal-axis fit after each rotation undoes it. A fourth run, not the paper's method, starts Algorithm 5 from the identity and from rotations of 90, 180 and 270 degrees about the long axis and keeps the run with the lowest assignment cost, using no annotations ("rotated"). Reading a identifies the named hand-annotated neurons; reading b identifies the automatic detections of ms1-detection-accuracy, an annotation counting as right when the detection matched to it within 3 um gets its name. Neurons whose name is not in the nine-worm atlas count as wrong.

def calibration(res, by_class):
    rows = {}
    for r in res:
        names = r["names"]
        nset = set(names) | set(r["labels"])
        cls = np.array([npl.pair_class(n, nset) for n in names])
        for k, (lab, a) in enumerate(zip(r["labels"], r["assign"])):
            if by_class:
                conf = r["P"][k, cls == cls[a]].sum()
                hit = cls[a] == npl.pair_class(lab, nset)
            else:
                conf = r["P"][k, a]
                hit = names[a] == lab
            rows.setdefault(lab, []).append((conf, hit))
    df = pd.DataFrame({n: np.mean(v, axis=0) for n, v in rows.items()}, index=["confidence", "accuracy"]).T
    rho, p = stats.spearmanr(df.confidence, df.accuracy)
    mad = 100 * np.abs(df.confidence - df.accuracy).mean()
    return df, dict(neurons=len(df), mean_conf=100 * df.confidence.mean(), mean_acc=100 * df.accuracy.mean(),
                    spearman_rho=rho, spearman_p=p, mean_abs_diff_points=mad,
                    a_holds=bool(rho > 0 and p < 0.05), b_holds=bool(mad < 10))

How the analysis differs from the paper's: only heads are in the dandiset; the atlas fit of Algorithm 4 does not converge on these data, and the atlas here is kept in the initial worm's frame and stopped after 20 alternations (an assumption, with variants shown); the colors are read from the volumes with the readout of Methods S1, since the files hold no per-neuron colors; the detection is a Python port of the paper's MATLAB code with a different optimiser. The five heads imaged in dorsal-ventral view are stored rotated by about 90 degrees about the long axis relative to the five in left-right view, which Algorithm 5's identity start cannot undo; a variant started from four rotations (not the paper's method) is shown for every identification claim. It changes no outcome on the main atlas, where fig7bc-identification-accuracy misses its bound by 0.02 points and ms1-position-only-accuracy by 1 point, but under three of the four variants of the atlas fit it puts a class reading of fig7bc-identification-accuracy, and the position-only accuracy, inside the tolerance.

What was found about the dataset: the files are the heads of the paper's ten otIs669 atlas worms, identical to the Zenodo volumes, but their metadata name the strain OH16230, a spinning disk confocal, a microfluidic chip and dates in 2021; the channel labelled GFP-GCaMP holds the transmitted-light channel; the tails are missing; neuron names are stored as one character per element of a ragged array; about 3% of the stored neurons have no name; and the files carry no per-neuron colors and no orientation of the worm, though half the heads are stored in another orientation from the other half.

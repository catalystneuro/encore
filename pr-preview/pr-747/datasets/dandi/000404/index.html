Dataset version 0.230605.2024 · tested 2026-10-30 · 5 open findings

  • Data missingThe files hold no decoder matrices (Kalman gain, steady-state cursor dynamics, the PPF's parameters), although the paper's Data availability lists decoder parameters among the deposited data. The code that wrote the files has these lines commented out (online_analysis/nwb_utils.py). Monkey G's steady-state gain and cursor update can be recovered exactly from the decoder state and spike counts (variance accounted for above 0.99999 on 99% of updates); Monkey J's PPF cannot, and its linear approximation must be refitted.
    Found by the attempt on Athalye et al. 2023 (athalye-2023-01, 2026-10-30)
  • File format errorMonkey J's target_state and obs_details series carry one target and obstacle for every trial of a session; the writer indexes frames with the position of each go event in the event list (nwb_utils.py, targets[(go_ - start_index_overall):] with go_ an index into strobed), so the last trial's values fill the file. In Monkey G's sessions 0 and 1, checked, target_state at reward is one value for all trials and does not hold the trial's target. Targets have to be read from the cursor position at reward.
    Found by the attempt on Athalye et al. 2023 (athalye-2023-01, 2026-10-30)
  • Description missingThe trials table has only start and stop times. Task, target, direction around the obstacle and Monkey J's obstacle trial type are not given; the task can be read from the obstacle series of each task entry, the target from the cursor at reward, and Monkey J's obstacle trial types (the paper analyses only partial and full obstruction) only by matching start and end positions to a target list in the paper's code.
    Found by the attempt on Athalye et al. 2023 (athalye-2023-01, 2026-10-30)
  • Metadata errorUnits differ within Monkey J's files. The cursor and decoder state are in m and m/s, while target_state, obstacle_position and obs_details are stated in cm; target_state holds center-out targets in m (0.1027, 0.1384) and obstacle-task targets in cm (-3.25, 8.13) under that one unit. Monkey G's files are in cm throughout.
    Found by the attempt on Athalye et al. 2023 (athalye-2023-01, 2026-10-30)
  • OtherMonkey G's decoder state does not follow the steady-state filter on 0.03 to 0.95% of updates per session, among them the first updates of each task entry, where the filter had not converged. The gain recovered on the other updates accounts for 0.928 to 1 of the variance of the velocity update over all updates, so the gain must be fitted on the updates the filter explains.
    Found by the attempt on Athalye et al. 2023 (athalye-2023-01, 2026-10-30)

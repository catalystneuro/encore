Reproducing Chang et al. (2023) from dandiset 000232¶

Paper. Chang Y-T, Finkel EA, Xu D, O'Connor DH. Rule-based modulation of a sensorimotor transformation across cortical areas. bioRxiv, doi:10.1101/2023.08.21.554194. This attempt used the full text of preprint version 2 (2024-03-09, CC-BY), as served by eLife for its reviewed preprint 92620v2, whose source is bioRxiv version 2; bioRxiv refused the download. Table 1 and the table of coding-dimension trial types are images in that copy and were not read.

Dandiset. DANDI:000232, version 0.240510.2038. The preprint cites no DANDI version (its data statement says "available upon request"); the paper's code repository cites this version's DOI, and it is the only published version. The draft holds the same 179 files (same assets and blobs) and differs only in contributor metadata.

What the dandiset holds. 49 silicon-probe sessions of the cross-modal selection task (S1, S2, MM, ALM and AMM, one area per session; trials and spike times of the units kept after the paper's quality filter) and 130 optogenetic behaviour sessions (cross-modal task and tactile detection task).

Code read. The paper's analysis code, https://github.com/YitingChang/cross_modal_task at commit 227631ee133709df979b9914c9031cfa992c3736 (MATLAB; preprocessing, data arrays, one folder per figure). Where the Methods leave a choice open, the analysis follows the code; where they disagree, the Methods' choice is the main result and the code's a variant. Nothing from outside the dandiset is used as data.

response agrees with the side of the first lick between 0.1 and 2 s after the stimulus in at least the minimum fraction printed (the remainder are licks the behavioural system timed differently); 1 is a right lick, 2 a left lick and 0 no lick. "Change" rows are the cue trials (water given on the 9th trial of a block), left out of all analyses as in the paper's code. No trial in any ephys file has a lick between -1 and 0.1 s of the stimulus: the trials the Methods remove for pre-stimulus licking (about 25%) are already absent, and the gaps between trials mark where they were. The dandiset does not say this. The stimulus comes at least 1 s after the trial start and the trial ends at least 3.4 s after it, so every analysis window lies inside a trial.

Spike times are sorted, each unit's observation intervals are the trial intervals, and spikes are stored only inside trials. No unit has a mean rate within trials above 50 Hz, consistent with the code's removal of such units, and the unit counts per area equal the paper's after its quality filter (see fig1e-recording-counts), so the Units tables hold the selected units only. def block_outcomes(t):
    c = t.category[t.category != ""]
    out = {}
    for blk, hit, cr, miss, fa in (("touch", "TTT", "TVN", "TTN", ["TTV", "TVT", "TVV"]),
                                   ("light", "VVV", "VTN", "VVN", ["VTT", "VTV", "VVT"])):
        n = c.str[0].eq("T" if blk == "touch" else "V").sum()

    return out

rng_opto = np.random.default_rng(808)

def counts_for(sub, key):
    return (np.array([len(L[key]) for L in sub.licks]), np.array([int(np.sum(L[key])) for L in sub.licks]))

def change(sub, task, measure, o):
    if task == "cross-modal":
        hit, fa = {"tactile": ((1, 1, 1), (1, 2, 1)), "visual": ((2, 2, 2), (2, 1, 2)), "tactile_hit": ((1, 1, 1), None)}[measure]
        c = {"h0": counts_for(sub, hit + (1,)), "ho": counts_for(sub, hit + (o,))}
        if fa:
            c.update({"f0": counts_for(sub, fa + (1,)), "fo": counts_for(sub, fa + (o,))})
    else:
        c = {"h0": counts_for(sub, (1, 1)), "ho": counts_for(sub, (1, o)), "f0": counts_for(sub, (2, 1)), "fo": counts_for(sub, (2, o))}
    formula = (lambda p: (p["ho"] - p["fo"]) - (p["h0"] - p["f0"])) if "f0" in c else (lambda p: p["ho"] - p["h0"])
    mouse = sub.mouse.to_numpy()
    b = xm.hierarchical_bootstrap(mouse, c, formula, 10000, rng_opto)
    bc = xm.hierarchical_bootstrap(mouse, c, formula, 10000, rng_opto, resample={"h0", "ho"})
    return {"point": xm.point_estimate(mouse, c, formula), "boot_mean": b.mean(),
            "lo": np.quantile(b, 0.025), "hi": np.quantile(b, 0.975),
            "code_lo": np.quantile(bc, 0.025), "code_hi": np.quantile(bc, 0.975),
            "sessions": len(sub), "mice": sub.mouse.nunique(), "trials_with_laser": int(c["ho"][0].sum())}

The decoding CIs use 200 resamples per area, the transition CIs 500 and the coding-dimension CIs 1000. The transition classifier is LDA with Ledoit-Wolf shrinkage in place of the code's optimized LDA. Subspace overlaps average 100 equal splits of the tactile hits; the code's single split per neuron is a variant. Where the Methods and code disagree (normalization offsets, the session rule of the subspace analysis, resampling of false alarms in the optogenetic CIs), the Methods' choice is the main result and the code's is shown.

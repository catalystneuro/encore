Flexible Cellular Phenotypes Retain a Shared Type-Level Organization across Response Regimes

Zihan Yang

Outcomes of 29 claims

  • ✓20 reproduced
  • ◐2 partially reproduced

Summary: The paper's phenotype findings hold up in this data: cell-level distances are only partly conserved across long-pulse, ramp and brief-pulse responses, local neighborhoods hardly at all, t-type explains more phenotypic variance than Cre line, and type-level distance maps are shared across the three regimes. The transcriptomic findings of Figure 4 could not be tested, because the server holding the public gene count matrix did not answer during the run. The alignment of t-type with phenotype exceeds shuffled labels as reported, but its printed sizes were not matched, and the paper's code run on its own published scores does not give them either. Most counts, such as the 57 shared t-types, equal the paper's exactly.

Notes on the paper

What the attempts found about the paper itself: a method or rule it does not give, a place where it disagrees with itself, published code that does something else. What they found about the data is on each dataset’s page.

  • Methods not availableQuestion for the paper's author. The code does not hold the script that ran IPFX on all cells: which IPFX version and call made results/features/ipfx_cell_features.csv, and what sets extract_ok = 1? This attempt used IPFX 2.1.2 through its per-regime functions and took extract_ok = 1 for a file that opened and ran; the resulting cells and features equal the paper's, so the choice made no difference here, but the paper should state it. The script that wrote results/q3b/q3b_primary_null_1000.csv (Table 2 rows m and n) is also missing.
  • OtherThe A_t values of Table 2 (rows d to i) depend on an arbitrary order. The code ranks the binary t-type mismatch with np.argsort(np.argsort(x)), so the tied 0s and 1s are ordered as the sort leaves them, and the coefficient carries an offset, shared with its null, that moves with the pair sample and with the order of the tied ranks (a stable sort moves A_t by up to 0.0021 and A_t minus the null mean by at most 0.0003). Run with the code's own draws and seed 0 on the paper's published PCA scores, it gives A_t 0.0370, 0.0316 and 0.0106 against the printed 0.0214, 0.0250 and 0.0213, while A_t minus the null mean (0.0264, 0.0261, 0.0161) is within 0.0005 of the printed difference (0.0264, 0.0266, 0.0166); what produces the larger gap in A_t itself is not shown. The significance against shuffles holds; the printed values have less precision than their three decimals suggest, and A_t minus the null mean, or the tie-corrected Spearman, would be reproducible.
  • OtherIn the split-half analysis the random fallback split draws its permutation from a generator made afresh with seed 0 for each cell, so every cell with the same number of sweeps gets the same permutation, and the seed decides which cells form the pool. With seed 0 this attempt gets the paper's 3,598 cells exactly (358 random splits); with the seeds 1000 to 4000 the pool has 3,582 to 4,100 cells, and with another seed 3,256. The paper reports the pool without saying that it depends on the seed.

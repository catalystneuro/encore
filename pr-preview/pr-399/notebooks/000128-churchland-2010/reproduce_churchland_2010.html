Claims file. claims/000128/10.1016-j.neuron.2010.09.015.yaml, written from the accepted author manuscript in PubMed Central (PMC2991102) with its supplement, and checked by a second reader. The claims file fixes every method; the labels M1 to M9, T2, S1 and so on are its readings.

Answers taken up. A reader answered three questions of this attempt on 2026-10-22 (questions/000128.yaml), and the claims file was updated. The proto-trial selection (M1) is now reading T2 alone: T1, which kept 73.8% of trials and emptied two conditions, is set aside. The tuning measure (M6) is now reading S1 (the range over conditions) alone: S2, the SD over conditions, is set aside. For suppfig1-population-averages the criterion now names both readings of the normalising maximum, (a) and (b), which were already run. Hand speed is checked against the movement onset of the trial table, and the spikes against the trial events by decoding the reach direction (the active target's angle in eight sectors) from the population spike counts in windows before and after target onset. Before target onset the direction is not yet known and decoding must be at chance; after it, it should be above chance.

tau = np.arange(-400, 201, 10)

def spliced(T):
    G, M, rt_c = D[T]["G"], D[T]["M"], D[T]["rt"]
    out = np.zeros(G.shape[:2] + (len(tau),))
    mv_part = M[:, :, np.searchsorted(tm, tau)]
    for c in range(G.shape[1]):
        go_end = 100 - rt_c[c]                   # end of the go-locked part, ms from onset
        g = np.array([np.interp(tau + rt_c[c], tg, G[u, c]) for u in range(G.shape[0])])
        m = mv_part[:, c]
        if go_end >= -300:     # overlap from -300 ms to go_end: fade linearly from go-locked to movement-locked
            w = np.clip((tau + 300) / max(go_end + 300, 1e-9), 0, 1)
            out[:, c] = (1 - w) * g + w * m
        else:                  # gap from go_end to -300 ms: join the two ends linearly
            g_end = G[:, c, np.searchsorted(tg, 100)][:, None]
            m_start = M[:, c, np.searchsorted(tm, -300)][:, None]
            w = np.clip((tau - go_end) / (-300 - go_end), 0, 1)
            out[:, c] = np.where(tau <= go_end, g, np.where(tau >= -300, m, (1 - w) * g_end + w * m_start))
    return out

def pd_dir(S_, x, idx):
    Xd = np.column_stack([np.ones(len(idx)), S_[idx]])
    b = np.linalg.lstsq(Xd, x[idx], rcond=None)[0][1:]

Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Data missingThe dandiset holds one subject (sub-Subject001), where the paper and the dandiset's own description report ten volunteers. Dandisets 001286 and 001287 carry the same description of the study and hold no files. Searching DANDI for propofol, Purdon, Yousefi, anesthesia, consciousness, Emery Brown and EEG found no other dandiset with these data.
  • Data missingThe behavioural task is not deposited (stimulus times and types, button presses), nor the infusion levels and their times, nor the behavioural markers EON, LOC, ROC and EOFF. Every finding of the paper is defined from or aligned to these, so none can be tested.
  • Description missingThe 64 EEG channels have no names, positions or bad-channel marks; the file has no electrode table, although the paper digitized each subject's electrode positions. The frontal channel the paper analyses, the Laplacian reference and every spatial result need them. Nine channels have SDs above 300 uV, which suggests noisy channels the paper would have excluded.
  • File format errorThe EEG is stored as a generic TimeSeries (named example_timeseries, description "no description") with data of shape 64 x 2,316,950, channels first. NWB puts time on the first axis, so pynwb reports 64 samples. The series is not an ElectricalSeries and has no electrodes.
  • Metadata errorThe subject's age is P30D (30 days) for a volunteer the paper describes as 18 to 36 years old. The session start time (2025-01-10T14:24:38Z) equals the file creation date, the date of the conversion, not of the recording. The identifier (NWB123) and session description (EEG Session Example) are placeholders, and the ORCID in the file's notes (0000-0001-2345-6789) differs from the contact's ORCID on DANDI (0009-0006-8777-8262).
  • Identifier missingSubject001 is not linked to the paper's numbering of its ten subjects (for example subject 7, shown in Figure 1), so the deposited recording cannot be matched to any per-subject result of the paper.
  • OtherThe values are consistent with the description where they can be checked. The 60 Hz mains peak and the roll-off above 100 Hz fit the stated 250 Hz rate, the amplitudes fit microvolts, no channel duplicates another, there are no gaps, and the band-power time course (beta rising at minutes 17 and 33, low-frequency and alpha power high from minute 48 to minute 97) has the outline of a gradual propofol induction and emergence, against a reference period (minutes 0 to 15) chosen after looking at the data. The duration does not match. The described protocol (a 20-min baseline, ten 14-min levels and 20 min after the infusion) implies about 180 min, and the file holds 154.5 min; the file marks none of the protocol's phases, so which part is shorter or missing cannot be told.

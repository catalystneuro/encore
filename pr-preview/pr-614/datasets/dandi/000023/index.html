Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Identifier missingThe files carry no SpecimenID, the identifier by which the paper's code and tables name cells. Each file can be linked only by its donor and its ephys session id, which lies 13 to 685 below the cell's SpecimenID. The code's per-cell features confirm the link for 261 of the 283 cells that have them under the Methods' sweep QC and for 282 under IPFX's sweep QC alone (one gives no features under either); for the 35 cells without features in the code, the sample dates and tube order in the code's sample_id are consistent with it.
  • Description missingThe files carry no t-type, soma depth, brain region or medical condition, on which every finding of the paper rests; they must be taken from the paper's code. session_description and the filtering field read PLACEHOLDER, and the archive summary gives the variable measured as ProcessingModule and the technique as "analytical technique".
  • Selection not documentedThe dandiset holds 318 of the 385 cells of the paper's table, including all 283 cells with electrophysiological features in the paper's code; the other 67 are absent. Of the 35 cells without features in the code, 19 give features here under the Methods' sweep QC (2 of them fail cell QC) and 25 under IPFX's sweep QC alone, and which recordings were judged too incomplete, or why, is not said.
  • Metadata errorDonor H18.03.318 is female in the files and male in the paper's donor table and cell table; donor H18.06.005 is 56 years old in the files (P20440.0D) and 57 in both tables.
  • Published code disagreesThe code's feature table measures adaptation as the mean over all spiking long squares, initial firing rate on the hero sweep (about 50 pA above rheobase) and tau from long squares, where the Methods describe adaptation at about 50 pA above rheobase, initial rate at rheobase and tau from short pulses. The features recomputed here match the code's table, not the Methods.
  • Published code disagreesThe code's feature table is consistent with sweep QC on noise alone, as IPFX applies it, not with the Methods' sweep QC.

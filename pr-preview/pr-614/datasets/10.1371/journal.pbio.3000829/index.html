  • unit-link

    The units the paper analysed can be found in the dandiset, and the dandiset's spike times and trials reproduce the per-unit peri-movement activity the paper's code stored.

    Data and code can be found at https://doi.org/10.5061/dryad.0cfxpnvxm.

    Data Availability; Dryad doi:10.5061/dryad.0cfxpnvxm, Gaia_Analy.mat and Isis_Analy.mat

    How it will be judged

    Records are matched by file name (session_id), channel id and sort letter of the curated units. For the 394 records the paper's code keeps (not VLp, no missing SDF), the link holds (reproduced) when at least 90% are found in every file they span and, for matched unit-directions with at least 10 valid trials, the SDF computed from the dandiset correlates with the stored SDF at r > 0.9 for at least 90%. Partially reproduced when 50 to 90% of the records are found or match; not reproduced below 50%. Trial counts and the location labels of the matched units are reported.

Most central findings held: a decoder tells trials with and without the object apart, its accuracy falls with distance from the object, population words carry more information than spike counts, and most CA1 cells change between trials. The object-tuned fraction held in part, since the CA1 fraction matched but the control level ran low. Object-trace cells did not reproduce (6 to 10% against 18.3%), possibly because field detection here differs from the Methods' contour. Stability of object cells across days could not be tested because no cell identities across days are deposited.

Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • File format errorIn the two Neuropixels population files (populationanalyses_27012.mat and populationanalyses_27207.mat) the tracking y equals x in every sample. The same recordings in singlecellanalyses_CA1.mat (sessions 58 and 59) have the same timestamps, x and spike trains and a y of their own, so the y column of the population files is a copy of x.
  • Data missingNo cell identities across days and no day of exposure to the object are deposited, so the cross-day analyses (Figures 1G and 1H) cannot be run.
  • Identifier missingOf the 425 tetrode units of the population files, 283 have no match in the CA1 single-cell file and carry no identifier; they are presumably repeat recordings of cells the file gives from another day, so they have no Object Moved or No Object' trial and no object-tuning status.
  • Data missingThe implant sites (Supplementary Figure 1) and head direction are not deposited; the data descriptor says histology is not shared, and tracking holds one position per sample.
  • Selection not documentedThe CA3 file holds 341 cells from 4 rats (including two Neuropixels sessions, 221 cells), while the paper's Supplementary Figure 3 counts 313 CA3 cells; which cells the paper used is not documented.
  • Metadata errorIn CA3 session 3 (rat 25987) the Object trial's object is near a corner (61.4 cm from the centre) and the Object Moved trial's near the centre (9.0 cm), the reverse of the protocol; the trials or the positions may be swapped.
  • File format errorThree units of singlecellanalyses_CA1.mat have spike times out of order within the Object Moved trial.
  • Selection not documentedA few deposited units break the paper's inclusion rules as computed from the trials (4 of 1189 CA1 units more than 1% ISIs under 2 ms, 7 outside 0.05 to 10 Hz), perhaps because the rates were computed over a recording not deposited.
  • Other26 of 273 gaps between trials in the single-cell files exceed 10 min (up to 4.1 h), while the Methods describe 1 to 3 min between trials.
  • Paper inconsistentThe Methods use 15 tetrode decoding sessions, the legends 14; the dataset holds 14, with the two Neuropixels sessions 16 in all.
  • Data missingThe population files hold the No Object and Object trials only; the Object Moved and No Object' trials of the decoding sessions exist only for the cells the single-cell file gives there (3 to 15 per tetrode session). The control file gives each cell once, and only one control session has 25 or more cells.
  • OtherThe tracking unit is stored as a MATLAB string object, which scipy and other non-MATLAB readers return as an opaque object; its value (centimeters) can be recovered only from the raw bytes.
  • Methods not availableThe paper's code holds no single-cell rate maps, field detection, object-vector score, population vector correlation or sampling analysis. The object-vector method cites references 11 and 12 for its vector maps and does not say which cells its exclusion before the criteria removes (28.8% of CA1 cells).

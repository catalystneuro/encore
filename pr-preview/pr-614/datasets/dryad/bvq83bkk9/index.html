Long-term increases in wing length occur independently of changes in climate and climate-driven shifts in body size

0.8 MB 2 files
  • ✓12 reproduced
  • ◐2 partially reproduced
  • ⊘18 blocked

The paper's central claim, that climate does not explain the long-term increase in wing length, could only be partly tested, because the Hatch-year and spring after-hatch-year models were too slow to fit here. In the one class that was fitted, autumn after-hatch-year birds, colder breeding seasons before development went with longer wings (effect -0.094), and the year effect of 0.19 per decade held. Two autumn effects sat within a few Monte Carlo errors of the 90% line. The preliminary models gave no effect for pre-breeding or wintering temperature, autumn migration temperature or breeding precipitation, and climate trends and phylogenetic signal matched. The spring migration temperature and wintering precipitation null results could not be settled, because the answer changed with the random seed, which the paper's code does not fix.

Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Metadata errorThe README says some specimens in morphdata.csv were filtered out before analysis and that the filtering steps are in the code. The code applies no filter, and the deposited file gives every sample size of the paper exactly without one; the Methods' 5-MAD filter, applied to the file, would remove 0 to 70 more specimens depending on how it is read. The file appears to be the filtered data.
  • OtherThe paper's 27 366 specimens are the birds in the three main models; morphdata.csv holds 27 486, the other 120 being in species-years without climate data. Neither the README nor the paper says so.
  • Identifier missingmorphdata.csv has no catalogue number or other specimen identifier, so its measurements cannot be linked to catnodata.csv. catnodata.csv has 26 436 rows, 1050 fewer than morphdata.csv, 5061 rows without a catalogue number and 945 repeated catalogue numbers; for 44 catalogue numbers the repeated rows differ in species, sex, age, year or season.
  • Othered_FHY.csv and ed_AHYfall.csv are identical files, and ed_AHYspring.csv is the same table shifted by one year; this fits the README's description of their use, but the README does not say so.
  • Methods not availableThe code selects climate columns by number from R's merged table and drops species-years by hand-coded row numbers; the notebook shows these match the deposited files. The Table S8 code reads an object (envdata3) that no script defines.
  • OtherThe hierarchical Stan model as published converges poorly on the autumn AHY data with the code's seed and settings (13.8% to 33.5% of draws divergent, largest R-hat 1.083 to 1.596; under one filtering reading a chain is stuck with every draw divergent). The Methods say convergence was confirmed with R-hat and trace plots, but no diagnostic values are reported. Script01 compiles the model with -march=native, so with the same seed the draws differ between machines, and pd values near 90% can fall on either side.

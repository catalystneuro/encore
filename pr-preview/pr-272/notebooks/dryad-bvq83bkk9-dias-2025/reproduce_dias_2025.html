Reproducing Dias et al. (2025) from Dryad dataset bvq83bkk9¶

Paper. Dias AC, Lemoine NP, Yanco SW, Zimova M, Bay RA, Weeks BC (2025). Long-term increases in wing length occur independently of changes in climate and climate-driven shifts in body size. Proc. R. Soc. B 292: 20242556. doi:10.1098/rspb.2024.2556. The claims file was written from the version of record (Europe PMC, PMC11750374) and its electronic supplementary material (Tables S1 to S11, Fig. S1).

Dataset. DRYAD:bvq83bkk9, version id 333377 (Dryad's version number 7, published 2024-12-09). The paper cites the dataset by its DOI, which always resolves to the latest version; Dryad's API lists one version, 333377, so it is the one pinned. The files are Data.zip (SHA-256 2185ac50e9a59c3a1dff59473216de2ab001d0d0044b1fa15442ae18a520d554) and README.md (6c19de67b1c6c52802be42a6593c175a02bee0dab0ca2f6f958f08a0a3fa0482). Dryad needs a token to download, so the workflow stages the files before the notebook runs and they are read in place; the first cell checks their SHA-256.

Outside input. The paper's code, Zenodo doi:10.5281/zenodo.14226724, Code.zip (SHA-256 cc9f58b9855aec4e3aca09be4138707d07fc34739ec5762e54e1f5bca48ddbc8), read in memory. It gives the Stan model (lm_mod.stan), the column numbers the scripts select and the rows they drop. No data come from outside the dataset: the phylogeny the preliminary models use, chitree.rds, is in it.

Notebooks. This notebook holds the data check, the sample sizes and every claim on the preliminary phylogenetic mixed models (Tables S4 to S8). The hierarchical Stan models of Tables 1 to 3 are slow (see stan_models.ipynb, which times them, and autumn_ahy_main_a.ipynb, _c and _d, which fit the smallest, once per filtering reading); the claims on them are blocked for time except where the attempt record says otherwise.

Preliminary phylogenetic mixed models (Tables S4 to S7)¶

Script02 fits, per class, scaled wing on scaled tarsus, sex, every climate variable and year, each with its tarsus interaction, with a random effect of species whose covariance is the phylogeny; inverse-Wishart priors V = 1, nu = 0.02; 4 chains of 15 000 iterations with 5000 burn-in (thinning 10, MCMCglmm's default). MCMCglmm is an R package and cannot be installed in this environment; wingallom.gibbs_glmm samples the same model with the same Gibbs scheme. The code sets no seed; the seeds here are a standard choice, one generator per class, reading and chain. The models are fitted under filtering readings (a), (c) and (d), as the claims require.

Interval readings, as the claims file names them: (i) the 2.5 and 97.5% quantiles of the four pooled chains; (ii) the 95% HPD interval of chain 4. pMCMC is from chain 4.

def gelman_rubin(chains, k):
    x = np.array([c["Sol"][:, k] for c in chains])
    n = x.shape[1]
    wv = x.var(axis=1, ddof=1).mean()
    b = n * x.mean(axis=1).var(ddof=1)
    return np.sqrt(((n - 1) / n * wv + b / n) / wv)

Seed readings and the Monte Carlo check for intervals that end near 0¶

The code sets no seed, so a 95% bound that ends within a few thousandths of 0 can fall on either side with another seed. The answer of 2026-10-27 to the attempt's question puts two seed readings into the criteria of s4-s6-spring-migration-temperature-none and s6-autumn-ahy-recent-wintering-prebreeding-precipitation-none: (1) one run with a recorded seed, the fits above; (2) a set of seeds, a term counting as excluding 0 when its interval excludes 0 in most of them. The set here is ten seed sets, one generator per seed set and chain, the same for every model; "most" is more than 5 of 10. Each preliminary model is refitted with all ten, under every filtering reading. seed_check prints the ten intervals of one term; seed_majority counts, for a list of terms, the seed sets in which each interval excludes 0.

def seed_majority(cls, terms, label):

How the analysis differs from the paper's:

  • The preliminary models are sampled by wingallom.gibbs_glmm, a Gibbs sampler of the same model and priors as MCMCglmm (an R package that cannot be installed in this Python environment), with seeds chosen here; the paper's runs set no seed. Two claims of absence are judged under two seed readings, the recorded seed and the majority of ten seed sets, as the answer of 2026-10-27 to this attempt's question sets out.
  • The Stan model is the paper's lm_mod.stan in current array syntax, run with CmdStan 2.40 in place of rstan; with the same seeds the draws still differ.
  • The outlier filter of the Methods is not in the code; readings (a) to (d) of the claims file are run, (b) being identical to (a).
  • The Table S8 data table is not defined in the code; it is built here from the deposited climate files under the claims file's two readings.

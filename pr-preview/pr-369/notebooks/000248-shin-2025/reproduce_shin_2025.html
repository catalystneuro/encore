Shin et al. (2025) from dandiset 000248: the Neuropixels claims¶

Paper. Shin H, Ogando MB, Abdeladim L, ... Lecoq J, Adesnik H (2025). Recurrent pattern completion drives the neocortical representation of sensory inference. Nature Neuroscience 28, 2319-2329. doi:10.1038/s41593-025-02055-5. The claims file was written from the version of record (main text, figure legends, Methods and Extended Data legends); the Supplementary Information was not available to it.

Dandiset. DANDI:000248, version 0.240502.2344. The paper cites the dandiset without a version. This is its only published version, so it is pinned. The draft has the same 78 assets and size; it was last modified at the time of publication (2024-05-02). The paper's analysis code reads a copy named 00248_v240130 (January 2024), before this version; no earlier version was published, so a difference between the two cannot be checked.

What the dandiset holds. The 12 Neuropixels sessions (12 mice), each a _ogen.nwb file with the units of all six probes, the stimulus tables, the receptive field and size blocks, and in 10 sessions eye tracking; and 66 _probe-N_ecephys.nwb files with LFP, which are not used. The 2p imaging, 2p mesoscope and 2p holography data of the paper are not in it.

Method sources. The claims file gives each method; where it leaves a detail open, the detail is taken from the paper or from the analysis code the claims file cites (github.com/hs13/IC_paper_code at commit 50e04ea), and the helper module illusion.py says which.

The receptive field block has 180 trials (four 0.25 s directions each, 0 s ITI) at 9 positions for standard and inverse patches, 10 each, as the Methods state. The stimulus tables carry the image index (frame) without image names; the names are the code's list, and the image templates stored in the files are consistent with it (shown at the end of this section).

# Clock check: decode the four training images from V1 in the 400 ms after onset, in the 400 ms
# before onset, and after shuffling the labels. If spike times and the trial table share a clock,
# only the first is above chance.
def clock_check(i, subject, b, m):
    rng = np.random.default_rng(100 + i)
    shuffled = b["codes"].copy()
    sel = np.isin(shuffled, [il.IC1, il.LC1, il.LC2, il.IC2])
    shuffled[sel] = rng.permutation(shuffled[sel])
    return {"subject": subject,
            "post_0_400ms": il.decode(b["R"][:, m], b["codes"], [106, 107, 110, 111], [1105], seed=i)["acc"],
            "pre_-400_0ms": il.decode(b["R_pre"][:, m], b["codes"], [106, 107, 110, 111], [1105], seed=i)["acc"],
            "post_shuffled_labels": il.decode(b["R"][:, m], shuffled, [106, 107, 110, 111], [1105], seed=i)["acc"],
            "rate_post_Hz": b["R"][:, m].mean(), "rate_pre_Hz": b["R_pre"][:, m].mean()}
def v1_block(s):
    m = ((s["units"].area == "V1") & s["units"].rs).values
    b = s["blocks"]["ICwcfg1"]
    return {"R": b["R"][:, m], "R_pre": b["R_pre"][:, m], "codes": b["codes"]}, np.ones(m.sum(), bool)

Ten sessions have eye tracking, as the Extended Data Fig. 2 legend states. The eye video is sampled at 60 Hz (timestamps 16.7 ms apart), where the Methods say "Videos of the eye and body were acquired at 30 Hz"; the paper's code assumes 60 Hz. The pupil position is stated in meters, but its values (pupil center near 300 to 400, pupil half-width near 20, eye half-width near 150) are camera pixels, as the code's comments say. No conversion to visual degrees is in the files. One timestamp per session is NaN, the last one, and is not used. Every IC trial has an eye frame within 17 ms of its onset, so eye frames cover the trial table; that the eye clock matches the stimulus clock is consistent with this, not shown by it.

def ic_ire_table(sel_by_subject, ic_trials=None):
    """Per selected unit and (test, block reading): IC- and IRE-responsiveness, preferred orientations.
    ic_trials: optional dict subject -> dict block -> boolean mask of trials to keep (fixed gaze)."""
    rows = []
    for s in sessions:
        idx = sel_by_subject.get(s["subject"], [])
        if len(idx) == 0:
            continue
        pos = s["units"].index.get_indexer(idx)
        for blocks in [("ICwcfg1",), ("ICwcfg1", "ICwcfg0")]:
            for test in ["a", "b"]:
                res = {}
                for blk in blocks:
                    b = s["blocks"][blk]
                    keep = np.ones(len(b["codes"]), bool) if ic_trials is None else ic_trials[s["subject"]][blk]
                    R, c = b["R"][keep][:, pos], b["codes"][keep]
                    for k, (icc, irec) in enumerate([(il.IC1, il.IRE1), (il.IC2, il.IRE2)], start=1):
                        icr, irer = il.ic_ire_responsive(R, c, icc, irec, test)
                        res[(blk, k)] = {"ire_mean": R[c == irec].mean(axis=0), "ic_mean": R[c == icc].mean(axis=0),
                                         "ic_resp": icr, "ire_resp": irer}
                keys = list(res)
                ire_means = np.stack([res[k]["ire_mean"] for k in keys], axis=1)
                ic_means = np.stack([res[k]["ic_mean"] for k in keys], axis=1)
                pi = ire_means.argmax(axis=1)
                pc = ic_means.argmax(axis=1)
                for j, unit in enumerate(idx):
                    kk = keys[pi[j]]
                    rows.append({"subject": s["subject"], "unit": unit, "blocks": "+".join(blocks), "test": test,
                                 "pref_ire_ori": il.BAR_ORIENTATION[kk], "pref_ic_ori": il.BAR_ORIENTATION[keys[pc[j]]],
                                 "ic_resp": bool(res[kk]["ic_resp"][j]), "ire_resp": bool(res[kk]["ire_resp"][j])})
    return pd.DataFrame(rows)

def frac_table(t, n_units):
    out = []
    for (blocks, test), x in t.groupby(["blocks", "test"]):
        ire = x[x.ire_resp]
        out.append({"blocks": blocks, "test": test, "units": n_units, "IC_resp_%": 100 * x.ic_resp.mean(),

                    "ori_match_%": 100 * (ire.pref_ic_ori == ire.pref_ire_ori).mean() if len(ire) else np.nan})
    return pd.DataFrame(out)

Fixed-gaze trial: the largest distance of the pupil center from its modal position, from the first eye frame after onset to the end of the trial (1 s for RF trials, 0.4 s for IC trials), is below 20 pixels and no frame is a likely blink (code, analyzeMouseEye.m). How the analysis differs from the paper's: the exclusive center selection (fig1e) uses the two readings of the criterion, as the code's analyzeRFCI.m was not compared line by line; the fixed-gaze criterion uses the code's 20 camera pixels, as the files give no conversion to visual degrees, and counts any RF trial towards the coverage of the 9 positions; the cross-correlogram correction is computed from the raw counts and the per-pair normalisation is left out (it does not change the comparison of a peak with the flank of the same pair).

What was found about the dataset (attempt record, findings): the files hold units labelled noise although the Methods say none were packaged; the Methods list 14 mice where the files and the Results have 12; the pupil position is labelled in meters but is in camera pixels; the eye video is 60 Hz where the Methods say 30 Hz; the IC block tables carry image indices without names; and the 2p data are not in the dandiset.

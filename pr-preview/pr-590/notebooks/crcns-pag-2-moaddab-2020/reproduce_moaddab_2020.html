Dataset: CRCNS pag-2, doi:10.6080/K0833Q7F, read from the public bucket at https://crcnsarchive.s3-us-west-2.amazonaws.com/pag-2/live/. Version: unversioned. CRCNS data sets carry no version numbers, so the only published state is the current one under live/ (no old/ folder exists). It is pinned by the MD5 sums of the data set's checksums.md5: data.zip 7d1686e3d4f6f36895c38f34eda632d4, docs/crcns_pag-2_data_description.pdf 9f6c40904e9123fe8ff488d6006c8df4; the first cell checks that the object read has that MD5. Claims: claims/crcns-pag-2/10.1038-s41598-020-74457-3.yaml, written from the version of record (PMC7582948) without its supplement. Data check¶

What the files hold: each unit file has the spike times (spike), the event times EVT01 to EVT14 and the mean waveform. The cube, vlPAGcube, has for every unit a trial table (tag: cue type 1 to 4 and onset time per trial), binned raw, differential and Z scored firing, nose poke rates and suppression ratios (poke, cer), and the waveform. The cell below lists every field of the cube with its shape, type and range, identifies the event codes against the cube's trial table, and checks the cube's stored values against values computed here from the spikes and pokes.

Single-unit regression¶

Per neuron, the 32 trials of its session; the response is the trial's normalized firing in each 1 s interval of the cue; the regressors are the trial's suppression ratio for the 10 s cue (fear output) and the cue's shock probability, 1, 0.375 or 0 (threat probability), with a constant (Methods, "Single-unit, linear regression"). The claims file names readings of the trial-wise normalized firing and of the 0/0 trials:

  • firing (a): trial rate minus its cue's mean 2 s baseline, Z scored with the neuron's normalization; (b): the same with the trial's own baseline; (c): the trial's rate Z scored over all trials and bins of the neuron;
  • 0/0 trials: set to 0, or dropped.

Two more readings come from the authors' script, which regresses the cube's trial-wise Z score (vlPAGcube.fire.z.s1.interval, columns 21 to 30) on the cube's suppression ratio (vlPAGcube.cer.cue) (vlpagAnalysis.m, lines 2162 to 2171, printed in the data check): firing (d), the cube's Z score, and 0/0 trials set to 1, as the cube stores them. All twelve combinations are run. The two window readings of the claims file (mean of the interval betas, or one regression on the window's mean firing) give the same beta (see pag2.interval_betas).

The rule, used for every claim that rests on the regressions (Figs. 5, S4, 6, S5, 7, S6): the outcome is judged under one combination, the script's own (d, 0/0 trials set to 1), the same for every claim and not chosen claim by claim. The paper leaves the trial-wise firing open and the authors' code in the data set settles it, so this follows the code (author, step 1.6), as an assumption. The section below shows that this combination also gives the paper's printed statistics more closely than any other. Each claim's section also gives the outcome under the claims file's own rule (reproduced under one of its six readings, a to c with 0/0 trials set to 0 or dropped); where the two differ, the outcome is marked as resting on the assumption.

For the population firing (Figs. 4, 6, 7), the Methods fix the normalization (the trial-averaged differential firing is Z scored), the claims file follows them, and the script's different normalization is a variant (reader, step 2: where the Methods and the code disagree, the Methods decide and the code's choice is a variant). It is run as a full variant, under every regression reading.

def corr_table(pop, win, which, span, F_all=None, readings=None, B=None, show=True):
    F_all = NF if F_all is None else F_all
    B = BETAS if B is None else B
    res = {}
    for rd in (READINGS if readings is None else readings):
        FO, TP = B[rd]
        Bm = (TP if which == "TP" else FO)[:, span].mean(1)
        rows = {}
        for k, ty in enumerate(pag2.TYPES):
            F = F_all[:, k, pag2.WIN[win]].mean(1)
            rr = {}
            for gg in ("Con", "EAA"):
                mm = (lab == pop) & (grp == gg)
                r, p = stats.pearsonr(F[mm], Bm[mm]); rr[gg] = (r, p, int(mm.sum()))
            z, p1, p2 = pag2.fisher_r_to_z(rr["Con"][0], rr["Con"][2], rr["EAA"][0], rr["EAA"][2])
            rows[ty] = dict(Con=rr["Con"], EAA=rr["EAA"], z=(z, p1, p2))
        res[rd] = rows
    for rd in res if show else ():
        print(f"{rd[0]} {rd[1]:4s}: " + " | ".join(
            f"{ty[:3]} Con r={v['Con'][0]:.2f} p={v['Con'][1]:.2g}, EAA r={v['EAA'][0]:.2f} p={v['EAA'][1]:.2g}, Z={v['z'][0]:.2f} p1={v['z'][1]:.2g} p2={v['z'][2]:.2g}"

The design that is not of full rank¶

A failure to reproduce here may be a failure of this attempt, not of the paper: see the reasoning and the differences from the paper's method.

How the analysis differs from the paper's: the selection uses the cube's stored rates, truncated to whole Hz, as the authors' script does (with exact rates the Control inhibited count is 54, not 48); the regressions are run under twelve readings of the trial-wise firing and of trials without pokes, and every regression claim is judged under one of them, the script's own (d, 0/0 trials set to 1), which also gives the paper's statistics most closely; the outcome of Fig. 5D rests on it, as the claims file's readings give a different outcome, while those of Figs. 5A to C and S4 are the same under the claims file's readings; the ANOVAs with bregma level could not be run; the ANOVAs and t tests use all selected neurons, so several error degrees of freedom are larger than the paper's (for example 79 against 65 for the cue-excited regression ANOVA). The population analyses follow the Methods' normalization, as the claims file fixes it; the authors' script instead averages the cube's trial-wise Z scores, and with that the statistics of Figs. 4C, 4F and 6 are the paper's to the second digit, and Fig. 6 would be reproduced. The paper's Fig. 7 statistics follow from firing over the first 5 s of the cue with the script's normalization and the adopted regression reading, where its legend says the last 5 s; with the last 5 s, as the claims file has it, Fig. 7 is not reproduced. The paper's smaller degrees of freedom for several tests are not explained by trials without pokes, missing betas or any step in the script. One cue-inhibited neuron has a design not of full rank; the regressions give it minimum-norm betas where Matlab regress gives a fear output beta of 0, and with Matlab's solution no outcome changes.

What was found about the data set: the units come from 182 sessions (74 Control, 108 EAA), not the stated 179; group membership and the event codes are documented only in the script (the codes change meaning with the behaviour program); the cube stores firing rates truncated to integers; poke.base is the 20 s baseline in pokes per minute, not the 2 s the description states; trials without pokes are stored with a suppression ratio of 1; the description gives the uncertainty shock probability as 0.25; there is no bregma level per rat, no body weight and no pre-surgery session.

Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Description missingThe spike files hold 2977 sorted clusters, good units and bad clusters alike, with nothing in the data set that says which are the 220 well-sorted units the paper analysed, or gives their auditory response class and window. These come only from metadata/unit_db.csv in the paper's code repository; the scripts that made the table are not published.
  • Selection not documentedThe auditory response classes of unit_db.csv apply rules the paper does not state (classes too brief, lasts to end, lasts too long). Recomputing responsiveness as the Supplement describes gives 46 mPFC and 61 A1 responsive units in place of the paper's 31 and 49, and, of 67 units responsive under both, 17 whose window starts at a different time. Part of the difference is the table's unstated classes (units classed too brief, lasts too long or lasts to end are responsive when recomputed), and part the threshold and trial choices of the recomputation (6 units classed nothing become responsive, 13 classed responsive do not).
  • OtherThe spike files (*.kkp) and the miscellaneous pickles are pandas 0.10 pickles written under Python 2. Current pandas cannot open them (module pandas.core.index no longer exists); the descriptor's pandas.load no longer exists either. They can be read with a custom unpickler.
  • Metadata errorTwo sessions, CR21A_120503_004 and CR21A_120504_004, hold a second spike file at the session level besides klusters0/. It has the same spike times, but its column is named spike_time, tetrode groups run 0 to 7 in place of 1 to 8, and the unit numbers differ, so the descriptor's unit-number rule may assign units differently. The descriptor does not mention these files.
  • Metadata errorThe data descriptor names the stimulus column stimulus_name; the files call it stim_name. The descriptor numbers the stimuli starting with le_lc_go as 1; in the files le_lc_go is 3, ri_lc_no 4, lo_pc_go 1 and hi_pc_no 2.
  • OtherThree sessions (CR20B_120613, CR21A_120502, CR21A_120506) have no spike file; their klusters0/ holds a README.txt, where the descriptor says the directory is empty. The data set holds the 55 sessions the paper reports after its four discarded sessions; the discarded ones are not in it.
  • Published code disagreesmetadata/figures_generated_by_each_script.csv names CR20B_120602_001_behaving-612 as Figure 4A and -712 as Figure 4B. The legends' values fit the reverse: 712 prefers localization (8.01 against 4.76 Hz) and 612 pitch discrimination (10.07 against 2.00 Hz).
  • Paper inconsistentThe Figure 4B legend gives the trial counts of the simultaneously recorded pair with the blocks swapped (pitch discrimination 312, localization 253) relative to the 4A legend (localization 312, pitch discrimination 253); the data have 312 localization and 253 pitch discrimination trials for both units.
  • Methods not availableFor the single-unit onsets of Figures 5A and 5B (fig5ab-single-unit-onset), 7 mPFC and 2 A1 rule-encoding units have no significant interval containing the bin just before stimulus onset. 5-2-timecourse_exemplars/main3.py marks them invalid but main4.py keeps them in the median, and the paper does not say how such units count. Kept, the medians are 0.550 s (A1) and 0.625 s (mPFC), the paper's values; counted with onset 0 they are 0.550 and 0.600 s; left out, 0.650 s in both. Were these units included in "the median rule-encoding unit", and with what onset?
  • Published code disagrees3-5-vidtrack/main5.py says statsmodels' stand_mad does not subtract the median, but the paper's PRE values (0.471 and 0.318) are reproduced exactly by the MAD about the median; the uncentered MAD gives 0.327 and 0.343.

Reproduction Task switching in rat prefrontal and auditory cortex (Rodgers and DeWeese 2014)

Tests the findings of Rodgers and DeWeese (2014) on CRCNS data set pfc-1, which holds the spike times and trial tables of 55 sessions of six rats performing an auditory stimulus selection task, with units in medial prefrontal cortex and primary auditory cortex, and the data of the paper's disruption, catch-trial, video-tracking and network-model analyses. It covers behaviour, the encoding of the selection rule before the stimulus, error trials, its time course, evoked responses and decoding, head posture, mPFC disruption and the model. The units analysed and their auditory response windows come from the paper's code repository. All files

Environment: Python 3.13, 63 packages pinned in requirements.lock.txt; CI runs each notebook from a new environment built from it.

Method differences

How the tests differed from the paper’s method or data, and the claims each applies to.

  • The best rat's typical performance is read, as the claims file's check notes, as the median over a rat's sessions; the value recorded is CR20B localization, the first rat meeting the criterion.fig2a-above-chance
  • Intervals are taken between consecutive rows of trial_timings, including intervals that span a munged or skipped trial; the variant with munged trials dropped is shown.iti-median
  • Assumed: the median is taken over all rule-encoding units, including the 7 mPFC and 2 A1 units that have no significant interval containing the bin just before onset, each with the onset main4.py gives it. The criterion defines the interval as the run that contains the bin just before onset, which these units lack, but also takes the median over units as main4.py does. The paper speaks of "the median rule-encoding unit" (Results, Within-Trial Timescale of the Encoding of the Selection Rule, paragraph 2), and Figure 5C gives n = 76 and 36 rule-encoding neurons, which supports a median over all of them. Leaving the units out fails in A1 (0.650 s); a question for a reader is in questions/crcns-pfc-1.yaml.fig5ab-single-unit-onset
  • The smoothing follows kkpandas.base.GaussianSmoother as 5-2-timecourse_exemplars/main1.py and main2.py use it: each spike is moved to the nearest 50 ms sample point and a Gaussian of one sample s.d., truncated at 3 s.d. and normalized to sum to one, is added there (modules/kkpandas/base.py, modules/DiscreteAnalyze/PointProc.py). The paper says only that spike trains were smoothed with a 50 ms Gaussian; the result in mPFC depends on this discretization.fig5ab-single-unit-onset
  • R's wilcox.test with fix_float=10000 (rounding of values) is not reproduced; scipy's test is applied to the smoothed values directly.fig5ab-single-unit-onset
  • Reading (b) uses choices the Supplement leaves open: all trials of all stimuli, 0 to 50 ms after onset, p < 0.05 uncorrected per bin, the code's discretized 1 ms smoother on a 0.5 ms grid; the 4 atypical units the Supplement discards cannot be identified and are not discarded.audresp-prevalence
  • The bootstrap draws (10000, seed fixed) differ from the paper's, so the evoked change of each unit differs by sampling error.fig6cd-baseline-evoked-correlation
  • The code's bootstrap draws the same number of trials for both blocks (it reuses the localization labels for the pitch discrimination draw); this is kept.evoked-beyond-baseline-rare
  • scikit-learn's LogisticRegression with the liblinear solver (the default of the code's version) and class_weight balanced (the code's 'auto').fig6e-decoding
  • 10000 shuffles with a fixed seed of their own; the shuffle p is limited to 1/10000 resolution.posture-equalized-sign
  • Which positive task signals count is not stated. "Most positive task signals" is read as most of the range of task signals that Figure 8B plots, the figure the quote describes; the narrow linear sweep agrees.

Reproducing Azcorra, Gaertner et al. (2023) from dandiset 001038¶

Paper. Azcorra M, Gaertner Z, Davidson C, et al., Awatramani R, Dombeck DA (2023). Unique functional responses differentially map onto genetic subtypes of dopamine neurons. Nature Neuroscience 26, 1762-1774. doi:10.1038/s41593-023-01401-9. This attempt used the full text, which is open access (CC BY 4.0), from PubMed Central (PMC10545540).

Dandiset. DANDI:001038, version 0.241111.1719. The paper cites no DANDI version (its data statement points to Zenodo records that the dandiset was converted from). This is the only published version; the draft holds the same 1238 files with the same blobs and differs only in metadata (it fixes a malformed DOI link to the paper and adds affiliations), none of which the analysis uses.

What the dandiset holds. Fiber photometry from 102 mice of five genotypes (Vglut2, Calb1, Anxa1, Aldh1a1 and DAT lines), one file per recording depth, with normalized dF/F, its 405 nm control, treadmill velocity and acceleration, and for sessions with stimuli the reward, air puff, light and licking events. These are the data of Figures 2 to 7 and Extended Data Figures 1 and 6 to 10. The snRNA-seq of Figure 1 is in GEO (GSE222558) and the histology images on Zenodo; two snRNA-seq claims are tested here on the GEO matrices, counted apart from the dandiset.

Code read. The paper's analysis code, https://github.com/DombeckLab/Azcorra2023 at commit fad12b25313f21611dd70c0056fb8bee48beeda1 (MATLAB; preprocessing, exclusion criteria and one script per figure group), and the conversion code, https://github.com/catalystneuro/dombeck-lab-to-nwb at commit 5794df1e13b1a44ab2f21ad7e5b38ef8b85940f7. The helper azcorra.py ports the code's selection and measures; its docstring says where each parameter comes from. Where the Methods and the code disagree (response windows, timing), the Methods give the main result and the code a variant.

def p_sr(x, factor=1):
    """Two-sided Wilcoxon signed-rank p-value times a Bonferroni factor, capped at 1."""
    x = np.asarray(x, float)
    x = x[~np.isnan(x)]
    if len(x) < 2:
        return np.nan
    return min(1.0, stats.wilcoxon(x).pvalue * factor)


def p_rs(a, b, factor=1):
    """Two-sided rank-sum (Mann-Whitney U) p-value times a factor, capped at 1."""
    return min(1.0, stats.mannwhitneyu(a, b, alternative="two-sided").pvalue * factor)

The coordinates column is described as "(AP, ML, DV) mm relative to Bregma". The values do not fit that order: the second value takes only the seven reference-slice positions of the Methods (+0.86 to -1.34 mm) and is negative for the tail of the striatum (TS), as an AP coordinate must be, and the first value is about 1.5 mm for DMS and 2.7 mm for DLS, as a lateral coordinate is. The paper's code builds this vector as [ML, AP, DV] (FiberLocations.m). The data show the order is (ML, AP, DV), and it is read that way here. Most SNc fibers have no coordinates.

How the analysis differs from the paper's. It is a Python port of the paper's MATLAB code. Response windows and peak times follow the Methods, which differ from the code by 0.05 s and by one or two bins; the code's choices are shown as variants. With them the reward means equal the paper's to the decimal and the Calb1 trough lag (0.160 against 0.17 s) is within tolerance. The locomotion selection, applied as the Methods and code state, keeps more recordings than the paper reports, so the locomotion and clustering claims rest on more recordings than the paper's. Running periods after rewards the mouse did not consume cannot be excluded, as those rewards are not in the Events table; for the event-size analysis the stored onsets, which carry that exclusion, are used. P-values come from scipy's Wilcoxon and Mann-Whitney tests, whose exact and approximate methods may differ slightly from MATLAB's. k-means uses scikit-learn and is summarized over 100 seeds.

What was found about the dandiset. It holds the paper's photometry: the stimulus analyses recover the paper's recording and mouse counts exactly, and with the code's windows its reward means to the decimal and its air puff means within tolerance except DAT (2.46 against 5.3); the DAT reward size difference is 1.83 against 1.9. The selection flags of the paper's table (running time, artifacts) are not in the files but can be recomputed, and the recomputed values match the stored 405 nm cross-correlations. Which recordings entered the locomotion figures cannot be recovered: the stated criteria select more. The coordinates column is stored as (ML, AP, DV), not the (AP, ML, DV) its description says. cross_correlation_with_acceleration holds the 405 nm control's peak cross-correlation, not that of dF/F. The dF/F series are normalized to their largest transient, which the files do not state. Consumed rewards only are in the Events table. Three subject ids ending in L are mice that also have ids without it, so the archive's 105 subjects are 102 mice. No recording is deposited twice. normalized_fluorescence holds two values per fiber in 123 files. The published version's link to the paper is malformed and its asset summary names no photometry technique or variable. The paper itself gives the Calb1 and Vglut2 reward P-values the other way round in the Results and the Figure 4g legend, 10 Anxa1 mice in the Figure 2f legend and 9 in the Methods, and different PC percentages for Extended Data Figure 9k in the legend and the Methods (printed in the claim sections).

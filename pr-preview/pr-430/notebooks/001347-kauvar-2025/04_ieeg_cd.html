The claims file was written from the version of record (29 May 2025) with Materials and Methods, figure legends and the supplement, including Table S3.

Dandiset. DANDI:001347, version 0.250528.0702, the only published version. The paper cites the dandiset without a version, so the latest published version is pinned (see dandi_io.py). The mouse Neuropixels data used for figs37a are in DANDI:001326, version 0.250528.1957, its only published version.

What this notebook reads. For the 7 included iEEG participants (SD168, SD172, SD181, SD185, SD186, SD211, SD245), the per-session files sub-SD*/sub-SD*_ses-puff<Session>_ecephys.nwb (LFP at 200 Hz, 20 min around the eyepuff assay, an electrode table with region labels, and 20 DC channels, one of which carries the puff TTL) and the behaviour files sub-SD*/sub-SD*_ses-puff_behavior.nwb (trials used, puff frames of the video, per-trial eye closure). For figs37a, the 13 Neuropixels sessions of DANDI:001326, processed with the entry's mouse_npx.py.

Outside input. The paper's code record Zenodo 10.5281/zenodo.14920570 (kauvar-richman-liu-2025_zenodo.zip, md5 bd1fb567121aaf0291337783df57bcfc, git commit b873ca5) is fetched at run time and its md5 checked. Two things are read from it: the list of bad channels per participant (ketman/analyze/utils.py, bad_ch; the dataset does not mark bad channels), a method detail shown as one reading against the dataset-only channel set; and the Yeo7 network label of each bipolar channel (anat/pts_ch_labels.pkl), which the dataset lacks and which figs35 needs (data: with_labels, tested by the link claim ieeg-channel-atlas-link). The analysis follows the code (human_ieeg/scripts/analyze_airpuff_ieeg_cd.py, ketman/analyze/trace_utils.py, cd_utils.py, for_reference/analyze_airpuff_ieeg_top_cd_network.py), reimplemented in ieeg_cd.py, whose docstring says where each parameter comes from.

Random numbers: the random-time null of the clock check uses seed 0 per participant, the Yeo7 shuffle uses seed 1.

Checks of the metadata against the data:

  • Session files. SD168 and SD172 have no Preinfusion file; their pre-infusion eyepuff session is the Baseline file, recorded the day before (ketman/DATASETS.py). The code takes the Baseline file as "preinfusion" for these two. For SD245 the code lists both Baseline and Preinfusion and renames 'baseline' to 'preinfusion' after loading, which replaces the Preinfusion data by the Baseline data in the coding-dimension path (load_and_organize_raw_traces, load_patients_erp), while the timescale path (load_raw_traces_and_merge_to_anat) keeps the Preinfusion file. SD245's behaviour file holds only 'baseline' eye-closure events. Both SD245 files are run here as readings.
  • Puff times. The TTL is on DC channel index 2, named 'DC03' in three participants' files and 'CCEP' in the other four, so the channel name does not identify it; the code reads index 2. 40 onsets are found in every preinfusion session (32 in some infusion and postinfusion sessions), with the first at sample 120001 to 120012, the middle of the 20-min epoch, as the epoch description ("10 min pre and post puff start") says. Their intervals match the puff frames of the 200-Hz video within 3 samples, except the first interval of SD172's infusion session (38 samples; its first trial is not used). The puff-locked broadband response at the TTL times is larger than at every random set of times and at the shifted times in every participant (counts above). The puff times are consistent with sharing the LFP clock.
  • Trials. The trials used (which_trials of the behaviour files) total 214 across participants, the number Table S3 gives for fig. S38H.
  • Units. The LFP's unit attribute is 'volts', but the values are of order 100 to 1000 and the series comment and device description give a 'scale_to_microvolts' factor (0.39 or 0.098), so the stored values are digitiser units. All analyses here are z-scored, so the scale does not matter. The x, y, z columns of the electrode table are all NaN.
  • Channels. The dataset gives a region label per contact, including 'WM', 'OUT OF BRAIN', 'EXCLUDE' and 'EXCLUDE AREA', but no bad-channel flag and no Yeo7 network label.

figs38a-baseline-coupling-not-different and figs38b-ketamine-coupling-loss-larger-at-persistent-sites¶

figs38a: Before infusion, phase locking among high-persistence sites does not differ from that among low-persistence sites in any band.

figs38b: The ketamine decrease in phase locking is larger among high-persistence sites than among low-persistence sites, significantly in the alpha, beta and gamma bands.

Criteria: per band, top and bottom 10% of absolute persistent weight (weights in that band), edges within each set, PLV regressed on high against low edge identity with a mixed-effects model grouped by participant, Benjamini-Hochberg over bands. figs38a uses preinfusion PLV (absence: reproduced when no band gives corrected p < 0.05); figs38b uses the ketamine minus preinfusion change (reproduced when alpha, beta and gamma give corrected p < 0.05 with larger decreases among high edges and the beta coefficient is within -0.038 ± 0.019). The paper's figure gives the change in z units ("Ket - Pre phase locking (z)", code ylabel; Methods z-score each channel's PLV to its preinfusion window), so both the raw change and the change z-scored by the preinfusion window SD are shown. Bonferroni (the code's 'pval_bonf') is shown beside BH.

  • Bands: the Table S3 bands, gamma 30 to 50 Hz ('main'), and the fig.   • Channels: white matter excluded (Methods) or kept, the code's bad-channel list or none.

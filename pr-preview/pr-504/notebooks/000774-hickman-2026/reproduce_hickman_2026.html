Reproducing Hickman et al. (2026) from dandiset 000774¶

Paper. Hickman, Hughes, Sahai, Miles and Denman (2026), "Neural population dynamics of direct electrical stimulation of neocortex", Cell Reports 45, 117420, doi:10.1016/j.celrep.2026.117420.

Dataset. DANDI:000774, version 0.260520.1753 (doi:10.48324/dandi.000774/0.260520.1753), streamed from the DANDI API. This is the version the paper cites in its key resources table, and the only published version of the dandiset; the draft has the same ten assets.

Text the claims were written from. The NIH author manuscript (PMC13404931) with the STAR Methods and Document S1 (legends of Figures S1 to S12); Table S1 was not in the text read (claims/000774/10.1016-j.celrep.2026.117420.yaml). Method details the claims file does not give are taken from the paper and cited where used; where the paper is silent, from its code (github.com/denmanlab/estim_populations at c4aaa608), as the claims file does.

What the dandiset holds. Spike times, Kilosort templates, CCF coordinates and regions of the units and the table of electrical pulses, for ten acute recordings. The raw AP band, the LFP band and the behaviour are not in it, as the paper says ("Raw data (LFP band, AP band, and NiDAQ binary files) are not included in the NWB"), so the evoked-potential claims (Figures 1 to 3, S1, S2) and the behaviour claims (Figure 7, S10) are blocked. The three claims that compare units with the evoked-potential boundaries (fig4f, fig4i, fig5i) are tested with the boundaries the paper's code computed (intermediates/EP_distances.pkl at commit c4aaa608), the outside input their criteria name; the units' side of these tests comes from the dataset.

CODE_COORDS = {s: estim.code_coords(s) for s in estim.PAPER_SESSIONS}
for s in estim.PAPER_SESSIONS:
    u, tr, trains, meta = DATA[s]
    contact_xyz = tr[["neg_ap", "neg_dv", "neg_ml"]].iloc[0].to_numpy()
    u["distance"], u["norm_distance"] = estim.signed_distances(u, contact_xyz)
    u["distance_code"], u["norm_distance_code"] = estim.code_distances(
        u, CODE_COORDS[s], tr.contact_negative.iloc[0])
    # the raw CCF distance signed as the code's `distance` column: the code makes it negative from the
    # channel closest to the contact on, as norm_distance (figure4_figure5_figure6.ipynb cell 7,
    # `dists[cross_index:] = -np.abs(dists[cross_index:])`); checked on the code's direct_df.csv below
    u["sdistance"] = np.where(u.norm_distance < 0, -u.distance, u.distance)
    u["sdistance_code"] = np.where(u.norm_distance_code < 0, -u.distance_code, u.distance_code)
    u["keep"] = (u.group == "good") & ~u.unstable
    u["sub_cort"] = u.region.map(estim.classify_region)
    u["region_group"] = u.region.map(estim.map_region_to_group)

# Clock check: population spikes in 0 to 20 ms after 100 uA pulses (cathodal, or bipolar where
# there is none) against the 20 ms before, with the true onsets and with onsets moved 1 s later
# (half way between pulses, which are 2 s apart). Paired Wilcoxon over trials.
rows = []
for s in estim.PAPER_SESSIONS:
    u, tr, trains, meta = DATA[s]
    pol = "cathodal" if len(estim.condition_trials(tr, "cathodal", 100)) else "bipolar"
    pop = np.sort(np.concatenate([trains[i] for i in np.where(u.keep)[0]]))
    res = {"session": s, "polarity": pol}
    for label, shift in [("true", 0.0), ("shifted", 1.0)]:
        st = estim.condition_trials(tr, pol, 100).start_time.to_numpy() + shift
        post = np.searchsorted(pop, st + 0.02) - np.searchsorted(pop, st)
        pre = np.searchsorted(pop, st) - np.searchsorted(pop, st - 0.02)
        res[f"{label}_post_over_pre"] = round(post.mean() / pre.mean(), 2)
        res[f"{label}_p"] = stats.wilcoxon(post, pre).pvalue if (post != pre).any() else 1.0
    rows.append(res)

The checks against the description:

  • Ten files; nine are the recordings the paper's code loads, and the tenth (jlh41, "lots of noise issues ... not much analyzed yet here") has no CCF coordinates or regions; it is left out. The nine give the paper's 25 probes (A 7, B 9, C 9). They come from eight subject ids: the file of session jlh49v1 is filed under subject jlh48, which the paper and its code treat as a separate recording and mouse; its age (P381D) is one day older than the jlh48 file recorded four months later.
  • The electrodes table holds placeholders (location "none", constant coordinates), so channel CCF coordinates come from the units' own coordinates.
  • Conditions are labelled "monopolar" or "bipolar" with signed amplitudes; cathodal and anodal are the sign. Cathodal single pulses are in seven of the nine recordings (jlh39 and jlh49v1 hold only bipolar pulses, jlh40 no bipolar), so the claims on cathodal pulses rest on seven recordings, where the paper's legends say nine. jlh33 has 60 trials per condition, where the Methods say 75; its anodal 50 uA single pulse is missing.
  • Each recording has one cathodal contact for monopolar pulses. jlh31 (25 to 100 uA) and jlh34 (all four amplitudes) ran each cathodal condition twice at that contact, 150 trials; the first 75 are the first run, which the analysis uses, and the claims file's "layer 5" reading takes the same trials. The second run is shown as a variant in fig4j-drp-increases. In jlh53concat, a concatenated recording, the run numbers 0 to 7 are used both by monopolar and by bipolar runs.
  • Trial onsets and spike times share a clock: population firing in the 20 ms after a 100 uA pulse differs from the 20 ms before it with the true onsets, and not with onsets moved 1 s later (table above). Two files (jlh40, jlh53concat) have negative times; this does not affect the alignment. In every recording the population fires less in the 3 ms before the logged onset, down to 0.07 to 0.20 spikes per trial from 2 to 1 ms before it (0.61 in jlh31), against 0.81 to 2.03 from 8 to 7 ms before (second table). rng_gmm = np.random.default_rng(3)
GRID = np.linspace(0, 15, 15001)
def gmm_window(x, k, seed):
    g = GaussianMixture(k, n_init=10, random_state=seed).fit(x[:, None])
    order = np.argsort(g.means_.ravel())
    if k < 2:
        return np.nan, g
    post = g.predict_proba(GRID[:, None])[:, order]
    m0 = g.means_.ravel()[order][0]
    after = GRID > m0
    cross = np.where(after & (post[:, 1] >= post[:, 0]))[0]
    return (GRID[cross[0]] if len(cross) else np.nan), g

def polarity_clusters(drp, ids):
    sub = drp.set_index(["session", "unit"]).loc[ids].reset_index()
    feat = sub.groupby(["session", "unit", "pol"]).ndrp.max().unstack(fill_value=0.0)
    feat = feat.reindex(columns=["bipolar", "cathodal", "anodal"], fill_value=0.0)
    feat = feat.div(feat.max(axis=1), axis=0).fillna(0.0)
    X = feat.to_numpy()
    Z, lab, ccc, sil = cluster_summary(X)
    rows = []
    for c in np.unique(lab):
        m = X[lab == c].mean(0)
        top = int(np.argmax(m))
        pref = feat.columns[top] if all(m[j] < 0.5 * m[top] for j in range(3) if j != top) else "none"
        rows.append(dict(cluster=c, n=int((lab == c).sum()), frac=round((lab == c).mean(), 3),
                         mean=np.round(m, 2).tolist(), prefers=pref))
    cl = pd.DataFrame(rows)
    cl["top"] = [feat.columns[int(np.argmax(m))] for m in cl["mean"]]
    fr = {p: round(cl[cl.prefers == p].frac.sum(), 3) for p in EXP_POL}
    return len(X), ccc, sil, cl, fr

def polarity_assignments(cl):
    """Every assignment of the clusters to the three polarities or none (the criterion's 'some
    assignment') whose three fractions are within 10%; marked when each labelled cluster's highest
    mean is at its label."""
    out = []

fig6f-no-propagating-wave¶

Response timing shows no propagating wave: time to peak inhibition and to peak rebound excitation do not correlate with distance from the stimulation site.

As the code (figure7.ipynb cells 20 to 23): cortical good stable units that are ZETA responders to 50 uA cathodal pulses; MI in 5 ms bins over 0 to 500 ms (first 75 trials), Gaussian smoothing (sigma 2.5 ms), the most prominent peak after 20 ms (prominence 0.2), time by the local centre of mass. The code's 4 ms minimum width and 6 ms centre-of-mass half-width are converted to whole 5 ms bins (its _to_bins, rounding 0.8 and 1.2 bins to 1), so it applies no width filter (only above 1 bin) and takes the centre of mass over +-1 bin, and a unit without a prominent peak falls back to its largest bin after 20 ms. The criterion lists the width of at least 4 ms; applied, it changes the outcome, so the width filter and dropping units without a peak are run as variants, alone and together. A centre of mass over +-6 ms and over +-1 bin of 5 ms take the same bins. The distance is the code's: Euclidean distance to the first trial's cathodal contact, signed negative where the unit is dorsal to it (the code takes the anodal contact for jlh32; both shown). jlh39 and jlh49v1, which the code leaves out, have no cathodal pulses, so the two readings are the same.

BIN = 0.005
def pick_peaks(resp, sign, width=False, drop=False):
    """The code's pick_peak_times: its 4 ms width and 6 ms centre-of-mass half-width round to 1 bin of
    5 ms (_to_bins), so the width filter is skipped (applied only when above 1 bin) and the centre of
    mass spans +-1 bin; units without a prominent peak fall back to the largest bin after 20 ms.
    width: apply the criterion's width of at least 4 ms (0.8 bins); drop: leave out units without
    such a peak in place of the fallback."""
    sig = resp if sign > 0 else -resp
    out = np.full(len(resp), np.nan)
    minlat = int(np.floor(0.02 / BIN))
    for k, y0 in enumerate(sig):
        y = y0.copy()
        y[:minlat] = -np.inf
        pk, props = find_peaks(y, prominence=0.2, width=0.004 / BIN) if width else find_peaks(y, prominence=0.2)
        if len(pk) == 0:
            if drop:
                continue
            idx = int(np.nanargmax(y[minlat:]) + minlat)
        else:
            idx = int(pk[np.argmax(props["prominences"])])
        w = np.maximum(y0, 0)
        lo, hi = max(0, idx - 1), min(len(w), idx + 2)
        out[k] = (np.sum(np.arange(lo, hi) * w[lo:hi]) / w[lo:hi].sum() if w[lo:hi].sum() > 0 else idx) * BIN
    return out

How the analysis differs from the paper's. Units, trials, the stability filter and the direct response follow the paper and its code; the unit counts per condition match the code's intermediate table direct_df.csv for the cathodal and anodal conditions, and differ by 1 to 5 units for bipolar. Distances use the dataset's coordinates; the paper's code uses its own, which differ for the stimulation contacts of jlh31 and jlh32, and the distance claims are also shown with the code's coordinates, which give the paper's statistics and most of its values (not the 50 uA extent, 868 against 965 um, or the 50 against 100 uA KS p, 0.8245 against 0.083). The signed distance needs channel coordinates that the dandiset does not give; they are fitted from the units' coordinates. The FS and RS classes follow the paper's code (a 0.4 ms duration threshold), where the Methods describe k-means; both are shown; the k-means classes change with the initialisation. The evoked-potential boundaries of fig4f, fig4i and fig5i are the code's, an outside input. ZETA uses zetapy 2.7.2, whose getZeta the code calls, and only the cathodal conditions are tested. The claims on cathodal pulses rest on seven recordings: two of the nine hold no cathodal pulses.

What was found about the dataset. The dandiset holds the spikes, templates, CCF coordinates and regions of the nine recordings the paper analyses, and a tenth (jlh41) without coordinates that the paper does not use. The raw AP band, LFP and behaviour are not deposited, so 21 of the 42 claims cannot be tested, and three more only with the boundaries the paper's code computed. The file of session jlh49v1 is filed under subject jlh48. The stimulation contact coordinates of jlh31 and jlh32 differ from those the paper's code uses by 206 and 373 um, which changes the outcome of the distance claims. The electrodes table holds placeholder locations and coordinates. jlh33 has 60 trials per condition, where the Methods state 75. Neither FS/RS labels nor the stability flags the paper uses are in the files; both are recomputed here. In jlh53concat the run numbers of monopolar and bipolar runs coincide.

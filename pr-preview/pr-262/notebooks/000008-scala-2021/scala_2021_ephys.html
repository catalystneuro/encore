Scala, Kobak et al. (2021): electrophysiology and metadata of dandiset 000008¶

Paper. Scala F., Kobak D. et al. (2021) Phenotypic variation of transcriptomic cell types in mouse motor cortex. Nature 598:144-150. doi:10.1038/s41586-020-2907-3

Dataset. DANDI:000008, version 0.211014.0809 (doi:10.48324/dandi.000008/0.211014.0809): one NWB file per Patch-seq neuron with its current-clamp sweeps and per-cell metadata.

Why this version. The paper cites no version (it links the dandiset itself). The dandiset has two published versions, 0.211014.0808 and 0.211014.0809, made a second apart; their asset lists have the same 1,328 paths and sizes (checked below). The latest published version, 0.211014.0809, is pinned. The draft was modified later (2026), so it is not used.

Text the claims were written from. The version of record (open access, Europe PMC PMC8113357): main text, Methods, figure and Extended Data legends, and the paper's code, mini-atlas at commit 3bf98a524b8e48aa8647e1b9ae8f2351d9c712c9. The claims file is claims/000008/10.1038-s41586-020-2907-3.yaml.

This notebook tests the claims that rest on the recordings and the per-cell metadata, the two link claims, and two claims that also need the paper's own tables (hold time and cDNA yield; morphological features). The claims that need gene counts or the transcriptomic reference data are in scala_2021_transcriptomics.ipynb and scala_2021_sequencing.ipynb.

Checks of the description against the values:

  • The voltage series say volts with conversion 1, but the median pre-stimulus value per file runs from -78.5 to -54.7 (5th to 95th percentile, printed above): they are millivolts. The extremes, about -1,025 and +1,026, come from one file (20190625_sample_13, see the summary). The stimulus series say amperes but hold -320 to 1,780: picoamperes. The analysis treats them as mV and pA, as the paper's code does.
  • No series has a start time (starting_time is NaN in every file), and there are no timestamps, so the time between sweeps is not recorded.
  • Every stimulus is a 600 ms step from sample 2,500 to 17,500 at 25 kHz (0.1 to 0.7 s), as the paper's code assumes (window 0.1 to 0.7 s). The 0 pA sweep has no stimulus series, which the code also assumes.
  • soma_depth_um is empty. cortical_thickness_4x and cortical_thickness_um do not hold what their names say; the next cell shows that the first is a soma depth and the second a cortical thickness, in the same (4x image) units.
  • The t-types and families use an older name for the ET subclass, PT (L5 PT_1 for the paper's L5 ET_1). They are the same labels; the analysis uses the paper's spelling.

At the true onset the voltage falls with the injected (negative) current in every cell, with slopes of the order of the input resistance; 50 ms earlier there is no such dependence, and at the offset the voltage recovers (negative slope) at 0.7 s and not 50 ms earlier. This is consistent with stimulus and response sharing one clock within each sweep. Between sweeps there is no clock at all.

Three pairs of files, each pair two different cells of one mouse (different depths and read counts, two of the pairs from different slices, and one pair of different t-types; shown under cohort-cells-mice), hold identical voltage matrices: one recording deposited under two cells. The paper's own feature table also has identical values for each pair, so the paper analysed the duplicates as two cells. Here each recording is counted once: the analyses of the recordings leave out the cell with the higher sample number of each pair (which cell the recording belongs to is not known), and the decisive numbers are also given with all cells, as the paper did. The labels of all 1,328 cells are kept for the claims about metadata.

def morph_representation(tt):
    # As phenotype-tsne.ipynb at the pinned commit. Cell 10: cells with any morphometric value, less two cells
    # without all dendritic features. Cell 11: inhibitory or excitatory family and not excluded; per class, the
    # features present in that class, standardized (np.std, ddof 0), 20 PCs scaled by the s.d. of PC1, and 0.25
    # added to the excitatory block. Cell 12: z-profiles, PCs 2 to 5 of a 5-component PCA, scaled by the s.d. of
    # the first kept PC, 0.25 added to the excitatory block. Cell 13: the four blocks in a 48-column matrix,
    # zero outside a cell's own class.
    fam = tt.family.where(~tt.excluded, "low quality")
    q = [c for c in tt.index if c in mf.index and mf.loc[c].notna().any() and c not in ["20180820_sample_1", "20180921_sample_3"]]
    inh = [c for c in q if fam[c] in scala.INHIBITORY]
    exc = [c for c in q if fam[c] in scala.EXCITATORY]
    def block(cs):
        M = mf.loc[cs]
        M = M.loc[:, M.notna().sum() > 0]
        M = (M - M.mean()) / M.std(ddof=0)
        P = PCA(n_components=20).fit_transform(M.values); P /= np.std(P[:, 0])
        Zp = PCA(n_components=5).fit_transform(zp.loc[cs].values)[:, 1:]; Zp /= np.std(Zp[:, 0])
        return P, Zp
    Pi, Zi = block(inh)
    Pe, Ze = block(exc)
    Mx = np.zeros((len(inh) + len(exc), 48))
    Mx[:len(inh), 0:20] = Pi; Mx[len(inh):, 20:40] = Pe + .25; Mx[:len(inh), 40:44] = Zi; Mx[len(inh):, 44:48] = Ze + .25
    return pd.DataFrame(Mx, index=inh + exc), len(inh), len(exc)

def variability(tt, handling, n_init):
    Zr = scala.ephys_representation(scala.features17(tt))
    zz = tt.loc[Zr.index]
    Zv = Zr.values
    ttl = zz.ttype.values.astype(object).copy()
    if handling == "methods":
        ttl[zz.excluded.values] = ""
    names_ = [n for n in sorted(set(ttl) - {""}) if (ttl == n).sum() >= 10]
    nv = pd.Series({n: scala.normalized_variance(Zv, ttl == n) for n in names_})
    restrict = np.isin(ttl, names_)
    km = KMeans(n_clusters=len(names_), random_state=42, n_init=n_init).fit(Zv[restrict])
    cvar = [np.sum(np.var(Zv[restrict][km.labels_ == k], axis=0)) / np.sum(np.var(Zv, axis=0))
            for k in range(len(names_)) if np.sum(km.labels_ == k) >= 10]
    lo, hi = min(cvar), max(cvar)
    above = nv[nv > hi]
    print(f"{handling} membership, n_init={n_init}: {len(names_)} t-types, {len(cvar)} clusters with at least 10 cells, "
          f"band {lo:.3f} to {hi:.3f}; t-types above the band: {len(above)} ({len(above) / len(names_):.0%}); "
          f"Pvalb Vipr2_2 {nv.get('Pvalb Vipr2_2', np.nan):.3f} (above: {nv.get('Pvalb Vipr2_2', 0) > hi}); "
          f"Vip Mybpc1_2 {nv.get('Vip Mybpc1_2', np.nan):.3f} (above: {nv.get('Vip Mybpc1_2', 0) > hi})")
    return nv, ttl, Zv

def leiden_entropies(tt, label, show=False):
    Zv = scala.ephys_representation(scala.features17(tt)).values
    A = kneighbors_graph(Zv, 10)
    src, dst = A.nonzero()
    G = ig.Graph(directed=True)
    G.add_vertices(A.shape[0])
    G.add_edges(list(zip(src, dst)))
    parts = np.zeros((len(Zv), 100), dtype=int)
    for i in range(100):
        parts[:, i] = la.find_partition(G, la.RBConfigurationVertexPartition, resolution_parameter=2, seed=i).membership
    ncl = np.array([len(np.unique(parts[:, i])) for i in range(100)])
    if show:
        print(f"Leiden clusters per run: median {np.median(ncl):.0f}, range {ncl.min()} to {ncl.max()}")
    out = {}
    for handling in ["methods", "code"]:
        nv, ttl, _ = fig5b[(label, handling, "10")]
        ent = {}
        for n in nv.index:
            ind = ttl == n
            E = []
            for i in range(100):
                np.random.seed(i)
                sub = np.random.choice(ind.sum(), size=10, replace=False)
                _, pr = np.unique(parts[:, i][ind][sub], return_counts=True)
                E.append(entropy(pr))
            ent[n] = np.median(E)
        ent = pd.Series(ent)
        rho = ss.spearmanr(nv[ent.index], ent)
        p1 = ss.spearmanr(nv[ent.index], ent, alternative="greater").pvalue
        print(f"{label}, {handling} membership: {len(ent)} t-types; Spearman rho between normalized variance and median entropy "
              f"{rho.statistic:.3f}, one-sided p {p1:.3f}")
        out[handling] = (nv, ent)
    return out

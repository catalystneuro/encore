Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Data missingThe manual extraction of 700 portal pages used for the Technical Validation (REDCap, University of Padova) is not deposited, so the discrepancy rates of the validation cannot be checked.
  • Paper inconsistentThe Methods say the 6552 scraped entries were cleaned of a duplicate and a test page to 6549 unique pages, and Data Records says each entry corresponds to a unique chemical, but the deposited table holds all 6552 rows, including the test page 5883 (named TEST, with no other field) and page 6316, a name-only stub of the chemical whose full record is page 6319.
  • Metadata errorThe item's description calls FAS a "FAO/WHO Food Additive Specification identifier". The column is the number of the Food Additives Series toxicological monograph, derived from the Tox monograph by R/process_df.R in every row, as the paper's Table 1 describes it.
  • Published code disagreesThe deposited fas column, from R/process_df.R, is empty for 355 rows whose Tox monograph is a FAS monograph (339 FAS 60, 10 FAS 74, 2 FAS 27, 4 written "FAS79"), which its "^FAS " pattern misses; 349 of the 752 empty values have a Tox monograph starting with the stray characters '">'. It holds 752 empty strings beside 468 NA, and some values keep a session or page ("77 JECFA 86", "67.29", "617"). R/add_metadata.R repairs part of this but its output is not deposited. With empty strings counted as absent the FAS share is 81.4%, against 93% in Table 1.
  • Metadata errorTable 1 describes the COE number as assigned by the Codex Alimentarius Commission; the item's description calls it the Council of Europe number. COE numbers are present for 3022 flavouring agents and 9 food additives and for no other class, which is consistent with the Council of Europe numbering of flavourings, not with Codex.
  • OtherScraped values carry formatting residue. 602 report, 349 Tox monograph and 398 specification values start with '">' (the Usage Notes mention this for Report); 33 FEMA numbers are plain integers padded with spaces; 31 JECFA numbers are not plain integers ("506a,b", "632.1"); 46 of 2127 plain CAS numbers fail the CAS check digit, and 190 CAS values hold several numbers or notes.

Reproducing Chartrand et al. (2023) from dandiset 000630¶

Paper. Chartrand T, Dalley R, Close J, et al. (2023). Morphoelectric and transcriptomic divergence of the layer 1 interneuron repertoire in human versus mouse neocortex. Science 382, eadf0805. doi:10.1126/science.adf0805. The claims file was written from the author manuscript in PubMed Central (PMC11864503) with its supplementary Materials and Methods, and from the paper's code, AllenInstitute/patchseq_human_L1 at commit 7777857c1b89b19735e45fd9c9bd7493cc1d805c, which this entry reads for the cell labels.

Dandiset. DANDI:000630, version 0.230915.2257, "Human L1 patch-seq electrophysiology": 210 NWB files, one human cell each. This is the version the paper cites (claims file, opening comment) and the only published version; the draft has the same 210 assets. The mouse comparison data (DANDI:000020) are used in mouse_comparison.ipynb.

What is tested here. The files hold current clamp recordings (long and short squares, ramps, in some cells chirps) and, in 38 files, nucleated-patch voltage clamp sweeps. The features are computed here with IPFX from the long square sweeps (reading (a) of the claims file's open detail O1); features that rest on code the paper did not release (irregularity ratio, depolarizing sag, ADP, the ramp and short square features, and others) come from the paper's per-cell table (reading (b)). A feature computed here is used in reading (a) when it agrees with the paper's value within 1% for at least half of the cells, an assumption of this attempt (the claims file does not say when a recomputed feature counts as computed); the five adaptation ratios fail it and are the paper's values in both readings (a variant, "a, ratios", uses the ratios computed here where they bear on a claim). Every claim on the human cells is run on both readings and on a variant (a') of reading (a) with the features extracted without the Methods' 500 ms rms noise criterion, which the paper's own values show its pipeline did not apply as measured here (see the cells after dandiset-cell-link). Cell types come from the paper's cell table, linked to the files by the claim dandiset-cell-link.

def gmm_f1(X, y):
    np.random.seed(0)
    pred = GaussianMixture(n_components=2, init_params="kmeans", n_init=5).fit_predict(X)
    i_true = int(np.mean(pred[y]) > 0.5)

def best_subspace(Xall, names, y):
    sets = [(i,) for i in range(len(names))] + list(combinations(range(len(names)), 2))

def cv_scores(X, y, outliers):
    steps = [("norm", RobustScaler()), ("impute", KNNImputer())]
    if outliers:
        steps = [("pre", L.preproc_pipeline())]
    pipe = Pipeline(steps + [("class", LogisticRegression(class_weight="balanced"))])

Reproducing Mayner, Marshall, Billeh et al. (2022) from dandiset 000036¶

Paper. Mayner WGP, Marshall W, Billeh YN, et al. (2022). Measuring stimulus-evoked neurophysiological differentiation in distinct populations of neurons in mouse visual cortex. eNeuro 9(1) ENEURO.0280-21.2021. doi:10.1523/eneuro.0280-21.2021. The claims file (claims/000036/10.1523-eneuro.0280-21.2021.yaml) was written from the version of record, full text from Europe PMC (PMC8856714), with the legends of the Extended Data figures, and from the paper's code at commit 2d959bd.

Dandiset. DANDI:000036, version 0.230515.1917. The paper cites no DANDI version (it names its code repository, whose README points to a Zenodo deposit). This is the only published version; the draft holds the same 57 files with the same sizes and differs only in metadata (contributors, ethics approval and other fields) that the analysis does not use.

What the dandiset holds. 57 two-photon sessions from 9 mice (dF/F per ROI, ROI masks, running velocity, and the 12 movies with their presentation times). The paper analysed 44 of them; 12 more are not in the paper, and one is the session it excluded. There are no L0 events and no eye tracking.

Outside inputs. The paper's code, GitHub wmayner/openscope-differentiation at commit 2d959bd71b47055d2a3fd306091fe9254ceb86fb: its results/main.parquet identifies the 44 analysed sessions (claim session-link) and, with other files of results/, gives reference values that are printed beside the results. The arousal notebook also streams the paper's Zenodo deposit (doi:10.5281/zenodo.5781567) for the running artifact parameters, the sync alignment and pupil area.

Notebooks. This one tests most claims. multivariate_mayner_2022.ipynb tests the two UMAP claims and arousal_mayner_2022.ipynb the running and pupil claims of Figure 4.

Five claims need L0 calcium events, which the dandiset does not hold. Their criteria name the detector of AllenInstitute/visual_coding_2p_analysis (l0_analysis.py) run on the dandiset's dF/F. That file is Python 2 code that imports allensdk and the compiled package FastLZeroSpikeInference, which is not on PyPI. The section "Blocked claims" at the end shows, from the published sources, why it cannot be installed as published: the package's setup.py does not find its C++ sources, its current Python API has no arfpop, the function l0_analysis.py calls, and the last version that has it is Python 2 code whose C++ lacks an include it needs. The paper's own events are in its Zenodo deposit, but the criteria do not name them. Three claims need the pupil diameter the Methods define (twice the semi-major axis of the fitted ellipse): the dandiset has no eye tracking (listing below), and the deposit holds only pupil area (listed in the arousal notebook).

How the analysis differs from the paper's.

  • Trials are cut where the NWB stimulus times put them. The paper's stimulus table (from its sync files) starts each trial 0 to 6 frames earlier, a shift that grows through the session; per-trial log10 ND differs from the paper's by an SD of 0.047.
  • ROIs whose dF/F is NaN at every frame (14 in the analysed sessions) are left out; without them the cell counts equal the paper's.
  • The statistics are run in Python (statsmodels and scipy), not R (lme4, multcomp, emmeans). On the paper's own per-trial values they give the paper's printed results.
  • Sessions are the 44 of the paper's results table, found through the link. The dandiset alone would give 56 complete sessions; that variant is shown for fig3a and fig3b.
  • The permutation tests use their own random numbers (seeded), not the paper's.
  • Cohen's d uses the Methods' pooled SD. The paper's code weights each group's SD by the other group's n - 1, which moves per-session values by up to 0.1; that variant is shown for discussion-session-effect-sizes and fig4-locomotion-effect-size.
  • Claims that need L0 events or the Methods' pupil diameter are not tested (header, and the section on the L0 detector).

What was found about the dataset.

  • It holds 57 sessions, not the paper's 45: 12 more (10 Cux2, 2 Rbp4 PM) that the paper does not describe, and the excluded L5 AL session, which was imaged at half the frame rate. Nothing in the files marks which sessions the paper analysed or why one was excluded.
  • session_start_time is 7 hours later than the paper's start times while labelled -07:00; it looks like UTC labelled as Pacific time.
  • The NWB identifier is not the session id the paper and its code use; it is the ophys session id that names the pupil files of the deposit.
  • 15 ROIs have dF/F that is NaN at every frame, with no flag.
  • The stimulus presentation times drift against the 2p frame times, compared with the alignment the paper used, by about 3 frames (105 ms) on average and up to 4.4 frames (146 ms) by the end of a session.
  • The dF/F timestamps have one entry more than the data in 39 files; the running velocity has one sample more than its timestamps in every file (the extra one is the first).
  • The stated imaging rate is 30.0 Hz; the frames are 30.15 Hz apart (15.08 Hz in the excluded session).
  • There are no L0 events, no eye tracking and no pupil data, and the subject's sex, age and date of birth are absent, all of which the paper reports or uses.

Summary: Most of the paper's main findings hold up in this data and in a rebuild of its model. In the recordings, L2/3 and L5 bursting is highest on the first repetition of an image and running raises it, as reported. Omission firing and L5 bursting fall below spontaneous levels only in part, depending on which spontaneous period is used, which the Methods leave open; running did not lower L5 firing during omissions. In the model, the prediction did not silence the neuron under weak sensory input and gain changed the release delay, probably because the model's code and input timings are not available. Two supplementary findings, on novel images and on L5 bursting and rate, did not reproduce.

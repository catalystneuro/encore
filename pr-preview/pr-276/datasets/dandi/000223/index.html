    How the test differed from the paper’s method

    • The convolved traces are computed at the frame times as a sum over spikes of the same causal exponential kernel, not with elephant at every 20 kHz sample; for three units of one recording the largest difference from elephant is 0.13 to 0.34 Hz on peaks of 19 to 45 Hz (R above 0.99997).
    • Units whose convolved trace is constant over the kept frames have an undefined R and are left out of the ranking (one unit in each of rows 16 and 18); the code's np.argsort would rank such a NaN first.
    • Bursts touching the start or end of the recording, which the code cannot handle (it would raise an error), are dropped, as Methods 2.6 says ("Edge cases, where data began or ended during a burst, were excluded").
    • Table 1 rows are matched to files by subject (culture) and unit count, as the claims file says; where two assignments fit equally (rows 14 and 15; rows 16 and 20) the one whose spike contrast is nearer to Table 1 is taken, and the swapped assignments are shown (16 to 17 matches, the same outcome). In the file with two spines, the first ROI pair is taken as row 9 and the second as row 10. The paper gives no identifier that settles either.
    • The lowess-smoothed population counts are rounded to 9 decimals before they are compared with the integer burst baseline. In every recording some smoothed values equal the baseline up to rounding error (within 1e-9) and lie above it unrounded, so without rounding the burst edges, and with them every later number, depend on the last bits of floating-point arithmetic, which can differ between machines. This is the likely reason the run the round-2 verifier read differed from the author's run, which this machine still reproduced unchanged before the fix. The paper's code compares the unrounded values.
    • The ROI pairs are taken in the order spine, shaft, as notebook 1 of the code draws and loads them ("the drawing order has to be spine1, adjacent shaft of spine1, ..."); the spine ROI is the smaller of each pair in 19 pairs and equal in one.

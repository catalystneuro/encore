    Findings about the data

    What attempts found about the dataset itself, for its owner and the archive.

    • Selection not documentedThe ephys files hold only the trials and units the paper analysed. No trial has a lick between -1 and 0.1 s of the stimulus (the Methods remove about 25%; gaps of 8 to 64 per session remain in the trial times), and the units are those passing the quality filter and the 50 Hz cut (unit counts per area equal the paper's). The dandiset does not say that trials or units were removed.
    • Description missingUnits carry only spike times and observation intervals; there are no quality metrics, waveforms, channel or depth, and unit ids run from 0, so units the paper names by cluster number (for example unit 127 of YT084, 2020-02-01) cannot be identified.
    • Data missingElectrode x, y and z are NaN in all 49 ephys files and electrode locations "unknown"; the probe locations of Figure 1E (histology) are not in the dandiset.
    • Description missingThe trials table columns have no descriptions. `response` (1 right lick, 2 left, 0 none, 3 on trials without a stimulus), `blockType` ("Whisker", "Visual", and "Change" for the cue trial), the opto trial types and the TTT to VVN indicator columns are explained only by the paper's code.
    • Metadata errorIn the 130 behaviour files `start_time` equals the stimulus onset (or laser time on laser-only trials), so trial intervals overlap and do not delimit trials; licks before the stimulus are stored in the trial's lists.
    • Metadata errorIn the tactile detection files, trials without a whisker stimulus are labelled "Stim_Vis" and "Stim_Vis_NoCue" with a visual stimulus type, though no visual onset is given.
    • OtherTwo laser trials start 1.6 and 2.7 s before the reference time and one lasts 9.5 s, outside the stated 0.8 s pre-stimulus and 2 s post-stimulus inhibition; the code counts them as pre-stimulus.
    • Paper inconsistentFigure 5B gives 88 and 91 block switches; the 40 recording sessions hold exactly 88 touch and 91 light blocks when the first block of each session is counted, and 63 and 75 non-first blocks with a hit, so the reported numbers appear to count blocks, not switches. The code's GetFirstHitInfo returns one entry per block, NaN for first blocks and blocks without a hit, which a count of entries would give.
    • Published code disagreesThe Methods describe soft normalization (x - mean) / (range + 5) for population analyses; the code's trajectory distance divides by the range alone, its subspace overlap uses offset 5 for the reference and 0.01 for compared data, the coding dimensions use 0.01, and decoding uses a z-score. The Methods exclude sessions with fewer than ten units from the subspace analysis; the code requires more than ten.
    • Published code disagreesThe code's hierarchical bootstrap of optogenetic sensitivity draws resampled false-alarm trials but computes the false-alarm rate from the original trials, so only hits are resampled.
    • Published code disagreesThe coding-dimension code keeps sessions with more than ten units (S1 8, S2 7, MM 5, ALM 11), while Figure S4 reports 10, 8, 9 and 13 sessions.
    • OtherThe shared clock of spike times and trial times could not be established by the stimulus-decoding check for three sessions, YT084 2020-02-02 and 2020-02-03 (AMM, 2 and 5 units) and YT086 2020-03-20 (MM, 5 units, accuracy 0.63 before and 0.65 after the onset). They are kept.
    • OtherThe cross-modal sham session set includes one session (of 28) that fails the code's own performance check as ported here; it is kept, as deposited.

    Reproduction Rule-based modulation of a sensorimotor transformation across cortical areas (Chang et al. 2023)

    Tests the findings of Chang, Finkel, Xu and O'Connor (bioRxiv 2023, version 2) on dandiset 000232, which holds silicon-probe recordings from S1, S2, MM, ALM and AMM of mice performing a cross-modal sensory selection task, and the behaviour of optogenetic inhibition sessions in that task and in a tactile detection task. It covers behavioural performance, single-neuron rule and stimulus discrimination, population decoding of the rule, neural trajectories and subspaces, coding dimensions, rule transitions and the effects of optogenetic inhibition.

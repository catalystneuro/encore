Schuck, Cai, Wilson & Niv (2016) on CRCNS data set ofc-4¶

Paper: Schuck NW, Cai MB, Wilson RC, Niv Y (2016). Human orbitofrontal cortex represents a cognitive map of state space. Neuron 91:1402-1412, doi:10.1016/j.neuron.2016.08.019. The claims file (claims/crcns-ofc-4/10.1016-j.neuron.2016.08.019.yaml) was written from the version of record with its Supplemental Information.

Data set: CRCNS ofc-4, "fMRI time series in orbitofrontal cortex during face-house state-space task" (Schuck, Cai, Wilson & Niv 2019), doi:10.6080/K0FN14CH, read from the public S3 bucket crcnsarchive under ofc-4/live/. Version: unversioned. CRCNS data sets carry no version numbers (docs/archives.md); the bucket holds one copy, under live/ (no old/ folder), described by version 0.6 of the data descriptor (April 19, 2019), the only version. The paper cites no version of the data set, which was published three years after it, so this copy is the one to pin. The notebook prints the data set's checksums.md5 and the MD5 of the zip as streamed; the files read are FHSS_OFC.zip (MD5 4372953c3900c5a965ad09526a9510ed) and checksums.md5, so a later change of the zip is detectable.

The data set holds, for the 24 participants of the paper's trial-wise analysis (the paper analysed 27), the OFC time series in native space with no voxel coordinates, the design matrices (16 state columns, 'first', 'err') with drift and motion nuisance time courses, and the event files (onset, reaction time, stimulus duration per state, 'first' and 'err'). It holds no whole-brain data, no other ROI, no training session, no response side or response mapping, and no voxel coordinates.

One assumption runs through the decoding claims: the beta maps are z-scored per voxel across the 16 state maps of a run ('voxel'), the operation of the Princeton MVPA toolbox's zscore_runs, which the Methods name ("Data Preprocessing"); the other reading of O2, each map across voxels ('map'), is shown everywhere beside it. The 'err' events are blocks, not single trials: their spans (onset to end of the last stimulus) run from 6.8 to 41 s, two to several trials. All 181 blocks that follow an Exit trial hold a trial of the other category, so their first trial is an Enter error, and the short ones (about two trials) hold the error and its repetition. In runs whose labelled trials and blocks add up to 96 (27 of 88 runs with blocks), every block holds one designed trial and the error trial's state follows from its neighbours; all 39 such states are legal, and they are all Enter errors. Elsewhere, blocks take up more designed trials than one (0.38 more per block in runs with only Enter errors, 0.69 in others), so a block can hold more than one error or the trials after it. The number of errors and the state of most error trials therefore cannot be read from the files: the class is known for 181 of 228 blocks, the full state for 39 (strict reading) or 98 (span reading).

Composition of the blocks. Measured in trial slots (onset to the next event over the run's mean trial interval), 82 of the 172 blocks after an Exit trial span about two slots, the error and its repetition, and most others three to five; blocks after Internal or Enter trials span about four (median 4.0 and 4.4), as an Exit error followed by the repeated preceding trial and the repeated Exit trial would. Over runs, each block after an Exit trial takes up 1.52 designed trials and each other block 1.87 (least squares), so a block after an Exit trial holds on average about half a designed trial (0.52) besides its error trial, and another block close to one (0.87). Whether that trial is a second error or a correct trial after the error the files do not say. The 'err' RT-file duration runs to the last response of the block (span less RT duration, median 2.1 s). def wald(fit, names):
    """Wald chi-square of the named coefficients of a fitted statsmodels model."""
    b = fit.params[names].values
    V = fit.cov_params().loc[names, names].values
    chi2 = float(b @ np.linalg.solve(V, b))
    return chi2, len(names), float(stats.chi2.sf(chi2, len(names)))

def ttest(x, mu, alternative="greater"):
    r = stats.ttest_1samp(x, mu, alternative=alternative)

def boot_p(x, mu, n=10000, seed=0):
    """Bootstrap over participants (Supplemental Results 1.2): share of resampled means at or below mu."""
    rng = np.random.default_rng(seed)
    x = np.asarray(x)
    means = x[rng.integers(0, len(x), (n, len(x)))].mean(1)
    return float((means <= mu).mean())

def between_run(betas, rs, prep, metric):
    """16 x 16 between-run similarity (Pearson r) or distance (Euclidean), averaged over ordered run pairs."""
    maps = {r: betas[("16", r)] if prep == "raw" else ofc4.zscore_maps(betas[("16", r)], prep) for r in rs}
    mats = []
    for r in rs:
        for r2 in rs:
            if r2 == r:
                continue
            A, B = maps[r], maps[r2]
            if metric == "corr":
                Az = (A - A.mean(1, keepdims=True)) / A.std(1, keepdims=True)
                Bz = (B - B.mean(1, keepdims=True)) / B.std(1, keepdims=True)
                mats.append(Az @ Bz.T / A.shape[1])
            else:
                mats.append(np.sqrt(((A[:, None, :] - B[None, :, :]) ** 2).sum(-1)))
    M = np.mean(mats, axis=0)
    if metric == "corr":
        M[M < 0] = np.nan
    return M

def courses(z, vol, err_reading, seed):

    for (s, r), g in q.groupby(["subject", "run"]):
        g = g.set_index("pos").sort_index()
        lab_pos = set(g.index[g.cond.isin(ofc4.STATES)])
        used = set()

            if pd.isna(e.truth) or not all((p - k) in lab_pos for k in range(1, 6)):
                continue
            eid = f"{s}-{r}-{p}"
            for k in range(-5, 2):
                pp = p + k
                if k == 0:
                    err_rows.append({"subject": s, "eid": eid, "rel": 0, "c": e.c, "cls": e.cls})
                elif pp in lab_pos:
                    err_rows.append({"subject": s, "eid": eid, "rel": k, "c": g.loc[pp, "c"], "cls": g.loc[pp, "cls"]})
            course = set(range(p - 5, p + 2))
            starts = [st for st in sorted(lab_pos) if all((st + k) in lab_pos for k in range(7)) and not (set(range(st, st + 7)) & course)]
            if starts:
                st = starts[rng.integers(len(starts))]
                for k in range(7):
                    mat_b.append({"subject": s, "eid": eid, "rel": k - 5, "c": g.loc[st + k, "c"]})
        st = min(lab_pos) if lab_pos else None
        positions = sorted(lab_pos)
        i = 0

                i += 1

def slope_test(df, formula, term, re="~rel"):
    """Random intercept and slope; when that fit does not converge, the random-intercept model
    is used and the result is marked."""
    try:
        m = smf.mixedlm(formula, df, groups=df["subject"], re_formula=re).fit()
        slope_ok = bool(m.converged)
    except np.linalg.LinAlgError:  # singular fit: counted as not converged
        slope_ok = False
    if not slope_ok:
        try:
            m = smf.mixedlm(formula, df, groups=df["subject"]).fit()
        except np.linalg.LinAlgError:
            print("   a random-intercept fit was singular; its result is left out:", formula, f"({len(df)} rows)")
            return np.nan, np.nan, np.nan, False
    chi2, _, p = wald(m, [term])
    return m.params[term], chi2, p, slope_ok

def fig5_tests(tt, metric):
    g = tt.groupby("enter")[["sim", "rate"]].mean()
    ra = stats.linregress(g.sim, g.rate)
    ordd = tt.assign(sim_rank=tt.sim.fillna(-np.inf)).sort_values(["subject", "sim_rank"])
    ordd["pos"] = ordd.groupby("subject").cumcount()
    go = ordd.groupby("pos")[["sim", "rate"]].mean().dropna()
    rb = stats.linregress(go.sim, go.rate) if len(go) >= 3 else None
    rs_ = []
    for s, d in tt.dropna(subset=["sim"]).groupby("subject"):
        if len(d) >= 3 and d.rate.std() > 0 and d.sim.std() > 0:
            rs_.append(stats.pearsonr(d.sim, d.rate).statistic)
    rs_ = np.array(rs_)
    alt = "less" if metric == "corr" else "greater"
    tc, pc = stats.ttest_1samp(rs_, 0, alternative=alt)
    _, pc2 = stats.ttest_1samp(rs_, 0)
    # mixed model on similarity standardised over the table (raw distances are in the thousands)
    d = tt.dropna(subset=["sim"]).assign(sim=lambda x: (x.sim - x.sim.mean()) / x.sim.std())
    try:

    except np.linalg.LinAlgError:
        ok = False
    if not ok:
        m = smf.mixedlm("rate ~ sim", d, groups=d["subject"]).fit()
    chi2, _, pm = wald(m, ["sim"])
    return ra, rb, rs_, tc, pc, pc2, chi2, pm, m.params["sim"]

How the analysis differs from the paper's:

  • 24 of the 27 participants (those of the paper's trial-wise analysis, as the data set says).
  • No spatial smoothing of beta maps or volumes: the files hold no voxel coordinates.
  • The GLM's nuisance set is the data set's (four drift terms, six motion parameters), without the 26 cardiac regressors of the paper; it uses the data set's design matrices, built with AFNI.
  • Beta maps are z-scored per voxel across the state maps of a run (an assumption; the per-map reading is shown throughout).
  • Errors are the error blocks of the event files, one per block, a lower bound; the state of an error trial is reconstructed from its neighbours (strict and span readings), and only Enter errors can be reconstructed.
  • The logistic readings of the behavioural models use participant fixed effects, as statsmodels has no frequentist logistic mixed model; the linear mixed models use statsmodels' MixedLM in place of lmer.
  • The data set's 'err' column puts the trials inside an error block after the error trial in no regressor; both readings of O3 are rebuilt from the error blocks and shown for the 16-way decoding and its components, with the same outcomes.
  • Every error trial that can be given a state is an Enter trial, and with maps z-scored by voxel Enter trials decode worse than others on single volumes, so the error trial is compared with Enter trials of the matched courses (an assumption; the criterion's readings are shown).
  • The trial-wise mixed models fall back to a random intercept where the random-slope fit did not converge.

What was found about the data set: the error events merge each error with its repetitions and often the trials after it, so the number of errors, time-outs, error RTs and the state of most error trials cannot be recovered; Enter errors are 181 of 228 error blocks, 79% against the 48% the paper's class rates imply; the 'err' column of the design matrices is not the boxcar the descriptor describes; three runs lack a 'first' column; one pair of adjacent labelled trials in Subj-01 run 4 breaks the task rules; and the files hold no voxel coordinates, no training session, no whole-brain data or other ROIs, and no response side or mapping.

Reproducing Gao, Ramachandran, Yu & He (2025) from dandiset 000946¶

Paper. Gao H, Ramachandran S, Yu K, He B (2025). Transcranial focused ultrasound modulates feedforward and feedback cortico-thalamo-cortical pathways by selectively activating excitatory neurons. J Neurosci 45(23): e2218242025. doi:10.1523/jneurosci.2218-24.2025. The claims file (claims/000946/10.1523-jneurosci.2218-24.2025.yaml) was written from the version of record as served by PubMed Central (PMC12139594): main text, Methods and figure legends; the paper has no supplement and links no analysis code.

Dandiset. DANDI:000946, version 0.250829.1249. The paper cites the dandiset without a version (Methods, Electrophysiological recordings: "All experimental data has been made public in a repository at the DANDI Archive (https://dandiarchive.org/dandiset/000946)"), so the most recent published version is pinned. The data check below compares its file list with the earliest published version, 0.250711.1640; all six published versions list the same 1920 files.

What the dataset holds. One NWB file per recorded area and session, each with a units table (spike times and a celltype_label column) and a trials table. There are no spike waveforms in any file, and celltype_label, described as "label 1 = RSU, label 2 = FSU", is 0 for every unit. The paper splits units into RSUs and FSUs by k-means on waveform measures (Methods, Neuronal type classification), so every claim about RSUs or FSUs, and every claim built on them, cannot be tested. No session is marked as sham or as tFUS aimed at CG1. The unit totals of the two count claims do not need the types, and they are tested on the totals. The auditory cortex units of Figure 11B are not split by type, and that claim is tested.

Clock check¶

start_time of the trials table is taken as sonication onset. If it is, the units' firing should change at fixed delays after it; with the trial starts shifted by 1 s (inside the 2.25 s minimum interval, where no tFUS is delivered), the same measure should show no change. The measure is the mean over units of the normalized rate (reading N1) in each 67 ms window, for every unit with more than 2000 spikes.

def unit_table(frame, min_spikes=tfus.MIN_SPIKES):
    rows = []
    for _, r in frame.iterrows():
        res = r["res"]
        for c, cs, ps in zip(res["true"], res["shifted"], res["psth"]):
            if c["n_spikes"] <= min_spikes:
                continue
            rows.append(dict(subject=r.subject_id, identifier=r.identifier, area=r.area, prf=r.prf,
                             true=c, shifted=cs, psth=ps))
    return pd.DataFrame(rows)

That start_time is the onset of sonication itself, and not a trigger at a fixed delay, is consistent with the data (the firing changes within the first 67 ms window at the high PRFs) but not shown. In every session with files from two areas, both files carry the same trial start times, so the two areas were recorded together on one clock (the description says "Each recording contains two areas"), though their session_start_time values differ (by the minutes printed above), so that field does not give the start of the recording.

The split needs the cell types, which the dataset does not hold (data check above). def evaluate(frame, nreading, breading, min_label=""):
    out, sig = [], {}
    for w in tfus.WINDOWS:
        groups, line = [], {}
        for p in PRFS:
            cs = list(frame[frame.prf == p]["true"])
            x = np.array([tfus.normalized_rates(c, w, nreading) for c in cs])
            groups.append(x)
            if breading == "B3":
                from scipy import stats as st
                win = np.array([c[w].mean() for c in cs]); bas = np.array([c["base"].mean() for c in cs])
                pr = st.wilcoxon(win, bas, alternative="greater").pvalue
                pc = min(1, pr * 5)
            else:
                base = tfus.baseline_sample(cs, nreading, breading)
                pc, pr = tfus.vs_baseline(x, base, 5, "greater")
            sem = np.nanstd(x, ddof=1) / np.sqrt(np.isfinite(x).sum())
            out.append(dict(N=nreading, B=breading, window=w, prf=int(p), n=int(np.isfinite(x).sum()),
                            mean=round(np.nanmean(x), 1), sem=round(sem, 1), median=round(np.nanmedian(x), 1),
                            p_corrected=float(f"{pc:.3g}"), above=pc < 0.01))
        kw = tfus.kruskal_levels(groups)
        for o in out[-5:]:
            o["kruskal_p"] = float(f"{kw:.3g}")
    return pd.DataFrame(out)


def judge(t):
    def sset(w):
        return {r.prf for r in t[(t.window == w) & t.above].itertuples()}
    during, post = sset("0-67"), sset("201-268")
    kw_ok = (t[t.window == "0-67"].kruskal_p.iloc[0] < 0.01) and (t[t.window == "201-268"].kruskal_p.iloc[0] < 0.01)
    d_err = len(during ^ {1500, 3000})
    p_err = len(post ^ {30, 1500, 3000, 4500})
    low = [t[t.window == w].sort_values("mean").prf.iloc[0] for w in ["0-67", "201-268"]]
    low300 = 300 in low
    if kw_ok and d_err == 0 and p_err == 0 and low300:
        verdict = "reproduced"
    elif kw_ok and ((d_err + p_err == 1 and low300) or (d_err == 0 and p_err == 0 and not low300)):
        verdict = "partially reproduced"
    else:
        verdict = "not reproduced"
    return dict(kruskal_both=kw_ok, during=sorted(during), post=sorted(post), lowest_0_67=low[0],
                lowest_201_268=low[1], verdict=verdict)

Seizure metrics¶

Per rat, hemisphere and block (M2 of the claims file, Methods C): Seizure Count; Percent Time in Seizure, summed durations over the block length; Seizure Duration, the mean duration of seizures that neither start at the first sample nor end at the last; and Inter-Seizure Interval, the mean interval between neighbouring seizures, computed both as the gap from one seizure's end to the next one's start (isi_gap) and from onset to onset (isi_onset). The paper's words, "time between neighboring seizures", favour the gap. For the interval the two tFUS rats with a block without seizures are left out (Methods C, "two rats were excluded because they had conditions without seizure occurrence").

def group_tests(df, value, hemi):
    # Fig. 3 and 4: group by block per hemisphere, blocks baseline to post 2. Families (M3):
    # 'within' each block against baseline in each group (6), 'between' sham against tFUS at each block (4).
    d = df[(df.hemi == hemi) & (df.block != "post3")]
    comps = [(f"{g} baseline-{b}", {"group": g, "block": "baseline"}, {"group": g, "block": b}, "within")
             for g in ("sham", "tFUS") for b in BL[1:4]]
    comps += [(f"sham-tFUS {b}", {"group": "sham", "block": b}, {"group": "tFUS", "block": b}, "between") for b in BL[:4]]
    out = {}
    for rm in (False, True):
        table, post = tfus.twoway(d, value, "group", "block", "subject", comps, rm=rm)
        out["repeated" if rm else "ordinary"] = (table, post)
    return out

def show(out, keep=None):
    for k, (table, post) in out.items():
        print(f"  [{k}] main effects:", {i: f"F={r.F:.2f}, p={r.p:.3g}" for i, r in table.iterrows()})
        p = post if keep is None else post[post.comparison.isin(keep)]
        print(p[["comparison", "family", "diff", "stat", "p_raw", "p_family", "p_all"]].round(4).to_string(index=False))

def pct_change(df, value, group="tFUS"):
    # M4: (a) the group mean of the block over the group mean at baseline, minus 1;
    # (b) the mean over rats of each rat's change from its own baseline.
    d = df[df.group == group]
    g = d.groupby(["hemi", "block"])[value].mean().unstack()
    a = (g.div(g["baseline"], axis=0) - 1) * 100
    w = d.pivot_table(index=["hemi", "subject"], columns="block", values=value)
    b = ((w.div(w["baseline"], axis=0) - 1) * 100).groupby("hemi").mean()
    cols = [c for c in BL[1:4]]
    return a[cols], b[cols]

How the analysis differs from the paper's. The seizure labels are the dandiset's own, so the metrics rest on the paper's labelling. The label times are in minutes and are converted. The percent changes of Fig. 3 match the paper to within one point under reading (b) of M4 (each rat's change from its own baseline), and the inter-seizure interval matches only when read as the gap from one seizure's end to the next one's start, so both readings are the paper's. The paper's two-way ANOVA is not specified further. Most of its significant within-group changes of Fig. 3 (the count at post 1 and post 2, percent time at the stimulation block, the interval at contralateral post 1) appear only under the repeated-measures reading; percent time at post 1 and post 2 is significant under the ordinary reading too. The reading is implemented here as a mixed model with a random intercept per rat, and it is adopted as an assumption where the readings disagree on a claim of absence. Its post hoc tests are t tests and its main effects F tests, on Satterthwaite degrees of freedom (on balanced data, the df of the classical repeated-measures ANOVA, as Prism uses); the first version of this attempt used normal and chi-squared references, which made two sham against tFUS comparisons look significant. The Bonferroni family is not specified either; both readings are shown. Each set of comparisons as its own family (reading i) is adopted where they disagree, as Prism corrects each set of multiple comparisons it is asked for on its own; this decides fig2f-sham-percent-time-post3 and fig3b-sham-percent-time-no-change. The durations leave out seizures that start or end at a block edge; counting the seizures within 2 s of either end of a block as cut off as well (14 left out, against 6) changes no result. BH635's five sham files are taken in time order though their labels say otherwise.

What was found about the dataset. It holds the paper's 16 epileptic rats (10 tFUS, 6 sham) with the seizure labels, and the percent changes computed from them match the paper's. The label table gives times in minutes, not the seconds NWB prescribes (the EEG check in eeg_blocks.ipynb confirms it). BH635's block files are mislabelled (two SHAM files, one named for rat BH636, no post3), and BH649's post 3 file has the session id None. Every file gives the strain as "HSD:WI rat" (Wistar) and the age as P24W, while the paper used Sprague-Dawley rats of 3 to 6 months. The labelling channels are not named in the files.

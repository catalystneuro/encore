Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Description missingThe files carry no t-type, subclass, cortical layer, brain region or donor medical condition, and no specimen id of the paper's cell table. They can be linked to the paper's table only through the LIMS number in session_id, which equals the Ephys_Roi_Result number inside the table's internal nwb_path column; the dandiset's description points to the code repository but does not say how to link.
  • Identifier missingSix files (five of donor 1122692698, one of 1154304730) carry a time stamp such as 2021_08_17_112853 in general/source_script file_name, where the other 204 carry the cell name (for example H21.03.315.11.11.01.01).
  • File format errorIn 145 of 210 files, 2586 long square sweeps that stopped early hold zeros for the samples that were not acquired, where NWB readers such as IPFX expect missing values. IPFX's integrity check passes them and reads the step to 0 mV as a spike, which changes rheobase and spike features unless the sweeps are left out.
  • File format errorbias_current is stored in pA, with a unit attribute of pA, where the NWB schema fixes the unit of bias_current as amperes; a reader that follows the schema gets values 10^12 times too large.
  • Metadata errorThe two files of donor 922967568 state an age of P0.0D where the paper's table gives the age as unknown, and one file (session 977186103, cell H19.03.321.12.04.01.04) states sex unknown where the table gives M. Ages are stated as whole years times 365 days. The species is written as Homo Sapiens in 192 files and Homo sapiens in 18.
  • Data missingThe dandiset holds only the 210 Seattle cells of the paper's primary set. The 50 Amsterdam (22) and Szeged (28) cells of the strict L1 set, which the paper uses as held-out validation (Fig. S8B) and in its LAMP5 t-type analysis, are not in it, and the paper names no other deposit of them.
  • Selection not documentedThe dandiset holds exactly the paper's primary set P, the Seattle cells of the strict L1 set (soma in L1 or within 40 um of the L1/L2 border) whose long square features were extracted. The 12 Seattle cells of the strict set that failed feature extraction and the other Seattle cells of the paper's table are not deposited, and the dandiset's description does not say how the cells were selected.
  • Description missingThe donor medical condition is given in the public cell table for only 86 of the 194 cells of P in L1 t-types and 20 of the 71 reconstructed strict-set cells with an L1 t-type; the paper's code read it from the Allen Institute's donor database. The claims on medical condition cannot be repeated on the paper's cells.
  • Methods not availableSeveral features the claims rest on (irregularity ratio, depolarizing sag, ADP slope and voltage, sag time to peak and time constant, the ramp, short square and chirp features) come from code the Methods say will be released in a future IPFX version; it is not in IPFX 2.1.2 nor in the code repository. The adaptation ratios computed here from the Methods' definition (third over first spike on the lowest step with at least 4 spikes) agree with the paper's values within 1% for only 4 to 53% of cells (six ratios; 4 to 37% for the five not used). The authors are asked whether the feature code can be released.
  • Methods not availableThe authors are asked what d' counts as high in Fig. 6A, where LAMP5 NMBR against LCP2 is said to be the only within-subclass pair with high d'. With the 2.2 grouping threshold it holds here on the features computed here for three seeds and on the paper's values for one of three; with the median between-subclass d' (2.40 to 2.62) no within-subclass pair is high.
  • Methods not availableThe authors are asked whether the two-way ANOVA of Fig. 3D was run on ranks with Type II sums of squares and heteroskedasticity-corrected tests (legend and Data S4), or on raw values with Type I sums of squares, as the code calls anova_lm without its robust option. With every visual area, as the code takes the mouse cells, the AP height species effect is FDR p = 2.6e-38 under the first and 1.4e-43 under the second, on either side of the legend's 1e-38.
  • Methods not availableThe authors are asked how the sweep QC criterion of rms noise below 0.5 mV over 500 ms (Methods, Quality control) was measured. Measured with IPFX on the deposited files, it leaves out sweeps from which the paper's per-cell values were computed: in 7 of the 9 cells where IPFX falls back to a lower sweep at rheobase + 40 pA and the value disagrees with the paper's, the paper's value comes from a sweep that fails only this criterion here. Without it, 38 of the 39 recomputed features agree with the paper's values for more cells, and the initial firing rate difference across subclasses (Fig. 2C) has FDR p 3.9e-9 against 4.7e-7 with it.
  • Published code disagreesThe Fig. S3A legend gives R2 = 0.74 for the upstroke adaptation ratio against sag. The code's regression (run_regressions, OLS with HC3) on the paper's own per-cell values over the cells of P in L1 t-types gives R2 = 0.36 (192 cells), and 0.31 on t-type medians.
  • OtherFor the mouse comparison (DANDI 000020 version 0.210913.1639, an outside input), 22 of the paper's 272 strict mouse L1 cells, 20 of them in VISp layer 1 and one of them a Lamp5 Krt73 cell, have no file in that version, and none of the paper's 15 mouse TEa cells does.
  • Published code disagreesThe paper compares human L1 with mouse VISp L1 (Fig. 3E legend; Methods), while the code's cross-species notebook (l1_cross_species.ipynb cell 5) takes mouse cells from every visual area (VISp, VISpm, VISl and others; 185 cells against 150 in VISp here). With VISp alone the AP height species effect is FDR p 3.3e-34 to 3.4e-33, above the legend's 1e-38.
  • OtherNucleated-patch voltage clamp sweeps are in 38 human files of the dandiset and 25 strict mouse L1 files of DANDI 000020, but the patch surface areas the paper's conductance densities (Fig. 3F) need, measured from images, are not deposited.

  • na-cell-table-link

    The dandiset's recordings are the 35 outside-out patches of the paper's code table (14 VEN and 21 PC), and the maximal Na+ current computed from each recording agrees with the value the table gives for it.

    https://dandiarchive.org/dandiset/001750 (sodium channel currents)

    Data availability; github.com/RFLiu2021/AIC_proj at commit 44cd8a6, ephysio/data_ephy/rawdata_ephysio/metadata_outSideOutSodiumCurrentRec.csv

    How it will be judged

    Recordings are matched to table rows by NWB file name (fileName_nwb), and the cell type is compared with the dataset's own label where it has one. For each cell, the maximal peak inward current is computed under each reading of fig4d-sodium-current-lower. The link holds (reproduced) when all 35 files are found, every cell type the dataset gives agrees with the table, and, under at least one reading, the absolute computed maximum is within 10% of the absolute max_Na_current for at least 28 of the 35 cells. Partially reproduced when the files and types match but fewer than 28 values agree under every reading; not reproduced when files are missing or types disagree. Which reading agrees best is reported; it does not choose the reading for the finding, which is judged under all of them.

  • fig4d-sodium-current-lower

    Somatic Na+ currents recorded in outside-out patches are significantly lower in VENs (n = 14) than in L5 PCs (n = 21).

    outside-out patch-clamp recording showed that the somatic Na + currents evoked in VENs ( n = 14) were significantly lower than those of L5 PCs ( n = 21) (Fig. 4d )

    Results, The AIC evolved a neural signal-processing strategy, paragraph 3; Figure 4d

    How it will be judged

    Selection, every outside-out patch of a VEN or an L5 PC, typed as the dataset labels it or, when it does not, as metadata_outSideOutSodiumCurrentRec.csv does (through na-cell-table-link). Protocol, steps from -80 to 0 mV in 5 mV increments, 25 ms, leak subtracted online (Methods). Measure, per patch, the largest peak inward current over the steps, as an absolute value in pA; the code compares abs(maxNaCurrent) in pA (Fig4d_plotNaCurrent.m), and the Methods' model section speaks of "peak sodium current", so current, not current density, is compared. Repeated sweeps of a step are averaged before the peak is taken, as the code does for its example traces. Open and run as readings, (a) baseline, (a1) the trace as recorded, already leak subtracted (Methods), or (a2) a pre-step baseline subtracted as in the code's example traces, the mean of the first 100 samples of a cut starting 2 ms before the step onset (2 ms at 50 kHz, 1 ms at 100 kHz); (b) steps, (b1) the 17 steps from -80 to 0 mV (Methods, and the code's nTraces = 17) or (b2) every step recorded (the code's example array holds 28); (c) window, (c1) 0 to 20 ms after the step onset (the code's plotted window) or (c2) the whole 25 ms step (Methods). The sampling rate and step onset are read from each file, as the code's examples differ (50 kHz and 40 ms against 100 kHz and 20 ms). Test, two-tailed Wilcoxon rank-sum, VEN against PC (Fig. 4d legend; ranksum in the code), at p < 0.05 (conventional; the panel's P value was not readable). Reproduced when, under every reading, the VEN median is lower with p < 0.05 and the counts are within tolerance; not reproduced when the VEN median is not lower or p >= 0.05 under every reading; blocked as methods_underspecified when readings disagree. The two-sample t-test the code also runs, and the current density (current over the area from each patch's capacitance at 1 uF/cm2, Methods), are shown as variants that do not decide.

Reproducing Girardeau, Inema & Buzsaki (2017) from dandiset 000061¶

Paper. Girardeau G, Inema I, Buzsaki G (2017). Reactivations of emotional memory in the hippocampus-amygdala system during sleep. Nature Neuroscience 20, 1634-1642. doi:10.1038/nn.4637. The article is not open access (it is not in PubMed Central, and its HAL record holds metadata only), so this attempt used the abstract alone (PubMed 28892057). Every claim is a sentence of the abstract, none has a reported number, and every method choice was fixed in the claims file before the analysis.

Dandiset. DANDI:000061, version 0.250624.0426. The abstract cites no DANDI version. There are two published versions, 0.210812.1517 and 0.250624.0426; they hold the same 40 files (same blobs and sizes) and differ only in metadata (contributor affiliations and ORCIDs, and a relatedResource link to the paper, added in 2025), none of which the analysis uses. The most recent published version is pinned.

What the dandiset holds. 40 NWB files, one per recording day, from four rats (Rat08 to Rat11): sorted units with a region label, sleep states, epochs, and event times of hippocampal ripples, air puffs and rewards; some files also hold raw voltage, LFP and video. There is no position tracking; the files hold the raw video frames, from which position is not derived.

Code. The dandiset links no analysis code, and the abstract names none. The parameters are common choices, listed in the helper module hpcbla.py and the claims file.

# (3) Lap direction decoded from hippocampal rates in each lap (leave one lap out, nearest
# centroid), with the true laps and with laps shifted by half their own duration.
def decode_direction(s, half_shift=False):
    u = s["units"]
    ids = [i for i in u["trains"] if u["region"][i] in hpcbla.HPC_LABELS]
    laps = hpcbla.run_laps(s)
    if len(ids) < 5 or len(laps) < 6:
        return None
    if half_shift:
        laps = [(a + (b - a) / 2, b + (b - a) / 2, d) for a, b, d in laps]
    x = np.array([[np.count_nonzero((u["trains"][i] >= a) & (u["trains"][i] < b)) / (b - a) for i in ids]
                  for a, b, _ in laps])
    y = np.array([d == "LR" for _, _, d in laps])
    x = np.log1p(x)
    x = (x - x.mean(0)) / (x.std(0) + 1e-9)
    hits = 0
    for k in range(len(y)):
        keep = np.arange(len(y)) != k
        c1, c0 = x[keep & y].mean(0), x[keep & ~y].mean(0)
        hits += (np.sum((x[k] - c1) ** 2) < np.sum((x[k] - c0) ** 2)) == y[k]
    return hits / len(y), len(y)

hpc-bla-reactivation-post-sleep¶

Coordinated hippocampus and BLA activity patterns of the training run are reactivated during non-REM sleep after training, more than during non-REM sleep before it.

Joint patterns are the singular vectors of the hippocampus by BLA cross-correlation matrix of the run (50 ms bins); a pattern is significant when its singular value exceeds the 95th percentile of the largest one over 200 shuffles of the BLA trains. Reactivation strength is (z_hpc . u)(z_bla . v) in each Non-REM bin.

rng_rip = np.random.default_rng(61003)
started = time.time()
rows = []
for s in sessions:
    u = s["units"]
    if s["states"] is None or s["ripples"] is None or u is None:
        continue
    pre, post, _ = hpcbla.sleep_epochs(s)
    nrem = hpcbla.intersect(hpcbla.intervals_of(s, "Non-REM"), np.vstack([pre, post]))
    r = s["ripples"]
    keep = hpcbla.in_intervals(r["peak"], nrem)
    start, stop = r["start"][keep], r["stop"][keep]
    end = max(b for _, _, b in s["epochs"])
    used_bla = set(hpcbla.unit_sets(s)[1])
    for i in u["trains"]:
        if u["region"][i] not in hpcbla.BLA_LABELS:
            continue
        real, chance = hpcbla.ripple_modulation(u["trains"][i], [(start, stop), (start + hpcbla.CHANCE_SHIFT_S, stop + hpcbla.CHANCE_SHIFT_S)], end, rng_rip)
        rows.append({"session": s["session"], "rat": s["rat"], "unit": i, "ripples": int(keep.sum()),
                     "in_reactivation_set": i in used_bla and hpcbla.usable(s),
                     "observed": real["observed"], "expected": real["null_mean"], "p_up": real["p_up"], "p_down": real["p_down"],
                     "chance_p_up": chance["p_up"], "chance_p_down": chance["p_down"]})
mod = pd.DataFrame(rows)
mod["up"] = mod.p_up <= hpcbla.RIPPLE_ALPHA
mod["down"] = mod.p_down <= hpcbla.RIPPLE_ALPHA
mod["chance_up"] = mod.chance_p_up <= hpcbla.RIPPLE_ALPHA

How the analysis differs from the paper's. The full text was not available, so the methods are common choices fixed before the analysis: hippocampus and BLA as the hpc/HIP and bla/BLA labels, 50 ms bins, joint patterns from the singular vectors of the run's hippocampus by BLA cross-correlation matrix with a shuffle threshold, reactivation strength as the product of the two projections, ripple windows from the rip annotations, laps and the air-puff direction from the reward and puff times (there is no position), so a lap also holds the time spent at the end where it starts. The paper's session selection, cell classification, bin size and statistics are unknown, and 15 sessions from three rats are used; Rat09 has no hippocampal units or ripples here.

What was found about the dandiset.

  • The epochs table is in milliseconds although it says seconds; video timestamps are also in milliseconds, stated as seconds, and are not on the session clock.
  • In ten files the units index is wrong at the first unit: unit 1 begins with the end of unit 0 (a fall back in time after a multiple of 65536 spikes).
  • Seven files have no units table, sixteen no sleep states and fourteen no ripple events; the Rat09 files have no hippocampal units.
  • The unit region labels are undescribed short codes, in two cases for the same region in some files, and one file has no labels; the electrode table gives every channel as unknown.
  • There is no position tracking, only raw video frames, so the behaviour on the track cannot be measured here; the trials table is undescribed.

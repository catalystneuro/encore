Reproducing Amjad et al. (2025) from dandiset 002013¶

Paper. Amjad U, Mahajan S, Choi J, Shrivastav R, Murray R, Somich A, Coyne O, Schwerdt HN (2025). Microinvasive probes for monitoring electrical and chemical neural activity in nonhuman primates. ACS Chemical Neuroscience 16:2237-2247. doi:10.1021/acschemneuro.5c00071. This attempt used the full text, which is open access (CC-BY 4.0, PMC12183687).

Dandiset. DANDI:002013, version 0.261012.0921. The paper cites no DANDI version (it was published before the dandiset; its data statement points to Zenodo, doi:10.5281/zenodo.14826579). 0.261012.0921 is the only published version, so it is pinned. The draft lists the same three assets with the same sizes.

What the dandiset holds. Three sessions: Monkey T on 09/13/2024 (shape task, raw and trial-aligned FSCV from site c8dg), Monkey T on 09/26/2024 (direction task, raw ephys from c3bs and c3a and their bipolar LFP), and Monkey P on 08/13/2018 (raw ephys and sorted spikes from one site, with no trials or events). These are the example sessions of Figures 3 to 5. The second FSCV channel of Figure 3A (c8ds) is not in it.

Code read. The paper links two code deposits: extractFSCVspikes (GitHub schwerdtlab/extractFSCVspikes, tag v0.2.0-alpha, commit ea215c3; FSCV artifact removal for spike recording, used upstream of the data here) and Zenodo doi:10.5281/zenodo.10397773 (ISI_Plot.m, spikes_PCA.m, percent_recovery.mlx; these plot Figure 5B and 5C and take Plexon unit 1 as the sorted unit). Neither holds the dopamine PCA or the beta-power code. The dandiset links its conversion code (GitHub catalystneuro/schwerdt-lab-to-nwb, commit 6edf729), which shows how the trials, events, trial-aligned FSCV and LFP tables were built.

Outside input. One claim (zenodo-link) compares the dandiset with the paper's own Zenodo files: four lists of trial numbers and the beta power of one example trial. The data check also reads Monkey P's Neuralynx events file from the same deposit (session126_events.mat), for the time of its first event, which places the spike times on the raw signal's clock, and to show its event codes (fig5a-spike-reward). No other claim uses outside data.

Direction task: every successful trial has exactly one reward code and one side code, and large and small rewards occur on both sides, with the mapping switching in blocks, as the Methods describe. Shape task: forced and choice trials are exclusive, and only forced trials carry the feedback code (21), so success can be read only for forced trials, the only ones the paper shows. The session has no small-reward code (100). In successful forced trials the big-reward code (101) occurs exactly when the condition code 35 does, and never with 36. Two independent codes agree on the reward size, so a successful forced trial without 101 is taken as small. The codes' labels ("right cue reward condition 1/2") do not say this; the meaning is inferred from the data. The value cue fixation lasts 3.4 to 3.8 s (value cue to feedback) in both sessions.

How the analysis differs from the paper's. The paper's dopamine and beta code is not public; the beta filter and envelope are common choices, which match the paper's example trace at r = 0.94. Trial conditions are decoded from event codes; in the shape task small reward is inferred from the absence of the big-reward code, which the cue condition codes confirm. Dopamine is re-referenced at the value cue from the stored PCA output, without the original currents. Only the first 734 trials of the shape-task session have dopamine. The paper gives no statistics or windows for Figures 3 to 5; the tests and windows here were fixed before those analyses ran. Outside data come only from the paper's Zenodo deposit: the trial lists and example trace of zenodo-link, and Monkey P's events file, used in the data check for its clock offset.

What was found about the dandiset.

  • Each event is stored about five times in the events tables, once per overlapping 60 s trial window.
  • The trials tables hold no conditions; the shape task has no small-reward code, and the labels of codes 35 and 36 do not say they code reward size.
  • The trial-aligned FSCV table covers only the first 734 of 1468 trials; its columns have no units; the stored da is not referenced at the value cue.
  • The raw FSCV current is labelled amperes with values in the hundreds; its scan times are a regular grid from the first trial start; it cannot be matched to the trial-aligned series at any offset tried, or to the task at the stored times.
  • The bipolar LFP's conversion factor is wrong (values are already in volts).
  • The raw ephys of 09/26/2024 starts at 0 s but belongs 9831.35 s later on the trial clock.
  • Monkey P's spike times are 6800.666 s later than its raw signal's clock; its units table counts the unsorted and poor-quality spikes as unit 0; the poor-quality spikes are not in time order; the file has no trials or events, so Figure 5A cannot be made (the Zenodo events of this session are TTL values without names).

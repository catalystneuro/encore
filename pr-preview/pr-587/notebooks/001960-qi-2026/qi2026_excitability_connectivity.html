Reproducing Qi et al. (2026) from dandiset 001960¶

Paper. Qi, Parot, Wang, Pomeroy, Lavis and Cohen, "Large-scale all-optical electrophysiology links excitability and connectivity to circuit dynamics in vivo", bioRxiv preprint doi:10.64898/2026.10.05.756595 (version 1). The claims file claims/001960/10.64898-2026.10.05.756595.yaml was written from the full text of that preprint (main text, figure legends, Methods) and its supplementary information PDF, and checked by a second reader.

Dataset. DANDI:001960, version 0.261013.2016 (doi:10.48324/dandi.001960/0.261013.2016), streamed from the archive. The paper's Data availability statement names the dandiset without a version, and this is the only published version (the draft has the same 7 assets and the same size, 505,494,176,572 bytes), so the most recent published version is pinned, as the protocol asks when no version is cited.

Code read for methods. The paper's code, https://github.com/adamcohenlab/Qi2026WideAreaL1 at commit 181ad475520224c44d27903e7522d3e2aa76857d, which the claims file cites for many criteria. Every method detail is cited in the helper l1opto.py or in the cell that uses it.

The attempt has three notebooks, so that each runs well inside the time limit: this one (data check, intrinsic properties, connectivity, the effect of connections on spontaneous activity, and the NPY subtype differences in excitability and connectivity), qi2026_spontaneous.ipynb (the spontaneous sessions: SNR, Figure 4 and the Figure 6 behaviour claims) and qi2026_excitability_spontaneous.ipynb (Figure 5A to C and Supplementary Figure 22).

Figure 1 claims that need recordings not in the dandiset¶

The dandiset holds, per mouse, one spontaneous session, one intrinsic-excitability session and one connectivity session, plus a raw-movie excerpt of the M-YQ0201-29 spontaneous session (asset list above). It holds no JF585 against JF608 comparison (jf608-brighter), no wide-field against targeted images of one field (targeting-signal-to-background; the excerpt has a segmentation reference image and GFP and RFP maximum projections only), no 76-cell periodic stimulation session (fig1d-stimulation-fold-change), no lattice off-target experiment (off-target-length-constants), no spinning-disk z-stack (l1-sampling-density; only the 47-plane GFP maximum projection) and no 7.5x high-magnification recordings (highmag-footprint). lasso-off-target-correction¶

Correcting the IPSP matrix for spikes evoked in non-targeted cells by lasso regression changes little; the corrected and raw matrices correlate with R = 0.82 and fewer than 20% of significant IPSPs differ by more than 20%.

The dandiset does not store the paper's matrices, so both are rebuilt from the sparsePulseHad sessions with l1opto.pulse_responses and l1opto.lasso_correction, whose docstrings say where each choice comes from. One row per 20 ms pulse (the Methods' 14,400 trials, each cell targeted 243 to 480 times): the response of every cell, its mean normalized voltage 20 to 60 ms after onset minus the 25 ms before (assumption: a window around the IPSP peak of about 30 ms, since the paper's per-trial response is not given), and the evoked spikes of every cell. The model is R = S W (Supplementary Fig. 16A) with S the spikes per pulse of targeted cells (stored estimate) and of non-targeted cells within 100 um of a target (detected), fitted per postsynaptic cell by lasso with an intercept. Penalty readings (a) least cross-validated error, (b) the largest within one standard error (claims file); least squares as a variant. The comparison is over the 1755 pairs, the stored synaptic flags of both mice (955 and 800; the 2 without a stored amplitude are kept here since the rebuilt matrices do not need it), and pairs 60 to 400 um as a variant: Pearson R of corrected against raw, and the fraction of pairs whose corrected value differs from the raw by more than 20% of the raw. def binned_prob(kind, lo, width, mice=L.MICE):
    edges = np.arange(lo, 400 + 1e-9, width)
    if edges[-1] < 400:
        edges = np.append(edges, 400)
    conn = np.zeros(len(edges) - 1)
    tot = np.zeros(len(edges) - 1)
    for m in mice:
        M, q, QQ, D, sets = pair_sets(m)
        C = M["synaptic_connection" if kind == "syn" else "gap_junction_connection"]
        T = QQ & (D <= 400)
        for i in range(len(edges) - 1):
            b = T & (D >= edges[i]) & (D < edges[i + 1])
            conn[i] += (C & b).sum()
            tot[i] += b.sum()
    return (edges[:-1] + edges[1:]) / 2, conn / np.maximum(tot, 1), tot

def speed_fit(traces, centers):
    nT = traces.shape[0]
    c0 = nT // 2  # zero lag (MATLAB ceil(nT/2), 1-based)
    tau = np.arange(nT) - c0
    delays = np.full(traces.shape[1], np.nan)
    for i in range(traces.shape[1]):
        loc = np.zeros(nT)
        w = slice(max(0, c0 - 16), min(nT, c0 + 17))
        loc[w] = traces[w, i]
        pk = int(np.argmax(loc))
        ff = pk + np.arange(-2, 5)
        if ff.min() < 0 or ff.max() >= nT:
            continue
        co = np.polyfit(tau[ff], traces[ff, i], 3)
        grid = np.linspace(-2, 4, 10000)
        delays[i] = grid[np.argmax(np.polyval(co, grid))] * L.DT
    return delays

def integral_lost(tr):
    """Spikes lost from a control-subtracted rate waveform (per frame, spikes per trigger)."""
    t = tr - tr[fr(-10, -4)].mean()
    a = t[Z:Z + int(round(0.1 / L.DT)) + 1].sum()
    after = t[Z:]
    neg = np.nonzero(after >= 0)[0]
    stop = neg[neg > 2][0] if np.any(neg > 2) else len(after)
    b = after[:stop].sum()
    return a, b


def integral_gained(tr):
    t = tr - np.maximum(tr[fr(-4, -2)].mean(), tr[fr(2, 4)].mean())
    a = t[fr(-1, 1)].sum()
    lo_, hi_ = Z, Z
    while lo_ > 0 and t[lo_ - 1] > 0:
        lo_ -= 1
    while hi_ < len(t) - 1 and t[hi_ + 1] > 0:
        hi_ += 1
    b = t[lo_:hi_ + 1].sum() if t[Z] > 0 else 0.0
    return a, b

npy-classifier¶

Readings: cells pooled or per mouse; z-scored or raw features; most informative feature by the largest absolute coefficient (z-scored) or the largest drop in balanced accuracy when left out. def model(scale):
    """Logistic regression; for z-scored features the scaler is fitted on the training cells of
    each split only, so no test cell enters the scaling."""
    lr = LogisticRegression(max_iter=1000)
    return make_pipeline(StandardScaler(), lr) if scale == "z-scored" else lr


def split_scores(X, y, n_splits, seed, cols=None, scale="z-scored"):
    cols = list(range(X.shape[1])) if cols is None else cols
    sss = StratifiedShuffleSplit(n_splits=n_splits, test_size=0.2, random_state=seed)
    out = []
    for tr, te in sss.split(X, y):
        clf = model(scale).fit(X[tr][:, cols], y[tr])
        out.append(balanced_accuracy_score(y[te], clf.predict(X[te][:, cols])))
    return np.array(out)


def shuffled_chance(X, y, n_rep, seed, scale="z-scored"):
    r = np.random.default_rng(seed)
    out = []
    for k in range(n_rep):
        ys = r.permutation(y)
        for tr, te in StratifiedKFold(5, shuffle=True, random_state=k).split(X, ys):
            clf = model(scale).fit(X[tr], ys[tr])
            out.append(balanced_accuracy_score(ys[te], clf.predict(X[te])))
    return np.array(out)

How the analysis differs from the paper's. It starts from the stored products of the dandiset (connection calls, amplitudes, decay constants, trial-average and spike-triggered waveforms) and does not re-run the paper's detection and fitting, except where a claim needs what is not stored: the lasso correction rebuilds per-pulse responses and evoked spikes from the voltage and the stimulation (with an assumed response window), and the scatter control reads the first 40,000 frames of the raw-movie excerpt. The mixed model is fitted with a Python implementation of the same REML likelihood, and numpy's generator replaces MATLAB's in the bootstrap. Where the paper leaves a measure open (the interaction kernel, the integration windows of spikes lost and gained, the length-constant fits) the claims file's readings are run.

What was found about the dataset. Unit ids do not refer to the same cells across the three sessions of a mouse (cells with the same id lie a median 1.1 to 1.3 mm apart, and only 6 to 26 of 320 cells have a cell of the other session within 10 um), and the gfp_positive flags of a mouse differ between its sessions (156, 171 and 171 NPY+ cells in M-YQ0201-27; 135, 144 and 157 in M-YQ0201-29); nothing in the files says so. ipsp_decay_source_units and its standard error carry no unit (the values are consistent with seconds). The paper's connection counts and pair counts are those of the 60 to 400 um band of QC pairs, which the files do not state. The x and y origin is undocumented. Everything else checked (frame interval, pairwise table order and orientation, distances, clock of stimulus and response) agrees with the description.

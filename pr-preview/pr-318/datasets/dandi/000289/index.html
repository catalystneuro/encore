Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Metadata errorThe dandiset's related resources name the bioRxiv preprint "Bayesian inference in ring attractor networks" (10.1101/2021.12.17.473253 version 4) as the paper it supplements, but its description says the data belong to "Uncertainty and learning in a biological ring attractor" (Basnak et al., in preparation). The linked paper, published as Kutschireiter et al. 2023 (PNAS), is a theory paper that analyses none of these data, so the dandiset links no paper that uses them.
  • Metadata errorimaging_rate is 9.18 Hz in every file, but sub-4 and sub-10 (cue-contrast experiment) are imaged at 7.87 Hz (0.127 s frame interval, 9446 frames in 1200 s) with 14 planes, against 9.18 Hz and 12 planes in the other 13 sessions.
  • OtherIn sub-2 the trials table has five blocks (high, zero, low, zero, low) where every other fly of the cue-contrast experiment has six with two of each contrast. The last block lasts 405 s against about 200 s in the protocol, so it may hold a low and a high block labelled as one.
  • Description missingThe processing behind the stored dF/F is not described (which planes, the extent of each ROI, the baseline). The ROI masks are 2D, 3 to 11 pixels each (median 7), and the dF/F agrees with the raw imaging averaged in those masks only after spatial smoothing (median correlation over ROIs 0.66 without, 0.93 with a 4-pixel Gaussian, sub-1). The RoiResponseSeries unit is "na".

  • Published code disagreesIn the released single-population network (RNN_filter_Run) at the Bayesian ring attractor's parameters, additive neural noise lowers the mean bump amplitude (from 1.00 to 0.42 to 0.83 after 5 s, N 64 and 256, noise SD 1 and 2). The Results and SI Appendix section 5 say the noise causes a positive drift of the amplitude. Method differences

How the tests differed from the paper’s method or data, and the claims each applies to.

  • The notebook calls vM_Projection_Run with the keyword kappa_y, which the function names kappa_v; the keyword was renamed (claims file header). Nothing else in the cells was changed except the rate for the second reading.fig2h-bump-tracks-circkf
  • The paper does not say at which noise level the 35% is taken; the claims file names six readings, three of them match, and all are shown.fig3f-retuning-reduces-drop
  • The runs use a batched copy of RNN_filter_Run (bra.rnn_batch), the same update term by term; on the same noise draws it matches the released function to 4e-16.noise-effects-on-mu-and-kappa
  • The released RNN_filter_Run has no z parameter and raises NameError; z=None was added to its signature, as the claims file says.noise-effects-on-mu-and-kappa
  • The criterion asks for two sorts. Reading (b), by the ellipsoid body or gall position in the neuron's name, cannot be formed: hemibrain instance names give only the PB glomerulus (EPG(PB08)_L1, PEN_a(PB06a)_R2). The outcome rests on reading (a) alone.fig4b-connectome-motifs
  • Assumed, as the Fig. 4B legend counts "the total number of synaptic connections between each cell pair" with no threshold, that a connection is any synapse; the counts at 3 and 5 synapses are shown.fig4b-connectome-motifs
  • Assumed a measure of the offset, since the paper gives none. For each PEN1 neuron, it is the synapse-weighted circular mean position (period 8 glomeruli) of its EPG targets minus that of its EPG inputs, among same-side EPG neurons, with both sides shown.fig4b-connectome-motifs
  • The connectome is the public hemibrain v1.2 export, not v1.2.1 as in the legend. neuPrint, which serves v1.2.1, now requires a personal API token for all data.fig4b-connectome-motifs
  • The dandiset holds data of a separate study, not of this paper; the paper does not test its prediction.prediction-bump-amplitude-cue-reliability
  • Raw fluorescence is read from 10% of the frames (25 volumes every 250), averaged over planes and smoothed in the plane (Gaussian SD 4 pixels) before averaging in each ROI mask; the baseline is each ROI's 10th percentile. The projection and the smoothing were chosen as those that best reproduce the stored dF/F (median correlation over ROIs 0.93, against 0.66 without smoothing). Smoothing 0 and 2 pixels, baselines at the 5th and 20th percentile and the baseline-divided signal are shown as variants.prediction-bump-amplitude-cue-reliability

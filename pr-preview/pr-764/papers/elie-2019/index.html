    over all stimuli and model neurons, the average error was less than 0.02 spikes/ms ... in the Temporal neuron ( Fig 1C & 1F ) a peak instantaneous information of 0.5 bits is expected as 1 out 4 stimuli will be almost perfectly discriminated

    Results, Time-varying information for model neurons, paragraphs 2 and 3; Figure 1

    The paper's code repository holds one model cell (ModelCell_InfoCumInfo_Tutorial.mat), a temporal neuron: 4 stimuli, 10 trials, 400 ms, each stimulus driving a response at a different time. The rate and onset neurons of Fig 1 are not there, so the criterion's 'each model neuron' can be checked for one of three. On it all three conditions hold. The mean absolute difference between the KDE and the model rate is 0.009 spikes/ms (per stimulus 0.0075 to 0.0103; RMS 0.016), below 0.02. Under the paper's procedure, as its code runs it, the bias-corrected cumulative information reaches 1.982 bits (14 bins at or above 1.8, last bin 1.884; all 40 bins computed, largest error 0.234 bits, two bins at 5,000,000 samples), at least 1.8; the MATLAB tutorial's saved results with the same procedure give 1.981 and 1.894. The peak bias-corrected instantaneous information is 0.520 bits at 140 ms, within 0.5 +- 0.05. The simplified procedure (one set of 200,000 samples for all bins, jackknife set k for every stimulus) gives 1.928 bits and a peak of 0.519, and the model rates give a largest cumulative information of 1.990 bits (last bin 1.956) and a peak of 0.540. With independent draws per jackknife replicate, which is not the code's procedure, the cumulative information rises to 2.206 bits and ends at 0.803. The Python KDE matches the KDE saved by the MATLAB tutorial to 0.0004 spikes/ms on average (largest 0.0033).

    How the test differed from the paper’s method

    • Data, the paper's tutorial model cell only (data elsewhere, GitHub julieelie/PoissonTimeVaryingInfo at commit 978020328321c7ed83be12c0152bed85ec77e218); the rate and onset model neurons of Fig 1 are not published.
    • KDE, the Python port of ssvkernel in the adaptivekde package (1.2.0), in place of the MATLAB ssvkernel the paper cites (reference 42); its output matches the MATLAB KDE saved with the tutorial (mean difference 0.0004 spikes/ms).
    • Model rate, the tutorial's Input_Spike_count read as the mean count per 10 ms bin and divided by 10 for spikes/ms; its rows sum to 12.0, 11.0, 9.0 and 10.5 spikes per trial for the four stimuli, against 12.1, 8.3, 8.5 and 11.4 observed.
    • Cumulative and instantaneous information as the paper's code computes them (Methods, The cumulative information: 'Monte Carlo samples were chunked in groups of 100,000 samples ... Sampling stopped when the standard error was below 0.2 bits or at a max number of samples set to 5,000,000 samples. If the error at the maximum number of samples was greater than 0.6 bits ... the calculation was not performed for any successive time points'; Bias correction, NB = 20; cumulative_info_poisson_model_MCJK_wrapper.m, cumulative_info_poisson_model_calculus_MCJK.m and Tutorial_TimeVarying_Information.mlx at the pinned commit). Taken from the code, as the text does not give them: the jackknife sets are evaluated on the Monte Carlo samples drawn for the full data, each bootstrap pairs the jackknife sets of the stimuli at random, the error is the square root of the mean over bootstraps of the variance of the pseudo-values N I - (N-1) I_k, and the wrapper stops at 3 x 0.2 bits. NB = 20 follows the paper; the tutorial uses 10 for the cumulative and 100 for the instantaneous information.

Notes on the paper

What the attempts found about the paper itself: a method or rule it does not give, a place where it disagrees with itself, published code that does something else. What they found about the data is on each dataset’s page.

  • Methods not availableThe paper selects its 404 units by a decoding analysis it does not describe, citing Elie and Theunissen 2015, and its code repository holds neither that selection nor the selection of the 337 units, the locally adaptive KDE step, the exponential fits or the CII. The single-unit SNR defined in the Methods, computed from the snippet files, does not recover the 914 units. Question for the authors: can the lists of the 914, 404 and 337 units be published, with the file names of the data set, and on which snippets and with which noise measure was the SNR computed?
  • OtherThe paper gives NB = 20 bootstraps of the jackknife for the error on information, while the tutorial of its code repository uses 10 for the cumulative and 100 for the instantaneous information. The text does not say that the jackknife sets are paired across stimuli at random in each bootstrap, nor that the jackknife sets are evaluated on the Monte Carlo samples of the full data; the code does both.

Method differences

How the tests differed from the paper’s method or data, and the claims each applies to.

  • Data, the paper's tutorial model cell only (data elsewhere, GitHub julieelie/PoissonTimeVaryingInfo at commit 978020328321c7ed83be12c0152bed85ec77e218); the rate and onset model neurons of Fig 1 are not published.fig1-model-neurons
  • KDE, the Python port of ssvkernel in the adaptivekde package (1.2.0), in place of the MATLAB ssvkernel the paper cites (reference 42); its output matches the MATLAB KDE saved with the tutorial (mean difference 0.0004 spikes/ms).fig1-model-neurons
  • Model rate, the tutorial's Input_Spike_count read as the mean count per 10 ms bin and divided by 10 for spikes/ms; its rows sum to 12.0, 11.0, 9.0 and 10.5 spikes per trial for the four stimuli, against 12.1, 8.3, 8.5 and 11.4 observed.fig1-model-neurons
  • Cumulative and instantaneous information as the paper's code computes them (Methods, The cumulative information: 'Monte Carlo samples were chunked in groups of 100,000 samples ... Sampling stopped when the standard error was below 0.2 bits or at a max number of samples set to 5,000,000 samples. If the error at the maximum number of samples was greater than 0.6 bits ... the calculation was not performed for any successive time points'; Bias correction, NB = 20; cumulative_info_poisson_model_MCJK_wrapper.m, cumulative_info_poisson_model_calculus_MCJK.m and Tutorial_TimeVarying_Information.mlx at the pinned commit). Taken from the code, as the text does not give them: the jackknife sets are evaluated on the Monte Carlo samples drawn for the full data, each bootstrap pairs the jackknife sets of the stimuli at random, the error is the square root of the mean over bootstraps of the variance of the pseudo-values N I - (N-1) I_k, and the wrapper stops at 3 x 0.2 bits. NB = 20 follows the paper; the tutorial uses 10 for the cumulative and 100 for the instantaneous information.fig1-model-neurons

    Discussion, paragraphs 1 and 6; Figures 4B and 7B

    Counting pairs of coincident PT5B cells, the parkinsonian rest file has more significant synchrony than the control rest file under every window reading, 3.8 to 3.98 s against 0.8 to 1.65 s against independent cells, and 4.0 s against 3.2 to 3.99 s against the null that keeps each cell's active bins (a small difference for slid windows, 4.0 against 3.98 and 3.99 s). Counting coincident bins or their spikes, both files have 0 s, but those counts are at their ceiling in every file (every 1 ms bin of the control rest file holds two or more PT5B cells) and miss both synthetic synchrony cases, so they cannot test the claim. The outcome was not reproduced before the first verification, on the bin count alone; it rests on the pair count as an assumption. The durations themselves do not match fig4 and fig7 (both not reproduced). Two caveats bear on it. Under the count-preserving null the comparison is at its ceiling (4.0 against 3.98 and 3.99 s for slid windows), and on independent cells that null's slid windows cover 0.64 to 0.75 s by chance, so the comparison rests in effect on the rate null, which is conservative. Both pair nulls take each cell's spikes as spread evenly over its 100 ms window, so the excess partly measures how strongly the PT5B rhythm modulates firing within a window - the median observed over expected pair count is 1.38 to 1.41 at parkinsonian rest against 1.04 to 1.05 at control rest, and the largest PT5B SCH spectral power above 5 Hz is 31.5 times higher. The paper's own Poisson window null probably shares this property.

    How the test differed from the paper’s method

    • The claims file does not say how a window's coincidences are counted. Four counts were run (m1sim.unitary_events) - coincident 1 ms bins with a Poisson joint-surprise test (Grun et al. 2002), the spikes in them, and pairs of cells firing in the same bin against independent cells at the window's rates or against a null that keeps each cell's active bins in the window. The last three take the normal tail with the exact mean and variance of their null, a stated choice. Each count's chance level was measured on independent Poisson cells.
    • Assumed - the pair count, the one count of the four that can exceed its expectation on these data. The Methods ask for "synchronous spikes significantly above the expected number of synchronous spikes for the neuron population size and firing rates", which a count capped at the window length cannot show. Grun's coincidence count is defined for given neurons, and summing it over all pairs of PT5B cells extends it to the population.

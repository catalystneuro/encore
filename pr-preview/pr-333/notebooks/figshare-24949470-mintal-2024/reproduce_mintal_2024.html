Checks of the description against the data:

  • The MD5 of every streamed file equals the one the archive lists.
  • The CSV has 134,699 rows and the 69 columns of the data dictionary, in its order. "No opinion" is the string NA in S1 to S39, not an empty string as the paper's Data cleaning says; unanswered statements are -1, as described. The S values are 0, 25, 50, 75 and 100 only.
  • UN2 to UN4 hold the three most salient statements as codes such as 6-1 (the dictionary's two-digit identifiers, block and item), not as S numbers. UN5 to UN15 and UN16 to UN26 are 0/1, as described. Gender, age and education are empty together in the same rows; the dictionary gives no categories, and the values are those of the R code's validation rules. The age labels use a hyphen ("18-20") where the paper prints an en dash; they are the same labels.
  • Table 1 of the paper shows 2023-10-09 08:57:38 as a sample timestamp: it is the first row of the file, which is sorted newest first, and the last date in it. The timestamps cover 5 September to 9 October 2023 (see collection-window).
  • EMAIL_ID repeats, as the paper says it may. The README says each row is "a unique respondent"; the paper says each row is a unique response. The repeats show that some respondents answered more than once.
  • The party workbook has one sheet with 429 coded rows and a legend of the categories below them. Its "Statement no." column disagrees with the English wording for 99 rows: the rows worded as statements 16 to 24 are numbered 22, 23, 24, 16, 17, 18, 19, 20, 21 for every party. The recoded CSV follows the wording, and so do the paper's Figures 2 and 3 (see uni-and-landscape-placements), so the wording is taken as right and the number as wrong. All analyses here number statements by their wording.
  • The data dictionary lists "Self-placement source" as a column; it is empty in all 429 rows.
  • This is survey data with one timestamp per response and no trial structure, so the protocol's check that all streams share one clock does not apply.

Row selections¶

Four sets of rows are used, as the claims file names them:

  • raw: all 134,699 rows;
  • paper: the paper's cleaning (Technical Validation, Data cleaning): rows with -1 in any of S1 to S39 removed;
  • code: the deposited R code's cleaning, which also removes rows that give the same answer to all 39 statements (same_response_rows in Volebny_Kompas_code.R), a step the paper does not mention;
  • code_email: the R code's rows for the factor analysis, code rows whose EMAIL_ID is given and occurs once.

    return out

def nan_cityblock(M):
    n = len(M)
    D = np.zeros((n, n))
    for i in range(n):
        for j in range(i + 1, n):
            ok = ~np.isnan(M[i]) & ~np.isnan(M[j])

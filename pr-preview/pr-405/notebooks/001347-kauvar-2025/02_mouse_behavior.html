Mouse eyepuff behaviour: Kauvar, Richman, Liu et al. (2025), dandiset 001347¶

Paper. Kauvar IV, Richman EB, Liu TX, et al. (2025). Conserved brain-wide emergence of emotional response from sensory experience in humans and mice. Science 388, eadt3971. doi:10.1126/science.adt3971. The claims file was written from the version of record (29 May 2025) with Materials and Methods, figure legends and both supplement PDFs, including Table S3.

Dandiset. DANDI:001347, version 0.250528.0702, the only published version. The paper cites the dandiset without a version, so the latest published version is pinned (see dandi_io.py). The mouse spiking data of the paper are in dandiset 001326; this notebook reads it only to count its sessions.

What this notebook reads. The 142 head-fixed mouse behaviour files sub-mouse/sub-mouse_ses-<experiment id>_behavior.nwb (one eye-closure trace at 200 Hz each) and the 10 Neuropixels-rig behaviour files sub-m<mouse>-<id>/..._ses-puff_behavior.nwb.

Outside input. The sub-mouse files carry no drug, dose, mouse, sex, day or pressure. The experiment lists that give these labels are in the paper's scripts (mouse_eyepuff/scripts/fig1_*.py) in the code record Zenodo 10.5281/zenodo.14920570 (kauvar-richman-liu-2025_zenodo.zip, md5 bd1fb567121aaf0291337783df57bcfc, git commit b873ca5). The notebook fetches the zip at run time, checks its md5 and parses the lists with ast. These lists only name codes the dataset holds, so the claims that use them are data: with_labels, and the link claim mouse-session-labels-link tests them. The processing follows ketmouse/eye_trace_utils.py of the same record, reimplemented in mouse_eye.py.

No random numbers are drawn anywhere in this notebook.

Recordings deposited twice. Every pair of sessions is compared: identical arrays (md5), identical first 20 trials, any identical 81-s trial, and the Pearson correlation of the first 20 trials.

Trial clock. The files have no timestamps or trial table; the code takes each 81-s block to start 6 s before the first puff, with puffs every 3 s. If that holds, the early response (0.1 to 0.2 s after a puff minus the 0.1 s before it) is large at the eight puff times and small at the mid-points between puffs. This is checked on the preinfusion trials of every 40-trial session and every trial of the 20-trial sessions.

Every acquisition of the 10 files is listed with its shape and, for scalars and short arrays, its value. events-on are trial onsets in frames at fps; the check confirms that eyeclosure_by_trial is eyeclosure cut from 3 s before each onset (w_pre) to 70 s after (w_post), with t_trial_eyeclosure running from -8 s, so that the first puff is 5 s (led_delay) after each onset, as analysis.py assumes (events['on'] + 5*fps).

Differences from the paper's method. The processing reimplements the paper's code, not the Methods' text where they differ: the scale factor is one (the code's) for the main values, with the Methods' 1/(1 - baseline) shown for absolute values; the infusion trials are the code's 23 to 37 (Open I a), with trials 23 to 40 as reading (b), since the sub-mouse files carry no trial times for the 3-min rule.

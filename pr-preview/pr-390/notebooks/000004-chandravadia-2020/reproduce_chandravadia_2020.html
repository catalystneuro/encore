Reproducing Chandravadia et al. (2020) from dandiset 000004¶

Paper. Chandravadia N, Liang D, Schjetnan AGP, Carlson A, Faraut M, Chung JM, Reed CM, Dichter B, Maoz U, Kalia SK, Valiante TA, Mamelak AN, Rutishauser U (2020). A NWB-based dataset and processing pipeline of human single-neuron activity during a declarative memory task. Scientific Data 7, 78. doi:10.1038/s41597-020-0415-9. The article is open access (CC BY 4.0); this attempt used its full text, including Tables 1 and 2 and Online-only Table 1.

Dandiset. DANDI:000004, version 0.220126.1852. The paper cites no DANDI version: its data statement points to the Open Science Framework (doi:10.17605/OSF.IO/HV7JA), and the dandiset was created on 2020-03-16, after the paper appeared. The archive has two published versions, 0.220126.1851 and 0.220126.1852, published a minute apart with the same 87 assets (checked in the first data cell) and metadata that differs only in version fields. The most recent is pinned. The draft holds the same files.

What the dandiset holds. One NWB file per session: 87 sessions of 59 subjects, with the trials table, the TTL event stream, the stimulus images, the spike-sorted units with mean waveforms, and the electrodes table. There are no raw broadband recordings.

Code read. rutishauserlab/recogmem-release-NWB at commit 1d95162 (2025-01-14): the Python and MATLAB export and analysis code, the session list defineNOsessions_release.ini, and plotFigure5.ipynb. The session list and the demo script python/export/demo/export.py are fetched from that commit where the notebook relies on them, and the lines used are printed. The code settles what the Methods leave open (the AUC, the z-ROC, the high/low confidence split, the label coding). Where it disagrees with the Methods (the analysis window, and correct trials only for memory selectivity), the Methods give the main result and the code's choice is shown as a variant. plotFigure5.ipynb writes the Figure 5f percentages into the plot as constants, so the code does not show how they were computed.

Outside inputs. Online-only Table 1 of the paper is copied into the helper module as text, to compare with the files' subject metadata. Table 1 of Faraut et al. 2018 (Scientific Data 5, 180010, doi:10.1038/sdata.2018.10), the paper describing the earlier release, is copied the same way; it lists that release's sessions and is used only to mark which sessions of the dandiset are new (previous-release-link and previous-release-additions).

How the analysis differs from the paper's.

  • Selectivity uses the Methods' window (200 to 1200 ms) and, for memory selectivity, all 50 new and 50 old trials. The paper's code uses 200 to 1700 ms and correct trials only; with these choices the counts are 343 VS, 147 MS and 26 dual cells, against the paper's 343, 146 and 26. The MS, dual and Figure 5f outcomes rest on the Methods' description, and come from its disagreement with the code.
  • The z-ROC slope is averaged over the 81 sessions whose interior points allow a fit; the six sessions left out are shown as a variant.
  • The bootstrap is the code's algorithm with a fixed seed; a second seed moves the main MS count from 110 to 118 and the code's choices from 147 to 149.
  • The paper names no test for the ROC asymmetry or for "comparable" proportions; a t-test of the z-ROC slope against 1 and Fisher's exact test were chosen.
  • Accuracy by confidence uses a paired test, as the Results say; the code runs an unpaired one, shown as a variant.
  • Units are counted per file, as in the paper; counts with the duplicated spike trains of sessions 44 and 55 dropped are shown.
  • The earlier release's sessions are taken from Table 1 of Faraut et al. 2018, not from its Dryad archive, which a script could not fetch.

What was found about the dandiset.

  • The new/old label is coded 1 = old, the reverse of the paper's text and the files' own column description. A user following the description would compute an AUC of 0.25.
  • Sessions 43 and 44, and 54 and 55, hold identical spike trains: the same neurons are deposited under two sessions, so 55 of the 1864 units are repeats. Session 55 also repeats session 54's learning block.
  • Seven sessions have 50 encoding trials and one has 97, where the paper describes 100; part of the images later shown as old are missing from their encoding blocks.
  • Electrode impedance is empty for every electrode, coordinates are missing for 99 electrodes, the isolation distance is NaN for 493 units, and SNR is not finite for 86.
  • Spike times are unsorted in 13 units, and two units of session 58 hold each spike time twice.
  • Age or sex differ from Online-only Table 1 for three subjects. One session date keeps its day, and another is set to 2000-01-01.
  • Event codes outside Table 1 occur in nine files and experiment ids outside Table 2 in four.
  • The Methods give 89 sessions where the paper's table and the files have 87, and the unit count is 1864 where the paper gives 1863.
  • The paper's Figure 3 example neuron is from session 144, which is not in the dandiset. The paper's code names NOID 144 as a recording of subject T103, whose one session here is 2009; one unit of session 2009 on channel 140 in the right hippocampus prefers phones, but no record maps 144 to 2009.
  • Session 98 of the earlier release (subject H48) is not in the dandiset; its section in the code's session list is commented out. The new sessions hold 325 units, not the 288 the paper gives.

Clock check. If spikes and presentations share a clock, many units' counts in the 30 to 200 ms window differ between stimuli (a one-way ANOVA over the stimuli of the file, per unit), and with the onsets moved by -1.3 s, onto other presentations or the gaps, that contrast should fall to the false-positive rate. Per file, the fraction of units with p < 0.01 is compared between true and shifted onsets; the clock is taken as established in a file when the true fraction exceeds 1% with a binomial p < 0.01 and exceeds the shifted fraction. The same cell also counts, per file, the units that fire more on stimulus presentations than on blanks (one-sided Mann-Whitney, p < 0.01), which separates a response to stimulus onset from selectivity among the stimuli.

def stim_key(s):
    tr = s["trials"]
    k = s["asset"]["kind"]
    other = {"SL": "luminance", "TX": "mode", "SP": "position"}[k]
    sel = (tr.cond_ID != 0).to_numpy() & tr.stim_ID.notna().to_numpy()
    if k == "SL":
        sel &= tr.luminance.isin([V.DARK, V.BRIGHT]).to_numpy()
    key = tr.stim_ID.astype(str) + "_" + tr[other].astype(str) + ("_" + tr.rotation.astype(str) if k == "SL" else "")
    return sel, key.to_numpy()

clock = []
for s in sess:
    sel, key = stim_key(s)
    groups = [np.flatnonzero(sel & (key == g)) for g in np.unique(key[sel])]
    groups = [g for g in groups if len(g) > 1]
    fr = {}
    for name, cnt in (("true", s["counts"]), ("shifted", s["shifted"])):
        with np.errstate(all="ignore"):
            p = np.array([stats.f_oneway(*[cnt[u, g] for g in groups]).pvalue for u in range(cnt.shape[0])])
        fr[name] = np.nanmean(p < 0.01)
    n = s["counts"].shape[0]
    # onset response: counts on stimulus presentations against blank presentations, per unit
    blank_ = (s["trials"].cond_ID == 0).to_numpy()
    with np.errstate(all="ignore"):
        p_on = np.array([stats.mannwhitneyu(s["counts"][u, sel], s["counts"][u, blank_], alternative="greater").pvalue
                         if blank_.sum() > 1 else np.nan for u in range(n)])
    clock.append({"kind": s["asset"]["kind"], "date": s["asset"]["date"], "units": n, "true": fr["true"], "shifted": fr["shifted"],
                  "onset_resp": np.nanmean(p_on < 0.01),
                  "p_binom": stats.binomtest(int(round(fr["true"] * n)), n, 0.01, alternative="greater").pvalue})

def all_pairs(c):
    M, S2, INV, RATE, ses, mk, dep = [], [], [], [], [], [], []
    for (m_, d), r in shape.items():
        if r["keep"].sum() == 0:
            continue
        arr, nrep = r["arrays"][c]
        mx, s2, inv = V._moments(arr[r["keep"]], nrep)
        M.append(mx); S2.append(s2); INV.append(np.broadcast_to(inv, mx.shape)); RATE.append(r[c]["rate"])

def pen_auc(key, stim=0):
    s = by_date[key]["SL"]
    tr = s["trials"]
    keep = shape[key]["keep"]
    lum = tr.luminance.isin([V.DARK, V.BRIGHT])
    hor = (lum & (tr.stim_ID == stim) & tr.rotation.isin([0, 180])).to_numpy()
    ver = (lum & (tr.stim_ID == stim) & tr.rotation.isin([90, 270])).to_numpy()
    au = np.array([V.auc(s["counts"][u, ver], s["counts"][u, hor]) for u in np.flatnonzero(keep)])
    d = shape[key]["depth0"][keep]
    bins = (d // 100).astype(int)
    b = pd.Series(au).groupby(bins).mean().sort_index()
    return au, b, int(hor.sum()), int(ver.sum())

position-optimal-consistent¶

In 33 M2 penetrations (723 neurons), Isimilarity computed from responses at each neuron's optimal stimulus position correlates positively with Isimilarity at the aggregate RF center (r = 0.325).

The files number the five positions 0 to 4 without saying which is the center. The center is taken to be the position with the largest mean response over the penetration's responsive neurons, since the aggregate RF center is where the stimuli were centred on the neurons' RFs (an assumption); how often each position wins is printed. Neurons are those responsive in the main shape test (the same units, by unit_ID); responsiveness within the position test is a variant. Penetrations enter with 4 or more neurons, since a line needs 3 other neurons with reliable similarities (Materials and Methods, Clusters of similarly tuned neurons); this follows from the line rule and is not a separate choice. Optimal position: the largest variance-to-mean ratio of mean rates over the 15 shapes (Materials and Methods, RF localization, paragraph 2).

def optimal_isim(p, keep, tag):
    A, rates_p = p["A"], p["rates"]
    with np.errstate(invalid="ignore", divide="ignore"):
        disp = np.nanvar(rates_p, axis=2, ddof=1) / np.nanmean(rates_p, axis=2)
    best = np.nanargmax(np.nan_to_num(disp, nan=-1), axis=0)
    R = max(A[q][0].shape[2] for q in range(5))
    pad = {q: np.pad(A[q][0], ((0, 0), (0, 0), (0, R - A[q][0].shape[2])), constant_values=np.nan) for q in range(5)}
    nreps = np.stack([A[q][1] for q in range(5)])
    # each neuron uses its own position; the repeats per stimulus are taken as the smallest over the
    # positions in use, so that every resampled repeat exists (the files have 8 at every position)
    nrep = nreps[np.unique(best)].min(0)
    arr = np.stack([pad[best[u]][u] for u in range(len(best))])[:, :, : nrep.max()]
    for j in range(arr.shape[1]):
        arr[:, j, nrep[j]:] = np.nan
    r, lo, hi = V.similarity(arr[keep], nrep, tag)
    out = {"best": best}
    for rd in "ab":
        out[rd] = V.isimilarity(r, V.reliable(r, lo, hi, rd), p["depth0"][keep], np.ones(keep.sum(), bool))
    return out

How the analysis differs from the paper's. Depth is the best channel's position in 20 um steps, as the files give it, not the template center of mass. The noise-corrected correlation is written here from the Methods' description and Pospisil and Bair (2021), for unequal repeats; the paper's MATLAB code is not public. The bootstrap interval's level (95%) and the reading of "confidence limit > 0.5" (width or half-width) are not stated, and both readings are run. The bootstrap of the corrected estimator sits below the point estimate (resampling with replacement inflates the noise it corrects for); only its width is used. Example penetrations are found by the files' pen_ID labels, which give the paper's neuron counts for M2p6, M1p12 and M2p28. The label p09 gives 18 shape-responsive neurons against Figure 11's 16 (a reader confirmed that 16 is the matrices' count), so the claims file's 10% rule takes the files' p12 as M2p9. The paper's counts of neurons without a regression line (2 of 1,850 shape and 48 of 979 texture neurons) favour the half-width reading of the reliability rule (64 and 62 here) over the width reading (140 and 304); the claims file accepts either, and a reader is asked. Of the 64 shape neurons without a line under the half-width reading, 62 have too few defined similarities (the corrected variance is not positive), so the remaining gap to the paper's 2 points to the estimator's handling of weakly tuned neurons, not to the reliability rule. The similarity takes the noise of two simultaneously recorded neurons as independent; their noise correlations are small but largest for near pairs (0.072 within 100 um), and subtracting them lowers the significant-Isimilarity counts by about a third. The aggregate RF center of the position test is inferred from the population response; the claims that need it are shown under every choice, and position-optimal-consistent is reproduced only if the center is not position 4.

The clock check (stimulus tuning at the true onsets, none at shifted onsets) holds in 152 of 159 files; it is not established in five M1 texture files, where 0% to 12% of units are tuned, and in the two single-unit files of 2021-05-29.

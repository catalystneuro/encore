Figure 4: bulk RNA-seq of CA2 (GEO GSE317499)¶

DESeq2 1.44 in R is replaced by pydeseq2, its Python port, with DESeq2's defaults. R's results() tunes independent filtering at alpha 0.1, while pydeseq2's DeseqStats defaults to 0.05, so alpha 0.1 is set explicitly; filtering at 0.05 is shown as a variant for the DEG counts. The claims file names the readings: (a) one model per contrast on its own samples, or (b) one model on all 16 samples with a four-level group factor; each with (c) unshrunken log2 fold changes or (d) apeglm-type shrinkage. All four are run. The Methods do not say which model was used (Methods 2.5 names only DESeq2 1.44.0). How the analysis differs from the paper's: DESeq2 1.44 in R is replaced by pydeseq2 0.5, with independent filtering tuned at R's alpha 0.1; it was not compared with R, which the entry's environment cannot lock. The paper's DESeq2 model, GO enrichment tool, background, term sizes and GO release are not stated, so every reading the claims file names is run, with two term-size limits for GO, and a claim whose readings disagree is blocked as methods_underspecified; the GO release is 2024-06-17, with releases 2024-01-17 and 2025-03-16 run as a variant for the ECM claim. The RNA-seq data are GEO's counts, not data in the dandiset.

What was found about the dataset:

  • All 481 NWB files (185,480 bytes each) hold only file-level metadata. No image, ROI, table or measurement is deposited, though the description says the dandiset includes "immunohistochemical imaging data quantifying PNN integrity".
  • The 175 behaviour videos are MP4 files outside NWB with no subject, genotype, treatment, trial or phase labels; several arenas share each video. The scored interaction and exploration times are not deposited.
  • The object recognition videos are deposited four times (Figures 2I, 2J, 2K and S7), and in each set Trial 6 and Trial 7 are the same file: 7 names per set, 6 recordings.
  • The description says the dandiset includes bulk RNA-seq data; it holds none, and they are in GEO GSE317499. The description also keeps a placeholder sentence ("GSEXXXXX").
  • The NWB subject is a group label, not an animal (82 subject_ids for 481 files, up to 31 files per subject_id); sex is "U" in 476 files although the paper used male mice for behaviour and both sexes for IHC.

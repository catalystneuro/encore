Reproducing Ishii et al. (2025) from dandiset 001249 and the authors' Figshare deposit¶

Paper: Ishii, Cortese, Leng, Lee, Bayless, Bhattacharya, Muir, Stuber (2025), "Post-ejaculatory inhibition of female sexual drive via heterogeneous neuronal ensembles in the medial preoptic area", eLife 12, RP91765, doi:10.7554/elife.91765.

Dataset: DANDI:001249, version 0.241109.2357 (doi:10.48324/dandi.001249/0.241109.2357), 14 NWB files of whole-brain light-sheet volumes, one per brain. The paper does not cite a version of the dandiset; this is the only published version (the draft has the same 14 assets and was last modified before it was published), so it is the version pinned (protocol, author step 1.3).

Outside data: The claims file marks every claim outside Figure 2 data: elsewhere: the paper deposited those data on Figshare, doi:10.6084/m9.figshare.27642768.v1 (version 1), read here in place. The MD5 of each zip read is printed below and must match mpoa.FIGSHARE_FILES.

Text: The claims file was written from the version of record (eLife RP91765, 5 March 2025), with the code at github.com/stuberlab/Ishii-MPOA-Ejaculation-2023, commit 4e98c43. The code's notebooks are named by the preprint's figures: "Figure S5" is the published Figure 3, "Figure 3, 4, 5, S6, S7, S8" the published Figures 4 to 6, "Figure 6" the published Figure 7, and "Figure S9", "S10", "S11" the published Figure 7, figure supplements 1 to 3. The dandiset¶

Every file is opened by streaming. For each, the metadata, the shape of both image series, and one plane from the middle of the stack (TRAP channel in full, background channel as a central 1024 x 1024 crop) are read: their intensity ranges and a checksum of the TRAP plane, to look for brains deposited twice. The time to read a plane gives the cost of the whole-brain analysis.

Figure 1: sexual motivation after male ejaculation (Figshare)¶

Tests as Figure 1.ipynb runs them: AnovaRM with one row per animal and epoch, then pairwise_tukeyhsd over the epochs (which treats them as independent groups), and scipy's wilcoxon for pre against post. Pairs are matched by animal id here; the code pairs by row order, and the check below shows the two agree. scipy 1.18 picks the exact or the normal approximation by itself; where the data have ties or zero differences the printed p of the paper came from the normal approximation, so both are printed.

def rm_and_tukey(df, value, subject, within, label):
    r = mpoa.rm_anova(df, value, subject, within)
    print(f"{label}: RM ANOVA F({r['df1']:.0f},{r['df2']:.0f}) = {r['F']:.3f}, p = {r['p']:.3g}")
    means = df.groupby(within)[value].mean()
    print("  means", means.round(3).to_dict())
    print(mpoa.tukey(df[value], df[within]).to_string(index=False))
    return r


def wilcox(x, y):
    out = {}
    for m in ["auto", "approx"]:
        out[m] = stats.wilcoxon(x, y, method=m).pvalue
    return out

Transitions: the code's column, isolation zone entries per 10 min; the legend's "number of transitions between the zones" read as entries into either zone (Number_of_Entry_per_10min) is shown as a variant. Time: the legend's "average time spent in the isolation zone", which the code computes as the mean visit duration from merge_df. The column named time per 10 min holds the same values (data check), so it is not a separate reading.

def per_section(df, num, den=None):
    """Per mouse, region and section: share of cells with all of `num` among cells with all of
    `den` (all cells when den is None)."""
    d = df if den is None else df[df[den].all(axis=1)]
    return d.assign(hit=d[num].all(axis=1).astype(float)).groupby(
        ["ID", "region", "Stim", "section"]).hit.mean().rename("value").reset_index()


def per_mouse(sec):
    return sec.groupby(["ID", "region", "Stim"]).value.mean().reset_index()


def ttests(pm, key, label):
    rows = []
    for k, d in pm.groupby(key):
        a = d[d.Stim == "Appetitive"].value
        b = d[d.Stim == "Post_ejaculatory"].value
        r = stats.ttest_ind(a, b)
        rows.append(dict(**{label: k}, n_app=len(a), n_post=len(b), app_mean=a.mean(), post_mean=b.mean(),
                         t=r.statistic, df=len(a) + len(b) - 2, p=r.pvalue))
    out = pd.DataFrame(rows)
    out["p_bonf"] = mpoa.bonferroni(out.p)
    return out

def saline_cno(df, groups, cols):
    rows = []
    for name, col in cols:
        rs_p, sr_p = [], []
        for gname in groups:
            sal, cno, ids = mpoa.paired(df[df.Stim_Group == gname], "ID", "drug", "Saline", "CNO", col)
            rs_p.append(stats.mannwhitneyu(sal, cno).pvalue)
            sr_p.append(stats.wilcoxon(sal, cno, method="approx").pvalue if np.any(sal != cno) else 1.0)
            rows.append(dict(measure=name, group=gname, n=len(ids), saline_mean=sal.mean(), cno_mean=cno.mean(),
                             n_cno_lower=int((cno < sal).sum()), n_cno_higher=int((cno > sal).sum()),
                             p_ranksum=rs_p[-1], p_signedrank=sr_p[-1],
                             p_signedrank_exact=stats.wilcoxon(sal, cno, method="exact").pvalue if np.any(sal != cno) else 1.0))
        k = len(groups)
        for r in rows[-k:]:
            r["p_ranksum_bonf"] = min(r["p_ranksum"] * k, 1)
            r["p_signedrank_bonf"] = min(r["p_signedrank"] * k, 1)
            r["p_signedrank_exact_bonf"] = min(r["p_signedrank_exact"] * k, 1)
    return pd.DataFrame(rows)

Figure 2: whole-brain TRAP mapping (dandiset), blocked¶

The seven Figure 2 claims (fig2-density-link, fig2c-brain-wide-increase, fig2ei-social-regions-higher, fig2-mpn-higher, fig2f-mpn-fourth-largest, fig2gh-consummatory-tendency, fig2s-dorsal-raphe) need tdTomato+ cell densities per atlas region and brain. The dandiset holds only the raw volumes (data check): no registration, segmentation, cell counts, atlas labels or region volumes. Computing the densities means streaming the volumes (the TRAP channel for the cells and the background channel for the registration), registering each brain to the Unified Anatomical Atlas with ClearMap, and segmenting cells with an ilastik classifier that is not deposited and that the Methods trained on manually labelled chunks ("To train the classifier, 10 chunks of images from the four of the subjects were randomly sampled and used as the training", Methods, Brain-wide analysis). The data check printed the streaming rate and the time to read the volumes once; that time alone exceeds the 60 minute limit of a notebook and the time left in this run, before any registration or segmentation. The 60 minute limit is the registry's: CI fails a notebook that runs over sixty minutes (docs/protocol.md, Author, step 3: "Aim for under ten minutes; CI fails a notebook over sixty"; and "Develop on a subset": "If the estimate is over the notebook limit, or over the time left ..., record the claim as blocked, too_large").

What can be checked without the densities is checked below: the Figure 2 zip on Figshare (its members, its subject table and the density table's Stim labels), the matching of the 14 brains to that table, and the cost of the cheaper reads a later attempt might use (a band of rows around a region, and a plane subsample for registration). Every Figure 2 claim corrects over a family of atlas regions that covers the brain (Benjamini-Hochberg over the level-4 or level-6 regions; the rank of the MPN among all regions), so each needs every region of every brain segmented at full resolution; reading only the regions named would not test them. How the analysis differs from the paper's. The Figure 2 claims, the only ones on the dandiset, were not run: the dandiset holds raw light-sheet volumes only, and the registration and segmentation would need the volumes streamed (hours at the measured rate) and an ilastik classifier that is not deposited. All other claims were tested on the authors' Figshare deposit, mostly on per-animal or per-cell tables the paper's code reads; the HCR proportions were recomputed from the per-cell table, the ejaculation magnitudes and decay lengths from the long traces, and the clustering was run again. Figures 4 to 6 treat cells as units, as the paper does; with animal means as units the magnitude differences of Figure 4H are not significant, the ejaculation responder fraction is significant by Mann-Whitney only, and the Figure 6C decay length is not significant. The response magnitudes for the five behaviors other than ejaculation come from the deposited table, because the traces they are computed from are not deposited. Where the legend and the code name different tests or quantities, both were run. For Figure 7, the claims file's choice of the unpaired tests as main readings (rank-sum for saline against CNO, unpaired t for Vgat against Vglut2) is asked of a reader.

What was found about the data. The dandiset's files store the z planes of each brain as frames of an ImageSeries with a "rate" of 4.0, the z step in micrometres, and give no voxel size, channel wavelengths or description; they are uncompressed and unchunked, 1.38 TB in all. The consummatory (Mount) brains have session dates in February 2024, a year after the others, and lower TRAP intensities in the middle plane. In the Figshare tables, Time_in_Isolation_zone_per_10min holds the mean isolation visit in seconds, Average_Isolation_zone_duration of the Figure 7 table is in frames for three of the four groups, and the arrays named norm_zscore are rescaled (for ejaculation, by each cell's SD over -5 to 0 s), so they do not give the table's magnitudes. The deposited decay lengths follow a definition the Methods do not give (from the peak, with 120 s for a trace that never returns below 0), the clustering's chosen neighbours (30) and silhouette (0.474) differ from the Methods' (55, 0.405), and the HCR populations count only cells with one of the two markers. The 14 brains match the Figure 2 subject table on Figshare by name and group, but the NWB files lack the orientation that table gives. For place preference, the legend's p-values for post-ejaculatory against appetitive hM3Dq (1, 1, 0.8472) are not those the test gives (0.162, 0.696, 0.0615).

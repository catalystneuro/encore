The paper's main findings on VTA dopamine neurons held up in this data. Under saline, reward responses fell with longer delays when reward was certain (task 1) and rose when it was sometimes omitted (task 2), and mPFC inactivation flattened the task 2 rise while leaving task 1 unchanged. The belief state model results reproduced in a Python port of the authors' code, though impaired timing weakens omission responses without abolishing them. The task 2 shift in single-neuron slopes holds only if baseline is subtracted trial by trial, which the paper does not specify. The mPFC recordings (Figure 2) and licking (Figure 3G) could not be tested, as the dataset holds only the 172 identified dopamine neurons.

Reproduction Medial prefrontal cortex and dopamine reward prediction errors (Starkweather et al. 2018)

Tests the findings of Starkweather, Gershman and Uchida (2018) on CRCNS vta-1, which holds the spike times of 172 light-identified VTA dopamine neurons, with odor and reward times and trial types, in two classical conditioning tasks after saline or SalB injection. It tests the temporal modulation of post- and pre-reward responses, the slopes of single neurons, the odor B and C and omission responses, and the paper's belief state TD model, ported to Python. Licks, free water deliveries and the mPFC recordings are not in the data set. All files

Environment: Python 3.13, 34 packages pinned with their hashes in requirements.lock.txt; CI runs each notebook from a new environment built from it.

Method differences

How the tests differed from the paper’s method or data, and the claims each applies to.

  • The 40-minute window is read two ways, as in fig4a-task1-saline-post-decrease; both agree.fig4b-task2-saline-post-increase fig4ab-saline-pre-decrease
  • The model is the Python port; see fig7cd-model-intact.fig7fgh-model-belief-impaired fig7ijk-model-timing-impaired
  • The files hold no recording onset, so "the 40 minutes following recording onset" (Methods, Data analysis) is read two ways, every trial in the file and odor onsets within 40 min of the session's first spike; both give the same outcome.fig4a-task1-saline-post-decrease
  • Three pairs of task 1 SalB files share 65 to 99.7% of their spikes within 0.5 ms. The main analysis keeps all 42, as the paper's statistics do; a variant counts each pair once, and gives the same outcome.fig4c-task1-salb-post-decrease
  • Assumed that baseline is subtracted trial by trial. The paper says only that "both pre- and post-reward responses were baseline-subtracted, with baseline taken 0-1 s prior to odor onset" (Methods, Data analysis), and the claims file names three readings. Trial by trial is adopted because it is the reading under which the paper's own slope counts are recovered exactly (29, 12 and 24 in task 2; 16, 0, 16 and 2 here) and Fisher p matches the paper's to two digits.fig5e-task1-significant-slopes-unchanged
  • Assumed trial-by-trial baseline subtraction, for the reasons given under fig5e-task1-significant-slopes-unchanged. The outcome depends on it.fig5f-task2-significant-slopes-shift
  • The per-mouse inset is not reproduced, for lack of subject identifiers.fig5f-task2-slope-variance-up
  • The paper's MATLAB code is run as a line-by-line Python port (belief_td.py), as MATLAB cannot be installed in the entry's locked environment; MATLAB's random streams are replaced by numpy's. No MATLAB or Octave run was available to compare traces with. The author compared blur_matrix, blur_vector, matrices, observations and the tonic, phasic and omission indexing of simulate line by line with blur_matrices_inputWeberFraction.m, blur_vector.m, the four SimulateOdor*.m files and Organize_for_Plotting.m, and found no difference.fig7cd-model-intact
  • "Around the expected reward time" is taken as the 5 sub-states (1 s) from it, the span of the data's omission window (Methods, Data analysis); the minimum near that time is also printed.fig7cd-model-intact

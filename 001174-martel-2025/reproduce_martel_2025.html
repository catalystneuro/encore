Paper. Martel A-C, Pittard D, Devergnas A, Risk B, Nassi JJ, Yu W, Downer JD, Wichmann T, Galvan A (2025). Microendoscopic calcium imaging in motor cortices of macaques during rest and movement. iScience 28, 112767. doi:10.1016/j.isci.2025.112767. The claims file (claims/001174/10.1016-j.isci.2025.112767.yaml) was written from the version of record as served by Europe PMC (PMC12192352), with the STAR Methods and figure legends; the supplement (Figures S1 to S3, Tables S1 to S3) was not in the text read.

Dandiset. DANDI:001174, version 0.250331.2218. This is the version the paper's key resources table cites (doi:10.48324/dandi.001174/0.250331.2218) and the only published version; the data check compares it with the draft.

What the dandiset holds. 45 NWB files, one per session and condition: the miniscope movie, the footprints of the accepted cells, one trace per cell (the CNMFe denoised trace, see the data check) and the deconvolved events as a frame by cell array of amplitudes. It holds no TTL or trial data and no raw (undenoised) traces.

Outside inputs. The paper's per-cell descriptors table (Zenodo doi:10.5281/zenodo.14727695) supplies the cells' first occurrences, which the dandiset does not mark; the link claim tests it. The paper's Jaccard output table (Zenodo doi:10.5281/zenodo.15116617) is shown next to this attempt's values, and decides nothing. The paper's table of z-scored trial windows (Zenodo doi:10.5281/zenodo.14976651) is used for a check of the Figure 2 classification on the paper's own processed data, which decides nothing. Method details come from the paper's code (Zenodo doi:10.5281/zenodo.14963213 and doi:10.5281/zenodo.14977106), as the claims file cites it. The sequence claims (Figure 4) are in the second notebook, sequences_martel_2025.ipynb.

# Which trace is in Fluorescence/RoiResponseSeries? A raw trace is noisy; the CNMFe denoised trace
# decays by one constant factor per frame between events (an AR(1) model). Ratios of successive
# samples, per file: the share of ratios equal (to 1e-4) to the cell's modal decay factor.
def decay_share(x):
    d = x["denoised"]
    out = []
    for c in range(d.shape[1]):
        v = d[:, c]
        r = v[1:] / np.where(v[:-1] > 0, v[:-1], np.nan)
        r = r[np.isfinite(r)]
        if len(r) < 10:
            continue
        mode = np.median(r[r < 1])
        out.append(np.mean(np.abs(r - mode) < 1e-4))
    return np.median(out)

# Shared clock of events and traces. Both are per frame in the same file; an event should fall where
# the denoised trace jumps up. Contrast: the share of event frames where the trace rises by more than
# 5% against the same with the events shifted by k frames.
def rise_share(x, k):
    d, e = x["denoised"], x["events"] > 0
    up = np.zeros_like(e)
    up[1:] = (d[1:] > 1.05 * d[:-1]) & np.isfinite(d[1:]) & np.isfinite(d[:-1])
    es = np.roll(e, k, axis=0)

Checks of the description against the data.

  • The dandiset holds 45 files over the sessions the claims file lists: each session of Q, U and V has a spontaneous and an arm-reaching file, F has spontaneous files only, and the 2022-09-15 spontaneous file of Q is named sub-Q/sub-Q_ophys.nwb, without a session label (counts printed above).
  • The two files of a session share their footprints (column same_footprints), so their cells are the same cells in the same order. No two files hold identical event arrays.
  • V's sessions have arm-reaching files, while the paper says only Q and U performed the task.
  • The Methods give 10 Hz; the U SMA session of 2023-03-14 is sampled at 20 Hz (both files).
  • The trace in Fluorescence/RoiResponseSeries decays by one constant factor per frame between events: it is the denoised CNMFe trace, though the files call it "Fluorescence data". The raw traces that Figure 2 uses are not in the dandiset.
  • Event frames fall on rises of the denoised trace, and much less often when the events are shifted, which is consistent with a shared clock of events and traces.
  • indicator and location are "N/A" in every file; the site is only in session_description.
  • None of the 45 files has a trial table, an intervals group, a stimulus or a TTL or behavioural channel, and the archive's metadata lists only imaging variables for every asset, so the task events of Figure 2 and Figure S1 cannot be located in the recordings.
  • The ids of PlaneSegmentation are 0..n-1 in every file and it has no other column that could name a cell across sessions, so the dandiset carries no cross-session identity.

zenodo-descriptors-link¶

The per-cell descriptors computed from the dandiset (event rate, IEI CV, mean amplitude, spontaneous and task) agree with the per-cell table the paper deposited on Zenodo, so that table can give the cells' first occurrences.

Cells are matched by subject, site, date and the index of the accepted cell (the table's cells column). The match of identity is checked with the centroids, which the table also gives; the criterion judges the descriptors.

def rel(a, b):

def signrank(g, meas):
    a, b = g[f"{meas}_spontaneous"], g[f"{meas}_task"]
    ok = a.notna() & b.notna()
    a, b = a[ok], b[ok]
    if (a - b).abs().sum() == 0 or ok.sum() < 2:
        return ok.sum(), np.nan, a.median(), b.median()
    return ok.sum(), stats.wilcoxon(a, b).pvalue, a.median(), b.median()

Differences from the paper's method. Each condition is a separate file in the dandiset, so each is analysed on its own, with durations from its frames. The cells' first occurrences come from the paper's Zenodo table; the median over a cell's sessions (the claims file's reading D, ii) cannot be computed. The Jaccard null is drawn from all circular shifts at once (an FFT), with 1000 shifts drawn as the Methods say. For Figure 2 and Figure S1, a check on the paper's own z-scored windows (Zenodo) finds 20 Q SMA cells modulated under the chamber-wide FDR, against 43 in the paper, and 42 uncorrected; it decides nothing, but suggests that the claims file's method Z is not the paper's procedure, which is put to a reader (questions/001174.yaml).

What was found about the dataset. The dandiset holds no TTL or trial data and no raw traces, so Figure 2 and Figure S1 cannot be tested; the trace it holds is the denoised one, without saying so. It carries no cross-session cell identity. Its event rates and amplitudes differ from the paper's per-cell table for most cells, and by large factors in two U SMA sessions, while the cells themselves match.

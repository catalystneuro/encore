Model claims (Figures 1 to 4)¶

These claims are simulations of the paper's two-compartment model, which uses no recorded data. Their data are "elsewhere": the model as the Methods specify it. The paper's code was not public, so the model is written here from the Methods' equations and parameters (seta_model.py). Each claim's generator is seeded from the claim, and each claim is also run under the seed plus 1000, 2000, 3000 and 4000.

def seeds(cid):
    base = zlib.crc32(f"{PAPER}/{cid}".encode())
    return [base + k for k in (0, 1000, 2000, 3000, 4000)]

def sim(rng, runs=80, **kw):
    """Simulate and summarise; keyword arrays are broadcast into one table of conditions."""
    keys = list(kw)
    arrs = np.broadcast_arrays(*[np.atleast_1d(np.asarray(kw[k], float)) for k in keys])
    flat = {k: a.ravel() for k, a in zip(keys, arrs)}
    spk = sm.simulate(rng=rng, runs=runs, **flat)
    out = pd.DataFrame(sm.summarise(spk))
    for k in keys:
        out[k] = flat[k]
    return out, spk

def thresh(df, x, col="count", level=2.0):
    """Lowest x at which df[col] reaches level (inf when it never does)."""
    d = df.sort_values(x)
    hit = d[d[col] >= level]
    return float(hit[x].iloc[0]) if len(hit) else np.inf

def seed_table(cid, fn):
    rows = []
    for s in seeds(cid):

fig2d-latency-grows-as-sensation-weakens¶

As sensory input weakens relative to the prediction, the latency of the breakthrough spike lengthens continuously.

"Without a single jump between two values" is tested as continuity, a choice made here (the criterion gives no number). The interval of the largest 5 nS step is resampled at 1 nS with 4000 runs per conductance; a jump is a single 1 nS step that carries more than half the latency change across that interval. A continuous curve spreads the change over the five steps, a discontinuity puts it in one. The earlier tests (largest 5 nS step below half, or below a quarter, of the latency range) are printed as well; with 80 runs per conductance their steps are limited by sampling noise where few runs spike.

    steps = np.abs(np.diff(s.lat_mean.values))

def percell(cells, fn):
    """One row per cell (or several), from fn(r, a, n, b, sn, sb) on the cell's counts."""
    out = []
    for c in cells.itertuples():
        r, a = res[c.sess], ANN[c.sess]
        got = fn(r, a, r["cnt"][c.unit], r["bst"][c.unit], r["scnt"][c.unit], r["sbst"][c.unit])
        if got is None:
            continue
        for d in (got if isinstance(got, list) else [got]):
            out.append(dict(session=c.session, subject=c.subject, sess=c.sess, layer=c.layer, unit=c.unit_id, **d))
    return pd.DataFrame(out)

def change(d, x, y, kind):
    """Per-cell change: 'diff' x - y; 'sqrt' sqrt(x) - sqrt(y) (O6 b); 'mi' modulation index (D5),
    0 when both are 0 (FSB) so that every cell with spikes counted stays in; NaN (left out)
    when a condition has no windows."""
    if kind == "diff":
        return d[x] - d[y]

Readings: block 1, block 3, both; each with all windows (O5 a) or stationary windows only (O5 b).

Assumption: both blocks are adopted. The Methods name one spontaneous period, "the period of mouse inactivity immediately following the task" (Methods, "Allen Brain Observatory data analysis"), and the Results call it "spontaneous activity outside the stimulus blocks" (Results, "LTD-favouring conditions"). Both blocks are grey-screen periods outside the stimulus blocks that follow the task, and the files list both, and only these, in intervals/spontaneous_presentations. The mice run in most windows of both blocks (the table below), so "inactivity" cannot mean stationary in either and reads as the end of the task. Block 1 alone gives each cell 40 windows (10 s) and a median of 0 stationary windows, so O5 (b) cannot be applied to most cells. Under O5 (a), the adopted reading, block 1 leaves out few cells (4 L2/3 and 15 L5 under O9 a, 1 and 9 under O9 b, the dropped column below), so this argues against block 1 only under O5 (b). How the analysis differs from the paper's. The model is integrated in NumPy from the Methods' equations, not in Brian 2, and the paper's code was not available; L4, ChC and L5 IT ranges for the model figures are plotting choices. On the recordings, which sessions enter is open (O9 of the claims file); all 153 sessions give about 35% more cells than the paper, and the paper's counts are matched only by the 104 sessions of the Sst-Cre and Vip-Cre Ai32 mice. Every claim is run under both, and on all 16 readings of O1 to O3; no outcome now depends on O9, and fig5c-fsb-highest-on-first-repetition is within tolerance only on 2 of the 16 selections under O9 (b), by 0.0003 at most, under a reading that codes repetition as k (8 selections under O9 a, by up to 0.0012). The spontaneous period of Figure 6 is taken as both spontaneous blocks, an assumption; the 10 s grey screen right after the task alone, the literal reading of "immediately following", gives a different outcome for fig6b and fig6c. Under D7, 26 of the 104 O9 (b) sessions have no stationary Repetition 1 presentation, so Figure 7A and 7B cannot include every cell, as the paper's degrees of freedom imply. Mixed models that did not converge were refitted with other optimizers; with the converged fit the novel against familiar L5 rate difference is significant under both O9 readings. Figures S1 and S2 were not in the text, so their tests are read from the Methods.

What was found about the dataset. The version holds 153 sessions from 81 mice (104 from Sst-Cre or Vip-Cre mice with ChR2, 49 wild type), with spikes, stimulus tables, running speed and optotagging pulses as the paper describes. Units carry no layer; the CCFv3 coordinates of their peak channels place 7996 of 7997 VISp units in VISp, but 351 VISp units in 7 sessions have all coordinates 0. The spontaneous block that follows the task lasts 10 s in every session and starts 18 to 29 s after it, except in one wild-type session, where it starts 3277 s after the last task presentation; the 289 s spontaneous block starts about 940 s after the task. Unit and electrode columns have no descriptions in the files. The clock check separates images from omissions in most sessions (median AUC 0.95 for the count 30 to 100 ms after onset, 0.50 before onset), but in 10 sessions the AUC is below 0.8 (lowest 0.55), and 2 sessions have no VISp unit to check; for these the shared clock is not established here.

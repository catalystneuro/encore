Reproducing Moaddab, Ray & McDannald (2021) from CRCNS data set bf-3¶

Paper. Moaddab M, Ray MH, McDannald MA (2021). Ventral pallidum neurons dynamically signal relative threat. Communications Biology 4, 43. doi:10.1038/s42003-020-01554-4. The claims file (claims/crcns-bf-3/10.1038-s42003-020-01554-4.yaml) was written from the version of record (PMC7794503) without its Supplementary Information.

Data set. CRCNS bf-3, "Recordings from ventral pallidum neurons in male rats undergoing fear discrimination" (Moaddab and McDannald), doi:10.6080/K0HH6H8V, read from the public bucket at https://crcnsarchive.s3-us-west-2.amazonaws.com/bf-3/live/. CRCNS data sets are not versioned, so the version is recorded as unversioned and pinned by checksum: the one data file read, data_and_scripts.zip, has MD5 43a2887fac54e7bd12db345257a29864 in the data set's checksums.md5, and the notebook checks the MD5 of the bytes it reads against it. This is the only copy the archive serves (the live/ folder; there is no old/ folder), and its data descriptor is version 0.6 of 3 February 2021, the initial version, so there was no other version to choose.

What the files hold. One MATLAB file per unit (435) with spike times, a mean waveform, and the session's Med Associates events as Plexon channels; a cube of all units precomputed by the authors; and the authors' MATLAB scripts cubeScriptPR25.m and vpAnalysis.m. The paper does not link these scripts (it points to a lab page that no longer resolves), but they are the authors' and are used here, as the protocol uses a paper's code: where the Methods leave a detail open, the scripts settle it; where they disagree with the Methods, the Methods' reading is the main result and the scripts' is shown as a variant. The one exception is the neuron groups (A1). The cells after the data check print the script lines cited here. Every number is computed from the spike and event times; the cube is used only for checks.

Assumptions the outcomes rest on (marked A1 to A3 in the table):

  • A1. The neuron groups are the paper's 257 cue-responsive neurons and their split into 131 cue-excited and 126 cue-inhibited neurons, as the authors' code computes them: rates floored to integers in the screen (the Methods say "mean firing rate (Hz)" and do not mention rounding), and the code's per-trial normalization for the split. Both steps depart from the rule above. They are taken from the code because the claims are about the neurons the paper analysed, and the code reproduces every count the paper reports (257 neurons from 153 sessions, 131 and 126). The Methods' unfloored rates give 271 neurons, whose split is outside tolerance under every reading of the claims file (groups B, shown as a variant where it bears on a claim). On the 257 neurons, the claims-file reading Hz with two window means (130/127), one of the readings within tolerance, puts 25 neurons in the other group (claim fig2-excited-inhibited-split).
  • A2. The cue-inhibited clusters are those of one Matlab k-means++ start after rng(1), as the authors' code runs it (Low 74, Intermediate 34, High 18). The claims file's reading (b) for the ISIs with raw features and the same start gives the same members. With more restarts k-means finds other clusters with a lower sum of squares, so the clusters depend on the start.
  • A3. A nose-poke pause is a gap of more than 2 s between pokes 18 to 2 s before a cue onset, as the authors' code defines it; the text read does not define it.

Firing measures use the Methods' normalization under the claims file's readings; the authors' per-trial normalization, which reproduces the paper's printed values, is a variant throughout. Changing one element at a time shows that Z-scoring single trials in place of trial means accounts for the difference (section "Which part of the normalization", before claim fig3b).

def split_values(us, measure, windows, pool="3"):
    out = []

def period_values(us, pool):
    Z = cue_array(us, pool)
    return {(c, p): Z[:, i, idx].mean(1) for i, c in enumerate("DUS") for p, idx in PERIODS.items()}

def period_cis(group_key, rng, groups=("A", "B"), pools=("3", "4", "code")):
    out = {}
    for g in groups:
        for pool in pools:
            pv = period_values(GROUPS[g][group_key], pool)
            res = {}
            for p in PERIODS:
                for c in "DUS":
                    res[(c, p)] = vp.boot_ci(pv[(c, p)], rng)
                res[("D-U", p)] = vp.boot_ci(pv[("D", p)] - pv[("U", p)], rng)
                res[("U-S", p)] = vp.boot_ci(pv[("U", p)] - pv[("S", p)], rng)
            out[(g, pool)] = res
    return out

def show_cis(cis):
    rows = []
    for (g, pool), res in cis.items():
        for (c, p), (m, lo, hi) in res.items():
            rows.append({"groups": g, "pool": pool, "measure": c, "period": p, "mean": m, "ci_low": lo, "ci_high": hi})
    df = pd.DataFrame(rows)
    return df.pivot_table(index=["measure", "period"], columns=["groups", "pool"],
                          values=["mean", "ci_low", "ci_high"]).round(3)

def judge(res, rules):
    """rules: list of (key, kind, expected, tol); kind 'below', 'above' (the interval excludes zero
    on that side) or 'contains'; expected may be None. Returns (pattern holds, values within
    tolerance)."""
    pattern = values = True
    for key, kind, exp, tol in rules:
        m, lo, hi = res[key]
        pattern &= {"below": hi < 0, "above": lo > 0, "contains": lo <= 0 <= hi}[kind]
        if exp is not None:
            values &= abs(m - exp) <= tol
    return bool(pattern), bool(values)

def corr_table(group_keys, groups=("A", "B"), pools=("3", "4", "code")):
    rows = []

def event_matrix(us, kind, reading, scale):
    rows, kept = [], []
    for u in us:
        ev = vp.reward_events(u, reading) if kind == "reward" else vp.pause_events(u, reading)
        sd = vp.normalize_cue(u, "3")["sd"]
        f = vp.event_firing(u, ev, scale, sd)
        if f is not None:
            rows.append(f)
            kept.append(u)
    return np.array(rows), kept

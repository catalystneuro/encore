Paper. Fan, Dal Monte, Nair, Fagan & Chang (2024), "Closed-loop microstimulations of the orbitofrontal cortex during real-life gaze interaction enhance dynamic social attention", Neuron 112, 2631-2644, doi:10.1016/j.neuron.2024.05.004.

Claims. claims/000959/10.1016-j.neuron.2024.05.004.yaml, written from the accepted author manuscript (PMC11309918) with its supplement, and the paper's code (github.com/changlabneuro/microstim-ofc-social-attention at cc0bf994).

Dataset. DANDI:000959, version 0.261020.0242. The paper cites the dandiset without a version. Two versions are published, 0.260531.2104 and 0.261020.0242; the most recent is pinned, as the protocol asks when the paper cites none. The data check below compares the two asset lists: both hold the same 1705 assets with the same identifiers, paths and sizes, so the choice does not change the data.

Each file is one 300-s run (a "session" in the paper) and holds M1's gaze and pupil at 1 kHz, M2's gaze and pupil in social runs, the stimulation and sham times, the day's ROIs, and fixation events as interval tables (M1-only, M2-only and mutual events by ROI). Files are read over HTTP into memory at the pinned version (nothing is written to disk) and reduced to small tables by microstim.py.

def signrank(a, b=None):
    """Two-sided Wilcoxon signed-rank test (scipy's default method: exact for small n
    without ties). Returns (n, p)."""
    a = np.asarray(a, float)
    d = a if b is None else a - np.asarray(b, float)
    d = d[~np.isnan(d)]
    if len(d) == 0 or np.all(d == 0):
        return len(d), np.nan
    return len(d), wilcoxon(d).pvalue


def ranksum(a, b):
    a = np.asarray(a, float)
    b = np.asarray(b, float)
    a, b = a[~np.isnan(a)], b[~np.isnan(b)]
    return mannwhitneyu(a, b, alternative="two-sided").pvalue


def day_test(dm, region, subject=None):
    """Signed-rank of stim against sham day means; returns n, median stim - sham, p."""
    x = dm[(dm.region == region) & ((dm.subject == subject) if subject else True)]
    x = x.dropna(subset=["stim", "sham"])
    n, p = signrank(x.stim, x.sham)
    return dict(region=region, subject=subject or "both", n=n,
                median_diff=np.median(x.stim - x.sham) if n else np.nan,
                mean_diff=np.mean(x.stim - x.sham) if n else np.nan, p=p)


def day_table(dm, subjects=(None, "L", "T"), areas=AREAS):
    return pd.DataFrame([day_test(dm, a, s) for a in areas for s in subjects])

def hemi_table(dsets, areas, subjects=(None, "L", "T")):
    rows = []
    for a in areas:
        for s in subjects:
            c = day_test(dsets["contra"], a, s)
            i = day_test(dsets["ipsi"], a, s)
            dc = dsets["contra"].assign(eff=lambda d: d.stim - d.sham)
            di = dsets["ipsi"].assign(eff=lambda d: d.stim - d.sham)
            m = dc.merge(di, on=["date", "subject", "region"], suffixes=("_c", "_i"))
            m = m[(m.region == a) & ((m.subject == s) if s else True)].dropna(subset=["eff_c", "eff_i"])
            n, p = signrank(m.eff_c, m.eff_i)
            rows.append(dict(region=a, subject=s or "both", n_contra=c["n"], contra_median=c["median_diff"], contra_p=c["p"],
                             n_ipsi=i["n"], ipsi_median=i["median_diff"], ipsi_p=i["p"],
                             n_cvi=n, contra_minus_ipsi_median=np.median(m.eff_c - m.eff_i) if n else np.nan, cvi_p=p))
    return pd.DataFrame(rows)

Causal decomposition claims (blocked)¶

figs4a-causal-strength-no-stim-effect, figs4b-causal-strength-no-epoch-effect, ofc-slope-unchanged-by-epoch, fig4c-dmpfc-slope-late-greater, fig4d-dmpfc-slope-permutation and dmpfc-slope-positive all rest on the relative causal strength of each trial, from the causal decomposition of Yang, Peng and Huang (2018), which is built on ensemble empirical mode decomposition (EEMD). The Yang et al. code (causal_decomposition.m, release causal_decomposition_20180901 at github.com/accyang/causal-decomposition-analysis) normalises both series, runs one EEMD of each, then for each IMF removes it from each series and runs one EEMD of each again: 2 + 2 x (number of IMFs) EEMDs per trial. Its eemd.m sifts a fixed 10 times per IMF (maxSift = 10, the default). Neither the noise level nor the ensemble size has a default in that code; its example call uses noise 0.35 and 1,000 ensembles. The claims file's reading (a) takes noise 0.2 and 1,000 ensembles, and reading (b), the code's settings, is taken here as the example's 0.35 and 1,000, so both readings need 1,000 ensembles and cost the same (the noise level does not change the work).

The cell below times one EEMD of one 150-bin series with PyEMD set to the Yang code's sifting (10 fixed sifts), at 1,000 ensembles on one core and on four processes, and counts the trials each claim needs: every social Eyes trial for figs4a and figs4b, and the first 90 stimulation trials of each of the 76 epoch days for the four slope claims (by area). It also gives a floor for any implementation: the number of cubic-spline envelopes the decomposition fits, times the measured cost of one scipy spline fit on 150 points.

# check of the port on synthetic gaze: fixations joined by saccades of 0.3 to 15 deg with a
# raised-cosine profile and main-sequence durations (2.2 ms per deg + 21 ms), 60 s at 1 kHz,
# with white noise of three levels; the last gives a velocity inside fixations like the data's
rng_s = np.random.default_rng(5959)


def synth_gaze(noise, T=60.0, rate=1000):
    n = int(T * rate)
    x, y, true = np.zeros(n), np.zeros(n), []
    t, px, py = 1500, 0.0, 0.0
    while t < n - 1500:
        amp, ang = rng_s.uniform(0.3, 15), rng_s.uniform(0, 2 * np.pi)
        dur = int(round(2.2 * amp + 21))
        prof = (1 - np.cos(np.pi * np.linspace(0, 1, dur))) / 2
        nx, ny = px + amp * np.cos(ang), py + amp * np.sin(ang)
        if abs(nx) > 15 or abs(ny) > 15:
            nx, ny = px - amp * np.cos(ang), py - amp * np.sin(ang)
        x[t:t + dur], y[t:t + dur] = px + (nx - px) * prof, py + (ny - py) * prof
        true.append((t, t + dur - 1))
        px, py = nx, ny
        t2 = t + dur + int(rng_s.uniform(250, 900))
        x[t + dur:t2], y[t + dur:t2] = px, py
        t = t2
    x[t:], y[t:] = px, py
    return x + rng_s.normal(0, noise, n), y + rng_s.normal(0, noise, n), np.array(true)

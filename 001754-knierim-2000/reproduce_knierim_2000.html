Reproducing Knierim, McNaughton & Poe (2000) from dandiset 001754¶

Paper. Knierim JJ, McNaughton BL, Poe GR (2000). Three-dimensional spatial selectivity of hippocampal neurons during space flight. Nature Neuroscience 3:209-210. doi:10.1038/72910. The paper is not open access. This attempt used only its abstract and the titles of its three figures, from the publisher's page. Four claims come from the dandiset's own description, which summarises the paper's findings; they could not be checked against the paper's text.

Dandiset. DANDI:001754, version 0.260728.1352. The paper (2000) cites no DANDI version. Three versions are published (0.260227.0029, 0.260227.0031, 0.260728.1352); they hold the same eight files (same blobs, checked below) and differ only in metadata (the last adds the journal name to the paper's link). The most recent is pinned.

What the dandiset holds. Three rats on the Neurolab mission (STS-90, April 1998): a preflight recording of each, flight day 4 (FD4) of each, and flight day 9 (FD9) of Rats 1 and 2. Each file has sorted units, task epochs (BL baseline, ES Escher staircase, MC Magic Carpet), and the 64 x 64 rate and occupancy maps of the original analysis for ES and MC. The flight files also hold the video position, but only at spike times. There is no EEG and no head direction.

Conversion code read. catalystneuro/mcnaughton2000-to-nwb at commit b538d9e07079394362a64e5118a226e91bdd7ab5, linked from the dandiset. It merges the per-epoch spike files (.CEL) of each tetrode and cluster id into one unit, takes position from the spike files' position columns, builds the epochs from the spike files' headers and names, and reads the .RMA rate maps. The paper's own analysis code is not linked and was not found.

def compare(a, b, alternative="two-sided"):
    if len(a) == 0 or len(b) == 0:
        return {"n_a": len(a), "n_b": len(b)}
    u = stats.mannwhitneyu(a, b, alternative=alternative)
    return {"n_a": len(a), "n_b": len(b), "median_a": round(float(np.median(a)), 3), "median_b": round(float(np.median(b)), 3),
            "diff": round(float(np.median(a) - np.median(b)), 3), "ratio": round(float(np.median(a) / np.median(b)), 2),
            "U": float(u.statistic), "p": float(u.pvalue), "rank_biserial": round(1 - 2 * u.statistic / (len(a) * len(b)), 3)}

How the analysis differs from the paper's. The paper's full text was not available, so its Methods, tests and thresholds are unknown; every method here is a common choice fixed before the analysis. Four claims come from the dandiset's description of the paper's findings, and one from a figure title alone. Spatial information is computed from the spikes for the spike-based claims, with the occupancy maps of the original analysis, as the dandiset holds position only at spike times; the comparisons with preflight use the original rate maps, as the preflight files have no position. The rate maps are smoothed with an unstated kernel and their spatial information is not corrected for the number of spikes; a count-adjusted variant is shown. The stability claim assumes that a cluster id names the same neuron in two epochs.

What was found about the dandiset.

  • The Rat1 and Rat2 files of each flight day hold the same position trace (99% of common samples within 2 pixels), each sampled at its own rat's spike times. Rat1's units are spatially selective with it; Rat2's are not, in any window, and in Rat2's FD4 ES epoch the trace is consistent with Rat1's position. Whose position the trace is in Rat2's task epochs is not stated and could not be established.
  • The description says the preflight recordings were on a flat rectangular track, but the preflight epochs and rate maps are labelled ES and MC, as in flight.
  • Position is given only at spike times, so occupancy cannot be computed from the files' position.
  • The rate-map cell_number comes from Windows 8.3 short file names (ESCELL~1, ES2BC0~1) and is not a cell number; it equals the cluster id of the best-matching unit in 84 of 211 unit-epochs, so the rate maps cannot be linked to units as the table's description says. The maps are smoothed, which the description does not state.
  • Rate maps use -999 for unvisited bins, which the description does not state; the tracker's lost position (0, 255) is counted in the original occupancy (up to 19% in flight). Eight rate maps are identical copies of another map in the same file, some under a different tetrode.
  • Units merge the per-epoch spike files with the same tetrode and cluster id; whether these are the same neuron is not stated. The unit table lacks the session_type and source_file columns the conversion's README lists.
  • Spike times are given to 10 ms in five files; 2 to 15% of within-unit intervals are zero, in every epoch type, for reasons not resolved.
  • There is no EEG, although the dandiset's description reports theta and ripples.

  • Metadata errorIn sub-11 the contacts named PHL lie at positive MNI x (right) and those named PHR at negative x, and the atlas labels follow the coordinates (PHL1 at x = 33.6, "Right Hippocampus"; PHR1 at x = -31.1), so the electrode names give the wrong hemisphere; 3 contacts of sub-12 have the same mismatch, and in sub-01 the atlas label names the hemisphere opposite to the x coordinate for 12 contacts (for example ECL1 at x = -24, "Right Amygdala").

The incorrect-trial sources of Figure 4f are not deposited either; they can be approximated because each virtual sensor is an exact linear combination of the file's own scalp channels, which gives the correct-trial filters.
  • Other17 trials (16 in sub-14, 1 in sub-12) have SetSize 0, no Match, ResponseTime 0 and the artifact flag, apparently placeholders; ProbeLetter is n/a for every trial of sub-10 to sub-15. Neither is described in the events sidecar.

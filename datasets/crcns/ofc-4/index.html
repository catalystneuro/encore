The paper's OFC decoding held in part in this data, and its link between decoding and errors did not. The 16 task states decoded above chance, at 8.9% against 12.2%, but of the three hidden components only previous category did. The absence of current-age information and the Enter versus non-Enter similarity structure reproduced. Lower decoding on error trials and similarity predicting error rates did not, and the error rate could not be tested because the event files merge errors with their repetitions. The searchlight and other-region findings could not be tested because only OFC data are held.

Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Description missingThe 'err' events are blocks that start at an error trial and run over its repetitions and often the trials after it (spans 6.8 to 41 s), and the data descriptor does not say so. The number of errors, time-outs, error reaction times and the state of most error trials cannot be read from the files; the class is known for 181 of 228 blocks and the full state for 39 to 98.
  • Metadata errorThe 'err' column of the design matrices does not follow the error blocks' RT or stimulus durations (r 0.30 to 0.76) but a short event at each block onset (r 0.83 to 0.98); the descriptor says the design matrices are boxcars from stimulus onset to button press.
  • Description missingThe OFC time series carry no voxel coordinates or mask (each run file holds only OFC_timecourse, TR, condition_label, design_matrix_task, n_TR, n_voxel and nuisance_timecourse), so spatial smoothing, searchlights and any spatial analysis cannot be done, and voxels can be taken to be the same across runs only from their equal counts.
  • Data missingThe data set holds 24 of the paper's 27 participants and the OFC only. The training session, whole-brain data, the hippocampus, DLPFC and PPA/FFA regions, the cardiac regressors and each trial's response mapping and response side are not in it; five of the paper's claims are blocked for missing data.
  • OtherEnter errors (after an Exit trial) are 181 of 225 error blocks after a run's first trial (79% of all blocks, where the paper's class rates imply 48%), an Enter error rate of 4.79% against at most 1.2% for the other two classes together, where the paper reports 3.4%, 2.3% and 1.4%.
  • File format errorIn Subj-01 run 4 a 'HoHy' trial follows a 'HoHy' trial, which the task rules do not allow; every other pair of adjacent labelled trials chains.
  • Description missingThree runs (Subj-11 run 3, Subj-18 runs 4 and 5) have no 'first' event or column, as their first trial was an error; the descriptor mentions only runs without an 'err' column.
  • Paper inconsistentThe Figure 1B legend says errors on Internal and Exit trials led to a repetition of the preceding trial, while the Methods (Task) say Internal and Enter trials were repeated and only Exit errors led to the preceding trial. The data show long blocks after Internal and Exit errors, consistent with the legend, but cannot settle it.
  • Methods not availableQuestion for the authors. How were the beta maps z-scored within each run (each voxel across the state maps, or each map across voxels) and with what kernel were they smoothed? The decoding results here change with the z-scoring (8-way decoding, the correlation with error rate and the error-trial comparison hold only with voxel-wise z-scoring), and the assumption made was the voxel-wise z-scoring of the Princeton MVPA toolbox's zscore_runs.
  • Methods not availableQuestion for the authors. How were errors counted, and how was the state of an error trial labelled, given that the shared event files merge each error with its repetitions? The attempt reconstructed the state of Enter errors from the neighbouring trials and counted one error per block.

Reproduction Human orbitofrontal cortex represents a cognitive map of state space (Schuck et al. 2016)

Tests the findings of Schuck, Cai, Wilson and Niv (2016) on CRCNS data set ofc-4, which holds the OFC fMRI time series, design matrices and event files of 24 of the paper's 27 participants. It covers the behavioural results that the event files allow, the 16-state and alternative decoding analyses, the permutation control, the similarity structure of state patterns, the trial-wise decoding around errors and the relation of pattern similarity to errors. The whole-brain, other-ROI, training and simulation results cannot be tested on it. All files

  • fig1b-dz-speed-posthoc

    Post hoc paired t-tests showed significant differences between previous and current DZ speed for pre-run, run and post-run (P = 0.0011, t(52) = 3.45; P = 9.70 × 10−9, t(51) = −6.84; P = 0.00307, t(51) = −3.10), as well as for the current DZ between pre-run and post-run

    Figure 1b legend, left; Results, Rats learn the daily location, paragraph 2

    How it will be judged

    Danger zone speed as in the opening comment; paired t-tests over sessions with both values defined (BehavioralMeasures_Stats.m). The text states only the post-run against pre-run direction; the others are read from the signs of t, which the code computes as current minus previous and pre-run minus post-run (ttest(current, previous), ttest(prerun, postrun)). The four reported tests are used, so the level is 0.05/4.   • figs1c-habituation

    Supplementary Figure 1c; Results, Rats learn the daily location, paragraph 2

    How it will be judged

    Habituation index per session as the number of laps divided by the time spent on the track, x 100 (Online Methods, Analysis). Which laps are counted is open; the Methods say all back-and-forth laps in the run, the legend of Supplementary Figure 1c says air puff laps, and Performance.m counts left-to-right laps in the run.

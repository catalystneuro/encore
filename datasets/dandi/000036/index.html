Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Selection not documentedThe dandiset holds 57 sessions where the paper analysed 44 and excluded one. The 12 extra sessions (second recordings of each area in Cux2 mice 389014 and 389020, and a second PM session in Rbp4 mice 402796 and 405808) are not described in the paper, and nothing in the files or the dandiset metadata says which sessions the paper used or that the L5 AL session 741889312 was excluded. They can be identified only through the paper's code outputs. Run on all complete sessions, the area result changes (AL no longer significant).
  • Identifier missingThe NWB identifier is not the session id the paper and its code use (for example 717235570 against 717911143); it is the id that names the deposit's pupil files. The paper's ids appear nowhere in the dandiset, so the sessions can be linked to the paper only by start time.
  • Metadata errorsession_start_time is 7 hours later than the start times of the paper's metadata in all 57 files while labelled -07:00; recordings appear to start between 15:00 and 00:46 local time, against 08:00 to 17:44 in the paper. The times look like UTC labelled as Pacific time (consistent with the data, not shown).
  • Metadata errorAgainst the 2p frame times, the NWB stimulus and running timestamps run late by an amount that grows through each session, compared with the vsync-to-frame alignment of the paper's sync files, from about 0 frames in the first minute to 1.3 to 4.4 frames (40 to 146 ms) in the last; the paper's trials start 0 to 6 frames earlier than the NWB stimulus times give. The frame timestamps themselves equal the paper's 2p vsync times.
  • File format errorEvery running_velocity series has one sample more than its timestamps; the extra sample is the first (the rest equal the deposit's run_speed, shifted by one), and in one session it is an artifact of -742.7 cm/s. In 39 of 57 files the dF/F timestamps have one entry more than the data has frames.
  • Description missing15 ROIs (14 in the paper's sessions) have dF/F that is NaN at every frame, with no flag or description; without them the cell counts equal the paper's. The PlaneSegmentation table holds only image masks, with no validity or cell id columns.
  • Metadata errorThe imaging plane states an imaging rate of 30.0 Hz; the frame timestamps step by 33.17 ms (30.15 Hz), and by 66.33 ms (15.08 Hz) in the excluded session 741889312, which was imaged at half the rate.
  • Data missingThe dandiset holds no L0 calcium events, no eye tracking or pupil data, and no sex, age or date of birth of the mice, all of which the paper uses or reports. The events and pupil area are in the paper's Zenodo deposit (doi:10.5281/zenodo.5781567); the fitted pupil ellipse whose semi-major axis the Methods define as the diameter is in neither. Eight claims are blocked for these data.
  • Methods not availableThe L0 event detector the paper names (l0_analysis.py of AllenInstitute/visual_coding_2p_analysis) is Python 2 code that needs allensdk and the compiled FastLZeroSpikeInference, which is not on PyPI, does not build with pip from its repository, and no longer has the arfpop function the detector calls.
  • Published code disagreesFor area AM in Figure 3 the paper prints Cohen's d = 0.268, 95% CI [0.128, inf). Its own per-trial values (results/main.parquet) give d = 0.128 with the pooled SD as its code computes it, and the post hoc test on them a lower bound of 0.0048. The paper's value looks like a transcription slip.
  • Published code disagreesThe code's pooled SD (analysis.pooled_std_dev) weights each group's SD by the other group's n - 1, where the Methods give the standard formula; its groupby sorts the labels, so s1 is the SD of "artificial" while n1 counts "natural". The per-session effect sizes of results/effect_size.parquet (0.570 to 1.258 in L2/3 AL and AM, the paper's 0.57 to 1.25, and the figure 4 correlation r = 0.896) come from this. They equal Cohen's d from results/main.parquet with the swapped weights to 4e-15, while the Methods' formula gives 0.592 to 1.155.
  • Published code disagreesThe paper says that for nearly all parameter combinations unscrambled stimuli elicit increased ND specifically in L2/3 of AL and AM; in its own sensitivity statistics (results/stats.parquet) AL and AM are both significant in 28 of 108 sets, AL alone in 50, AM alone in 24 and neither in 6, while L2/3 is the only significant layer in all of them.

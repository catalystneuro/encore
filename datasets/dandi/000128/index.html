Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Metadata errorEvery unit's electrode reference in the units table points into the first 96 rows of the electrodes table, which are labelled PMd, so by the file all 182 units are in PMd. The dataset describes two arrays, in M1 and PMd. The reference equals the unit id's channel digits minus one, which suggests the array offset was dropped in conversion.
  • Description missingThe electrodes have no coordinates (x, y and z are NaN), and the leading digit of the unit ids (1 or 2), which may be the array, is not documented. No unit can be placed on the anterior-posterior axis or on an array.
  • Selection not documentedThe dataset holds 182 units where the paper reports 146 isolations for the J-array dataset, and does not record which units or trials the paper used, or that this session is the paper's.
  • Other574 of the session's successful trials are in the test file as 0.7 s segments around movement onset, without condition labels or behaviour and with only the 137 held-in units, so they cannot enter a condition-mean analysis. None duplicates a train trial. The test file has a clock of its own (segment times restart at 0) and no delay or success column, and the train file's trial ids are contiguous, so the files do not record which session trials the packaging dropped.
  • Other14 trials have a negative delay (as low as -3 ms), where the go cue precedes the recorded target onset.

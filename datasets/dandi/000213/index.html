Fixed since an earlier attempt 5

  • File format errorFixedIn all 67 files the third column (z) of position is a copy of the second (y).
    None of the 56 files with three position columns has z equal to y, and the 11 DT2 files now store only x and y (earlier_findings.ipynb, section 5). Found fixed on dataset version 0.261109.2219 by tingley-2018-02, 2026-11-16.
  • File format errorFixedIn eight of the eleven DT2 files the position timestamps repeat or go back; the time per sample (33.3 ms) can only be taken from the session span.
    The DT2 positions are now stored at a regular 30 Hz from 0 s, with no repeated or decreasing times in any of the 11 files, and the description says how the lab's rounded timestamps were rebuilt. Found fixed on dataset version 0.261109.2219 by tingley-2018-02, 2026-11-16.
  • File format errorFixed11 units in six files hold spike times that are not in increasing order.
    No unit in the 66 files with units has spike times out of order (earlier_findings.ipynb, section 7). Found fixed on dataset version 0.261109.2219 by tingley-2018-02, 2026-11-16.
  • Metadata errorFixedThe head-orientation quaternion in processing/behavior/allocentric_frame_tracking states its unit as meters.
    The quaternion is now processing/behavior/head_orientation, with unit dimensionless, in all 56 OptiTrack files, and no file has allocentric_frame_tracking. Found fixed on dataset version 0.261109.2219 by tingley-2018-02, 2026-11-16.
  • OtherFixed42 files chunk the LFP as 500 samples by all channels, so reading one channel of a session means reading the whole LFP; chunks along time per channel would make single-channel access practical.
    All 67 files now chunk the LFP as 1048576 samples by 16 channels, so a single channel is read with 16 of the 96 or 128 channels. Found fixed on dataset version 0.261109.2219 by tingley-2018-02, 2026-11-16.

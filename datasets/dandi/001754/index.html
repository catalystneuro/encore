    Reading M-b recomputes rate maps from spikes and position. The dandiset gives position only at the spike times of each file's units, so no occupancy time can be computed from it, and the preflight files hold no position at all.     Passage. The Fig. 1 legend says all statistical analyses kept off-track positions; the paper gives no bin size, smoothing or occupancy rule.

    Why it matters. Unsmoothed 64 x 64 maps give a spatial information about twice that of the deposited maps (2.9 to 4.0 bits per spike in flight against 0.7 to 1.6 for M-a), so a test of M-b flight values against M-a preflight values finds a difference in every rat, and judging on M-a alone does not.     The reader’s answer. The paper does not say. It is a two-page brief communication with no Methods, no supplement and no code; it gives the measure only by citation to Skaggs et al. (ref. 13), whose formula needs occupancy, and says only that "all statistical analyses included these off-track data" (Fig. 1 legend). Dividing spike counts by the epoch's deposited occupancy map is a reading it allows for M-b. It compares one index computed alike for both groups ("An index of spatial tuning specificity ... did not significantly differ between cells recorded preflight and those recorded on FD9"), so a comparison uses the same map reading on both sides; where M-b cannot be computed for preflight, the comparison is judged on M-a and the mixed test is a variant.     The criterion computes, per bin, a counterclockwise rate and a clockwise expected count, which need the time spent in each bin in each direction. The dandiset has position only at spike times and one occupancy map per epoch, not split by direction, and nothing gives the track's layout in the image from which the circuit's direction could be read. Is there a reading the paper allows with these data, or does the claim stay blocked?

    Why it matters. Without a time base per direction no rate can be formed, so the attempt blocks the claim.

    The reader’s answer. The paper gives no method, only "Some cells demonstrated place fields when the rat was moving only counterclockwise through a single location", and no track layout or time base by direction. It allows no reading that does without time spent per bin in each direction, so the claim stays blocked as methods_underspecified; the criterion now says so.

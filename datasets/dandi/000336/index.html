      How the test differed from the paper’s method

      • The public package (version 0.6.0, default parameters) in place of the paper's custom-modified version, which is not public, as the claims file directs.
      • Assumed that the dendritic overlap is the intersection over union of the registered masks that the package reports, applied to every pairwise match within a three-session match. The paper does not define the overlap; IoU is the overlap measure the package itself computes. The result holds at both thresholds the criterion names.
      • The package expects an average intensity projection for registration; the files hold only a max projection, which is used in its place.
      • The six directed pairwise matchings of each mouse are computed once and combined per ordering, as NwayMatching.run combines them (itertools.combinations in the given order); the notebook checks this against NwayMatching.run on all six orderings of 418779 and 420011 (12 of 12 equal). The package's summary plots are not made; they fail with the locked pandas (a read-only array in numpy.fill_diagonal) and do not change the matches.
      • A pair of ROIs within a three-session match that has no direct pairwise match counts as IoU 0, so the match fails any threshold; the variant that applies the threshold only to linked pairs is shown and gives the same outcome.

    Method differences

    How the tests differed from the paper’s method or data, and the claims each applies to.

    • The files carry no QC status or session number. Both come from the paper's code table (mouse_df.csv), which agrees with Table 2 for all 50 sessions on QC, date, depth, ROI count and tracked ROI count (-1 in the table for 0), and whose session numbers run 1, 2, ... in date order within each mouse.table2-sessions
    • The claim holds under span reading (ii), calendar days inclusive, and not under (i).session-schedule
    • The theoretical maximum is not defined in the paper; the claim holds under reading (a), the sum of the smallest session ROI count of each mouse, and not under (b) or (c).tracked-rois-per-plane
    • The public package (version 0.6.0, default parameters) in place of the paper's custom-modified version, which is not public, as the claims file directs.fig8-ordering-variation
    • Assumed that the dendritic overlap is the intersection over union of the registered masks that the package reports, applied to every pairwise match within a three-session match. The paper does not define the overlap; IoU is the overlap measure the package itself computes. The result holds at both thresholds the criterion names.fig8-ordering-variation
    • The package expects an average intensity projection for registration; the files hold only a max projection, which is used in its place.fig8-ordering-variation
    • The six directed pairwise matchings of each mouse are computed once and combined per ordering, as NwayMatching.run combines them (itertools.combinations in the given order); the notebook checks this against NwayMatching.run on all six orderings of 418779 and 420011 (12 of 12 equal). The package's summary plots are not made; they fail with the locked pandas (a read-only array in numpy.fill_diagonal) and do not change the matches.fig8-ordering-variation
    • A pair of ROIs within a three-session match that has no direct pairwise match counts as IoU 0, so the match fails any threshold; the variant that applies the threshold only to linked pairs is shown and gives the same outcome.fig8-ordering-variation
    • Assumed that durations are judged on the sampling grid the Methods state ("sampled randomly and uniformly ... across multiples of 1.5 seconds for the Gabor sequence stimulus and of 1 second for the visual flow stimulus", Methods, Visual stimulation, paragraph 4), as the stated ranges describe the design; measured row times run past the grid values by display timing, up to 0.39 s, and on row times 49 consistent, 377 Gabor and 347 flow inconsistent runs fall outside the ranges.inconsistent-event-fraction
    • Assumed that the block count is judged on its mean over sessions, as "approximately 30 blocks" describes sessions in general; per session 2 Gabor and 11 flow counts of 33 fall outside 27 to 33.inconsistent-event-fraction
    • Block counts hold under reading (i), per stimulus, and not under (ii), per session.inconsistent-event-fraction
    • Reading (b) for Gabor computes the legend's criteria on single consistent sequence responses from 0.9 s before to 0.6 s after D onset (the Fig. 5a legend's selection); for flow on single inconsistent flow responses from 2 s before to 2 s after onset, with the mean response after minus before onset as the inconsistent minus consistent difference. Under (b) the flow selection uses the tested difference itself, so its test is not independent of the selection.fig5-stimulus-responses
    • The paper's code scales traces for this figure ((trace - median) / (95th - 5th percentile), analysis/session.py); the claims file uses unscaled dF/F, and the scaled result is a variant with the same outcome.fig5-stimulus-responses

    The ISI part holds for all 999 units (largest fraction of intervals below 3 ms 4.93%). Method differences

How the tests differed from the paper’s method or data, and the claims each applies to.

  • Video frame counts are read from each file's duration tag at the nominal 30 frames/s, not by decoding 2 TB of video. Every duration is a whole number of seconds; the container duration equals the tag in all 115 files. No video stream reports its own frame count (0 of 115), so the tag is the only count the headers give.dataset-size
  • Reading (b) takes the longest of the four whiskers' raw pose series in each session, as the criterion's N_frames differs between whiskers.dataset-size
  • The samples of each Open Ephys file are computed from its size (1024-byte header, 2070-byte records of 1024 samples). To leave out segments apart from the main recording, such as the test recordings the Data Records mention ("In some cases the Open Ephys file includes test recordings that were just a few seconds long"), segments are found from the first and last record headers and a bisection on the record timestamps of channel CH1, which splits each file where the timestamps break; the longest contiguous segment is taken as the main recording.neural-hours
  • The files hold stimuli "flatter convex" and "flatter concave", which Table 6 does not list. The rule is judged on the Table 6 stimuli, and the flatter shapes are shown apart with the rule of their shape.task-rules
  • The criterion allows the task from the experiment description or the keywords. The description is used. The keywords include "shape discrimination" in all 115 files, the 30 detection sessions included, so they cannot name the task.nothing-detection-only
  • For each whisker the angle timestamps are read in full; the other six processed series are checked to have the same length and the same first and last time, not read in full.video-timebase
  • The files hold no timestamps array, contrary to Table 2; the rate and regular spacing are taken from the stored rate, which equals (samples minus one) over the span.neural-timestamps
  • In reading (a) the last, partial 60 s bin of each unit's interval is left out (a standard choice).unit-quality-isi
  • The change per minute in spike amplitude is measured, for information only, as the slope of a least-squares line of Kilosort amplitude against time over the mean amplitude; the paper does not say how it measured it. Kilosort amplitudes are template scaling factors, not microvolts, and the paper gives no detection threshold, so the other amplitude criteria cannot be run.unit-quality-isi
  • The layer names of the files ("1", "2/3", "4", "5a", "5b", "6", "6b") are read as L1 to L6, with 5a and 5b in L5 and 6b in L6.unit-depth-layer
  • A whisker with no contacts table in a session (C0 in 21 sessions, C3 in 8) is counted as making no contacts there.c0-rare-contacts
  • A contact covers its frames from start to stop inclusive, as duration_frames = frame_stop - frame_start + 1 and stop_time = frame_stop x 0.005 s in the files (shown in the notebook).session-labeling-quality

What attempts found about the dataset itself, for its owner and the archive.

  • Metadata errorThe session start times are stated with a Pacific offset (-07:00 or -08:00), but their clock values are those Supplementary Table 1 gives as UTC, for all 50 sessions. For four sessions (412933 session 765427689, and 418779's three sessions) the stated date is a day after the imaging date of Table 2, and the date of birth implied by 418779's age is a day after Table 1's.
  • Metadata errorThe three sessions of mouse 433414 are recorded at a depth of 60 um; Table 2 and Supplementary Table 1 give 75 um. Which is right is not known from the files.
  • Description missingThe files hold no QC result, local session number or stimulus seed. The paper's analyses use only sessions 1 to 3 that passed QC, and the dandiset's description points to an outside table (the metadata repository) for which sessions were excluded.
  • Description missingThe imaging plane (somata or distal apical dendrites) is not recorded; it follows from the depth. The field of view in um is not recorded.
  • Description missingVisual flow square size and position are given in pixels of the unwarped stimulus, with no screen geometry to convert them to the degrees the paper states (8 degrees, 50 degrees/s).
  • OtherThe dF/F of the 28 dendritic sessions is stored gzip-compressed in small chunks (991 to 1994 frames by 5 to 26 ROIs), and the chunk index is spread through the file, so streaming it through remfile and h5py is slow; the 22 somatic files store it contiguous. The notebook therefore streams each basic file whole into memory before reading it.
  • OtherIn two sessions the dF/F response to grey screen transitions does not exceed the 99th percentile of the responses at shifted times (777496949, 15 ROIs, above 94.6% of them; 838633305, which failed QC and whose experimental notes in Supplementary Table 1 say the laser was set to 800 nm, while the file states 910 nm), so their alignment to the trial table could not be shown. It is shown in the other 48.
  • Methods not availableThe per-ordering ROI matching counts behind Fig. 8 are published for two mice only, and the paper's modified matching code is not linked, so the comparison of order dependence between somata and dendrites cannot be repeated.

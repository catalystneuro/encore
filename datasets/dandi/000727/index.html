    • ⊘Blocked· Too large to analyse

      figs4a-supervoxel-number

      Needs Ward clustering of every plane of the nine flies pooled at seven cluster numbers, so every voxel of all 91 planes. The 12 planes streamed here are 22.1 GB compressed and took 306 s in the latest run (214 s in the run before), including about 40 s for metadata; all 91 planes are several times that, which leaves no room within the 30 minute limit for the clustering itself. The files total 610 GB. A partial sweep on the 12 streamed planes was not attempted. It would need each plane's voxel time series held in memory (about 27,000 in-brain voxels x 30,456 points, some 3 GB per plane) for Ward clustering at seven sizes, followed by the PCA and ridge models at each size, while the streaming here keeps only block means and per-voxel sums.

    Findings about the data

    What attempts found about the dataset itself, for its owner and the archive.

    • Description missingThe processed volumes are registered into the Functional Drosophila Atlas, but the dandiset holds no neuropil labels, atlas or template for that space, nor the paper's own mean brain and registered atlas. None of the paper's region-level results (Figures 2E to I, 3, 6E to G, 7) can be tested.
    • OtherThe processed series is in the Functional Drosophila Atlas, a space from a later paper of the lab, while the preprint analyses its data in its own mean brain. The dandiset does not say how the FDA series relates to the preprint's analysis space or which preprocessing it shares.
    • Data missingThe per-plane acquisition times of the Bruker recordings are not in the files, which give only a volume rate. The paper aligns behaviour to each plane's time. Sampling behaviour at the start in place of the middle of each volume changes the correlated share of the brain from 31.1% to 39.2% and the 99th percentile of forward-velocity lead from 0.32 to 0.58 s.
    • Data missingThe supervoxel labels, the z-depth maps used to give each supervoxel its acquisition time, and the motion-corrected tdTomato channel used as the paper's motion control are not deposited.
    • Description missingThe processed series has grid spacing 1, 1, 1 in unit "unknown", so its voxel size is not given, and nothing states which half of the volume is the fly's left.
    • Description missingImaging and FicTrac both start at 0 s; the conversion code set FicTrac timestamps to a uniform 50 Hz from 0 because synchronisation data were missing, and the dandiset does not say so. The data are consistent with a shared start (brain-wide activity follows walking speed by 0.4 to 0.8 s in every fly), to within a few hundred milliseconds.
    • Metadata errorEvery FicTrac SpatialSeries has unit "meters" and conversion 0.0045 (the ball radius), while most hold angles in radians, as their descriptions say (heading, orientations, positions in radians, speed in radians per frame). SpatialSeriesRotationDeltaError, described as an error in radians, has medians of 6067 to 10,435.
    • Published code disagreesThe paper's code computes the walking state with np.sqrt(a, b), where b is taken as the output array, so the state reduces to absolute forward velocity over its s.d. above 0.2; the line was written to combine forward and rotational velocity. The two versions mark 47.2% and 57.3% of time points as walking.
    • Paper inconsistentThe Methods cite Figure 3F and 3G for the PCA model sweep and the per-fly PCs, which are in Figure 4F and 4G. The Results describe Figure 3G as the Nodulus, while the Figure 3 legend calls panel G the Ellipsoid Body.
    • OtherThe preprint says the microscopy and behavioural data were deposited at Dryad and the code at GitHub, with DOIs in a key resources table that the preprint does not include. No Dryad record of these data was found, and the dandiset links neither the analysis code nor Dryad. The analysis code was found as ClandininLab/brezovec_volition_2023, whose README gives a different title.

    Reproduction Brain-wide neural correlates of walking in Drosophila (Brezovec et al. 2022)

    Tests the findings of Brezovec, Berger, Druckmann and Clandinin (2022) on dandiset 000727, which holds whole-brain two-photon imaging and ball tracking of nine walking flies. It streams 12 planes of the authors' processed volumes in the Functional Drosophila Atlas for all flies, and tests the voxel correlations with forward and turning velocity, their symmetry, the principal components and the models that predict velocity from them, the demixing of velocity components, and the timing of neural activity relative to behaviour. Region-level results cannot be tested, as the dandiset has no neuropil labels. All files

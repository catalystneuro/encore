Method differences

How the tests differed from the paper’s method or data, and the claims each applies to.

  • Assumed that the deposited seed maps, one per session, are the maps the paper analysed. The paper leaves open whether runs were concatenated or averaged, and only one version is deposited, so only one run reading can be run.   • The paper reports no test for monkey D; the criterion applies the Methods' ANOVA to its bins.ed1-monkey-d-no-change
  • The model terms and the Tukey-Kramer family (the 12 PrePost x side x tract cells) are those of the paper's Fig2A script in the dandiset (`anovan` with `model_mat2`, `multcompare` with Dimension [2 3 4]), which the claims file left to the code. Monkey enters as a main effect only, which the claims file's reading also has.fig2a-cb-fa-increase
  • Subregions are the labels in the dataset (column `part`), which the criterion says to use; the model is that of the Fig2B script.fig2b-mcc-cb-fa-increase
  • The connectome is the group average the dandiset holds, not recomputed from runs; its ROIs have no names, and the cortical block is taken from the Fig. 4 script (first 54 ROIs).fig4a-cortical-down-subcortical-up
  • The matrices have 123 ROIs, so each ROI has 122 values, the n of the legend; the threshold uses 123 as the script and the amended criterion do (0.01/122 is also shown).fig4b-roi-changes-counts
  • The deposited seed tables hold one value per voxel and session (column date), and the paper's scripts analyse them as they are. The paper does not say whether a session's map comes from concatenated runs or from per-run maps averaged; the file name's "concatenated" may refer to runs or to subjects and ROIs combined in one sheet. Only this one version is deposited, so only one of the criterion's two run readings is run.fig5a-pre-scc-connectivity
  • One seed map per session as deposited, as for fig5a-pre-scc-connectivity.fig5b-scc-decreases
  • SciPy's studentized range tail loses accuracy for small P. Against the reported values the computed P is 1.12 to 1.14 times them near 1e-5 (HIP, AMY), 1.11 to 1.28 times near 1e-6, 1.5 to 2.8 times between 5e-9 and 4.4e-8, and 5.5 times for PCC (4.5e-11 against 8.22e-12); below about 1e-11 it prints a floor or 0.

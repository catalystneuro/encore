Findings about the data

What attempts found about the dataset itself, for its owner and the archive.

  • Data missingThe dandiset holds one recording session (2016-12-11) of monkey H, with 54 units, where the paper analyses 17 sessions of H and 12 of monkey G (617 and 741 units recorded, 536 and 636 kept for analysis). The dandiset's description does not say that it holds one session of the paper's 29 or which one. The 48 units that pass the paper's rate rule match its count for the single session of H used for GPFA.
  • Data missingFollowing the Neural Latents Benchmark design, 283 trials of the session are in the test file without ts, tp, prior, effector or direction and without 14 of the 54 units, on a separate clock. These trials cannot be used for any analysis of the paper.
  • Metadata errorThe description of the `iti` column says 500 ms after Short prior trials and 1220 ms after Long ones; the values are the reverse (Short 1220, Long 500), as the paper states.
  • Description missing`tp` is described as the time between Set and Go, but is a median 17.9 ms longer than go_time minus set_time (5th to 95th percentile 1.1 to 29.8 ms, up to 200.6 ms in used trials). `ts` is the nominal interval, within 23.5 ms of ready_time minus set_time. Neither difference is documented.
  • Selection not documentedThe `is_outlier` flag is described only as a probabilistic mixture model. It flags 46 completed trials (4.47%); a refit of the Methods' Gaussian and uniform mixture per prior, ts, effector and direction flags 10 of these and no others, and the other 36 have tp from 0.53 to 1.60 times ts.
  • Description missingUnits carry no single-unit or multi-unit label and no electrode or probe; the electrode table has no positions or impedances and gives the filtering as unknown. The paper distinguishes 456 single units from 902 multi-units.
  • Methods not availableThe paper's analysis code is available only on request. The code the dandiset links (nlb_tools) loads the data and scores benchmark models, and holds none of the paper's analyses.
  • Paper inconsistentFor the single high-yield session of each monkey used for GPFA, the Results give the number of neurons as N = 48 for monkey H and N = 107 for monkey G, the Methods as N = 48 in H and 96 in G.

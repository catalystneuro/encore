Reproducing Asari & Zador (2009) from CRCNS ac-1¶

Paper. Asari H, Zador AM (2009). Long-lasting context dependence constrains neural encoding models in rodent auditory cortex. J Neurophysiol 102:2638-2656. doi:10.1152/jn.00577.2009

Dataset. CRCNS ac-1, Asari, Wehr, Machens & Zador (2009), "Auditory cortex and thalamic neuronal responses to various natural and synthetic sounds", doi:10.6080/K0KW5CXR. Streamed from the public S3 bucket crcnsarchive (ac-1/), zip files opened in place.

Version. CRCNS data sets are not versioned, so the version is recorded as unversioned (docs/archives.md, CRCNS). The paper cites no version. The files read and their MD5 sums from the data set's checksums.md5 (2026-11-14) are crcns-ac1.zip 2300ee76d93383ab8c808ddf16761a23, crcns-ac1-asari-results-1.zip 18537da81d98e311c0274f62aea04daa and crcns-ac1-asari-results-2.zip 2f7ab955cc778fc6839ce59ed51bce89; a later change of the files would change these sums. This is the only version the archive offers, and its contents match the claims file's description (39 natural-sound A1 cells, 14 MGB cells, the synthetic-sound cells).

Claims. claims/asari-2009.yaml, written from the version of record (text extraction of the publisher's PDF); the supplement was not read by the claims reader.

Code. The paper links no code. The data set ships the authors' analysis scripts (asari/Tools/CxtDep.m, "Basic analysis script for Asari and Zador (2008)", with ViewResp.m, GetEvoked.m, GetSpikes.m; wehr/Tools/STRFanalysis.m). They are followed here where the Methods leave a detail open; asari.py says which detail comes from where.

Checks of the description against the data are stated with the numbers above: all A1 recordings are whole-cell (current clamp) and all MGB recordings cell-attached, at 10 kHz, in mV. No recording in the data set is a voltage-clamp recording. The fragment durations stored with each recording add up to the trigger duration of each sequence to within a fraction of a millisecond, except in the files listed: in two cells (one A1, one MGB) the fragment lists of a cell's two files are swapped, the stored durations of each file fitting the triggers of the other exactly, and here each file's probes are cut with the list that fits its triggers; in one synthetic recording the triggers are 308 ms longer than the seven stored fragment durations (4200 ms each) in every sequence; no other file fits, and the stored durations are used, as the authors' CxtDep.m would use them. The gaps between sequences are about 6 s for the natural-sound recordings, as the Methods say, and shorter in others (minimum and median above). Every sequence onset evokes a response in nearly every file while the same contrast moved into the silence does not, which is consistent with the triggers sharing the clock of the traces; files without an onset effect are listed.

def cell_rates(infos, key=None):
    agg = {}
    for i in infos:
        r = i["rates"][key] if key is not None else i["rates"]
        a = agg.setdefault(i["cell"], dict(sp=0.0, sp_t=0.0, ev=0.0, ev_t=0.0, pre=[]))
        a["sp"] += r["spont"] * r["spont_s"]; a["sp_t"] += r["spont_s"]
        a["ev"] += r["evoked"] * r["evoked_s"]; a["ev_t"] += r["evoked_s"]
        a["pre"].append(r["pre1s"])
    return pd.DataFrame([{"cell": c, "spont": a["sp"] / a["sp_t"], "evoked": a["ev"] / a["ev_t"],
                          "pre1s": np.nanmean(a["pre"])} for c, a in agg.items()])

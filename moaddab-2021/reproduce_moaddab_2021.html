Reproducing Moaddab & McDannald (2021) from CRCNS rrf-1¶

Paper: Moaddab M, McDannald MA (2021). Retrorubral field is a hub for diverse threat and aversive outcome signals. Current Biology 31:2099-2110, doi:10.1016/j.cub.2021.02.055.

Dataset: CRCNS rrf-1, "Recordings from retrorubral field neurons in male rats undergoing fear discrimination", doi:10.6080/K04B2ZJ5, read from the public S3 bucket crcnsarchive (rrf-1/live/data.zip). CRCNS data sets are not versioned; the version is recorded as unversioned. There is only one published state to pin: the bucket holds one live copy, with data descriptor version 0.6 (April 23, 2021), the only version in its change history. The files read are identified by the MD5 sums in the data set's checksums.md5: data.zip bf5cb2951c928394084d7b67c6b4663b (the same as the S3 ETag; the notebook checks it). Inside the zip, data/cubeFile/cube.mat (the authors' derived file of all units) and data/matFiles.tar (one file per unit with spike and event times) are read in memory.

Claims: claims/crcns-rrf-1/10.1016-j.cub.2021.02.055.yaml, written from the version of record with its supplement (Figures S1 to S6, Tables S1 to S4).

The data set also holds the paper's MATLAB code (cubeScriptPR25.m, rrfAnalysis.m). The claims file's last check asks an author who finds the code to follow it where it settles an open reading; the helper rrf.py cites the lines followed.

# Clock check: spikes against the trial table. For each unit, danger against safety spike count
# (t test over trials) in the 12 s from cue onset; in the 12 s from 20 s before cue onset (no cue);
# and from cue onset with the trial labels moved one trial later in time (each trial takes the
# type of the trial before it).
def frac_discriminating(start, shift_labels=False):
    hits = []
    for i, n in enumerate(names):
        u = by_name[n]
        on = cube["tag"][:, 1, i]
        lab = rrf.TRIAL_TYPE.copy()
        if shift_labels:
            order = np.argsort(on)
            lab[order[1:]] = lab[order[:-1]]
            lab[order[0]] = 0
        t0 = on + start
        cnt = np.diff(np.searchsorted(u["spike"], np.stack([t0, t0 + 12]).T, side="right"), axis=1)[:, 0]
        p = stats.ttest_ind(cnt[lab == 1], cnt[lab == 4]).pvalue
        hits.append(np.nan_to_num(p, nan=1.0) < 0.05)
    return np.mean(hits)

kmeans-elbow¶

In k-means clustering of the 423 cue-responsive units, the mean squared Euclidean distance to the centroid falls as the cluster number rises from 1 to 15, and the decrease diminishes after eight clusters.

The matrix is the code's: 1-s normalized firing, cue bins 0-10 s for danger, uncertainty and safety, and six 1-s bins from 13 s after cue onset for the four outcome types (rrfAnalysis.m, "K means clustering"; the code starts the outcome epochs at 13 s, 0.5 s after shock offset). The code runs rng(1); kmeans(aa, k) once for each k. MATLAB's k-means with its default generator is reproduced exactly here (rrf.matlab_kmeans; the next section shows it gives the paper's eight cluster sizes), so the main reading is the code's own run. The measure is the mean over units of the squared distance to the centroid (Methods); the code's measure, the mean over clusters of the summed squared distances (mean(sumd), sum at k = 2, which is what the code plots for Figure 1E), is shown too. Variants: the claims file's readings of the outcome start (e-a: 12 s, or 12.5 s from the 250-ms z-scores) and of "10 times" (e-b: best of 10 replicates, or the mean of 10 runs), and the Methods' normalizations z-a and z-b. The 10 runs are made two ways: continuing the MATLAB stream after rng(1) (rrf.matlab_kmeans with replicates=10, an assumption about how 'Replicates' draws, since the code never uses it), and with scikit-learn's k-means++, whose greedy seeding differs from MATLAB's.

def kmeans_matrix(start, mm1=None, mm250=None):
    """start: outcome epoch start in s after cue onset (13 code, 12 or 12.5 claims e-a)."""
    to1 = lambda a, b0, n: a[b0:b0 + 4 * n].reshape(n, 4, -1).mean(1)
    if mm1 is not None and start in (12, 13):
        b = slice(20 + start, 26 + start)                  # 1-s bin j covers (j-20, j-19] s
        parts = [mm1[t][20:30] for t in ("D", "U", "S")] + [mm1[t][b] for t in ("D", "US", "UO", "S")]
    else:                                                  # from 250-ms bins
        b0 = int(round((start + 20) * 4))
        parts = [to1(mm250[t], 80, 10) for t in ("D", "U", "S")] + [to1(mm250[t], b0, 6) for t in ("D", "US", "UO", "S")]
    return np.concatenate(parts, axis=0).T

def elbow(X, mode, seed=0):
    rows = []
    for k in range(1, 16):
        if mode == "code":
            lab, sumd = rrf.matlab_kmeans(X, k, seed=1)
            sumds = [sumd]
        elif mode.startswith("MATLAB"):
            runs = rrf.matlab_kmeans(X, k, seed=1, replicates=10, all_runs=True)
            sumds = [min(runs, key=lambda r: r[1].sum())[1]] if mode == "MATLAB best of 10" else [r[1] for r in runs]
        else:
            fits = [KMeans(k, n_init=10, random_state=seed).fit(X)] if mode == "best of 10" else \
                   [KMeans(k, n_init=1, random_state=seed + r).fit(X) for r in range(10)]
            sumds = [np.bincount(f.labels_, weights=((X - f.cluster_centers_[f.labels_]) ** 2).sum(1), minlength=k)
                     for f in fits]
        msd = np.mean([sd.sum() / len(X) for sd in sumds])
        code_measure = np.mean([sd.sum() if k == 2 else sd.mean() for sd in sumds])
        rows.append((k, msd, code_measure))
    return pd.DataFrame(rows, columns=["k", "mean sq distance", "code mean(sumd)"]).set_index("k")

def elbow_verdict(curve):
    d = -np.diff(curve.to_numpy())           # drop from k to k+1, k = 1..14

BIN_NAMES = ["pre1", "pre2"] + [f"cue{i}" for i in range(1, 11)] + ["delay1", "delay2"]

def peak_betas(tp, fo, peaks_by_cluster, invert=True):
    rows_tp, rows_fo, grp = [], [], []
    for k in SEVEN:
        a = int(round(peaks_by_cluster[k] / 0.125))
        sign = -1.0 if (invert and k in rrf.INVERTED) else 1.0
        rows_tp.append(sign * tp[cl == k, a]); rows_fo.append(sign * fo[cl == k, a]); grp += [k] * (cl == k).sum()

Bootstrap CIs over 20 draws and with MATLAB's nested standard errors¶

Several CIs end within 0.01 of zero, where one random draw decides whether they exclude it. Every CI that a criterion judges (behavior, Table S1, Figure S4, Table S2 and Table S4) is redrawn here with 20 seeds, with the main reading's standard errors (s / sqrt(n)) and with the nested bootstrap that MATLAB's bootci(..., 'type', 'student') uses when no StdErr is given (100 samples per standard error; MATLAB documentation, NBootStd). For the outcomes, each CI is judged by the sign it gives in most of the 20 draws; the per-claim sections show the single draw of their own seed.

How the analysis differs from the paper's. The data set includes the paper's MATLAB code, and the analysis follows it wherever the claims file left a reading open: the trial-level z-scores the code computes (the Methods describe z-scoring trial-type means; the claims file's readings z-a and z-b of the Methods are shown as variants, under which the code's k-means run no longer gives the paper's clusters; every claim that uses normalized firing or the clusters is therefore marked as resting on the assumption that the code is what the paper did), the code's k-means matrix (outcome epochs from 13 s after cue onset) and its single k-means run, reproduced outside MATLAB so that the cluster sizes are the paper's (there is no label file to check membership), the cluster-specific tuning periods, and the sign inversion of k4, k6 and k8. Statistics are recomputed in Python: repeated-measures ANOVAs from sums of squares (type III for the within effect of the mixed designs, as SPSS), studentized bootstrap CIs with 1,000 resamples and standard errors s / sqrt(n), where MATLAB's bootci estimates them by a nested bootstrap; each CI is judged by the sign it gives in most of 20 draws (this attempt's convention; the claims file sets none), which changes fig6f-k6-ppe-then-valence from the single draw's 7 of 7 to 6 of 7. Meng's Z. The outcome windows of Figure 6 are those the claims file reads from the gray boxes; for k1, k3, k5 and k6 Table S4's values come from 0 to 4 s, not 0 to 8 s.

What was found about the data set. It holds every unit, session and rat the paper reports, and the authors' derived file (cube.mat) agrees exactly with the spike and event times of the unit files.

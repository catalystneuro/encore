Reproducing Robotka et al. (2023) from CRCNS aa-5¶

Paper. Robotka, Thomas, Yu, Wood, Elie, Gahr & Theunissen (2023), "Sparse ensemble neural code for a complete vocal repertoire", Cell Reports 42, 112034, doi:10.1016/j.celrep.2023.112034.

Dataset. CRCNS aa-5, "Simultaneous extracellular recordings of avian auditory neurons in freely behaving zebra finches...", doi:10.6080/K0TT4P5Q, read from the public bucket crcnsarchive/aa-5/live/. CRCNS data sets are not versioned: the version is recorded as unversioned, the one published version there is, and the MD5 sums of every file read (from the data set's checksums.md5) are printed below so that a later change can be detected. The paper cites this DOI and no version; the bucket holds a single copy (live/, data descriptor v0.6 of 29 Nov 2022), so that is what is pinned.

Claims. claims/robotka-2023.yaml, written from the version of record with its STAR Methods and supplement, and the paper's code (github.com/ftheunissen/Ensemble-Code-Cell-Reports-2022 at commit f2d2376). Method details the claims file lacks are taken from the paper and that code, cited in the helper aa5.py and below.

The per-trial database and the clock of spikes and stimuli¶

Auditory units (SNR >= 5, auditory test p <= 0.01, with vocalization trials; C1 and GenerateDataBase.ipynb), their trial Z (C2), the PCA of trial-averaged KDE responses and the per-trial T1 to T5 (C4). Spike times are stored relative to stimulus onset. The check that they share the stimulus clock: the population rate around onset, and decoding call type from spike counts in a window before onset (where no information should be) against the same window after onset.

def unit_regressors(name):
    # Per good unit: MRF projections (per window and LDA rule), SI (a, b), ES (a, b), neural noise (variance, SD)
    g = good[name]
    cv, nperm, m = readings[name]
    allz = np.concatenate([db["trials"][x]["z"].to_numpy() for x in g])
    allT = np.vstack([db["T"][x] for x in g])
    sdz, sdT = allz.std(), allT.std(axis=0)
    sres = single[(name, "ZT")]
    pos = {x: i for i, x in enumerate(full)}
    out = {}
    for x in g:
        tr = db["trials"][x].copy()
        T = db["T"][x]
        for k in range(5):
            tr[f"T{k + 1}"] = T[:, k]
        w = tr.groupby("stim")[["z", "T1", "T2", "T3", "T4", "T5"]].mean().reindex(db["stims"])
        za, zb = aa5.zct_unit(byuid[x], db["trials"][x])
        noise_var = np.mean([g_.z.var(ddof=0) for _, g_ in tr.groupby("call")])
        noise_sd = np.mean([g_.z.std(ddof=0) for _, g_ in tr.groupby("call")])
        conf, nt = sres["conf"][pos[x]], sres["ntest"][pos[x]]
        out[x] = dict(w=w.to_numpy(), SI_a=aa5.selectivity_index(za.values()), SI_b=aa5.selectivity_index(zb.values()),
                      ES_a=aa5.entropy_selectivity(conf, nt, True), ES_b=aa5.entropy_selectivity(conf, nt, False),
                      noise_var=noise_var, noise_sd=noise_sd)
    scale = np.concatenate([[sdz], sdT])
    proj = {}
    for win in ["methods", "code"]:
        X = mps[win][:, fsl, tsl]
        dev = (X - X.mean(axis=0)).reshape(len(X), -1)
        for rule in ["largest", "eigh"]:
            axes, _ = aa5.lda_axes(X, db["y"], rule)
            for x in g:
                mrf = dev.T @ np.nan_to_num(out[x]["w"])            # (features, 6): sum over stimuli
                proj[(win, rule, x)] = (axes.T @ mrf).T / (110 * scale[:, None])   # 6 x 3
    return out, proj

def ensemble_table(name, out, proj):
    rows = []
    for e in ens5[name]:
        r = {}
        for win in ["methods", "code"]:
            for rule in ["largest", "eigh"]:
                V = np.vstack([proj[(win, rule, x)] for x in e])
                r[f"logvol_{win}_{rule}"] = np.log(np.linalg.det(np.cov(V.T)))

            r[k] = np.mean([out[x][k] for x in e])
        rows.append(r)
    return pd.DataFrame(rows)

How the analysis differs from the paper's. The Methods and the paper's code differ on the decoder's cross-validation (one exemplar per call type held out, against one random trial per stimulus); both are run, and the ensemble claims are judged on the code's, whose results match the paper's printed values (an assumption). The code's scheme tests trials of exemplars it was trained on, so it rewards exemplar-specific responses as well as call-type ones (78% against 10% on synthetic units with exemplar signal alone). For Figure 5 the code's sound window and LDA axes are likewise adopted where they decide the outcome, as the paper's printed values come from them. The Figure 4B ensembles are decoded once each (the Methods' single leave-one-out; the code ran 100 repetitions). Both readings of zCT, SI, ES, neural noise, the MPS window, the LDA axes and the 30% ensemble filter are shown. The good-unit set is selected here (89 units) and differs from the paper's 100. The best ensemble of fig4b-top-ensembles is taken from the 1,800 Figure 5 ensembles decoded with 100 repetitions, not from the Figure 4B ensembles decoded once. The neural clustering of Figure 6C is run on the 1,800 Figure 5 ensembles, not the legend's 10,000, and its tree is cut on both the C12 threshold grid and the code's.

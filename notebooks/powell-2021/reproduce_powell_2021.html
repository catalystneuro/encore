Reproducing Powell et al. (2021) from Zenodo record 3924718¶

Paper. Powell D, Haddad SA, Gorur-Shandilya S, Marder E (2021). Coupling between fast and slow oscillator circuits in Cancer borealis is temperature-compensated. eLife 10:e60454. doi:10.7554/elife.60454. The claims file (claims/powell-2021.yaml) was written from the version of record (Europe PMC, PMC7889077) with its figure supplements, and from the paper's code, https://github.com/marderlab/gastric at commit fa07d36a7e57fc7787a9a8e2fed72300b1a8e6e2.

Dataset. ZENODO:3924718, DOI 10.5281/zenodo.3924718, record 3924718. The paper's data statement cites https://zenodo.org/record/3924718, this record, and the deposit has no other version (concept 3924717 has the one version 3924718), so it is pinned. Files read: evoked_data.mat whole (72,856,015 bytes, MD5 7b4062371133a07e373900cde8c42b15, checked on loading), the zip directories of the eleven zip files (their central directories only, not their contents), and the first 200 kB of the first ABF file of 941_003.zip and 941_006.zip and of 901_046_0006.abf in 901_046.zip, for their headers. Those partial reads have no MD5 to check.

What the record holds. evoked_data.mat holds the sorted PD, LG and DG spike times, the saline temperature and a stimulation mask (1 kHz) of the ten evoked preparations of the paper's second set (Methods, N = 10, 2017). The zip files hold the raw ABF recordings of nine of those ten (no zip for 901_005) and of two preparations recorded in June 2019 (941_003, 941_006) that are in no set the paper describes, with no spike annotations. The spontaneous set (nine preparations of Haddad and Marder 2018) and the set with the pyloric pacemaker hyperpolarized (nine preparations, 2020) are not in the record. The record has no README; its description is the paper's abstract.

Burst rule. The Methods keep bursts of at least 5 spikes (LG, DG) or 2 (PD); the paper's code (crabsort.computePeriods) compares the count with the number of ISIs in the burst, so it keeps bursts of at least 6 or 3 spikes. Every claim is tested under the Methods rule, as the claims file states it, and the code's rule is shown as a variant.

# Clocks. (1) Stimulation mask against LG spikes: LG bursting should follow each stimulation.
# LG burst starts in the 300 s after the end of each stimulation block (mask 0, blocks separated
# by > 120 s) against the 300 s before its first train, and with the mask shifted by +-1000 s.
def lg_after_before(p, b, shift_s=0.0):
    stim = np.flatnonzero(~p["mask"]) / 1e3 + shift_s
    if len(stim) == 0:
        return np.nan, np.nan
    gaps = np.flatnonzero(np.diff(stim) > 120)
    firsts = np.r_[stim[0], stim[gaps + 1]]
    lasts = np.r_[stim[gaps], stim[-1]]
    s = b["LG"]["starts"]
    after = np.mean([np.sum((s > l) & (s < l + 300)) for l in lasts])
    before = np.mean([np.sum((s > f - 300) & (s < f)) for f in firsts])
    return after, before

fig4c-q10-about-2¶

Most preparations (8 of 10) had a cycle period Q10 of about 2 for both the pyloric and the gastric mill rhythm.

The Methods' Q10 (one per temperature, from the mean frequency at T against 11 C, averaged per preparation) is the main analysis; the code's per-burst Q10 is a variant. Which temperatures enter the Methods' Q10 is not fixed by the claims file. The Methods compute it "at every temperature", the temperatures being the steps of the protocol, held "for the duration of evoked gastric mill activity" (Methods, "Spontaneous and evoked gastric mill rhythm temperature ranges"). Most preparations pass through 9, 13 and 17 C only on the way between 4 C steps (data check), with 1 to 17 LG bursts there; a Q10 from such a bin next to 11 C is raised to the power 5. Two readings are run: (i) every bin with bursts, (ii) only bins held at least 120 s (the temperature steps). T is the bin centre; as a variant, T and T_11 are the mean measured temperatures at the starts of the bursts in each bin (suffix _mT), since a bin centre can be far from the temperatures a pass-through bin was crossed at.

def q10_table(Bx):
    rows = []
    for p, b in zip(preps, Bx):
        steps = [c for c, s in stg.held_seconds(p).items() if s >= 120]
        r = {"prep": p["name"]}
        for neuron, limit in (("PD", 5), ("LG", 50)):
            r[f"{neuron}_all_bins"], q_all = stg.q10_methods(p, b, neuron, limit)
            r[f"{neuron}_steps"], _ = stg.q10_methods(p, b, neuron, limit, bins=steps)
            r[f"{neuron}_all_bins_mT"], _ = stg.q10_methods(p, b, neuron, limit, temperature="measured")
            r[f"{neuron}_steps_mT"], _ = stg.q10_methods(p, b, neuron, limit, bins=steps, temperature="measured")
            r[f"{neuron}_code"] = stg.q10_code(p, b, neuron, limit)
            r[f"{neuron}_per_bin"] = {c: round(v, 2) for c, v in q_all.items()}
            _, q_mT = stg.q10_methods(p, b, neuron, limit, temperature="measured")

def pooled_coupling(Bx, slow):

def ks_by_bin(cat, claim, reading, k_seed=0, n_rep=1000):

def areas(cat, rng, shuffle="perm"):
    ok = np.isfinite(cat["x"]) & np.isfinite(cat["y"])
    if shuffle == "perm":
        rand_rem = np.mod(cat["y"] / cat["x"][rng.permutation(len(cat["x"]))], 1)
    else:   # independent draws with replacement, as the KS shuffle of plotIntegerCoupling.m
        xo, yo = cat["x"][ok], cat["y"][ok]
        rand_rem = np.mod(yo[rng.integers(0, len(yo), len(yo))] / xo[rng.integers(0, len(xo), len(xo))], 1)
    rand_rem = rand_rem[np.isfinite(rand_rem)]
    A = np.full((len(stg.BIN_CENTRES), 10), np.nan)
    R = A.copy()
    for i, c in enumerate(stg.BIN_CENTRES):
        for j in range(10):
            v = cat["rem"][stg.in_bin(cat["temp"], c) & (cat["prep"] == j)]
            v = v[np.isfinite(v)]
            if len(v) < 30:
                continue
            rr = rand_rem[rng.integers(0, len(rand_rem), len(v))]
            A[i, j] = stg.integerness(v, rng)
            R[i, j] = stg.integerness(rr, rng)
    def ms(X):
        n = np.sum(np.isfinite(X), 1)
        sem = np.where(n > 1, np.nanstd(X, 1, ddof=1) / np.sqrt(n), 0.0)
        return np.nanmean(X, 1), sem, n
    return ms(A), ms(R)

def spike_pdf_table(Bx, neuron):
    stops, sT, ph, T = [], [], [], []
    for p, b in zip(preps, Bx):
        s, t = stg.measure_phase(p, b, b["PD"]["ends"])
        stops.append(s); sT.append(t)
        a, t2 = stg.measure_phase(p, b, p[neuron])
        ph.append(a); T.append(t2)
    stops, sT = np.concatenate(stops), np.round(np.concatenate(sT))
    ph, T = np.concatenate(ph), np.round(np.concatenate(T))
    edges = np.linspace(0, 1, 31)
    centres = (edges[:-1] + edges[1:]) / 2
    rows = []
    for c in range(5, 26, 2):
        u = (T == c) & np.isfinite(ph)
        if u.sum() < 1000:
            continue
        h, _ = np.histogram(ph[u], edges, density=True)
        M = np.nanmean(stops[sT == c])
        k = min(int(M * 30), 29)
        near = np.abs(centres - M) <= 0.1
        rows.append({"T": c, "spikes": int(u.sum()), "PD_end_phase": M, "pdf_a": h[k], "pdf_b": h[near].min(),
                     "pdf_min": h.min(), "pdf_max": h.max()})
    return pd.DataFrame(rows)

How the analysis differs from the paper's. Bursts follow the Methods (at least 5 or 2 spikes); the paper's code keeps bursts with at least that many ISIs, one spike more, and is shown as a variant throughout. With the code's rule and the code's computations, several reported numbers are matched exactly (paired t-test t = 1.27, p = 0.235; n = 3799 cycles and Spearman p = 0.88; phase Spearman rho = -0.31, p = 0.46), so the record holds the data the paper analysed. The Methods' phase sample (first 40 starts) does not give the reported Rayleigh ranges; the later code's (first 50) does, and the archived code's pooled sample with the code's burst rule gives the reported 3816 LG burst starts. The Methods' Q10 does not give the reported count of 8 of 10 near 2; the code's per-burst Q10 does. Random draws (KS shuffles, bootstraps) use seeds from the claim ids, not the paper's.

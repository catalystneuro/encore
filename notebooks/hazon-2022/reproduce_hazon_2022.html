Reproducing Hazon et al. (2022) from CRCNS hc-30: tensor, noise and signal analyses¶

Paper. Hazon O, Minces VH, Tomàs DP, Ganguli S, Schnitzer MJ, Jercog PE (2022). Noise correlations in neural ensemble activity limit the accuracy of hippocampal spatial representations. Nature Communications 13, 4276. doi:10.1038/s41467-022-31254-y

Dataset. CRCNS hc-30, Jercog P and Schnitzer M (2022), "Functional calcium imaging recordings of hippocampal area CA1 from mice performing a linear track task", doi:10.6080/K0GH9G5X. One file, hc-30/live/event_traces.mat (142,350,100 bytes), streamed from the public S3 bucket crcnsarchive into memory.

Version. CRCNS data sets are not versioned, so the version is recorded as unversioned (docs/archives.md). The paper cites no version; the only one published is the one in the bucket (data descriptor version 0.6, July 8, 2022, the initial version), which matches the claims file's description (110 sessions with mouse name, session ID, sparse event array and position). The MD5 sum from the data set's checksums.md5, which the next cell checks against the streamed bytes, is fe0f5dd2fca6d64dbf0cd3f35e31e1f0 (event_traces.mat); the descriptor PDF is 320d157fbcc43be385485cc186842636.

Text the claims were written from. The version of record (PMC9314334) with its Methods and Supplementary Information; the paper's code, github.com/approbatory/ML-project at commit 2057af9facfd3035c573e1254bdc32ed4781ba60, was read for method details (claims/hazon-2022.yaml). Method details taken by this attempt cite the passage or code file in hc30.py.

Data. 110 sessions of 12 mice with an event-onset array (frames x neurons) and the position in camera pixels. There are no cell positions, no frame times and no trial table; trials, bins and the event trace are built here from the Methods and the code (hc30.py).

Checks of the description against the data:

  • The data descriptor says 110 sessions, each with a frames by neurons sparse array that holds "a positive value if neuron n had a calcium event in time frame t". The cell below checks that the values are single frames (event onsets with their amplitude) and not the convolved trace the paper decodes from; the alpha convolution and normalisation of the Methods are therefore applied here (hc30.event_trace).
  • Frame rate: no sampling rate is stored; 20 Hz is from the Methods. Session lengths in minutes below are at 20 Hz; the paper and the descriptor say about 20 min.
  • Position is in camera pixels, with no unit in the file. The scale is the code's: 118 cm over the 5th to 95th percentile span.

N_SPLITS_4A = 100

def eigen_snr(i):
    rng = np.random.default_rng(4000 + i)
    T, d = TENS[i]
    h = min((d == 1).sum(), (d == -1).sum())
    X = np.concatenate([T[:, :, d == 1][:, :, :h], T[:, :, d == -1][:, :, :h]], axis=1)
    N, K, Tn = X.shape
    t2 = Tn // 2
    nd = t2 - 1
    out = np.zeros((38, nd))
    for pi, b in enumerate(list(range(19)) + list(range(20, 39))):
        Xa, Xb = X[:, b, :], X[:, b + 1, :]
        acc = np.zeros(nd)
        for _ in range(N_SPLITS_4A):
            perm = rng.permutation(Tn)
            p1, p2 = perm[:t2], perm[t2:2 * t2]
            V, _ = hc30.pca_dirs(Xa[:, p1])
            V = V[:, :nd]
            pa, pb = Xa[:, p2].T @ V, Xb[:, p2].T @ V
            acc += (pa.mean(0) - pb.mean(0)) ** 2 / ((pa.var(0, ddof=1) + pb.var(0, ddof=1)) / 2)
        out[pi] = acc / N_SPLITS_4A
    return np.median(out, axis=0)

rng_5 = np.random.default_rng(55)
centers_x = np.arange(20) + 0.5

def sim_nsv(n_cells, halfwidths):
    c = rng_5.uniform(0, 20, n_cells)
    sigma = halfwidths / np.sqrt(2 * np.log(2))  # half-width at half maximum to SD
    F = np.exp(-0.5 * ((centers_x[None, :] - c[:, None]) / sigma[:, None]) ** 2)
    D = np.diff(F, axis=1)
    U = D / np.linalg.norm(D, axis=0, keepdims=True)
    return np.var(U ** 2, axis=0)  # per bin pair

Rozsa et al. (2023) on DANDI:000341, part 3: in vivo recordings¶

Paper: Rozsa, Toth, Olah, Baka, Lakovics, Barzo and Tamas (2023), Sci. Adv. 9, eade4511, doi:10.1126/sciadv.ade4511. Claims file: claims/rozsa-2023.yaml, written from the version of record (Europe PMC full text) and its supplement.

Dataset: DANDI:000341, version 0.241220.1312 (doi:10.48324/dandi.000341/0.241220.1312), the only published version; the paper cites the dandiset without a version.

This notebook covers the folder In_vivo (259 files, 383 GB): whole-cell recordings of layer 1 interneurons in mice, most with a layer 5 LFP. Each file is taken as one cell (checked for repeats below). It was added after the first verification round, which found that the earlier block of these claims as too large was not justified.

The dandiset carries no AP labels, so AIS-APs and RA-APs can only be separated by reading (b) of the claims file's header, a two-component Gaussian mixture on threshold and pre-AP slope fitted to all in vivo APs pooled, RA-APs being the component with the lower threshold (raf.gmm_classes). Its components are checked against the paper's description of RA-APs (lower threshold and lower slope) before any claim is judged.

Per-cell reduction¶

APs (main rule, peak above 0 mV; artefacts with a threshold outside -80 to -10 mV or a peak above 100 mV left out) of the Vm sweeps without a current step; the recording duration of a cell is the summed length of those sweeps. Steady holding current is allowed (the paper's Figure S5F shows "injected holding currents during recordings"); APs with a positive absolute current at threshold are left out in a variant.

def ap_triggered_lfp(c, shift=0.0, half=1.0):
    a = c["aps"]
    if not len(a) or not c["lfp"]:
        return None, 0, np.nan
    t = (a.sweep_start + a.t_peak).to_numpy() + shift
    segs = []
    for st, rate, x in c["lfp"].values():
        h = int(half * rate)
        i = np.round((t - st) * rate).astype(int)
        i = i[(i - h >= 0) & (i + h < len(x))]
        for k in i[:2000]:
            seg = x[k - h:k + h + 1].astype(float)
            segs.append(seg - seg.mean())
            used = rate
    if not segs:
        return None, 0, np.nan
    L = min(len(z) for z in segs)
    return np.mean([z[:L] for z in segs], axis=0), len(segs), used

fig4j-invivo-ais-phase-coupling, fig4j-invivo-ra-no-phase and fig4-invivo-up-down-balance¶

In vivo, AIS-APs are coupled to the trough of the slow (0.5 to 4 Hz) LFP oscillation (mean vector length 0.019, angle 330 degrees). RA-APs are not significantly coupled to any phase of the slow oscillation. AIS-APs dominate during up states and RA-APs during down states.

The Methods' phase procedure, as in the slices notebook: the 4 s LFP segment centred on each AP peak, FFT power times frequency, the AP kept when the power in 0.5 to 4 Hz over that in 0.5 to 45 Hz exceeds 0.1; the LFP band-passed 0.5 to 4 Hz (Butterworth order 2, zero phase; order 4 the variant), Hilbert phase at the AP peak shifted by 180 degrees so that the trough is 0 degrees. All cells with an LFP and all states pooled (criterion).

FS = 500.0


def ap_phases(c, aps, order=2):
    out = []
    for name, (st, rate, x) in c["lfp"].items():
        dur = len(x) / rate
        t = (aps.sweep_start + aps.t_peak).to_numpy()
        sel = aps[(t >= st + 2) & (t <= st + dur - 2)]
        if not len(sel):
            continue
        q = int(round(rate / FS))
        y = signal.decimate(x.astype(float), q, ftype="fir") if q > 1 else x.astype(float)
        fs = rate / q
        sos = signal.butter(order, (0.5, 4.0), btype="band", fs=fs, output="sos")
        ph = np.angle(signal.hilbert(signal.sosfiltfilt(sos, y)), deg=True)
        for _, ap in sel.iterrows():
            i = int(round((ap.sweep_start + ap.t_peak - st) * fs))
            h = int(round(2 * fs))
            if i - h < 0 or i + h > len(y):
                continue
            seg = y[i - h:i + h]
            F = np.fft.rfftfreq(len(seg), 1 / fs)
            Pw = np.abs(np.fft.rfft(seg - seg.mean())) ** 2 * F
            ratio = Pw[(F >= 0.5) & (F <= 4)].sum() / Pw[(F >= 0.5) & (F <= 45)].sum()
            out.append(dict(file=c["file"], ra=ap.ra, steady=ap.steady, ratio=ratio, phase=(ph[i] + 180) % 360))
    return pd.DataFrame(out)

How the analysis differs from the paper's. The dandiset has no AP labels. The one runnable reading of the claims file, a two-component mixture on threshold and pre-AP slope, gives a lower-threshold component with the steeper slope in these recordings, while the paper describes RA-APs as having the lower threshold and the lower slope. The claims are therefore blocked; the numbers under the mixture's classes are shown for each. The claims file's reading (b) does not ask for this check of the components; applied as written, it would give mixed outcomes (fig4-invivo-up-down-balance reproduced, fig4i and figs4i partially reproduced, as the verifier noted in round 2). The mixture is fitted to a seeded draw of 200,000 APs and its counts differ slightly between runs.

What was found about the dataset. The folder holds 259 files from 149 mice against the paper's 242 cells; 245 files have an LFP. In 135 of them every LFP series starts at the same time as a Vm series (median fraction 1.000; in some files none does), and in 143 of the 167 files with at least 20 APs the AP-triggered LFP average departs from its time-shifted value (|z| > 2, median z -10.4), which is consistent with a shared clock. The genotype is recorded in each file's subject description, the anesthesia condition nowhere. Some files also hold camera images (Moovie).

Reproducing Saez et al. (2018) from CRCNS ofc-3¶

Paper. Saez I, Lin J, Stolk A, Chang E, Parvizi J, Schalk G, Knight RT, Hsu M (2018). Encoding of multiple reward-related computations in transient and sustained high-frequency activity in human OFC. Current Biology 28:2889-2899. doi:10.1016/j.cub.2018.07.045. The claims file (claims/saez-2018.yaml) was written from the version of record (main text, legends, STAR Methods, Supplemental Information).

Data set. CRCNS ofc-3, "High-frequency activity of human orbitofrontal sites during decision-making play", doi:10.6080/K0VM49GF, read from the public bucket crcnsarchive under ofc-3/live/. Version: unversioned. CRCNS does not version data sets, and the paper cites the data set by its DOI only, so the files as published under live/ (data description version 0.7 of Feb 19, 2019, which added ofc_behav_data.zip) are the only version that can be pinned. The MD5 sums of the files read, from the data set's checksums.md5, are printed below so that a later change is detectable (data.zip 3531c772af4e4eb0c4e5332e74f94c81, ofc_behav_data.zip c35393e7734d33dc52e2c62b1a806274). The folder ofc-3/orig/ holds only older descriptions (no data).

What the data set holds. For 10 patients: window-averaged and 1-kHz HFA epochs around game presentation and around a second event called "buttonpress" (the data show it is near the outcome reveal, see the data check), the behaviour of every round with event times, the game of each round, and the authors' regressors per HFA trial. It holds no broadband signal, no electrode locations and no data of the 10 healthy participants.

Each HFA trial is matched to a round (the files give no round number for HFA trials). The match uses the authors' regressors in sXX_behav_globals.mat (win probability, gamble, win, regret, previous win probability). The cell checks that every trial matched and that the other regressors agree with the values computed from the csv files (Table S1 definitions), including the t-1 values. It also matches the trials in reverse (each to the latest remaining round): where both matches give the same rounds, no other order-preserving match exists, so the t-2 to t-5, left/right and gamble-outcome values taken from the rounds are fixed by it.

def r2_pairs(pairs, reg=None):
    """R2 per pair: mean over patients of within-patient R2, and R2 on pooled trials."""
    reg = REG if reg is None else reg
    per_pat, pooled = [], []
    for a, b in pairs:
        vals = []
        xa, xb = [], []
        for s in saez.SUBJECTS:
            u, v = reg[a][s], reg[b][s]
            ok = ~np.isnan(u) & ~np.isnan(v)
            if u[ok].std() > 0 and v[ok].std() > 0:
                vals.append(np.corrcoef(u[ok], v[ok])[0, 1] ** 2)
            xa.append(u[ok]); xb.append(v[ok])
        per_pat.append(np.mean(vals))
        pooled.append(np.corrcoef(np.concatenate(xa), np.concatenate(xb))[0, 1] ** 2)
    return np.array(per_pat) * 100, np.array(pooled) * 100

def run_around(mask, k):
    """Length of the run of True in mask that contains index k."""
    if not mask[k]:
        return 0
    a = k
    while a > 0 and mask[a - 1]:
        a -= 1
    b = k
    while b < len(mask) - 1 and mask[b + 1]:
        b += 1
    return b - a + 1

def peak_logp(key):
    sc = SC[key]
    r2 = sc["r2"].reshape(-1, sc["r2"].shape[2])
    best = r2.max(0)
    n = np.array([sc["n"][s] for s in SUBJ])
    t = np.sqrt(best * (n - 2) / np.maximum(1 - best, 1e-12))
    return -np.log10(2 * stats.t.sf(t, n - 2))

Baseline readings¶

The claims file names two baseline readings: (a) subtract, per trial and electrode, the mean of the 200 ms before each epoch's event, and (b) subtract the mean of the 200 ms before game presentation from both epochs. The analysis above uses the HFA as deposited (game epoch corrected over [-1000, -800] ms, buttonpress epoch with an offset close to it, see the data check). The window centred at -100 ms is the mean of [-200, 0] ms, so (a) subtracts that window of each epoch from the epoch, and (b) subtracts that window of the game epoch from both, after putting the buttonpress epoch on the game epoch's level with its own per-trial, per-electrode offset (data check). Where the two epochs do not overlap (181 of 1,753 trials, 115 of them in s10) the offset is not known and the electrode's median over the subject's matched trials is used. Every encoding scan, the stepwise selection and the per-window mixed models are run again under each reading, with the same seeds, and the numbers each criterion rests on are printed side by side. How the analysis differs from the paper's. The deposited HFA is used as it is: already window-averaged and, in the game epoch, baseline-corrected; the buttonpress epoch carries a per-trial offset close to the game epoch's. This is taken as the authors' baseline (an assumption). The claims file's two baseline readings, applied on top of it, change the outcomes of fig4-past-encoding, fig5-past-sustained, figs5d-sharp-boundary and figs6b-stepwise-similar, which are marked as resting on the assumption; under reading (a) mixed-effects-robust passes, and its outcome rests on that reading. Eight electrodes of s03 that copy others are dropped (191 analysed against the paper's 192). The buttonpress epoch is read as locked to the outcome reveal, as the data indicate. The regressors are the authors' own file; t-2 to t-5 follow its convention. Random-effects logits are fitted by maximum likelihood with Gauss-Hermite quadrature. The stepwise procedure takes the longest stretch in each epoch and compares models at the base regressor's peak window (assumptions). The nested mixed models are fitted by a closed-form REML in the helper, checked against statsmodels.

What was found about the data set. The files hold 199 electrodes, of which seven in s03 are exact copies of others and one (s03 electrode 42) holds copies of two different electrodes in its 1-kHz and window arrays; without the seven, the per-patient counts match Table S2. The "buttonpress" epoch is centred 470 to 600 ms after the csv's button press, and the gamble outcome is encoded from about 200 ms after its time 0: it behaves as locked to the outcome reveal, not the button press. reveal.time is 0.53 to 0.59 s after the button press in s01 to s05 but 0.03 to 0.05 s in s06 to s10 (up to 0.24 s in s10), where the description gives 550 ms. HFA trials carry no round number and are fewer than the non-timeout rounds (1,753 against 1,839), without documentation of the exclusions; they can be matched to rounds through the authors' regressor file. s10 played 138 rounds with reaction times up to 80 s and no timeouts; timeouts are 5.1% of rounds, not 9.98%. The column choice.time, the HFA units and the baseline subtraction are not described. The data set holds no broadband signal, no electrode locations and no data from the healthy participants.

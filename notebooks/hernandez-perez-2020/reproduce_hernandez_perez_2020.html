Hernández-Pérez, Cooper and Newman (2020) on CRCNS hc-27¶

Paper: "Medial entorhinal cortex activates in a traveling wave in the rat", eLife 2020, doi:10.7554/elife.52289. Claims: claims/hernandez-perez-2020.yaml, written from the version of record (PMC7046467), its Methods, legends and Figure 1, figure supplement 1. The paper links no code, and the data set's code folder holds a loading script only (readData.m, spreadLFP.m), so every method below is from the paper's text, through the claims file or a passage cited where it is used.

Dataset: CRCNS hc-27, doi:10.6080/K0C53J2R, read anonymously from the bucket crcnsarchive under hc-27/live/, the zip opened in place over range requests. CRCNS data sets are not versioned; the version is recorded as unversioned. It is the only published state of the data set (its data descriptor is version 0.6 of February 13, 2020, and the bucket holds no hc-27/old/), so it is the one pinned. The MD5 sums of the files read, from the data set's checksums.md5, are printed in the data check below (RawSignalTravelingWaveRats.zip c9cd6981d8559d125c02dc64c27e5b09), so a later change of the files can be detected.

The data set holds, per rat, one matrix of LFP at 500 Hz, 5 or 6 channels ordered dorsal to ventral, and nothing else: no units, positions, electrode geometry, behaviour, or broadband signal.

Readings. The claims file's open details (O1 to O8 in its header) and one question of units (below) are run under every reading that can be run here:

  • Units (assumption). The theta epochs need a 400 µV threshold (Methods, Data inclusion criteria), but the files state no unit, and the data check shows two kinds of file. Readings: counts (main): the non-integer files (rats 2 and 3) divided by 0.195 µV per bit, so that all rats are on the scale of the integer files, and 400 applied on that scale; file: 400 applied to the values as stored; none: no amplitude restriction. Under counts the threshold is 400 µV if the integer files are in µV, and about 78 µV if they are Intan counts (0.195 µV per count). The section "Theta threshold sweep" shows the results with thresholds of 200 to 2051 on that scale, 2051 being 400 µV with the integer files read as Intan counts.
  • O3, which channel's epochs: a (main) each channel's own, pairs on the times both keep; b times kept on all channels; c the dorsal-most channel's. Per-cycle analyses across all channels use b for readings a and b.
  • O7, waveform extrema: a (main) local extrema of the 1-25 Hz signal; b one extremum between zero crossings of the 6-12 Hz signal (Cole and Voytek).
  • O1: positions 0.566 mm times the channel index (reading a); the data set gives no positions, so reading b cannot be run. O2: every channel (reading a). The data set's author proof (docs/MEC-TW_authorProof.pdf, Figure 1, figure supplement 1) marks the electrode tips at the key recording (green) and, in blue, electrodes outside the MEC, which its key labels "unused electrode". Read by eye, the green tips number 6, 5, 6, 5, 6 and 5 for rats 1 to 6, the channel counts of the files, so the files hold only the electrodes used, and reading b (only electrodes inside the MEC) selects the same channels as reading a. The figure does not say which tip is which channel, so it cannot give positions (O1 b).

What the data check shows, against the descriptor and the paper:

  • Six rats, as the descriptor and the paper (Methods, Animals) say; 6, 5, 6, 5, 6 and 5 channels. No channel repeats another, within or across rats (the largest correlation between rats is printed above).
  • Sampling rate: the descriptor's 500 Hz is consistent with the data: the spectra peak at theta (6.7 to 7.4 Hz in the 4-12 Hz band) and line noise stands out at 60 Hz in every rat. This is consistent with the stated rate, not a proof of it.
  • Duration: 20.1 to 33.5 min; the paper's trials last 25 min (Behavioral protocol), so rat 5 holds more than one trial's length, and the others less.
  • Units: none is stated. Rats 1, 4, 5 and 6 hold integers (smallest step 1) and rat 5 reaches 32767, the int16 limit: these look like ADC counts. Rats 2 and 3 hold non-integers about five times smaller in spread. With the Intan step of 0.195 µV, the theta amplitudes of all rats are on one scale only if rats 2 and 3 are in µV and the others in counts. Under the paper's 400 µV threshold applied as stored (file), rats 2 and 3 have no theta epoch at all, so no test over six rats is possible; under counts all rats have epochs, and the dorsal-most channel of rats 2 to 6 gives 3200 to 6286 cycles, near the paper's "Between 3500 to 5000 individual theta cycles ... for each phase in each rat" (Methods, Conduction delays). Rat 1's dorsal-most channel has low theta amplitude and gives 815. The main reading is counts, as an assumption; none is shown throughout. The second table above gives each channel's median theta amplitude: on the common scale 268 to 1029, which is 52 to 201 µV if the integer files are Intan counts. Under that reading of the integer files the paper's 400 µV is 2051 on the common scale, above every channel's median, and the sweep below shows it leaves no theta epoch in any rat. So the counts reading, which applies 400 to the integer files as stored, puts the threshold at 400 µV only if those files are in µV; if they are Intan counts it is about 78 µV.
  • Clock: each rat is one matrix whose channels share one sample clock; the data set holds no trial table, behaviour or annotation, so no check against task events is possible.
  • Positions and channel selection: the data set gives no positions; they are taken from the nominal 0.566 mm spacing (O1 a). Every channel is used (O2 a); the data set's author proof (Figure 1, figure supplement 1) marks as many electrodes at the key recording as the files hold channels, and labels the electrodes outside the MEC "unused" (see the header), so O2 b selects the same channels.

Theta threshold sweep¶

The counts reading applies 400 on the scale of the integer files, so the threshold is 400 µV only if those files are in µV (see the data check). Here the main measures are recomputed with thresholds of 200 to 2051 on that scale (2051 is 400 µV if the integer files are Intan counts), beside the number of reference cycles per rat, which the paper gives as "Between 3500 to 5000 individual theta cycles ... for each phase in each rat" (Methods, Conduction delays of specific theta phases). Main readings otherwise (O7 a; fig2d and fig2e on O3 a and c; delays on O3 b and c). NaN: some rat has no epoch or no reference cycle at that threshold.

fig8c-relative-delay-flat, fig8d-absolute-delay-slope, fig8-correlation-strength¶

Per reference cycle, the asymmetry-corrected peak delay (the per-cycle residual of fig7-residual-delay, reading a), in ms/mm; relative delay is that delay over the cycle's period in percent; frequency is the inverse of the period. Period: the dorsal-most channel's peak to next peak (the claims file's reading) or previous peak to peak (shown, as the criterion asks). A third variant, half the interval from the previous to the next peak (centred), is this attempt's own: it does not use the reference peak's time, which enters the delay as well, and so shows how much of a relation comes from timing noise shared by the delay and the period. A fourth variant, hilbert, takes the frequency from the dorsal-most channel's Hilbert phase, averaged over a fixed 250 ms window centred on the reference peak, so it does not use the extrema's times at all. Per rat, the least-squares slope on frequency and the Pearson r. Absolute delay reading (b) multiplies the delay by the rat's span.

def fig8_rat(d, pos, period_key, span):
    if period_key == "centred":
        allper = (d["period"] + d["prev_period"]) / 2
    elif period_key == "hilbert":
        allper = 1000.0 / d["hilbert_freq"]
    else:
        allper = d[period_key]
    ok = d["resid_ok"] & np.isfinite(allper)
    absd = d["resid_cycle"][ok] * (pos[-1] if span else 1.0)
    per = allper[ok]
    freq = 1000.0 / per
    rel = d["resid_cycle"][ok] / per * 100
    return dict(abs_slope=np.polyfit(freq, absd, 1)[0], rel_slope=np.polyfit(freq, rel, 1)[0],
                abs_r=stats.pearsonr(freq, absd)[0], rel_r=stats.pearsonr(freq, rel)[0],
                abs_rho=stats.spearmanr(freq, absd)[0], rel_rho=stats.spearmanr(freq, rel)[0], n=int(ok.sum()))

Reproducing Seyedolmohadesin et al. (2026) from dandiset 000981¶

Paper. Seyedolmohadesin M, Fu X, Torkashvand M, Rasouli S, Lang S, Li L, Kalinski C, Cook S, Schroeder F, Yemini E, Venkatachalam V (2026). Whole-brain chemosensory responses of both C. elegans sexes. Current Biology 36, 4803-4816. doi:10.1016/j.cub.2026.08.040. The claims file (claims/seyedolmohadesin-2026.yaml) was written from the version of record, main text, STAR Methods and the supplement's Figures S1 to S20 with their legends.

Dandiset. DANDI:000981, version 0.260910.1747 (doi:10.48324/dandi.000981/0.260910.1747). The paper cites the dandiset without a version. This is the only published version ("First public release after publication", 2026-09-10); the draft lists the same 47 assets and the same total size, so the most recent published version is pinned.

What the dandiset holds. One NWB file per animal, 47 in all: the raw GCaMP and NeuroPAL volumes, the NeuroPAL identities, a table of calcium traces of the identified head neurons (ActivityTraces) and the stimulus annotations (StimulusInfo). Only the traces, labels, stimulus annotations and subject metadata are read here; the image volumes are not.

Paper's code. Method details the claims file does not give are taken from the paper, and where the Methods leave them open from the code the claims file cites (github.com/venkatachalamlab/whole-brain-chemosensory-responses at commit b0dbdbf); the helper chemo.py says where each parameter comes from.

Outside inputs. The connectome claims ("with inputs") use the chemical connectomes of White et al. (1986) as annotated by Cook et al. (2019) and of the male (Cook et al. 2019), from that paper's supplement (doi:10.1038/s41586-019-1352-7), and datasets 7 and 8 of Witvliet et al. (2021) from its supplement (doi:10.1038/s41586-021-03778-8), read into memory from the journal's servers. The paper's own merged table is not public.

Layers. The layer of each class (sensory, inter, motor, pharyngeal) is read from the column groups of the paper's Figure 3A, which label every subclass (read from the PDF). The first version of this entry assumed an assignment before that figure was read; it is kept as a variant in the layer claims to show how much they depend on it.

Random numbers are drawn only in the timing check of the data check, from a generator with a fixed seed.

def class_calls(rd, thr=0.05, strict=False, rep="dt1"):
    """Per sex-shared subclass and canonical class: responsive, dimorphic, and per-cue calls."""
    rt, dt = X[rd]["rt"], X[rd][rep]
    sig = (lambda p: p < thr) if strict else (lambda p: p <= thr)
    rt = rt.assign(sig=sig(rt.p)); dt = dt.assign(sig=sig(dt.p))
    rt = rt[~rt.subclass.isin(chemo.MALE_SPECIFIC)]; dt = dt[~dt.subclass.isin(chemo.MALE_SPECIFIC)]
    resp_cue = rt.groupby(["subclass", "cue"]).sig.any().unstack().reindex(columns=chemo.CUES).fillna(False)
    dim_cue = dt.groupby(["subclass", "cue"]).sig.any().unstack().reindex(columns=chemo.CUES).fillna(False)
    sub = pd.DataFrame({"responsive": resp_cue.any(axis=1), "dimorphic": dim_cue.any(axis=1)}).fillna(False)
    sub["canonical"] = sub.index.map(chemo.canonical)
    can_resp_cue = resp_cue.groupby(chemo.canonical).any()
    can_dim_cue = dim_cue.groupby(chemo.canonical).any()
    can = sub.groupby("canonical")[["responsive", "dimorphic"]].any()
    can["both"] = can.responsive & can.dimorphic
    can["layer"] = can.index.map(chemo.LAYER)
    return {"sub": sub, "can": can, "resp_cue": resp_cue, "dim_cue": dim_cue,
            "can_resp_cue": can_resp_cue, "can_dim_cue": can_dim_cue}

def cell(rd, sub, cue, window):
    d = X[rd]["dt1"]; r = X[rd]["rt"]
    row = d[(d.subclass == sub) & (d.cue == cue) & (d.window == window)].iloc[0]
    rr = r[(r.subclass == sub) & (r.cue == cue) & (r.window == window)].set_index("sex").p
    return {"exclusion": rd, "class": sub, "cue": chemo.CUE_NAMES[cue], "window": window,
            "n_herm": row.n_herm, "n_male": row.n_male, "mean_herm": row.mean_herm, "mean_male": row.mean_male,
            "norm_diff": row.norm_diff, "p_sex": row.p,
            "resp_h": rr.get("hermaphrodite", np.nan), "resp_m": rr.get("male", np.nan)}


def cells(subs, cues, windows=("onset", "offset")):
    out = pd.DataFrame([cell(rd, s, c, w) for rd in "ab" for s in subs for c in cues for w in windows])

# `ma_past`; docstrings left out). Toy trace: noise on a slow drift, with a block of missing frames.
def code_correct(trace):
    return code_band_pass(code_z_score(trace))

def code_band_pass(arr, k_small=10, k_large=240):
    return code_ma_past(arr, k_small) - code_ma_past(arr, k_large)

def code_z_score(trace):
    mean = np.nanmean(trace)
    std_dev = np.nanstd(trace)
    trace_mean_subtracted = trace - mean
    z_scored_trace = trace_mean_subtracted / std_dev
    return z_scored_trace

def code_ma_past(arr, k):
    if k <= 1:
        return arr.copy()
    w = k + 1
    arr_cumsum = np.nancumsum(arr, axis=0)
    result = np.zeros_like(arr_cumsum, dtype=np.float64) * np.nan
    result[:w] = arr_cumsum[:w] / (1 + np.arange(w))
    result[w:] = (arr_cumsum[w:] - arr_cumsum[:-w]) / w
    result[np.isnan(arr)] = np.nan
    return result

def class_pair_values(corr_list):
    """Per animal, the mean r over the left-right combinations of each pair of cues and subclasses,
    and per sex the pooled values of all combinations of all animals."""
    pa = np.full((len(corr_list), nE, nE), np.nan)
    pool = {}
    for a, (subj, sex, c) in enumerate(corr_list):
        names = [n for n in c.index if (n in idx) or (chemo.subclass(n) in idx)]
        lab = np.array([idx[n] if n in idx else idx[chemo.subclass(n)] for n in names])
        v = c.loc[names, names].values
        for i in np.unique(lab):
            mi = lab == i
            for j in np.unique(lab):
                if j <= i:
                    continue
                vals = v[np.ix_(mi, lab == j)].ravel()
                vals = vals[np.isfinite(vals)]
                if len(vals):
                    pa[a, i, j] = vals.mean()
                    pool.setdefault((i, j, sex), []).extend(vals)
    return pa, pool

The paper's code reads a connectome table prepared by S.J. Cook that is not public. def directed_stack(mats, neurons):
    names = ["white", "witvliet7", "witvliet8", "male"]

    return pre, post, np.stack([mats[k].reindex(index=pre, columns=post).fillna(0.0).values for k in names])

Methods, "Classifying motor state": the raw AVA trace is corrected for bleaching "by estimating the baseline using an exponential fit"; the 5 s before each stimulus is a transition if the activity changes by more than 20%, otherwise reverse when its mean is above the global mean of the recording and forward when below. def exp_fit(y, target="whole"):
    """Exponential a * exp(-k t) + c fitted by least squares to the whole trace ("whole") or to its
    baseline ("baseline": the 10th percentile of each 100-frame bin, at the bin centres)."""
    t = np.arange(len(y), dtype=float)
    ok = np.isfinite(y)
    tt, yy = t[ok], y[ok]
    if target == "baseline":
        bins = [(t0, y[t0:t0 + BIN]) for t0 in range(0, len(y), BIN)]
        bins = [(t0 + BIN / 2, np.nanpercentile(b, 10)) for t0, b in bins if np.isfinite(b).sum() >= BIN // 2]
        tt, yy = np.array([b[0] for b in bins]), np.array([b[1] for b in bins])
    try:
        n0 = max(len(yy) // 25, 2)
        p, _ = optimize.curve_fit(lambda t, a, k, c: a * np.exp(-k * t) + c, tt, yy,
                                  p0=(max(yy[:n0].mean() - yy[-n0:].mean(), 1e-3), 1e-3, yy[-n0:].mean()),
                                  bounds=([0, 0, -np.inf], [np.inf, 1, np.inf]), maxfev=5000)
        return p[0] * np.exp(-p[1] * t) + p[2], True
    except Exception:
        b = np.polyfit(tt, yy, 1)
        return np.polyval(b, t), False

def interaction_p(y, sx, st):
    n = len(y)
    X1 = np.column_stack([np.ones(n), sx, st])
    X2 = np.column_stack([X1, sx * st])
    r1 = y - X1 @ np.linalg.lstsq(X1, y, rcond=None)[0]
    r2 = y - X2 @ np.linalg.lstsq(X2, y, rcond=None)[0]
    rss1, rss2 = r1 @ r1, r2 @ r2
    if rss2 <= 0 or n <= 4:
        return np.nan
    F = (rss1 - rss2) / (rss2 / (n - 4))
    return float(stats.f.sf(F, 1, n - 4))


def state_tables(rd, rdg):
    e = X[rd]["e"].merge(STATE[rdg], on=["subject", "cycle", "position"], how="inner")

How the analysis differs from the paper's. Responses, exclusion, the class tests and the correlations follow the claims file and the paper's code. The code's identification-confidence filter cannot be applied, as the dandiset has no confidence values; its time ranges to ignore are already blank in the traces, and its ganglia to ignore cannot be checked. The layer of each class is read from the column groups of Figure 3A, as the code's class file is not public; the assignment assumed before that figure was read is shown as a variant. The motor state uses an exponential fit to the whole AVA trace or to its baseline, and a 13-frame window, with every open detail of the Methods run. The connectomes are rebuilt from their published sources, as the paper's merged table is not public, with Cook's synapse counts and EM sections both run; the male connectome is normalized by the same quantile rule as the hermaphrodite ones.

What was found about the dandiset.

  • Files 20220403-h3 and 20220403-m3 hold the same 382-row trace table, h3's traces followed by m3's; the blocks are told apart only by the responses and the male-specific labels.
  • The subject sex field is "O" in every file; the sex is only in the description and the subject id. The strain field is "[]" though the paper names OH16230.
  • The stimulus annotation times are labelled seconds but are frame numbers, and lie 1 to 3 frames after the onset frames the paper's code uses.
  • The traces have no unit or description of how they were computed; blocks of frames are blank (the first 96 frames in 13 recordings, and other ranges), without a note of why.
  • No tail neuron has a trace, though the NeuroPAL segmentations identify tail neurons and the tracked ROIs include them; the tracked ROI coordinates are zero in 99.75% of ROIs over all 47 files, never above 2 voxels, and zero for every tail neuron.
  • There is no identification confidence, which the paper's code uses to select neurons.

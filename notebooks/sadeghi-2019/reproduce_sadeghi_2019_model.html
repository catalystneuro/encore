Sadeghi et al. (2019): auditory model claims (CRCNS bst-2)¶

Paper: Sadeghi M, Zhai X, Stevenson IH, Escabi MA (2019). A neural ensemble correlation code for sound category identification. PLoS Biol 17(10):e3000449, doi:10.1371/journal.pbio.3000449. The claims file (claims/sadeghi-2019.yaml) was written from the version of record (PMC6788721) with its supplement.

Dataset: CRCNS bst-2 (doi:10.6080/K03X84V3), bst-2/live/data.tar.gz in the public bucket crcnsarchive, crcns:bst-2/unversioned (CRCNS does not version data sets; the paper cites the DOI only, and this is the bucket's only copy). MD5 of data.tar.gz from bst-2/live/checksums.md5: 916ae724cd3334a16a4396b861e4abe0. The model sounds are data/Sounds/ModelSounds//Sound_.wav.

This notebook tests the auditory model claims; the neural claims are in reproduce_sadeghi_2019_neural.ipynb.

Model correlations of every sound¶

Per sound: the cochlear envelopes (58 channels, 1 kHz); the short-term spectro-temporal correlation at tau_W = 100 ms with 99 lags (for SI, CDI and the spectral breadth); the time-averaged short-term autocorrelations at tau_W = 566 ms (lags within 283 ms); and the long-term autocorrelation of the whole envelopes (lags within 283 ms).

LAG566 = np.arange(-283, 284).astype(float)
cbar, si_terms, auto566, autolong, zero_long = {}, {}, {}, {}, {}
t0 = time.time()
for i, key in enumerate(sorted(sounds)):
    fs, x, _ = sounds[key]
    Sg = M.cochleogram(x, fs)
    n, s1, s2 = 0, 0.0, 0.0
    acc = None
    for c in M.short_term_iter(Sg, 100, 49, pairs="all"):
        v = c.astype(np.float64)
        acc = v.copy() if acc is None else acc + v
        s2 += (v ** 2).sum()
        n += 1
    cbar[key] = (acc / n).astype(np.float32)
    si_terms[key] = (s2 / n, float((cbar[key].astype(np.float64) ** 2).sum()), n)
    auto566[key] = np.mean(list(M.short_term_iter(Sg, 566, 283, pairs="auto")), 0)
    autolong[key] = M.long_term_auto(Sg, 283)
    X = Sg - Sg.mean(1, keepdims=True)
    zero_long[key] = np.corrcoef(X)
    if i % 30 == 0:
        print(i, key, f"{time.time() - t0:.0f} s", flush=True)
print("time points per sound at 100 ms:", sorted({v[2] for v in si_terms.values()}))

fig5-speech-water-widths¶

In the cochlear model, the example speech sound has broad spectral correlations and a slow temporal correlation (64 ms half width), while the example water sound has diagonal spectral correlations and a fast temporal correlation (4 ms half width).

Readings: window (ii)(a) time average of the short-term correlation at tau_W = 566 ms, (ii)(b) long-term correlation of the whole envelopes; width (iii)(a) full width at 50% of the channel-averaged autocorrelation, (iii)(b) median over channels. Spectral breadth is the mean off-diagonal zero-lag correlation (time-averaged at 100 ms, and long-term).

def widths(curves):
    return M.width_at(curves.mean(0), LAG566, 0.5), float(np.median([M.width_at(c, LAG566, 0.5) for c in curves]))

def breadth(key):
    off = ~np.eye(58, dtype=bool)
    return float(cbar[key][:, :, 49][off].mean()), float(zero_long[key][off].mean())

from threadpoolctl import threadpool_limits
def si_terms_of(x, fs, bandwidth):
    with threadpool_limits(1):
        Sg = M.cochleogram(x, fs, bandwidth=bandwidth)
        n, s2, acc = 0, 0.0, None
        for c in M.short_term_iter(Sg, 100, 49, pairs="all"):
            v = c.astype(np.float64)
            acc = v.copy() if acc is None else acc + v
            s2 += (v ** 2).sum()
            n += 1
        return s2 / n, float(((acc / n) ** 2).sum()), n

How the analysis differs from the paper's: the Methods' critical bandwidths are used where the code (criticalbandwidth.m) has another formula; envelopes are at 1 kHz as the Methods say (the code's example keeps 3675 Hz); the short-term correlation is sampled every tau_W / 4; white noise is generated. The criticalbandwidth.m bandwidths, run as a variant for fig7i, give the same SI to within 0.003 in the group means. What was found about the dataset: the 195 sounds, 15 per category, 10 s at 44.1 kHz, are all there, as 16 bit integer WAV files where the description says double precision; white noise is not included.

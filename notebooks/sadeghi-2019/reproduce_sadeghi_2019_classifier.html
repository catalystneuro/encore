Sadeghi et al. (2019): auditory model classifier claims (CRCNS bst-2)¶

Paper: Sadeghi M, Zhai X, Stevenson IH, Escabi MA (2019). A neural ensemble correlation code for sound category identification. PLoS Biol 17(10):e3000449, doi:10.1371/journal.pbio.3000449. The claims file (claims/sadeghi-2019.yaml) was written from the version of record (PMC6788721) with its supplement.

Dataset: CRCNS bst-2 (doi:10.6080/K03X84V3), bst-2/live/data.tar.gz in the public bucket crcnsarchive, crcns:bst-2/unversioned (CRCNS does not version data sets; the paper cites the DOI only, and this is the bucket's only copy). The model sounds are data/Sounds/ModelSounds//Sound_.wav. The deposit's code (data/Code) has no classifier code, so the classifier follows the Methods.

This notebook tests the model classification claims; the model correlation claims are in reproduce_sadeghi_2019_model.ipynb and the neural claims in reproduce_sadeghi_2019_neural.ipynb.

Chance is 1/13 = 7.69%.

Classifiers at every resolution¶

For each tau_W: features of the 195 sounds; PCA of each feature set fitted on the training observations of all sounds (an assumption: PCA is unsupervised and the held-out sound is 1 of 195; a variant below refits it in every fold); leave-one-sound-out GMM classifiers under reading (7b) and, where the PC count for 90% of the variance differs from the reported one, (7a); test windows under readings (6a) and (6b). The spectrum classifier has no reported counts; it uses the PCs explaining 90% and 8 components (the spectral count) under both readings.

fig9a-optimal-resolution¶

In the 13-category model task, the spectral and temporal correlation classifiers perform best at a window resolution of 141 ms and the spectro-temporal classifier at 100 ms, and all perform above chance (7.69%) at every resolution.

Optimum: the resolution with the highest accuracy at the full duration (ties go to the first; the cell after the first one lists every tie, as one sound is 0.51 points and ties are common). t test of the 195 per-sound outcomes against 7.69%, Bonferroni over the 10 resolutions; the 13 category accuracies are a variant.

# Every grid point at the maximum full-duration accuracy, two tie-breaks for the tied ones, and a
# bootstrap over the 195 sounds of where the maximum falls (a tied maximum shares its credit).
# Tie-break 1: the mean posterior probability of the true category at the full duration, a
# continuous form of the same accuracy. Tie-break 2: the mean accuracy at 1, 2, 4 and 8 s, each
# read at the longest sampled duration not exceeding it, so that every resolution is read at the
# same durations.
def post_true(kind, r7, sp, tw):
    n = NS[(sp, tw)][-1]
    p = [np.exp(s[LAB[j]] - np.logaddexp.reduce(s)) for j, s in
         ((j, np.cumsum(L, 0)[n - 1]) for j, L in enumerate(LL[(kind, r7, sp, tw)]))]
    return 100 * float(np.mean(p))
def acc_common(kind, r7, sp, tw, durs=(1, 2, 4, 8)):
    t = np.array(NS[(sp, tw)]) * SPACING[tw][sp]
    cols = np.searchsorted(t, np.array(durs) + 1e-9) - 1
    return 100 * float(ACC[(kind, r7, sp, tw)][:, cols].mean())

def rise(t, y):
    thr = 0.9 * y[-1]
    i = int(np.argmax(y >= thr))
    lin = t[0] if i == 0 else t[i - 1] + (t[i] - t[i - 1]) * (thr - y[i - 1]) / (y[i] - y[i - 1])

        yy = f(tt, pinf, p0, tau)

    except RuntimeError:

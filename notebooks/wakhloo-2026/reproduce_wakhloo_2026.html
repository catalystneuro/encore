Clock check¶

Spikes, position and trials must share one clock. Two contrasts show it: (1) position from trials: at the end of each trial the animal should be at the trial's end well, so the position just before the end time should be nearest to that well, and less often so 15 s earlier; (2) spikes from position: a ridge decoder of x and y position from CA1 counts (500 ms bins, five contiguous folds) should do better with the true alignment than with the counts shifted by 10 s or more. The decoder and its penalty are a standard choice for this check only.

Readout analysis (shared pipeline)¶

For each area, rat and session: locomotion bins (speed of the smoothed velocity above 4 cm/s), units above 0.1 Hz, each unit centred and divided by its standard deviation plus 0.01 counts per bin (0.02 Hz), latents x, y, vx, vy z-scored (Methods, Readout analysis; code rat_utils.process_dat). Then 500 random subsets of units (19 PFC, 24 CA1 as the Methods; 19 CA1 as the code, a variant) and of 500 bins; per subset the theoretical error (Eq. 5, p = 300), the empirical Hebbian error (300 training and 200 test bins, 500 Gaussian tasks with |mean label| < 0.25), dimension, correlation, SNF and SSF (Eqs. 6 to 9). Each session's value is the mean over subsets. Each (area, rat, session) has its own random generator, seeded from its indices.

The linear SVC of the code is fitted on the same split, one per task, which costs about 1.4 s per subset (timed on one PFC session while preparing); on all 500 subsets of the 128 PFC and CA1 cases that is about 25 hours on one core. It is run here on every 125th subset (4 per session), a reduction recorded as a deviation.

GLM fits (shared pipeline)¶

Per-unit Poisson GLMs (Methods, Generalized linear model analysis; code fit-GLMs-rat.py with the basis the code chose: position bins of 10 cm, velocity bins of 3 cm/s, variances 100 and 40, centres from bins holding more than 20 time bins over all of a rat's sessions). Bins are those with the dataset's speed column above 4 cm/s, as the GLM code (rat_utils.get_all_lat) does. The l2 penalty is chosen per unit by 10-fold cross-validation over 10 values; the folds are scikit-learn's unshuffled KFold, which GridSearchCV uses for a regressor, so they involve no random choice. The basis grid search itself was not repeated: the code's chosen basis is used. Each unit's best score is taken with np.argmax over the penalties, as rat_utils.format_glm_results does.

def mixed_table(units_ro, units_td, t0=0):
    rows = []
    for a in AREAS:
        v = units_ro[a]; td = TD[units_td[a]]
        for meas in ["dim", "corr", "snf", "ssf"]:
            g, e, pg, pe = w.fit_mixed(M[v][meas], quad=True, t0=t0)
            rows.append(dict(area=a, model="quad", meas=meas, gamma=g, p_gamma=pg, eta=e, p_eta=pe))
        g, e, pg, pe = w.fit_mixed(M[v]["ssf"], quad=False, t0=t0)
        rows.append(dict(area=a, model="lin", meas="ssf", gamma=g, p_gamma=pg, eta=e, p_eta=pe))
        g, e, pg, pe = w.fit_mixed(td, quad=True, t0=t0)
        rows.append(dict(area=a, model="quad", meas="task_dim", gamma=g, p_gamma=pg, eta=e, p_eta=pe))
        g, e, pg, pe = w.fit_mixed(td, quad=False, t0=t0)
        rows.append(dict(area=a, model="lin", meas="task_dim", gamma=g, p_gamma=pg, eta=e, p_eta=pe))
    T = pd.DataFrame(rows)
    pv = np.concatenate([T.p_gamma.values, T.p_eta.dropna().values])
    adj = multipletests(pv, method="fdr_bh")[1]
    T["p_gamma_adj"] = adj[:len(T)]
    T["p_eta_adj"] = np.nan
    T.loc[T.p_eta.notna(), "p_eta_adj"] = adj[len(T):]
    return T

Paper. Masset P, Tano P, Kim HR, Malik AN, Pouget A, Uchida N (2025). Multi-timescale reinforcement learning in the brain. Nature 642:682-690. doi:10.1038/s41586-025-08929-9. The claims file (claims/masset-2025.yaml) was written from the accepted author manuscript in PubMed Central (main text, legends, Methods and Extended Data legends), with the paper's Mendeley code (doi:10.17632/tc43t3s7c5.1) and simulation code (github.com/pablotano8/multi_timescale_RL at 37f11c6).

Data. DANDI:000251, version draft, modified 2023-06-20T00:56:22Z. The dandiset has no published version, so the draft is the only version there is; it is pinned by its modification time, which the notebook checks. It holds the data of Kim et al. (2020), which the paper reuses: the VR task single units, one unit per file, and no cued delay task recordings. The cued delay units are in the paper's own deposit, Mendeley Data doi:10.17632/tc43t3s7c5.1 (version 1, 2025-04-09), file DA_SU_ODOR_NEW_W_OL.h5; its FinalAverageArray.mat (the paper's per-neuron table) and Valid_S.mat (the paper's neuron flags) link the two tasks' units. All files are streamed into memory.

Seeds. Random draws use each claim's seed, zlib.crc32(b"masset-2025/<claim id>"), and four more (plus 1000 to 4000); a second generator of a claim adds 1. Shared computations use the seed of the claim that defines them: the VR half splits that of fig3b-vr-ramp-population, the VR fit's initial values that of fig3-common-value-fit, the cued delay fits that of cued-delay-neurons.

The entry has four notebooks: vr_population.ipynb (VR claims on the population), vr_single_mouse.ipynb (single-mouse VR fits), vr_reward_expectation.ipynb (the common reward expectation model), cued_delay_and_cross_task.ipynb (link, cued delay and cross-task claims). Link: the units of the two tasks (link-units-across-tasks)¶

The units of DANDI:000251 (VR) and of the Mendeley cued delay file can be matched to the rows of the paper's per-neuron table (FinalAverageArray.mat), which gives each neuron's VR and cued delay recordings on one row.

Each unit is matched, within its mouse and among rows with the same number of trials, to the row whose per-trial spike counts (from the table's 10 ms rates) are closest. A match is accepted when the mean absolute difference is under 1 spike per trial and the next best row differs by more.

M4: for each of the 200 half-fits, the discount matrix from that half's gammas over 0 to 12 s (120 points), and the other half's mean cue responses per delay, minus a baseline, each neuron scaled to its maximum over delays; regularised inverse with alpha = 2. Readings: (a) every singular component, (b) the first 12. Baseline: the Methods take it from the same half as the responses (main); the code from the half that gives the gammas (variant). The shuffle permutes neurons in the test responses, one permutation per decoding as in the code; every reading uses the same permutations (the same generator), so that the readings differ only in the decoder. Twenty draws of the permutations are made: the first is the test, and the share of the twenty with p < 0.05 shows how much the draw matters. def other(k):
    return (k + 100) % 200


N_SHUFFLE = 20


def decode_set(fit, k_sel, rng, n_comp, baseline="methods", gam=None, matrix=None, n_shuffle=N_SHUFFLE):
    """M4 on the neurons k_sel. gam: (200, n) discount factors for the matrix (default: this
    task's own fits); the responses are the cued delay responses of the other half."""
    g = fit["gamma"][:, k_sel] if gam is None else gam
    F = fit["firing"][:, k_sel]
    A = fit["exp"][:, k_sel, 0]
    resp_test = F[[other(k) for k in range(200)]]
    base = A[[other(k) for k in range(200)]] if baseline == "methods" else A
    keep = ~np.isnan(resp_test).any((0, 2))
    W, WS = ms.run_decoding(g[:, keep], base[:, keep], resp_test[:, keep], rng, n_comp=n_comp,
                            matrix=None if matrix is None else matrix[:, keep], n_shuffle=n_shuffle)
    return W, WS, int((~keep).sum())


def single_discount(fit, k_sel):
    F = fit["firing"][:, k_sel]
    A, B = fit["exp"][:, k_sel, 0], fit["exp"][:, k_sel, 1]
    out = np.zeros((200, 4))
    for k in range(200):
        x = (F[other(k)] - A[k][:, None]) / B[k][:, None]
        keep = ~np.isnan(x).any(1)
        P = ms.single_discount_decode(x[keep], fit["gamma"][k, k_sel][keep].mean())
        out[k] = ms.wasserstein_to_point(P, ms.TRUE_IDX)
    return out

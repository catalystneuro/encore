Reproducing Peyrache et al. (2009) from CRCNS pfc-6¶

Paper. Peyrache A, Khamassi M, Benchenane K, Wiener SI, Battaglia FP (2009). Replay of rule-learning related neural patterns in the prefrontal cortex during sleep. Nature Neuroscience 12(7):919-926. doi:10.1038/nn.2337

Dataset. CRCNS pfc-6, "Activity of neurons in rat medial prefrontal cortex during learning and sleep" (doi:10.6080/K0KH0KH5), read anonymously from the public bucket at https://crcnsarchive.s3-us-west-2.amazonaws.com/pfc-6/live/. The data set holds one archive, mPFC_Data.tar.gz, with seven text files per session (spikes, cell types, behaviour, position, awake and SWS intervals), described by docs/crcns_pfc-6_data_description.pdf (version 0.7, March 12, 2018).

Version. CRCNS data sets are not versioned (docs/archives.md), so the version is recorded as unversioned, and the file read is pinned by its MD5 from the data set's checksums.md5: mPFC_Data.tar.gz 2c255b44209ece01326dd09efaabd92a, checked below against the bucket's ETag. The data set's description is checksummed too (pdf 3464d68562a83bb15d843999ec3227c8, docx c536d32bb1a791ac00a9a7d1056f57a6); the learning sessions are read from the docx. This is the only published version (live/; there is no old/ folder), and the paper cites none.

Claims. claims/crcns-pfc-6/10.1038-nn.2337.yaml, written from the version of record and its supplement, and checked by a second reader. Methods taken from the paper are cited where they are used and in pfc6.py.

Rest epochs. The data set gives the awake interval and the SWS intervals, not the bounds of the pre and post rest epochs. Pre is taken as the time before the awake epoch and post as the time after it to the end of the position record, or to the end of the last post SWS interval if that is later (an assumption; a 30 min variant is shown for supp5-sws-only, the claim that compares non-SWS bins). Every analysis that uses SWS bins only is unaffected by it except through the z-transform reading epochz.

Do the streams share the clock of the trial table?¶

Two contrasts. The arm the rat chose (behavior column 5) should be decodable from the position and from the spikes at the end of each trial, and should not be when the trial times are moved by 30 s. And head speed from the position record should be lower inside the SWS intervals than in the rest of the rest epochs.

def arm_decoding(s, shift_ms, use="spikes"):
    b = s["behavior"]
    y = b[:, 4].astype(int)
    if min(np.bincount(y, minlength=2)) < 3:
        return np.nan
    ends = b[:, 1] + shift_ms
    if use == "pos":
        p = s["pos"]
        X = np.column_stack([np.interp(ends - 500, p[:, 0], p[:, 1]), np.interp(ends - 500, p[:, 0], p[:, 2])])
    else:
        t, c = s["spikes_t"], s["spikes_id"] - 1
        X = np.zeros((len(ends), pfc6.n_cells(s)))
        for k, e in enumerate(ends):
            m = (t >= e - 2000) & (t < e)
            np.add.at(X[k], c[m], 1)
        X = np.sqrt(X)
    folds = min(5, min(np.bincount(y, minlength=2)))
    return cross_val_score(LogisticRegression(max_iter=2000), X, y, cv=folds).mean()

def steiger(r12, r13, r23, n):
    """Steiger (1980) Z for two correlations sharing variable 1."""
    z12, z13 = np.arctanh(r12), np.arctanh(r13)
    rm2 = (r12 ** 2 + r13 ** 2) / 2
    f = min((1 - r23) / (2 * (1 - rm2)), 1.0)
    h = (1 - f * rm2) / (1 - rm2)
    Z = (z12 - z13) * np.sqrt(n - 3) / np.sqrt(2 * (1 - r23) * h)
    return Z, 2 * stats.norm.sf(abs(Z))

def tail_fraction(post, pre, q=99):
    r99 = np.percentile(post, q)
    net = post.mean() - pre.mean()
    below = post[post <= r99].sum() / len(post) - pre[pre <= r99].sum() / len(pre)
    return 1 - below / net, net

How the analysis differs from the paper's. The rest epochs' bounds are not in the data set and are taken from the awake interval and the position record. The data set holds 56 sessions that pass the inclusion rule, where the paper analysed 63. Each claim with an open z-transform was run with z over the whole rest epoch and over its SWS bins; no outcome changes between them. What was found about the data set. It holds spikes, cell types, behaviour, position and the awake and SWS intervals of 86 sessions, but no LFP, no SPWR, delta or spindle times and no tetrode per cell, so 14 of the 29 claims cannot be tested.

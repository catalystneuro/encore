Every rate map is built as the claims file's opening comment now says ("Smoothing and unvisited bins", answered on 2026-10-21 from the paper's calculateRateMap.m): the rate per bin (spikes over time, the time per position sample clipped at 0.1 s), unvisited bins 0, then smoothed; blanked maps have the unvisited bins set to NaN after smoothing. Tables still print this as rm b, the name the questions file gave it. The other readings run side by side are the claims file's own and are listed in the docstring of objcode.py: speed (decoders), field (rate criterion of a field), template width w (a, the code's SDs; b, the Methods' variances) and the readings each criterion names.

ovs-method-extra-cells¶

The object-vector score method of earlier studies classified 40 cells (3.4%) that the template matching did not, mostly false positives on inspection.

The Methods' four criteria (Object-vector score and object-vector cell criteria), with the vector map of the paper's reference 12 as the criterion now gives it (answer of 2026-10-21): distance bins of 2 cm, direction bins of 10° from East, the rate per bin smoothed with a Gaussian of SD 1.5 bins, circular in direction. The rate per bin, its unvisited bins (0 before smoothing, blanked after) and the speed filter follow the opening comment's rate-map method. Range readings of the criterion: (r-a) 0 to the largest distance sampled in either trial, the correlation over bins with a value in both maps; (r-b) 0 to the largest distance sampled in both trials. Shuffles as the Methods' Shuffling of spike data: each trial's spike train circularly shifted by 20 s to its duration less 20 s, 500 times for the object-vector score (O and OM shifted independently) and 1,000 times per trial for spatial information; 99th percentiles.

Details the criterion does not fix, run as readings here and asked in the questions file (question of 2026-10-21): which fields count for the exclusion of cells whose fields "would fall outside of the arena" in OM (x-a, a cell is excluded when the centroid of any of its O fields, moved with the object to the OM object position, lies outside the arena; x-b, when that holds for all of them); the lambda of spatial information (si-a, si-b, as the fig7 criterion names them); the field rate rule (field a, b) and which field must be 15 cm from the object (distance readings a, b, c of fig1d). The count is of cells meeting the four criteria and not object-tuned by template matching under each width reading w. Shuffles are run for the cells that have a field in both trials under some field reading, as the other cells fail criterion 3 under every reading.

def pair_measures(sessions, a, b, rm):
    sc, roa, rob, rats = [], [], [], []
    for s in sessions:
        ta, tb = s.trial(a), s.trial(b)
        if ta is None or tb is None:
            continue
        ma, _ = oc.single_maps(ta, rm)
        mb, _ = oc.single_maps(tb, rm)
        for u in range(s.n_units):
            sc.append(oc.pearson_nan(ma[u], mb[u]))
            roa.append(oc.rate_overlap(oc.mean_rate(ta, u, True), oc.mean_rate(tb, u, True)))
            rob.append(oc.rate_overlap(oc.mean_rate(ta, u, False), oc.mean_rate(tb, u, False)))
            rats.append(s.rat)
    return pd.DataFrame({"sc": sc, "ro_a": roa, "ro_b": rob, "rat": rats})


PAIRS = [("NO", "O", "CON1", "CON2"), ("O", "OM", "CON2", "CON3"), ("OM", "NOp", "CON3", "CON4"), ("NO", "NOp", "CON1", "CON4")]


def compare(obj_sessions, con_sessions):
    rows, store = [], {}
    for rm in "b":
        for a, b, ca, cb in PAIRS:
            X = pair_measures(obj_sessions, a, b, rm)
            Y = pair_measures(con_sessions, ca, cb, rm)
            store[rm, a, b] = (X, Y)
            for meas in ("sc", "ro_a", "ro_b"):
                x, y = X[meas].dropna(), Y[meas].dropna()
                z, p = oc.ranksum(x, y)
                rows.append({"rm": rm, "pair": f"{a}-{b}", "control": f"{ca}-{cb}", "measure": meas,
                             "n obj": len(x), "n con": len(y), "median obj": x.median(), "median con": y.median(),
                             "difference": x.median() - y.median(), "z": z, "p": p})
    return pd.DataFrame(rows), store

How the analysis differs from the paper's: rate maps follow the paper's calculateRateMap.m as the claims file now gives it, also for the single-cell maps, whose own code is not given. Whether a field's 1 Hz rule applies to its peak or to every bin (field) is not given by the paper, and both are run. The object-vector method's exclusion rule, field and lambda are not given and are run as readings (asked). Speed uses a standard choice. The template's form is the claims file's reading, an isotropic Gaussian at bin centres. Fields are the regions above the threshold with bins joined at corners; joining them only along edges is shown as a variant.

What was found about the dataset: in the two Neuropixels population files the y coordinate of the tracking is a copy of x; the CA1 file holds the correct tracking of the same recordings. The counts match the paper for CA1 and the controls. The CA3 file holds 341 cells from 4 rats against the paper's 313. The files carry no cell identities across days, no day of exposure, no implant sites and no head direction. The population files repeat 142 tetrode cells and all Neuropixels cells of the CA1 file, and add 283 tetrode units that cannot be linked to it. One CA3 session has its Object and Object Moved positions the reverse of the protocol. Some gaps between trials last hours. A few units break the inclusion rules as computed here, and three CA1 units have spike times out of order. Up to 29% of Neuropixels tracking samples are NaN. The unit of the tracking is stored as a MATLAB string object that only MATLAB reads directly.

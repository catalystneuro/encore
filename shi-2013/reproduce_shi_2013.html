Reproducing Shi, Apker and Buneo (2013) on CRCNS ppc-1¶

Paper. Shi Y, Apker G, Buneo CA (2013). Multimodal representation of limb endpoint position in the posterior parietal cortex. J Neurophysiol 109: 2097-2107. doi:10.1152/jn.00223.2012

Dataset. CRCNS ppc-1, Buneo, Shi, Apker and VanGilder (2016), doi:10.6080/K0CZ353K, identified here as crcns:ppc-1/unversioned. It is read from the public bucket (https://crcnsarchive.s3-us-west-2.amazonaws.com/ppc-1/live/data.tar.gz, streamed, not downloaded).

Version. CRCNS data sets are not versioned, and ppc-1 has one published copy, under live/ (no old/ copy exists in the bucket), so that copy is the one pinned. The paper cites no version. To detect a later change: data.tar.gz has MD5 bbb341b8947a6314b2618f0caa0b64f8 in the data set's checksums.md5 (printed below as read), size 4,394,813,551 bytes; data descriptor version 0.8 (Dec 7, 2016).

Claims. claims/shi-2013.yaml, written from the version of record (Methods, Results, Discussion, Table 1, legends of Figures 1 to 6; the paper has no supplement and links no code), and checked by a second reader.

What the data set holds, in short. Spike times of sorted units and strobed event codes for each session, in MATLAB and Plexon files; each trial's events end with a text record that gives the target, a two-valued condition code and the hand position. All sessions have monkey X's target layout; monkey B is not in the data set. Which condition code is Vision is not documented and is inferred from the data (see "Which code is Vision"). Outcomes that depend on it are marked as resting on that assumption.

Reading of the codes, from the timing and the paper's paradigm (Methods, Experimental paradigm). Ranges below are the 5th to 95th percentiles of the table above, with the minimum and maximum in brackets. Code 3 comes 0.54 to 0.96 s (0.54 to 1.92 s) after the trial starts (the start position is shown, then held for 500 ms): it fits target onset, the go signal. Code 8 follows 0.22 to 0.58 s (0.08 to 1.12 s) later (a reaction time), and the target code 0.03 to 0.38 s (0.02 to 1.25 s) after 8 (median 0.13 s): 8 fits the cursor leaving the start window and the target code the cursor entering the target window. Code 10 follows the target code by a median of 320 ms (5th to 95th percentile 0.30 to 0.32 s, range 0.22 to 0.42 s), the 300 ms after which the target is extinguished (on a 32 ms strobe clock). From 10 to 12 is 0.83 to 1.86 s, the saccade to the central fixation point and the 800 to 1,200 ms hold. Code 12 is taken as the end of the static holding period, and 13, 32 ms later, as reward. These are readings of the data, not documented; the clock check below tests the alignment.

On every completed trial the time from code 10 to code 12 is at least the trial's own record field 11 plus 28 ms (the table above): the shortest intervals, 0.83 s, are on trials with field 11 = 800, and with 900 and 1,000 the shortest are 0.93 and 1.06 s. Field 11 is therefore read as the minimum hold, timed from a point at least 28 ms after code 10 (target offset, the cue to saccade to the centre), and code 12 as its end, so the 800 ms before code 12 lie inside the hold as the task timed it. A start 28 ms after the cue is too early for a saccade; the fixation window is 6.5 degrees in radius (Methods, Experimental paradigm), so the eyes may already have been inside it. Where the window starts soon after code 10 it may still include the end of a saccade, and this bears most on the first 400 ms. The share of such trials is printed above. A variant that starts the window at least 250 ms after code 10 is run for hold-subepochs and decoding-subepochs.

Which code is Vision¶

Field 14 splits each session's completed trials into two halves, five per target, as V and NV should. No file says which is which. The conditions differ only from the end of the reach, when the cursor is blanked on NV trials. The table counts aborted trials by whether they ended before or after code 10.

Aborts before code 10, when the two kinds of trial do not yet differ, are equal in number; aborts after it are about 29% more frequent on code 7 trials. def measures(unit_list, v_code=ppc.V_CODE, nv_code=ppc.NV_CODE):
    rows = []
    for k, u_, sp in unit_list:
        t = kept[k]
        r = dict(session=k, unit=u_)
        for w, win in ppc.WINDOWS.items():
            cnt = ppc.unit_counts(t, sp, win)
            r[w] = ppc.cell_array(t, cnt / (win[1] - win[0]), v_code, nv_code)
            r[w + "_count"] = ppc.cell_array(t, cnt, v_code, nv_code)
        mv = ppc.unit_counts(t, sp, (-ppc.MOVE_HALF, ppc.MOVE_HALF), align="t8")
        r["move"] = ppc.cell_array(t, mv / (2 * ppc.MOVE_HALF), v_code, nv_code)
        r["psth"] = ppc.cell_array(t, ppc.psth_rate(t, sp, ppc.WINDOWS["hold"]), v_code, nv_code)
        hold_sp = np.empty(len(t), dtype=object)
        for i, t12 in enumerate(t.t12.values):
            hold_sp[i] = ppc.spikes_in(sp, t12 - 0.8, t12)
        arr = np.empty((2, 8, ppc.N_PER_CELL), dtype=object)
        for ci, code in enumerate((v_code, nv_code)):
            for ti, tg in enumerate(ppc.TARGETS):
                idx = np.flatnonzero((t.cond.values == code) & (t.target.values == tg))
                for j, i in enumerate(idx[:ppc.N_PER_CELL]):
                    arr[ci, ti, j] = hold_sp[i]
        r["hold_spikes"] = arr
        rows.append(r)
    M = pd.DataFrame(rows)
    active = M.hold_count.apply(lambda a: a.sum() > 0)
    return M[active].reset_index(drop=True), M[~active][["session", "unit"]]

def late_measures(M):
    out = {"hold": [], "first": [], "last": []}
    for r in M.itertuples():
        t = kept[r.session]
        sp = np.sort(D["sessions"][r.session]["units"][r.unit])
        s0, mid, e0 = ppc.late_windows(t)
        for key, (a_, b_) in (("hold", (s0, e0)), ("first", (s0, mid)), ("last", (mid, e0))):
            dur = b_ - a_
            cnt = np.searchsorted(sp, b_) - np.searchsorted(sp, a_)
            out[key].append(ppc.cell_array(t, np.where(dur > 0, cnt / np.where(dur > 0, dur, 1), np.nan)))
    return out

    rng = np.random.default_rng(seed)

def ff_slope(m, v):
    return np.sum(m * v) / np.sum(m * m)
def ff_test(M, keep=None, seed=2, n_perm=1000):
    I = indexes(M)
    cm = np.array([[r.hold_count[c_, p].mean() for c_ in (0, 1)] for r, p in zip(M.itertuples(), I.pnv)])
    cv = np.array([[r.hold_count[c_, p].var(ddof=1) for c_ in (0, 1)] for r, p in zip(M.itertuples(), I.pnv)])
    if keep is not None:
        cm, cv = cm[keep], cv[keep]
    ffv, ffn = ff_slope(cm[:, 0], cv[:, 0]), ff_slope(cm[:, 1], cv[:, 1])
    rng = np.random.default_rng(seed)
    pm, pv_ = np.concatenate([cm[:, 0], cm[:, 1]]), np.concatenate([cv[:, 0], cv[:, 1]])

How the analysis differs from the paper's.

  • Only monkey X: the data set holds no session with monkey B's target layout. The paper pools 219 monkey X and 124 monkey B neurons; here 359 monkey X sessions with the complete design are used, one unit from each, as the paper has one neuron per session; that it is the first sorted unit is an assumption, and all 483 sorted units are a variant. Four outcomes (hold-vision-main-effect, hold-subepochs, fig4-indx1-negative, decoding-subepochs) would differ with all units and are marked as resting on it. Counts are compared with the paper's as percentages, or scaled to 343.
  • Which condition code is V is inferred from more aborts after code 10 on code 7 trials (assumed: 4 = V, 7 = NV). The directional results (rate variance, FF, CV2, V better than NV decoding) rest on this.
  • The meaning of the event codes is read from their timing: 12 as the end of the hold, 8 as movement onset (cursor leaving the start window). On every completed trial code 10 to code 12 lasts at least the record's field 11 (the minimum hold) plus 28 ms, so the 800 ms window lies in the hold as the task timed it; in 11.6% of trials it starts less than 250 ms after code 10, and a variant that starts it later leaves the sub-epoch results as they are.
  • Each trial has one hand position (the record's x, y, z), not a position trace, so behavioural tests use it in place of the mean over the 800 ms hold. No continuous arm or eye position is identified in the data.
  • Where a cell of the design has more than five completed trials (4 sessions), the first five are used.

What was found about the data set.

  • The data descriptor says 343 cells, 219 from monkey X and 124 from monkey B; every session with a trial record has monkey X's layout, in every month from October 2008 to November 2009, and there are more usable monkey X sessions (359, with 485 sorted units, all recorded before the paper was submitted, and not repeats of one neuron within a day) than the paper's 219. Which of them the paper used is not documented.
  • The condition (V or NV) of a trial is coded as 4 or 7 in an undocumented text record; the event codes are not described (EventCodes.txt is a generic list that does not match them), nor are the record's fields (target, condition, hand position, possibly eye position, task parameters).
  • The analog files' channels are named AD01 to AD16 without description, and the layout of the .plxAnaAD.dat files is not documented. Under the layout read here no channel of three sessions follows the hand or differs between targets in the hold.
  • Nine early files (d<n>.mat) have a shorter record without positions and a hold below 800 ms.
  • The .mat spike times are in milliseconds and the event times in seconds; the descriptor gives neither unit. They agree with the .plx file of the session checked.

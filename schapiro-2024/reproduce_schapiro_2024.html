Reproducing Schapiro et al. (2024) from Dryad dataset 1rn8pk129¶

Paper. Schapiro KA, Rittenberg JD, Kenngott M, Marder E (2024). Ih block reveals separation of timescales in pyloric rhythm response to temperature changes in Cancer borealis. eLife 13:RP98844. doi:10.7554/elife.98844. The claims file was written from the version of record (full text from Europe PMC, PMC11479588), with its Methods, figure legends, Figure 1-figure supplement 1 and Table 1.

Dataset. DRYAD:1rn8pk129, "Data from: Effects of Cs on temperature response of C. borealis pyloric rhythm", version id 310115 (published 2024-08-09). The paper cites the dataset's DOI, which always resolves to the newest version, and no version. Two versions are published: 290160 (2024-04-23) and 310115. 310115 is the newest, and it is the one that matches the paper as published: its README and analysis script add the voltage-clamp cells of the revision (Figure 1-figure supplement 1 and the Ih numbers of the version of record), and only VoltageClampData.mat, VoltageClampTraceData.mat (new), MakePaperFigures_Clean.m and README.md differ between the two (same SHA-256 for every other file, from the public file lists). The files are staged from Dryad, checked against their SHA-256, and read in place (docs/archives.md, "Dryad"); the digest of each file read is printed below.

Code. The dataset holds the paper's MATLAB code (MakePaperFigures_Clean.m, CalculateFrequencyPhaseEtc.m, extractBurstFrequency_Final.m, Phase_Calc.m, ProbabilityUpDown.m). The helper pyloric.py ports the parts used here; its docstring says where each parameter comes from.

The README says spike times, a subsampled temperature (Tempsub) and its time (x_sub), the condition table Timings (file indices) and the file start times (fileTimes). The values agree: spike times are in seconds (they end at the last file time), x_sub is in minutes, sampled every 0.02 min (1.2 s), and file times are 120 s apart, as the Methods' 2 min files imply. The 21 experiments of the summary files are all deposited as spike files; each has PD and LP spikes, and PY spikes are present in the number printed (the paper's Table 1 uses 12 with PY). Three files go beyond this: 981_025 is a control experiment (two saline protocols, then Cs+ ramps), 981_035 and 969_154 are picrotoxin experiments outside the 21. 981_035 holds two PD spike trains, PD and PD2, which the README does not mention. In two files (969_152, 981_010) the temperature runs on after the sorted spikes end (to 278 and 142 min against 122 and 81 min); the spikes and the temperature agree on the windows used (the step protocol in each window, below), so this only means the temperature recording continued. Temperatures below 5 C (to -46.7 C), impossible in this preparation, occur in three files: thermocouple dropouts, shown in the cell finding-temperature-dropouts.

# Is any recording deposited twice? Compare every pair of PD spike trains: fraction of spikes of one
# within 1 ms of a spike of the other (independent recordings give the chance level, a few percent).
def coincidence(a, b, tol=0.001):
    i = np.clip(np.searchsorted(a, b), 1, len(a) - 1)
    return float(np.mean(np.minimum(np.abs(a[i] - b), np.abs(a[i - 1] - b)) < tol))

def ih_readings(t, i, step_on, step_len=12.0):
    """Ih at a hyperpolarising step: initial minus steady-state current (criterion; the deposited
    script's Leak - Sag). The capacitive transient is taken to end 20 ms after the step (standard
    choice); steady state the mean of the last 1 s of the step. Initial current: (a) the mean of the
    first 100 ms after the transient; (b) the current farthest from the steady state in the first
    500 ms, after a 10 ms moving average (standard choice against noise); (c) the least inward
    current (10 ms moving average) in the first 1 s, the point before the slow inward Ih develops,
    after a faster current has relaxed (printed below; a standard choice, closest to the script's
    "initial current" read by eye)."""
    fs = 1 / np.median(np.diff(t))
    a = int(round((step_on + 0.02) * fs))
    ss = np.mean(i[int((step_on + step_len - 1.0) * fs): int((step_on + step_len) * fs)])
    ia = np.mean(i[a: a + int(0.1 * fs)])
    k = int(0.01 * fs)
    w = np.convolve(i[a: a + int(0.5 * fs)], np.ones(k) / k, mode="valid")
    ib = w[int(np.argmax(np.abs(w - ss)))]
    ic = np.max(np.convolve(i[a: a + int(1.0 * fs)], np.ones(k) / k, mode="valid"))
    return ia - ss, ib - ss, ic - ss

def phase_shares(e, cond, trace=False, t_from=13, t_to=15, win=30.0, keep_gaps=False):
    d = A[e]
    c = d["cycles"]
    s_idx, e_idx = d["Timings"][cond]
    m = P.condition_mask(c["start"], d["fileTimes"], s_idx[0], e_idx[0])
    k = P.step_onset(c, m, t_from, t_to)
    if k is None:
        return None
    t_on = c["start"][k]
    pre = np.nonzero(m & (c["start"] >= t_on - win) & (c["start"] < t_on))[0]
    post = np.nonzero(m & (c["start"] >= t_on) & (c["start"] < t_on + win))[0]
    if not keep_gaps:
        pre, post = pre[~c["gap"][pre]], post[~c["gap"][post]]
    post = post[c["period"][post] > np.mean(c["period"][pre])]
    ph = {"burst": c["pd_dur"], "repol_b": c["LP_lat_on"] - c["pd_dur"], "inhib_b": c["LP_lat_off"] - c["LP_lat_on"],
          "depol_b": c["period"] - c["LP_lat_off"]}
    if trace:
        v, _ = P.raw_trace(e, "PD", t_on - win - 5, t_on + win + 5)
        v = np.convolve(v, np.ones(50) / 50, mode="same")
        t0 = t_on - win - 5
        rep = np.full(len(c["period"]), np.nan)
        for i in np.r_[pre, post]:
            a = int((c["start"][i] + c["pd_dur"][i] - t0) * 1e4)
            b = int((c["start"][i] + c["period"][i] - t0) * 1e4)
            if b > a:
                rep[i] = (np.argmin(v[a:b])) / 1e4
        ph["repol_a"] = rep
        ph["depol_a"] = c["period"] - c["pd_dur"] - rep
    dper = np.mean(c["period"][post]) - np.mean(c["period"][pre])
    out = {"expt": e, "cond": cond, "onset_min": t_on / 60, "T_onset": c["temp"][k], "n_pre": len(pre), "n_post": len(post),
           "period_pre": np.mean(c["period"][pre]), "period_post": np.mean(c["period"][post]) if len(post) else np.nan, "dperiod_ms": 1e3 * dper}
    for kk, v_ in ph.items():
        out[f"share_{kk}"] = (np.nanmean(v_[post]) - np.nanmean(v_[pre])) / dper if len(post) else np.nan
    return out

def first_hold_cycles(d, cond, reading):
    """Cycles of the first 11 C hold. (a) within 0.3 C of 11 C (O2, as for frequency); (b) every
    cycle of the holding period, from the first cycle of the condition window within 1 C of 11 C
    (a standard bound) to the last cycle before the warming toward 13 C begins (step_onset with
    hold_end: the rise from the last cycle within 0.3 C of 11 C, traced back by the paper's
    increasing-temperature rule), whatever its temperature; (a_gaps) as (a) with the cycles
    left by the outlier removal kept, as the deposited code keeps them."""
    h = P.hold_means(d, cond, which="first", strict_cs=False, drop_gaps=reading != "a_gaps")
    ii = h["cycle_index"][11]
    if reading in ("a", "a_gaps"):
        return ii
    c = d["cycles"]
    s_idx, e_idx = d["Timings"][cond]
    m = P.condition_mask(c["start"], d["fileTimes"], s_idx[0], e_idx[0]) & (c["freq"] > 1 / 8)
    k = P.step_onset(c, m, 11, 13, hold_end=True)
    idx = np.nonzero(m)[0]
    near = idx[np.abs(c["temp"][idx] - 11) <= 1]
    if k is None or not len(near):
        return np.array([], int)
    jj = idx[(idx >= near[0]) & (idx < k)]
    return jj[~c["gap"][jj]]

def per_expt(reading, expts=EXPTS):
    rows = []
    for e in expts:
        d = A[e]
        for cond, lab in (("Saline", "S"), (CS.get(e, "Cs"), "C")):
            ii = first_hold_cycles(d, cond, reading)
            c = d["cycles"]
            r = {"expt": e, "cond": lab, "n": len(ii), "T_min": np.min(c["temp"][ii]) if len(ii) else np.nan, "T_max": np.max(c["temp"][ii]) if len(ii) else np.nan}
            for k in ("freq", "period", "pd_dur", "PD_OFF", "LP_ON", "LP_OFF", "PY_ON", "PY_OFF", "LP_duty"):
                r[k] = np.nanmean(c[k][ii]) if len(ii) else np.nan
            r["delay"] = np.nanmean((c["LP_ON"] - c["PD_OFF"])[ii]) if len(ii) else np.nan
            rows.append(r)
    return pd.DataFrame(rows).pivot(index="expt", columns="cond")

def slopes(reading):
    """(a) line through the six hold means against 11, 13, ..., 21; (b) through every cycle of the
    condition window against its temperature; (b_hold) through the cycles within 0.3 C of a target;
    (a_gaps) as (a) with the cycles left by the outlier removal kept, as the deposited code."""
    out = {}
    for e in EXPTS:
        d = A[e]; c = d["cycles"]
        for cond, lab in (("Saline", "S"), (CS[e], "C")):
            h = P.hold_means(d, cond, strict_cs=False, drop_gaps=reading != "a_gaps")
            s_idx, e_idx = d["Timings"][cond]
            win = P.condition_mask(c["start"], d["fileTimes"], s_idx[0], e_idx[0]) & (c["freq"] > 1 / 8) & ~c["gap"]
            for k in ("PD_OFF", "LP_ON", "LP_OFF", "PY_ON", "PY_OFF"):
                if reading in ("a", "a_gaps"):
                    y = h[k]; x = P.TARGETS.astype(float)
                else:
                    ii = np.concatenate([h["cycle_index"][int(T)] for T in P.TARGETS]) if reading == "b_hold" else np.nonzero(win)[0]

    s = pd.Series(out).unstack([1, 2])
    return s

How the analysis differs from the paper's. Everything is computed in Python from the deposited spike and temperature files with a port of the paper's deposited MATLAB code (burst detection, phase, cycle temperature, condition windows, the 1/8 Hz cycle filter, the jag measure); the per-experiment values agree with the deposited summary files to a few thousandths in most cases, not exactly. The cycles that the deposited outlier removal leaves spanning two bursts (1.6%) are left out of the hold means and phases, an assumption that brings the phases much closer to the deposited summaries and that the authors' own per-experiment phases support for the slopes of fig6a (their LP ON slope in Cs+ has adjusted p = 0.0004). Every claim built on hold means or phases prints the variant with them kept (the jag measure of fig3d,e and fig4d,e counts every cycle's frequency, which these cycles keep): it changes no outcome but fig6a-lp-advances-cs, whose LP ON slope then misses p < 0.01; matched-period-lp-earlier then holds under its reading (b) only. The 11 C values are from the first 11 C hold, which is every 11 C cycle of the deposited windows. Repeated-measures ANOVA and Tukey comparisons are computed here (two Tukey readings). The picrotoxin tests use the paper's six, which include the two preparations recorded in 981_035, and take their top hold (20.7 C) as the 21 C value, which the criterion's 0.3 C rule does not allow; the two-saline frequency test uses the deposited per-experiment table. The Cs+ + PTX example of fig2c is analysed on PD spikes detected on its intracellular trace. No step uses random draws.

What was found about the dataset. (1) VoltageClampData.mat holds only the first trial of each experiment, no Cs+ trial, while its ConditionsKey lists all of them: the Ih numbers cannot be recomputed. (2) Five of the six two-saline control experiments have no spike file; ControlTable holds their per-experiment values only, and says three of their second protocols were ramps. (3) 981_035 holds two PD spike trains (PD, PD2, not in the README) that do not burst together: two preparations recorded with one thermocouple, which the picrotoxin summaries enter as two experiments; nothing in the file says so. (4) Thermocouple dropouts (to -46.7 C) in three files, outside the analysis windows. (5) LPAdvanceSamePeriod.mat includes 969_120, which has no spike file, and the code that made it is not deposited. Spike times, temperature and the condition windows otherwise agree with the README, and the raw intracellular trace and temperature of 969_113 share the spike times' clock.

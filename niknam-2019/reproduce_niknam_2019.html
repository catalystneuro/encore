Niknam et al. (2019) on CRCNS mt-3¶

Paper: Niknam, Akbarian, Clark, Zamani, Noudoost and Nategh (2019), "Characterizing and dissociating multiple time-varying modulatory computations influencing neuronal activity", PLoS Comput Biol, doi:10.1371/journal.pcbi.1007275. The claims (claims/niknam-2019.yaml) were written from the version of record (PMC6759185), its figure legends and the legends of its supplement.

Dataset: CRCNS mt-3 (doi:10.6080/K0FB514J), mt-3/live/data.zip in the public bucket crcnsarchive, streamed and opened in place. CRCNS data sets are not versioned, so the version is recorded as unversioned (docs/archives.md). The bucket holds one copy of the data (live/, no old/), so there is no other version to choose; the data descriptor is version 0.6 of 2019-08-06, the only one, and describes these files. # Probe timing: runs of one code (probe durations) and gaps with no probe, over all trials of one
# neuron per session; the paper says each probe lasted 7 ms with exactly one probe on screen at a time.
run_len, gap_len, first_on, last_on, cycle_ok = collections.Counter(), collections.Counter(), [], [], []
for s in inv.session.unique():
    d = next(x for x in N if x["session"] == s)
    for row in d["stimcode"]:
        ch = np.flatnonzero(np.diff(row) != 0) + 1
        starts = np.r_[0, ch]; lens = np.diff(np.r_[starts, row.size]); vals = row[starts]
        on = np.flatnonzero(vals > 0)
        run_len.update(lens[on].tolist())
        inner = np.arange(on[0], on[-1] + 1)
        gap_len.update(lens[inner][vals[inner] == 0].tolist())
        first_on.append(starts[on[0]]); last_on.append(starts[on[-1]] + lens[on[-1]])
        seq = vals[on]
        # is the probe order a repeating 81-long cycle (each code once per 81 consecutive onsets)?
        cycle_ok.append(all(len(set(seq[i:i + 81])) == min(81, len(seq[i:i + 81])) for i in range(0, len(seq) - 81, 81)))
tot = sum(run_len.values())
print("probe run lengths (ms: share of runs):", {k: round(v / tot, 4) for k, v in sorted(run_len.items())})
print("gaps between probes inside the sequence (ms: count):", dict(sorted(gap_len.items())))
print(f"first probe at {np.min(first_on)}-{np.max(first_on)} ms, last probe ends at "
      f"{np.min(last_on)}-{np.max(last_on)} ms of the 3000 ms arrays")
print("trials whose onsets run in blocks of 81 distinct codes:", np.mean(cycle_ok).round(3))

Recorded perisaccadic effects (Figure 1)¶

Each neuron is classified by D2 under every reading of O1 (pairs: (a) trial, (b) condition, (c) unpaired rank-sum, a variant) and O2 (presentations: (i) onset, (ii) every ms, a variant). Two pairings outside O1, raised by the verifier, are shown as variants: a one-sided signed-rank test over the 1 ms bins of the response window, on the mean count per bin (timebin) and on the curves smoothed as for plots (timebin_smoothed). The Methods allow the first ("comparing the perisaccadic and fixation spike counts (during the same stimulus-aligned window)") and exclude the second ("all statistical analyses were performed on spike counts ... (not estimates of firing rate)"). Only (a) and (b) with onsets decide (column decides). Reading (a) cannot be tested: in no session does any trial show a probe in both the fixation and the perisaccadic window (data check, probe_in_both_windows), as a probe returns only after a pass through the whole order, 562 to 604 ms (median per session). The outcomes therefore rest on (b).

The normalized responses follow D3; O4 (a) is the mean over the effect window of the normalized response, averaged over neurons with SE across neurons, and O4 (b) the peak inside the window of the neuron-averaged curve smoothed with a Gaussian of FWHM 13 ms.

def population(names_sel, loc, peri, win, mode="onset"):
    """D3 normalized responses of the selected neurons; O4 a and b."""
    fs, ps = [], []
    for d in N:
        if d["name"] not in names_sel:
            continue
        F, P = mt3.mean_trains(d, PROBES[d["name"]][loc], peri, mode)
        f, p = mt3.normalized(F, P)
        fs.append(f); ps.append(p)
    fs, ps = np.array(fs), np.array(ps)
    if len(fs) == 0:
        return dict(n=0)
    wf = fs[:, win[0]:win[1] + 1].mean(1); wp = ps[:, win[0]:win[1] + 1].mean(1)
    sf, sp = mt3.gauss_smooth(fs.mean(0)), mt3.gauss_smooth(ps.mean(0))
    return dict(n=len(fs), fix_a=wf.mean(), fix_a_se=wf.std(ddof=1) / np.sqrt(len(wf)) if len(wf) > 1 else np.nan,
                peri_a=wp.mean(), peri_a_se=wp.std(ddof=1) / np.sqrt(len(wp)) if len(wp) > 1 else np.nan,
                fix_b=sf[win[0]:win[1] + 1].max(), peri_b=sp[win[0]:win[1] + 1].max(), curves=(fs, ps))


def within(v, e, tol):
    return abs(v - e) <= tol + 1e-9


def fig1_table(eff, loc, peri, win, expected, selector=None):
    rows = []
    for p, m in READINGS:
        row = dict(pairing=p, presentations=m, decides=(p, m) in DECIDES)
        if not TESTABLE[(p, m)]:
            row["count"] = "not testable"
            rows.append(row)
            continue
        sel = sig[(eff, p, m)] if selector is None else selector(p, m)
        names_sel = {d["name"] for d, s in zip(N, sel) if s}
        pop = population(names_sel, loc, peri, win, m)
        row["count"] = int(sel.sum())
        if pop["n"]:
            row.update(fix_a=pop["fix_a"], fix_a_se=pop["fix_a_se"], peri_a=pop["peri_a"], peri_a_se=pop["peri_a_se"],
                       fix_b=pop["fix_b"], peri_b=pop["peri_b"])
            row["in_tol_a"] = [within(row["count"], expected[0][0], expected[0][1]), within(row["fix_a"], *expected[1]),
                               within(row["peri_a"], *expected[2])]
        rows.append(row)
    return pd.DataFrame(rows)

How the analysis differs from the paper's. The Methods name a one-sided signed-rank test without saying what is paired. Pairing by trial (O1 a) is impossible in these data, because no trial shows the same probe in both windows, so the outcomes rest on pairing by condition (O1 b). Under that reading saccadic suppression matches the paper (8 neurons, 5 of them in the code's nuron_list) but FF- and ST-remapping are found in far fewer neurons (8 and 11 against 23 and 37). Variants the claims file does not let decide come closer: the unpaired test on every millisecond a probe is on gives 12, 17 and 31, and a signed-rank test over the 1 ms bins of the smoothed response curves, which the Methods exclude, gives 15, 19 and 34, agreeing with nuron_list on ST for 36 of 41 neurons. Whether the claims file should include a pairing over time bins is asked of a reader. The example neurons' fixation rates differ slightly from the paper's while their perisaccadic rates match, so the paper's fixation set also differs from -500 to -100 ms in a way not identified here. What was found about the dataset. The 41 files match the paper's 41 neurons and 11 sessions and the descriptor's per-session counts, and they are identical to the copies in the paper's code repository. Each recording appears once. The stimulus and saccade clocks hold: the RF response peaks at 58 ms after probe onset and disappears with codes shifted by 300 ms. Probes do not tile time as the paper says: about 91.5% of probe runs last 7 ms and 5.6% last 6 ms; most others last 14 or 21 ms, and a few 8 to 28 ms.

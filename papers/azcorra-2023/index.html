Most main findings held up in this data: Vglut2 and Calb1 axons rise after decelerations and respond to rewards and air puffs, Anxa1 axons rise after accelerations, ignore rewards and fall to air puffs, the subtypes cluster from these responses, and SNc somas track their axons. The locomotion recording counts did not reproduce (Anxa1 82 against 47), likely from exclusions the files do not record, so those findings used a larger set. Vglut2 deceleration timing and the DAT air puff response matched only in part, for unexplained reasons. The snRNA-seq clustering could not be tested without R software.

What the attempts found about the paper itself: a method or rule it does not give, a place where it disagrees with itself, published code that does something else. What they found about the data is on each dataset’s page.

  • Published code disagreesThe Methods integrate responses from +0.05 to +0.55 s minus -0.5 to 0 s; the code integrates 0 to +0.5 s minus -0.55 to -0.05 s.   • Published code disagreesThe 405 nm artifact detection marks everything from the last noisy section to the end of a recording and from the start to the first, which the Methods do not describe.

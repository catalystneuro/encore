None of the paper's main findings could be tested in this data: that light on the opsin HcKCR1 suppresses unit firing in human hippocampal slices across culture media and in closed loop, that kainic acid bursts show theta coherence and spread across the granule cell layer, and that waveform clusters over that layer are linked to an opto-response cluster. The dandiset holds raw voltage only, without the curated units these analyses rest on, the light times or labels for each recording's medium. Of the minor claims, the paper's network model, rerun from its code, reproduced the dampening of seizure-like events, and the cohort matches Table 1 except that no file records each slice's opsin.

    Results, Computational modeling of glutamatergic neuron inhibition; Extended Data Fig. 3; Methods, Simulation Prototype

    The model needs NEST 3.4 with a neuron compiled by NESTML 5 (Simulation/environment.yml at commit 6865bf6, printed in the notebook). PyPI has no NEST 3.4 (its releases are 3.9.0.post0.dev14 and 3.10.0), and with NEST 3.10.0 and NESTML 5.3.0, the newest 5.x, the script's first step, generate_nest_target on the published model, fails (module 'nest.ll_api' has no attribute 'sli_func'). The outcome verified in round 2 was blocked (not_runnable) on that basis. In the final revision, as the round-2 verifier asked, NEST 3.4 is taken from conda-forge in a throwaway environment made with micromamba 2.10.0, with NESTML 5.3.0 and the other packages of the environment file. The model then fails to build twice, first because odetoolbox, unpinned in the environment file, resolves to a release NESTML 5.3.0 cannot call (analysis() got an unexpected keyword argument 'simplify_expression'), and with odetoolbox 2.5 at cmake, because the conda-forge nest-config prints an empty compiler. With nest-config made to print the environment's compiler the model builds, and Simulation/simulation.py runs unchanged, printing mean rates of 80.65, 60.06, 52.49 and 49.65 Hz at opsin fractions 0, 0.10, 0.25 and 0.50 (closed-loop light 0, 16, 11 and 9 times). Events are runs of 1 ms bins with more than 100 spikes over the 1012 cells, the script's opto_threshold. At the script's seed, 20, (a) the total event duration is 278, 124, 37 and 4 ms, (b) the number of events 10, 10, 10 and 4, and (c) the spikes in events 52,366, 17,594, 4,086 and 441. Readings (a) and (c) meet the criterion and (b) does not. With seeds 21, 23 and 24 (a check, the script has one seed), (a) and (c) are at most 0.70 of their value at 0 at every fraction. Seed 22 does not meet the criterion under any reading; the network spends 1 ms above threshold at fraction 0, and at 0.50 the event duration is the same and the spikes in events are 103 against 101 at 0. The verdict uses the script's seed. Reproduced was proposed in the final revision and the round-3 verifier agreed.

    How the test differed from the paper’s method

    • The model is run in an environment built from conda-forge with micromamba, outside the entry's locked pip environment, in a throwaway directory. Besides the environment file's packages it holds cmake 3, a C++ compiler and make from conda-forge, which NESTML 5 needs to build the module, and braingeneers is pinned to 0.3.1.16 (unpinned in the environment file).
    • odetoolbox, which the environment file leaves unpinned, is set to 2.5 (October 2022, the release current when NESTML 5.2.0, the version the README cites, came out); the newest release fails with NESTML 5.3.0 in the notebook.
    • The conda-forge nest-config of NEST 3.4 prints an empty --compiler, which leaves the generated CMakeLists without a C++ compiler; it is changed to print the environment's compiler. The model and the script are not changed.
    • The script is run once as published (seed 20), and its sim() again with seeds 21 to 24, a check the paper does not make.

Reproduction Optogenetic inhibition in human hippocampal slices on HD-MEAs (Andrews, Geng, Voitiuk et al. 2024)

Tests the findings of Andrews, Geng, Voitiuk et al. (2024) on dandiset 001132, which holds 69 raw HD-MEA voltage recordings of 12 human hippocampal slices from 7 patients. The files hold no sorted units, light events or condition labels, so only the cohort claim is tested; the notebook surveys every recording, recovers light periods of slices 3C, 4C and 7D from the voltage, shows a threshold-crossing variant for those of 3C, and runs the paper's network model. Method differences

How the tests differed from the paper’s method or data, and the claims each applies to.

  • Assumed reading of the criterion's partial clause. "Present and identifiable" is read as present and identifiable by name, the slice names of the files matching those of Table 1 and Table 2, as no file or metadata field names a slice's opsin. Under a reading that requires each HcKCR1 slice to be identified as HcKCR1 from the dandiset itself, neither clause of the criterion holds.table1-cohort
  • Slices and patients are taken from the file and subject names (`3C-7` is recording 7 of slice 3C of patient C); `subject_id` itself names the recording, not the patient or slice.table1-cohort
  • The model is run in an environment built from conda-forge with micromamba, outside the entry's locked pip environment, in a throwaway directory. Besides the environment file's packages it holds cmake 3, a C++ compiler and make from conda-forge, which NESTML 5 needs to build the module, and braingeneers is pinned to 0.3.1.16 (unpinned in the environment file).simulation-dampening
  • odetoolbox, which the environment file leaves unpinned, is set to 2.5 (October 2022, the release current when NESTML 5.2.0, the version the README cites, came out); the newest release fails with NESTML 5.3.0 in the notebook.simulation-dampening
  • The conda-forge nest-config of NEST 3.4 prints an empty --compiler, which leaves the generated CMakeLists without a C++ compiler; it is changed to print the environment's compiler. The model and the script are not changed.simulation-dampening
  • The script is run once as published (seed 20), and its sim() again with seeds 21 to 24, a check the paper does not make.simulation-dampening

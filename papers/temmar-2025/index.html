Most of the paper's main findings held up in this data: signal power, active channel count and dimensionality decline over the years, most channels keep their tuning, same-day decoding stays stable with the LSTM ahead of ridge regression, cross-day accuracy drops sharply then levels off, and multi-day training softens the early drop. Population drift held up only in part. The text's tuning by array came out reversed with the files' array labels, though it matches the paper's own figure panels. The long-term decay fits failed, likely because only 12 of 283 starting sessions could be run, and daily fine-tuning was too costly to test. One supplementary slope came out with the opposite sign.

Notes on the paper

What the attempts found about the paper itself: a method or rule it does not give, a place where it disagrees with itself, published code that does something else. What they found about the data is on each dataset’s page.

  • Paper inconsistentThe supplement gives the inactive channels' SBP slope as +0.54e-3 while Section 4.1 says all categories decreased; the data give -0.536e-3, the same size with the main text's sign.
  • Paper inconsistentOn these data the paper's statements about the two arrays cannot both hold. With the files' array labels, which agree with Figure S1's example (channel 47 medial, row 5, column 5), the lateral bank has the lowest SBP and the shallowest slope, as Appendix C.2 and Figure S4 say, but medial channels are tuned to extension of both fingers and lateral channels to flexion, the reverse of Section 4.2. With the labels swapped the tuning would match and the SBP result would not. Either the tuning description names the arrays the other way round, or its angles use another sign.
  • Published code disagreesIn bci_decoding/nn_utils.py, train_model calls add_training_noise(inputs, noise_neural_std, noise_bias_std), whose parameters are (x, bias_neural_std, noise_neural_std), so the code adds a bias of SD 0.1 and white noise of SD 0.2, the reverse of Appendix C.1 (noise 0.1, bias 0.2).

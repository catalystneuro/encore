Pseudopopulation trials¶

Methods: the trials are the full rotations before and after each rest that separates light-on from light-off; each trial is resampled to 200 bins and trials are aligned across recordings into pseudopopulations. Here, in each recording, the last 5 light-on trials before and the first 5 light-off trials after each of the three light-to-dark transitions of a 7550-frame recording (15 trials each; HeadingDecoder takes up to 15 a side). The 1950-frame recordings have one transition and some have fewer than 5 trials a side, so they are left out (their cells are counted below). Each trial is resampled to 200 bins on its heading (bins every 1.8 degrees from -180 to 180) in place of time, so that bin k is the same heading in every recording; at the motor's constant speed the two differ only by speed fluctuations (a standard choice). Trial k of each recording is put with trial k of the others.

grid = -180 + (np.arange(N_RS) + 0.5) * 360 / N_RS

def resample(act, h, seg):
    hu = np.rad2deg(np.unwrap(np.deg2rad(h[seg])))
    sgn = 1 if hu[-1] >= hu[0] else -1
    hu = sgn * hu
    target = hu[0] + np.mod(sgn * grid - hu[0], 360)
    return np.stack([np.interp(target, hu, act[seg][:, n]) for n in range(act.shape[1])], 1)

def trials_around(i):
    r = recs[i]
    L, D = r["blocks"]
    on, off = [], []
    for bl, bd in zip(L, D):
        sl = [s for s in r["seg_l"] if s[0] >= bl[0] and s[-1] <= bl[-1]]
        sd = [s for s in r["seg_d"] if s[0] >= bd[0] and s[-1] <= bd[-1]]
        if len(sl) < K or len(sd) < K:
            return None
        on += sl[-K:]; off += sd[:K]
    return on, off

Decoders¶

  • (a) Naive Bayes (Etter et al. 2020): activity binarized (spikes: above 0; dF/F: above its mean plus 2 SD over the recording's trials, a standard choice), P(active | heading state) per cell for 60 states of 6 degrees from the even bins of every trial, with a +1/+2 prior; the odd bins are decoded as the state of maximum summed log-likelihood.
  • (b) HeadingDecoder: for each trial, each cell's tuning curve (60 bins) from the other trials of the same condition, rescaled 0 to 1; the heading distribution is activity times tuning weights, normalized, filtered over 10 samples (temporalFilter); the maximum is taken. Activity below 0 (dF/F) is set to 0, as the product needs non-negative weights.

Accuracy per trial: the share of decoded bins within 18 degrees of the true heading. Each bootstrap iteration samples 332 cells with replacement from the group (all tuned cells: all three classes, so in their proportions); 1000 iterations; mean and 2.5 and 97.5 percentiles over iterations. p of light-on against light-off is one minus the share of iterations in which a t-test over trials gives p < 0.05 ((a) paired, (b) unpaired). Errors at 180 degrees: the share of light-on bins with an error of 162 degrees or more. Chance is computed with each decoder by decoding with each cell's test activity circularly shifted along the trial by its own random amount (the tuning to heading is broken, the activity kept).

NS = 60
state = np.clip(((grid + 180) // 6).astype(int), 0, NS - 1)
centres = -177 + 6 * np.arange(NS)

def err_deg(dec, true):
    return np.abs((dec - true + 180) % 360 - 180)

def prep_bayes(A, inp):
    """Log-likelihood weights from the even bins; binarized odd bins to decode."""
    n = A.shape[2]
    flat = A.reshape(-1, n)
    th = np.zeros(n) if inp == "sp" else flat.mean(0) + 2 * flat.std(0)
    B = (A > th).astype(np.float32)
    tr, te = B[:, 0::2], B[:, 1::2]
    s_tr = state[0::2]
    p = np.stack([(tr[:, s_tr == s].sum((0, 1)) + 1) / (tr[:, s_tr == s].shape[0] * tr[:, s_tr == s].shape[1] + 2)
                  for s in range(NS)], 1)
    return dict(kind="bayes", W=(np.log(p) - np.log(1 - p)).astype(np.float32), B=np.log(1 - p).astype(np.float32),
                X=te, true=grid[1::2])

def prep_hd(A, inp):
    """Leave-one-trial-out tuning weights per trial (trials x cells x 60), rescaled 0 to 1 per cell."""
    A = np.clip(A, 0, None)
    S = np.stack([A[:, state == s].mean(1) for s in range(NS)], 2)
    loo = (S.sum(0)[None] - S) / (A.shape[0] - 1)
    lo = loo.min(2, keepdims=True); rg = loo.max(2, keepdims=True) - lo
    W = np.where(rg > 0, (loo - lo) / np.where(rg > 0, rg, 1), 0)
    return dict(kind="hd", W=W.astype(np.float32), X=A.astype(np.float32), true=grid)

def temporal_filter(P, w=10):
    """HeadingDecoder.temporalFilter: product of (1 + p) over a window of w samples, renormalized."""
    Lg = np.log1p(P)
    c = np.concatenate([np.zeros_like(Lg[:, :1]), np.cumsum(Lg, 1)], 1)
    F = P.shape[1]; i = np.arange(F)
    a, b = np.clip(i - w // 2, 0, F), np.clip(i + w // 2, 0, F)
    out = np.expm1(c[:, b] - c[:, a])
    return out / out.sum(2, keepdims=True)

def decode(Pp, idx, X=None):
    X = Pp["X"] if X is None else X
    if Pp["kind"] == "bayes":
        sc = X[:, :, idx] @ Pp["W"][idx] + Pp["B"][idx].sum(0)
    else:
        sc = np.matmul(X[:, :, idx], Pp["W"][:, idx])
        tot = sc.sum(2, keepdims=True)
        sc = temporal_filter(np.where(tot > 0, sc / np.where(tot > 0, tot, 1), 1 / NS))
    return err_deg(centres[sc.argmax(2)], Pp["true"][None])

Checks of the decoders (asked for in verification)¶

Three checks bear on the choice of decoder reading.

  1. Both decoders as written here are run on synthetic cells whose tuning is known, with as many trials and bins as the real pseudopopulation, and the HeadingDecoder is also run on the real data without its temporal filter. If the reimplementation works, it decodes the synthetic cells well, and its low accuracy on the real cells comes from the data or from the reading, not from a coding error.
  2. The resampled heading bins are 1.8 degrees apart and each is interpolated from the two nearest frames, so neighbouring even (training) and odd (test) bins share frames. The paper does the same: it resamples each trial to 200 bins and then splits "even and odd timepoints for training and testing" (Methods, Decoding RSC somatic activity, "Preprocessing and alignment" and "Decoding strategy"), so reading (a) follows the paper. Variant (a') trains the naive Bayes decoder on the even trials and tests it on the odd trials, so that no frame and no trial is in both.
  3. Variant (a'') keeps the paper's split of even and odd time points but removes the interpolation: each trial is cut into 100 heading bins of 3.6 degrees, each holding the one frame nearest to it, so the even and odd bins hold different frames (the share they still share is printed). Neighbouring frames remain correlated through the calcium dynamics, as in any split of time points within a trial.

Both variants use the same bootstrap and enter every claim's table below as further readings of (a).

def prep_bayes_general(A, inp, st, true, split):
    n = A.shape[2]
    flat = A.reshape(-1, n)
    th = np.zeros(n) if inp == "sp" else flat.mean(0) + 2 * flat.std(0)
    B = (A > th).astype(np.float32)
    if split == "trials":
        tr, te, s_tr, true_te = B[0::2], B[1::2], st, true
    else:
        tr, te, s_tr, true_te = B[:, 0::2], B[:, 1::2], st[0::2], true[1::2]

Reading (a) is still the one the Methods describe (resampling to 200 bins, then even and odd time points), and it is the reading on which the Bayes outcomes below rest. How the analysis differs from the paper's: the classes are those of somata.ipynb, not the paper's; spikes and dF/F are computed from raw fluorescence without neuropil correction; only the 7550-frame recordings with 5 trials on each side of every transition enter the pseudopopulations; trials are resampled on heading, not time; the naive Bayes decoder is written here after Etter et al. (2020), with a binarization threshold that is a standard choice; the HeadingDecoder is reimplemented in numpy. The accuracies of the naive Bayes decoder depend heavily on test bins sharing frames with training bins, as the paper's own resampling and split of time points do; two variants without shared frames are shown.

What was found about the dataset: the files do not mark light-on and light-off; the segments are the code's hard-coded ones.

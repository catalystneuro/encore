Reproducing Dvali et al. (2025) from dandiset 001075¶

Paper. Dvali S, Seguin C, Betzel R, Leifer AM (2025). Diverging network architecture of the C. elegans connectome and signaling network. doi:10.1103/6wgv-b9m6. The claims file was written from the full text supplied with the attempt (its body is the arXiv preprint 2412.14498v2, with Methods and Extended Data), and from the paper's code (FunconnNetworkAnalysis, commit 35e87ca).

Dandiset. DANDI:001075, version 0.240920.1434, the version the paper cites (Methods, The Networks; reference 88). The paper reuses the signal propagation atlas of Randi et al. (2023). One later version exists, 0.240930.1859. It holds the same 223 files, and its 110 segmentation files differ: they add target_pumpprobe_id, the ROI that each stimulation targeted, and split the green and red signals into a series with missing frames as NaN and an interpolated one. The cited version does not say which ROI was stimulated, so the stimulated-ROI identities, and only they, are read from 0.240930.1859 (listed under inputs in the record). The data check below shows the difference.

What the dandiset holds and what it does not. Per recording, the calcium signal of every segmented ROI, the NeuroPAL labels, and the stimulation times and targets, for 110 recordings of wild-type animals. It does not hold the signaling network itself, nor the q-values that define it, nor the control recordings without stimulation that Randi et al.'s code uses to compute the q-values (pumpprobe Funatlas.get_ctrl_distributions). Reading (a) of the claims file (recompute the q-values from the dandiset) therefore cannot be run, and the signaling network is taken under reading (b), from the wild-type atlas released with Randi et al. 2023 (worm-functional-connectivity, commit 81af01c), whose entries are NaN where q > 0.05. A link claim (atlas-dataset-link) tests that this atlas matches the dandiset's recordings. The atlas holds no q-values, so the networks at q < 0.01 and q <= 0.18 cannot be built.

Outside inputs. The anatomical network comes from the four EM datasets that Randi et al.'s code combines (White 1986 adult and L4, Witvliet 2021 datasets 7 and 8), as stored in pumpprobe at commit 1dbc5e0. Neuron classes and roles are the lists in the paper's code (compared with its source in the data check).

Software. The stochastic block model of the paper runs in graph-tool, which has no PyPI distribution and cannot be installed in the entry's locked environment; every claim on communities is blocked as not_runnable (PyPI holds no files for graph-tool; data check). The paper prints the first-level memberships of both networks (Tables 1 and 2), but they are the output of the model that cannot be run, so they are not typed in here as an input: the entry computes every result from the data. The rich club null uses a degree-preserving rewiring written here in place of graph-tool's random_rewire.

Random seeds. Each claim's generator is seeded with zlib.crc32(b"dvali-2025/<claim id>"); results that depend on random draws are also given under the seed plus 1000, 2000, 3000 and 4000.

def swapping_edges(G, nswap=1, max_tries=2000, seed=None):
    n = 0
    swapcount = 0
    keys, degrees = zip(*G.degree())  # keys, degree
    cdf = nx.utils.cumulative_distribution(degrees)  # cdf of degree
    discrete_sequence = nx.utils.discrete_sequence
    while swapcount < nswap:
        #        if random.random() < 0.5: continue # trick to avoid periodicities?
        # pick two random edges without creating edge list
        # choose source node indices from discrete distribution
        (ui, xi) = discrete_sequence(2, cdistribution=cdf, seed=seed)
        random.seed(seed)
        if ui == xi:
            continue  # same source, skip
        u = keys[ui]  # convert index to label
        x = keys[xi]
        # choose target uniformly from neighbors
        if list(G[u]) and list(G[x]):
           v = random.choice(list(G[u]))
           y = random.choice(list(G[x]))
        else:
           continue

        if v == y:
            continue  # same target, skip
        if (y not in G[u]) and (v not in G[x]):  # don't create parallel edges
            G.add_edge(u, y)
            G.add_edge(x, v)
            G.remove_edge(u, v)
            G.remove_edge(x, y)
            swapcount += 1
        if n >= max_tries:
            #e = (
            #    f"Maximum number of swap attempts ({n}) exceeded "
            #    f"before desired swaps achieved ({nswap})."
            #)
            print("Maximum number of swap attempts exceeded before desired swaps achieved.)")
            print(str(swapcount)+" swaps done")
            #raise nx.NetworkXAlgorithmError(e)
            return G
        n += 1
    return G
--- the port in the helper:
def swapping_edges(a: np.ndarray, rng: np.random.Generator, nswap: int = 2000,
                   max_tries: int = 4000) -> tuple[np.ndarray, int]:
    """Port of `swapping_edges` in SIM_doubleedge.py: x->y and a->b become x->b and a->y.

    Sources are drawn with probability proportional to total degree, targets uniformly among
    each source's successors; a swap that would create a parallel edge is skipped. As in the
    code, self-loops are not prevented, and draws that end in `continue` there (the same
    source twice, a source without successors, the same target) do not count towards
    `max_tries`; the code stops once its counter reaches `max_tries`. The code calls it with
    nswap=2000, max_tries=4000 for the signaling network and nswap=6000, max_tries=9000 for
    the anatomical one (SIM_doubleedge.py lines 237 and 493). Returns the swapped adjacency
    and the number of swaps made.
    """
    succ = [np.nonzero(a[i])[0].tolist() for i in range(a.shape[0])]
    succ_set = [set(x) for x in succ]
    deg = total_degree(a).astype(float)
    p = deg / deg.sum()
    swaps = 0
    n = 0
    chunk = 4096
    pairs = rng.choice(len(deg), size=(chunk, 2), p=p)
    picks = rng.random((chunk, 2))
    j = 0
    while swaps < nswap:
        if j == chunk:
            pairs = rng.choice(len(deg), size=(chunk, 2), p=p)
            picks = rng.random((chunk, 2))
            j = 0
        ui, xi = pairs[j]
        pv, py = picks[j]
        j += 1
        if ui == xi or not succ[ui] or not succ[xi]:
            continue
        vi = int(pv * len(succ[ui]))
        yi = int(py * len(succ[xi]))
        v, y = succ[ui][vi], succ[xi][yi]
        if v == y:
            continue
        if y not in succ_set[ui] and v not in succ_set[xi]:
            succ[ui][vi], succ[xi][yi] = y, v
            succ_set[ui].discard(v)
            succ_set[ui].add(y)
            succ_set[xi].discard(y)
            succ_set[xi].add(v)
            swaps += 1
        if n >= max_tries:
            break
        n += 1
    out = np.zeros_like(a)
    for i, t in enumerate(succ):
        out[i, t] = 1
    return out, swaps

Degree is in-degree plus out-degree; phi(k) over nodes of degree > k (richclub.py), normalized by its mean over 1000 degree-preserving rewired networks (Methods); the first 100 (legend) and 500 (code) of the same draws are variants. def local_maxima(x):
    out = []
    for k in range(1, len(x) - 1):
        if not np.isfinite(x[k]) or x[k] == x[k - 1]:
            continue
        nb = x[max(0, k - 2):k + 3]
        if x[k] >= np.nanmax([x[k - 1], x[k + 1]]) and np.nanmin(nb) < x[k]:
            # walk over a plateau to its end before comparing with the next distinct value
            e = k
            while e + 1 < len(x) and x[e + 1] == x[k]:
                e += 1
            if e + 1 >= len(x) or not np.isfinite(x[e + 1]) or x[e + 1] < x[k]:
                out.append(k)
    return out

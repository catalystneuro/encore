Masset et al. (2025): VR task, population (DANDI:000251)¶

Paper. Masset P, Tano P, Kim HR, Malik AN, Pouget A, Uchida N (2025). Multi-timescale reinforcement learning in the brain. Nature 642:682-690. doi:10.1038/s41586-025-08929-9. The claims file (claims/masset-2025.yaml) was written from the accepted author manuscript in PubMed Central (main text, legends, Methods and Extended Data legends), with the paper's Mendeley code (doi:10.17632/tc43t3s7c5.1) and simulation code (github.com/pablotano8/multi_timescale_RL at 37f11c6).

Data. DANDI:000251, version draft, modified 2023-06-20T00:56:22Z. The dandiset has no published version, so the draft is the only version there is; it is pinned by its modification time, which the notebook checks. It holds the data of Kim et al. (2020), which the paper reuses: the VR task single units, one unit per file, and no cued delay task recordings. The cued delay units are in the paper's own deposit, Mendeley Data doi:10.17632/tc43t3s7c5.1 (version 1, 2025-04-09), file DA_SU_ODOR_NEW_W_OL.h5; its FinalAverageArray.mat (the paper's per-neuron table) and Valid_S.mat (the paper's neuron flags) link the two tasks' units. All files are streamed into memory.

Seeds. Random draws use each claim's seed, zlib.crc32(b"masset-2025/<claim id>"), and four more (plus 1000 to 4000); a second generator of a claim adds 1. Shared computations use the seed of the claim that defines them: the VR half splits that of fig3b-vr-ramp-population, the VR fit's initial values that of fig3-common-value-fit, the cued delay fits that of cued-delay-neurons.

The entry has four notebooks: vr_population.ipynb (VR claims on the population), vr_single_mouse.ipynb (single-mouse VR fits), vr_reward_expectation.ipynb (the common reward expectation model), cued_delay_and_cross_task.ipynb (link, cued delay and cross-task claims). The claims each one tests are listed below.

This notebook. Tested: fig3b-vr-ramp-population, fig3-common-value-fit, ed8b-slope-correlates-with-discount, ed7c-discount-not-related-to-ml-position, ed7de-gain-baseline-not-related-to-ml-position, ed8cd-vr-licking-not-related-to-discount. The other claims are in the other three notebooks (ed9g-models-agree in vr_reward_expectation.ipynb), or blocked (the four simulation claims; see the summary).

def contrast(spike_list, align_list, shift):
    out = []
    for s, a in zip(spike_list, align_list):
        a = a[np.isfinite(a)] + shift
        post = ms.counts_aligned(s, a, 0, 0.5, 0.5)[0][:, 0].mean() / 0.5
        pre = ms.counts_aligned(s, a, -0.5, 0, 0.5)[0][:, 0].mean() / 0.5
        out.append(post - pre)
    return np.array(out)

for shift in (0.0, 5.0, -5.0):

VR task (DANDI:000251)¶

Neurons as M6: the open-loop units with a mean rate above 2 spikes/s over 3.05 to 7.35 s after scene motion onset (all trials) and ML below 900 um. Each unit's trials are split at random in halves 100 times; each half gives a PSTH of 43 bins of 0.1 s. The common value model (M7) is fitted to each half (200 fits). This is run under the claims' seeds and four more; the sections below use the first and give the range over the five.

def slope_stats(sl):
    m = sl.mean(0)
    p = stats.ttest_1samp(sl, 0).pvalue
    return dict(n=sl.shape[1], mean=m.mean(), p=stats.ttest_1samp(m, 0).pvalue,
                pos=int(((p < 0.05) & (m > 0)).sum()), neg=int(((p < 0.05) & (m < 0)).sum()),
                ns=int((p >= 0.05).sum()))

def cv_summary(fits):
    g = fits["gamma"].mean(0)
    V = fits["V"].mean(0)
    d2 = np.diff(V, 2)
    chord = np.linspace(V[0], V[-1], len(V))
    return dict(mean=g.mean(), sd=g.std(ddof=1), p20=np.percentile(g, 20), p70=np.percentile(g, 70),
                p90=np.percentile(g, 90), frac_d2_pos=(d2 > 0).mean(),

Differences from the paper's method. The common value model is fitted with L-BFGS-B over the discount factors and the value function, with the gains and baselines solved exactly at each step, capped at 10,000 iterations, where the code uses fmincon (interior point, 2000 iterations); few fits reach the tolerance, and the variant shows that the cap moves the result. Half splits are disjoint (the code's halves share one trial when the trial count is odd). PSTHs are spike counts in 0.1 s bins from 3.05 to 7.35 s after scene motion onset; the code averages 10 ms rates in 43 slightly overlapping bins ending at the mean reward time. The VR licking windows are taken before each trial's reward (Methods); the code's windows, aligned on scene motion, are a variant.

The dataset. 78 open-loop units are deposited twice (SU-VR-OL and SU-VR-ALL-OL files with identical spike trains) under different identifiers and session IDs; only the subject and start time, which distinct units of one session also share, are the same, and one SU-VR-OL file of mouse 3015 holds a teleport session (the same unit as an SU-VR-ALL-TP file). The files carry no optogenetic identification flag and no description of the units. The reward comes a median 7.31 s after scene motion onset (7.35 s in the paper). The dandiset has no published version.

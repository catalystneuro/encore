Reproducing Gu et al. (2026) from dandiset 001836¶

Paper. Gu S, Liu C, Gillespie AK, Nevers R, Denovellis EL, Coulter ME, Kay K, Frank LM (2026). Naturalistic behavior and self-generated neural activity predictive of self-correction. bioRxiv, doi:10.64898/2026.05.26.727951. The claims file (claims/001836/10.64898-2026.05.26.727951.yaml) was written from the bioRxiv preprint, version 1 (May 27, 2026), with its supplement (Materials and Methods, Figures S1 to S12).

Dandiset. DANDI:001836, version 0.261030.0428. The paper cites the dandiset without a version. Two versions are published, 0.260526.1804 and 0.261030.0428; the cell below shows that they hold the same 2494 assets with the same blobs, so they differ only in metadata. The most recent one is pinned, as the protocol asks when the paper cites none.

What is tested. The dandiset holds the raw recordings (30 kHz voltage, inertial sensors, LED tracking, well pokes and pumps, Statescript logs), a 1 kHz LFP file per day, and Spyglass analysis files: head position, linearized position, and decodes triggered on events. The scratch/triggered tables carry no description; they are identified here by aligning their trigger times with this entry's COM times and outer pokes, and read with the paper's code (Gu2026 at commit 0f0c9a7), which wrote them. They hold the decoder's MAP position in windows around COM times and outer pokes, which is what the Figure 3 claims use. The dandiset does not hold the decoder's posterior over whole sessions, its state probabilities, the remote or local extended events, theta cycles or ripples. The behavioral claims (Figure 1, Figure S1F) and the Figure 3 claims are tested, and so is the SWR claim (Figure S7B), with ripples detected on the deposited LFP. The other claims on hippocampal content need the decoder output over every COM event, which would have to be recomputed from the raw voltage (12.5 TB of raw files), and are blocked.

def add_correct_arm(df):
    """Correct arm of each trial: the cycle's next arm after the last rewarded arm of the session."""
    out = np.full(len(df), np.nan)
    for _, g in df.groupby(["rat", "day", "epoch"], sort=False):
        last = None
        for i, (rat, fin, rew) in zip(g.index, zip(g.rat, g.final, g.rewarded)):
            if last is not None:
                out[i] = seqs[rat][last]
            if rew:
                last = int(fin)
    df["correct_arm"] = out
    return df

def run_through(df, label, seed):
    rng = np.random.default_rng(seed)
    sessions = [(k, g.reset_index()) for k, g in df.groupby(["rat", "day", "epoch"], sort=True)]
    pvals = {r: [] for r in RATS}
    diffs = {r: [] for r in RATS}
    no_ctrl = 0
    for draw in range(100):
        rows = []
        for (rat, day, ep), g in sessions:
            if not g.com.any():
                continue
            ctrl = ct.nearby_control(g, rng)
            comrows = g[g.com]
            for (_, cr), j in zip(comrows.iterrows(), ctrl):
                rows.append({"rat": rat, "dayidx": cr.dayidx, "com_rew": float(cr.rewarded),

def sign_p(x, ref):
    x = np.asarray(x)
    above, below = int((x > ref).sum()), int((x < ref).sum())
    return stats.binomtest(above, above + below, 0.5).pvalue if above + below else np.nan, above, below

The triggered decode tables (Figure 3)¶

The paper's code (Gu2026, commit 0f0c9a7, changeOfMind_triggered_position.py and changeOfMind_triggered.py) writes these tables: per row, a window of the linearized head position and of the decoded position, with triggered_trial_info = (trial, arm). Which parameters made each file (trigger, window, decoder, MAP or mean) is kept in the lab's database and not in the file. The cells below identify each file by aligning its trigger times with this entry's COM times (both thresholds) and outer pokes, by its window, and by whether its positions are relative to the trigger (a table restricted to the COM arm, where the code sets the decode to NaN when 0.2 or less of the posterior is in the arm). The arm regions on the linearization are the code's (loc1d_to_baseoff), checked against the deposited linearization. Two further cells look at the tables that match neither trigger ("other"), and at which decoder made which table, from how often two tables that share samples have the same decode.

def ols_pinv(y, X, rcond=1e-10):
    """OLS by pseudo-inverse, as statsmodels does it, with an explicit cutoff for the singular values so that
    the exact collinearity is always removed (statsmodels' default cutoff left it in some of these fits)."""
    Xv, yv = X.values.astype(float), y.values.astype(float)
    beta = np.linalg.pinv(Xv, rcond=rcond) @ yv
    rank = np.linalg.matrix_rank(Xv, tol=rcond * np.linalg.svd(Xv, compute_uv=False)[0])
    df = len(yv) - rank
    cov = (np.sum((yv - Xv @ beta) ** 2) / df) * np.linalg.pinv(Xv.T @ Xv, rcond=rcond)
    t = beta / np.sqrt(np.diag(cov))

How the analysis differs from the paper's. Trials are built from the digital poke and pump events, and agree with the Statescript logs to within one trial per session. COM trials are detected on the deposited 500 Hz linearization with the Methods' rule; both thresholds of the claims file are run (10 cm and 0.1 of the 96 cm arm) and give the same outcomes for every claim but the counts. The closing structure of the reversal detection is a standard choice. The per-rat sequence is read from the reward log. Each rat's peak day is its last day in the dandiset. The Figure 3 claims are tested on the paper's own triggered tables, identified by their trigger times. The whole-track tables come in pairs from two decoders; the files do not name them, but one (A) made every arm-restricted table, and the code takes a figure's COM and control decodes from one decoder, so A is assumed for fig3d. The control arm ranges are a random draw, as in the code, and the Figure 3B and 3D results are shown over 20 further draws; fig3b-extended and fig3d sit at the edge of a bar and change with the draw. SWRs are detected on the deposited LFP with the Methods' parameters, using every tetrode in the LFP file (no locations are given), with and without subtracting the reference channel, and a session baseline sampled from 20 windows per epoch; rat M's fifth day has no LFP file, so its 64 windows are dropped.

What was found about the dataset. The dandiset holds fewer trials than the paper reports for rats M (5 days against 6 in the paper), K and L. Rat M's 500 Hz linearizations are each deposited twice, as identical copies, its Statescript logs are named "syayescript", and it has 4 LFP files for 5 days. The electrode table has no locations. The decoder's posterior and the events the other neural claims rest on are not deposited. The reward log gives the sequence 3-4-2-1-3 for M, E and J and 1-2-4-3-1 for K and L, against Figure S1E's labels.

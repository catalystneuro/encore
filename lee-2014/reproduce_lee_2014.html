Dataset. CRCNS hc-10, Lee, Krook-Magnuson, Bezaire & Soltesz (2016), Intracellular, in vitro somatic membrane potential recordings from whole cell patch clamped rodent hippocampal CA1 neurons, doi:10.6080/K00P0WXQ, streamed from https://crcnsarchive.s3-us-west-2.amazonaws.com/hc-10/live/Soltesz_data.zip.

Version. CRCNS data sets are not versioned, and the paper cites no version (it predates the data set). There is one published copy, under hc-10/live/; hc-10/old/ holds only an older description (CRCNSAxoFiles.pdf). The entry pins crcns:hc-10/unversioned and identifies the files by the MD5 sums of the data set's checksums.md5: Soltesz_data.zip 99bc6c87c503c724a1e692f520e25162 (checked below while streaming), described by docs/crcns_hc-10_data_description.pdf 75bb0f47568161037e46965f77f952c0 (version 0.7, 2 December 2016).

Claims. claims/crcns-hc-10/10.1016-j.neuron.2014.03.034.yaml, written from the version of record with its Supplemental Information. The data set holds, for this paper, the current-step sweeps of 8 superficial and 9 deep CA1 pyramidal cells (PCs) and 6 PV+ basket cells (PVBCs); its other cells belong to other papers. Only the six claims on these recordings can be tested.

Counts match the descriptor and the paper (sPC n = 8, dPC n = 9, Figure S1 legend), and each file has one sweep per step of the descriptor's range (20 for the PCs, -400 to +550 pA; 13 to 23 for the PVBCs). Every column is a voltage in mV; no file has a current column, so the step levels come from the descriptor alone. Sampling is 0.1 ms (10 kHz, as the Methods state). Each sweep lasts 2 s; the step starts at 0.5315 s and lasts 1.000 s in every cell, as the Supplemental Experimental Procedures 2B ("1s-long step currents") and the descriptor ("about half a second into the recording") say. Voltages range from -140 to +54 mV, as expected of a somatic recording in mV. The ATF header holds the acquisition mode, the display range, the start time of each sweep (SweepStartTimesMS, one sweep every 5 s in every cell) and the signal name. It gives no step onset, amplitude or holding current, so the onset is found from the voltage.

The files have no trial table and only the voltage stream, so the check of the step labels is made on the voltage itself: if sweep k carries the k-th step of the descriptor's range, the steady-state deflection rises with k, is near 0 for the 0 pA sweep, and changes sign there.

def paper_rule(x, y, paired=False):
    # Statistical Analysis: t test unless a group fails Shapiro-Wilk, then the rank test.
    normal = stats.shapiro(x).pvalue >= 0.05 and stats.shapiro(y).pvalue >= 0.05
    if paired:
        return ("paired t", stats.ttest_rel(x, y).pvalue) if normal else ("Wilcoxon", stats.wilcoxon(x, y).pvalue)
    return ("t", stats.ttest_ind(x, y).pvalue) if normal else ("Mann-Whitney", stats.mannwhitneyu(x, y).pvalue)

def cohen_d(x, y):
    sp = np.sqrt(((len(x) - 1) * np.var(x, ddof=1) + (len(y) - 1) * np.var(y, ddof=1)) / (len(x) + len(y) - 2))
    return (np.mean(x) - np.mean(y)) / sp

Reproducing Nair et al. (2018) from CRCNS data set bf-1¶

Paper. Nair J, Klaassen A-L, Arato J, Vyssotski AL, Harvey M, Rainer G (2018). Basal forebrain contributes to default mode network regulation. PNAS 115:1352-1357. doi:10.1073/pnas.1712431115. The claims file was written from the version of record and its supplement (SI Results, SI Materials and Methods, legends of Figs. S1 to S7).

Data set. CRCNS bf-1, "Basal forebrain LFP recordings from rats in home cage and during arena exploration", doi:10.6080/K0MK6B2Q, read from the public bucket crcnsarchive under bf-1/live/. Version: unversioned. CRCNS data sets have no versions; the paper cites the data set's DOI only, and the bucket holds one copy (live, no old), so that copy is the one read. It is pinned by the MD5 sum of its single data file, from the data set's checksums.md5: basal_forebrain_lfp.tar.gz a8acbf0400260f8395257778ed04dd8c (22,301,364 bytes); the notebook checks the sum of what it streams against it. The data descriptor is version 0.5 (Jan 23, 2018).

What the data set holds. BF LFP at 400 Hz from six rats, as 2-s segments with artifact segments removed, one movement-sensor value per segment, and two home-cage and two arena sessions per rat. It holds no ACC or VC recordings, no single units, no object sessions, no behaviour scoring or video, no day labels, no identification of bipolar electrodes and no recording across the transfer between arena and home cage.

Removed segments, % of each file's span: 2.6 to 23.5 (SI: 1-4% of epochs rejected)

Every file holds LFP_data, T_data and mov_data with 800 samples per segment, and sample intervals of exactly 2.5 ms (400 Hz), as the descriptor says. Segment starts step by multiples of 2 s, so segments are consecutive 2-s blocks with some removed, as the descriptor says. Each file's clock starts at or near 0, so no two files share a clock: an arena file cannot be placed in time relative to a home-cage file. The descriptor names the home-cage condition Hcage; the files use HCage. Arena files span 8.8 to 13 min and keep 8.5 to 11.8 min of segments; home-cage files keep 8.7 to 31.6 min. The share of removed segments (2.6% to 23.5% of a file's span) is larger than the SI's 1-4% of rejected epochs, so the data set's cleaning differs from the paper's rule or removed more. The LFP has no stated unit; its range (a few hundred, standard deviations of 60 to 115) is consistent with microvolts, the unit of the paper's Figure 4 axis. The movement values have no unit (the descriptor says dimensionless); in rats 4 and 5 they are about a quarter of those in the other rats, so they are only compared within a rat.

Units of analysis and readings shared by the claims¶

Gamma power and the other band powers are computed per 2-s segment (bflfp.epoch_table). The claims file's header names readings that apply to several claims, and each is run:

  • epoch length: 2-s segments (main) or 10-s epochs of five contiguous segments;
  • artifacts: segments as delivered (main) or the SI's peak-to-peak rule applied again;
  • unit of pairing: per rat, the two sessions of a condition averaged (rat 3's home cage is session 1 alone), n = 6; or session pairs (session 1 with session 1), n = 11 without the duplicate, and 12 with the files as delivered.

def drop_duplicates(tab):
    keys = list(zip(tab.rat, tab.condition, tab.session))
    return tab[[k not in DUPLICATES for k in keys]].copy()


def unit_means(tab, unit, measure="gamma"):
    # Per recording, the mean over its epochs; then per rat (sessions averaged) or per session pair.
    m = tab.groupby(["rat", "condition", "session"])[measure].mean().reset_index()
    if unit != "session_asis":
        m = m[[(a, b, c) not in DUPLICATES for a, b, c in zip(m.rat, m.condition, m.session)]]
    if unit == "rat":
        return m.groupby(["rat", "condition"])[measure].mean().unstack()
    return m.set_index(["rat", "session", "condition"])[measure].unstack().dropna()

def quartile_means(tab, scope):
    # Quartiles of the movement value within each recording, or within a rat's pooled sessions,
    # for each condition separately (criterion). Returns per-rat quartile means and the epoch table.
    grp = ["rat", "condition", "session"] if scope == "recording" else ["rat", "condition"]
    t = tab.copy()
    t["q"] = t.groupby(grp)["mov"].transform(lambda x: pd.qcut(x, 4, labels=False) + 1)
    return t.groupby(["rat", "condition", "q"])[["gamma", "mov"]].mean().reset_index(), t

def scaled(x, scale, ref):
    return {"raw": x, "log10": np.log10(x), "normalized": x / ref}[scale]


def run_excursions(scale, method, data):
    per_rat, events = [], []
    for rat in range(1, 7):
        t = main[main.rat == rat]
        ref_g, ref_t = t.gamma.mean(), t.theta.mean()
        home, ar = t[t.condition == "HCage"], t[t.condition == "Arena"]
        if data == "together":
            sets = [(home, ar, 1)]
        else:
            sets = [(home[home.session == s] if (home.session == s).any() else home, ar[ar.session == s], 2) for s in (1, 2)]
        for h, a, factor in sets:
            find = bflfp.histogram_intersection if method == "20 bins" else bflfp.kde_intersection
            thr = find(scaled(h.gamma.values, scale, ref_g), scaled(a.gamma.values, scale, ref_g))
            ev = []
            for s, g in a.groupby("session"):  # files do not share a clock: one series per file
                ev += bflfp.excursions(scaled(g.gamma.values, scale, ref_g), scaled(g.theta.values, scale, ref_t),
                                       g.t.values, thr)
            per_rat.append({"rat": rat, "threshold": thr, "count_20min": factor * len(ev),
                            "arena_minutes": len(a) * 2 / 60})
            events += [dict(e, rat=rat) for e in ev]
    per_rat, events = pd.DataFrame(per_rat), pd.DataFrame(events)
    ok = events.dropna(subset=["gamma_before"])
    by_rat = ok.groupby("rat")[["gamma_peak", "gamma_before", "theta_peak", "theta_before"]].mean()
    g_test = stats.ttest_rel(by_rat.gamma_peak, by_rat.gamma_before)
    t_test = stats.ttest_rel(by_rat.theta_peak, by_rat.theta_before)
    return per_rat, events, {
        "scale": scale, "bins": method, "arena_data": data,
        "threshold_range": f"{per_rat.threshold.min():.3g}-{per_rat.threshold.max():.3g}",
        "count_per_20min": per_rat.groupby("rat").count_20min.mean().mean(),
        "mean_duration_s": events.duration_s.mean(), "sd_duration_s": events.duration_s.std(),
        "min_duration_s": events.duration_s.min(), "max_duration_s": events.duration_s.max(),
        "n_events": len(events), "events_without_before": len(events) - len(ok),
        "gamma_rise": (by_rat.gamma_peak - by_rat.gamma_before).mean(), "gamma_p": g_test.pvalue,
        "theta_change": (by_rat.theta_peak - by_rat.theta_before).mean(), "theta_p": t_test.pvalue,
        # scale-free comparison with the paper's 0.56 / 2.6: the rise over the mean threshold, shown not judged
        "rise_over_threshold": (by_rat.gamma_peak - by_rat.gamma_before).mean() / per_rat.threshold.mean()}

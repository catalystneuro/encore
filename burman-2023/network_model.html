def pooled(key):
    sh = np.concatenate([r[-60][key] for r in runs])
    hy = np.concatenate([r[-80][key] for r in runs])
    return sh, hy
def paired_report(key, label):
    sh, hy = pooled(key)
    ok = ~np.isnan(sh) & ~np.isnan(hy)
    t = stats.ttest_rel(sh[ok], hy[ok])
    print(f"{label}: neurons {len(sh)}, defined in both conditions {ok.sum()} (dropped {(~ok).sum()})")
    print(f"  shunting {sh[ok].mean():.4f} +- {stats.sem(sh[ok]):.4f} (SEM), hyperpolarizing {hy[ok].mean():.4f} +- {stats.sem(hy[ok]):.4f}")
    print(f"  paired t test t = {t.statistic:.2f}, p = {t.pvalue:.2e}")
    print(f"  range shunting {np.nanmin(sh):.3f} to {np.nanmax(sh):.3f}, hyperpolarizing {np.nanmin(hy):.3f} to {np.nanmax(hy):.3f}")
    return sh[ok].mean(), hy[ok].mean(), t

figs7-model-decoding¶

Responses of networks with shunting E_GABAAR to 100 different input patterns are decoded more accurately by a downstream classifier.

The gist's decoder: spike counts of the first 50 excitatory neurons in each 25 ms epoch, a k-nearest neighbour classifier (scikit-learn defaults), 5-fold shuffled stratified cross-validation over the 10,000 trials of a condition, mean accuracy. Chance is 1%. Readings: (D1) paired t test of the 20 per-run accuracies, (D2) shunting higher in every run.

The spike counts are small integers, so many training trials are at the same distance from a test trial, and which of them are the five neighbours depends on how the classifier breaks ties. That is not fixed by the seeds: executions of this notebook on different runners, with the same per-run rate, entropy and synchrony, have printed D1 t = 16.92 (p = 6.52e-13) and t = 16.42 (p = 1.11e-12) from slightly different per-run accuracies. So the cell below also gives, per condition, the share of test trials whose fifth neighbour is tied with the sixth, and D1 and D2 recomputed with tied neighbours chosen by five other random orders of the training trials (network.decoding_ties).

The two partial outcomes are means a little outside tolerances that are the SEM over pooled neurons; the spread of the per-run means is wider (the standard error of a 20-run mean is 0.0013 for synchrony and 0.0023 for entropy, and the misses are 1.6 and 1.9 of these), and the paper's seeds are not known.

How the analysis differs from the paper's. The model is the paper's code, with the stimulus held as one periodic set to fit in memory and seeds fixed, so the 20 runs are other draws of the same model than the paper's. On a small run with one seed, network.py gives the same spikes as its own whole-run stimulus and as the gist itself run unmodified, and the same per-neuron rate, entropy and synchrony as the gist; in every full run the learning rate in the compiled synapse code is 0.1 during balancing and 0 during the test (checked above). The seeds fix the spikes but not the decoding accuracy exactly, as the classifier's ties between equally distant trials are broken differently on different runners; the decoding conclusion holds under each tie-breaking order tried.

Reproducing Burman et al. (2023) on DANDI:000458: Neuropixels claims¶

Paper. Burman RJ, Brodersen PJN, Raimondo JV, Sen A, Akerman CJ (2023). Active cortical networks promote shunting fast synaptic inhibition in vivo. Neuron 111, 3531-3540. doi:10.1016/j.neuron.2023.08.005

Dataset. DANDI:000458, version 0.230317.0039 (doi:10.48324/dandi.000458/0.230317.0039), the Allen Institute recordings of Claar et al. (2023) that the paper reuses (Figure 4A to 4D, Figure S6). This is the only published version of the dandiset, and the one the paper's analysis code names in its docstring (gist a77bcf5e, revision 43a13d89), so it is pinned. The draft has the same 24 assets (checked below).

Text the claims were written from. The version of record (Europe PMC, PMC11913778), with STAR Methods; the supplement (Figures S1 to S7) was not available (claims file, opening comment).

What this notebook tests. The claims on the dandiset. The network model claims are in network_model.ipynb. The patch-clamp claims (Figures 1 to 3, S1 to S5) rest on recordings that are not in the dandiset nor deposited anywhere ("available on request"), and are blocked.

figs4-intrinsic-properties. The paper's NEURON model of an L2/3 pyramidal neuron and its analysis are public (github.com/richardjburman/burman-et-al-2022---Awake-EGABAAR at commit a404c3e: hoc files and a Matlab analysis, NEURON_Egaba_Analysis.m), and the Methods ("Simulating measurements of synaptic EGABAAR", Table 2) give its parameters: membrane properties per state, 20 synapses within 75 µm of the soma, E_GABA set from -85 to -35 mV in 5 mV steps, two voltage ramps before and during GABA_A activation, estimates with 0% or 90% series resistance correction. A simulation of the ramp estimates under the anesthetized and awake membrane properties could be run. What it would be judged against is not fixed: the measure Figure S4 shows and the comparison that supports "could not be explained" are in the Figure S4 legend, which was not in the text read, and the claims file gives no criterion. Any choice (for example, the estimation error under each state's properties against the measured difference in synaptic E_GABA of Figure 2H) would be arbitrary, so the claim is blocked as methods_underspecified and not simulated. The question is for the paper's authors (attempt record, findings).

# Population spike count per trial 2 to 12 ms after stop_time, against the same window placed
# 1.5 s before and after each pulse (npx.SHIFTS; inter-pulse intervals are 3.5 to 4.5 s), for
# the selected units (reading A1) of all 17 files. read_session counts the shifted windows from
# the full spike trains as it streams them. Per trial, the evoked count is compared with the
# mean of the two shifted counts by a Wilcoxon signed-rank test.
clock = []
for k, s in S.items():
    rows_ = npx.select_units(s, "A1", "ge")
    for c in npx.CONDITIONS:
        tr = npx.condition_trials(s["trials"], c)
        u, pos, x = npx.peristimulus(s, rows_, tr)
        ev = np.bincount(pos, minlength=len(tr))
        row = dict(session=k, condition=c, trials=len(tr), units=len(rows_), evoked=ev.mean())
        sh = []
        for lag, (uu, tt) in s["shifted"].items():
            m = np.isin(uu, rows_) & np.isin(tt, tr)
            where = {t: i for i, t in enumerate(tr)}
            sh.append(np.bincount([where[t] for t in tt[m]], minlength=len(tr)))
            row[f"shift {lag / 1000:+.1f} s"] = sh[-1].mean()
        base = (sh[0] + sh[1]) / 2
        row["evoked / shifted"] = ev.mean() / base.mean() if base.mean() else np.inf
        row["wilcoxon p"] = stats.wilcoxon(ev, base).pvalue
        clock.append(row)

Readings from the criterion: (R1) one linear regression of the measure on the evoked rate across all unit and condition values, residuals compared by the paired t test; (R2) OLS of the measure on condition and rate, condition coefficient tested; (R3) per unit, the awake minus isoflurane difference of the measure regressed on the difference of rate, intercept tested. def regressed(K, measure, rate):
    a, b = K[measure + "_aw"], K[measure + "_an"]
    ok = a.notna() & b.notna()
    K = K[ok]
    long = pd.DataFrame({"y": np.r_[K[measure + "_aw"], K[measure + "_an"]],
                         "rate": np.r_[K[f"rate_{rate}_aw"], K[f"rate_{rate}_an"]],
                         "awake": np.r_[np.ones(len(K)), np.zeros(len(K))]})
    # R1
    slope, icpt = np.polyfit(long.rate, long.y, 1)
    res = long.y - (icpt + slope * long.rate)
    n = len(K)
    t1 = stats.ttest_rel(res[:n], res[n:])
    # R2
    m2 = smf.ols("y ~ awake + rate", data=long).fit()
    # R3
    d = pd.DataFrame({"dy": K[measure + "_aw"].values - K[measure + "_an"].values,
                      "dr": K[f"rate_{rate}_aw"].values - K[f"rate_{rate}_an"].values})
    m3 = smf.ols("dy ~ dr", data=d).fit()
    return dict(n=n, R1_diff=res[:n].mean() - res[n:].mean(), R1_p=t1.pvalue,
                R2_awake_coef=m2.params["awake"], R2_p=m2.pvalues["awake"],
                R3_intercept=m3.params["Intercept"], R3_p=m3.pvalues["Intercept"])

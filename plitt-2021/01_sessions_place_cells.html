Plitt & Giocomo (2021) on dandiset 000054, part 1: sessions, behaviour and place cells¶

Paper. Plitt MH, Giocomo LM (2021). Experience-dependent contextual codes in the hippocampus. Nature Neuroscience 24, 705-714. doi:10.1038/s41593-021-00816-6. The claims file was written from the NIH author manuscript in PubMed Central (PMC8893323), with the Methods, the main and Extended Data legends and the supplementary information; it is the accepted manuscript, not the version of record.

Dandiset. DANDI:000054, version 0.260415.1712. The paper's data statement points to the draft and cites no version. Of the six published versions, the three of 2021-08-19 hold 85 files (1.96 TB, raw imaging included) for 10 mice only (F1, F2, F3, F5 and R1 to R6). The three of April 2026 hold processed files for all 16 mice. The most recent, 0.260415.1712 (126 files, 112 GB), is pinned: the protocol asks for the most recent published version, and no earlier one matches the claims file better, as the 2021 versions lack six of the twelve rare and frequent morph mice and all four decision mice. It differs from 0.260409.0433 in mouse R5 only (training sessions 1, 5 and 7 removed and the other R5 files replaced); the cell below lists the difference.

What the files hold. One file per imaging session: the deconvolved activity of every Suite2P cell, the VR behaviour aligned to the imaging frames (imaged trials only), and a JSON annotation with per-trial values. The non-imaged trials, and the sessions without imaging, are not in the dandiset.

Outside input. The authors' "Unprocessed VR data" on figshare (doi:10.6084/m9.figshare.31974756.v1, one zip of 1.09 GB, published 2026-04-09) holds every VR session, imaged or not, with a session database (header M7 of the claims file, answer of 2026-10-22). It is read here by HTTP range requests, file by file, into memory, in part 2 (02_population_inference.ipynb), which tests its link to the dandiset (vr-deposit-link) and training-intermediate-fraction, which uses the deposit alone (data: elsewhere).

This notebook tests the claims on sessions, behaviour and place cells. The population, SF and inference claims are in part 2 (02_population_inference.ipynb), which also holds the summary.

def cell_matrices(s, g, smooth=True):
    m = s["pc"][g]["mask"].any(0)
    raw_maps = s["pc"][g]["maps"][:, :, m]
    sm = M.nan_smooth(raw_maps, M.SMOOTH_SIGMA) if smooth else np.nan_to_num(raw_maps, nan=0.0)

    C = np.einsum("nij,nkj->nik", a, a)

def pooled_perm(sums, counts, rare, freq):
    mice = rare + freq
    S = np.array([sums[m] for m in mice]); n = np.array([counts[m] for m in mice], float)
    def diff(mask):
        return S[mask].sum(0) / n[mask].sum() - S[~mask].sum(0) / n[~mask].sum()
    obs = diff(np.isin(mice, rare))
    import itertools
    perms = []
    for combo in itertools.combinations(range(len(mice)), len(rare)):
        mask = np.zeros(len(mice), bool); mask[list(combo)] = True
        if set(np.array(mice)[mask]) == set(rare):
            continue
        perms.append(diff(mask))
    return obs, np.array(perms)

def leave_mouse_out(e, y, mice, seed, n_relabel=100):
    """Verifier's check: balanced accuracy of the same classifier when each mouse's cells are held out
    in turn (no cell of a test mouse in training), against relabelings that assign 6 of the 12 mice to
    each group (n_relabel of the 923, drawn with the cluster's seed)."""
    ms = np.array(sorted(set(mice)))
    def bal(lab_of):
        yy = np.array([lab_of[m] for m in mice])
        if yy.all() or not yy.any():
            return np.nan
        pred = np.zeros(len(yy), bool)
        for m in ms:
            te = mice == m
            tr = ~te
            if yy[tr].all() or not yy[tr].any():
                return np.nan
            clf = LogisticRegression(C=1.0, class_weight="balanced", max_iter=1000).fit(e[tr], yy[tr])
            pred[te] = clf.predict(e[te]).astype(bool)
        return 0.5 * (np.mean(pred[yy]) + np.mean(~pred[~yy]))
    real = bal({m: m in RARE for m in ms})
    rng = np.random.default_rng(seed)
    all_mice = RARE + FREQ
    null = []
    for _ in range(n_relabel):
        pick = set(rng.choice(all_mice, 6, replace=False))
        if pick == set(RARE):
            continue
        null.append(bal({m: m in pick for m in ms}))
    null = np.array(null)
    return {"mice": len(ms), "LMO balanced acc": round(real, 3), "LMO null 95th pct": round(float(np.nanpercentile(null, 95)), 3),
            "LMO above null 95": bool(real > np.nanpercentile(null, 95))}

Science Advances 12, eaef0343. doi:10.1126/sciadv.aef0343. The claims file (claims/001868/10.1126-sciadv.aef0343.yaml) was written from the version of record (PMC13544205) with its supplement; this attempt read the same text.

Dandiset. DANDI:001868, version 0.260715.2016, pinned because the paper's data availability statement cites it (doi:10.48324/dandi.001868/0.260715.2016), as the claims file does. It is the only published version; the draft has the same 85 assets and size and was last modified at publication (2026-07-15), so there is no other version to compare.

What the dandiset holds. 85 NWB files of 12 mice. Six behavioural mice (ICMS92, 93, 98, 100, 101 and 83, the paper's Mice 1 to 6) have 55 sessions with sorted units (spike times, one mean waveform, cell type, position on the probe), trial and train tables, wheel position, and in most sessions volumetric and planar per-ROI dF/F with ROI masks. Six control mice have 30 files with survey imaging (ROI masks and binary activation per channel and current) and, in some, sorted units. The behavioural files hold no stimulation-site position in the imaging volume, no activation calls, and no identity of planar ROIs across sessions; no file holds spike waveforms in and out of stimulation or multi-channel templates.

Method details from the paper's code. Where the claims file leaves a detail open, it is taken from the code the paper links (XieLuanLab/icms-activation-plasticity at d1922d1), each cited where it is used: the threshold at 50% of the fitted function (processing/dataloader.py), the pulse-locking null drawn from 20% of the pulses (responses_v2/pulse_locked_response_metrics.py), the position of the stimulation contact, (32 - stim_channel) x 60 um, and the cortical depths of fig. S4 (longitudinal_data_utils.py), and the control pipeline (processing/control, python/fig_s7, processing/pop_coupling/pop_coupling_control.py). The code is a source of method only; no data come from it.

Random numbers. Every random draw uses its own numpy generator with a fixed seed, given in the cell that draws.

Outside inputs. None.

fig2a-threshold-decrease¶

Behavioural detection thresholds fall with learning; thresholds in the late phase (weeks 2 to 4) are lower than in the early phase (weeks 0 to 1), median 5.5 against 4.2 uA.

Per channel and block, a cumulative Gaussian with free guess and lapse is fitted with psignifit 4 at its default grid to the hit proportion at each current, with the block's catch-trial false-alarm rate as a 0 uA point; the session threshold of a channel is the mean of its block thresholds. The threshold is the current at which the fitted function reaches 50% detection (ps_x50), as the criterion says and as the paper's code takes it (ps.getThreshold(result, 0.5) in processing/dataloader.py, whose default is the scaled function). psignifit's own threshold parameter (the midpoint of the unscaled sigmoid) and a bounded maximum likelihood fit (its mu and its x50) are shown as variants. The dataset stores no thresholds, so only refitted ones are shown. Mouse 6 (ICMS83) has no catch trials in the files; its fits have no 0 uA point. Effect size r = |Z| / sqrt(n1 + n2) (claims, common method, for thresholds).

# The pulse-locking call: how it treats synthetic responses, and where the PL calls peak
rng_syn = np.random.default_rng(50)


def synth_pulses(shape, rate, n=2100):
    """n pulses (30 trains of 70) with Poisson spikes in the unblanked 1.5 to 9.5 ms, shaped by `shape`."""
    c = (np.arange(20) + 0.5) * 0.5
    valid = (c >= 1.5) & (c <= 9.5)
    w = np.zeros(20)
    w[valid] = shape(c[valid])
    w /= w.sum()
    tot = rng_syn.poisson(rate * n)
    M = np.zeros((n, 20), np.int32)
    np.add.at(M, (rng_syn.integers(0, n, tot), rng_syn.choice(20, tot, p=w)), 1)
    return M

def s4b_fits(PLR, label, verbose=True):
    edges = np.arange(60, 901, 120)
    centres = (edges[:-1] + edges[1:]) / 2
    out = {}
    for c in icms.CURRENTS:
        d = PLR[(PLR.current == c) & PLR.dist.notna()]
        dr = d[(d.dist >= 120) & (d.dist <= 840)]
        b = np.digitize(dr.dist, edges) - 1
        o = {}
        for agg in ["mean", "median"]:
            y = np.array([getattr(np, agg)(dr.latency_ms[b == i]) if (b == i).sum() else np.nan for i in range(len(centres))])
            use = ~np.isnan(y)
            lr = stats.linregress(centres[use], y[use])
            o[agg] = (lr.slope, lr.pvalue, lr.rvalue ** 2, 1e-3 / lr.slope if lr.slope > 0 else np.nan)
            if verbose:
                print(f"{label} {int(c)} uA latency, binned {agg}s 120-840 um: slope {lr.slope:.5f} ms/um, p = {lr.pvalue:.3g}, "
                  f"r2 = {lr.rvalue ** 2:.2f}, velocity {o[agg][3]:.3f} m/s; bin means/medians "
                      f"{np.round(y, 2).tolist()}, n {[int((b == i).sum()) for i in range(len(centres))]}")
        bj = np.digitize(d.dist, edges) - 1
        yj = np.array([np.mean(d.jitter_ms2[bj == i]) if (bj == i).sum() else np.nan for i in range(len(centres))])
        use = ~np.isnan(yj)
        lj = stats.linregress(centres[use], yj[use])
        lj2 = stats.linregress(d.dist, d.jitter_ms2)
        o["jitter_binned"], o["jitter_unbinned"] = (lj.slope, lj.pvalue), (lj2.slope, lj2.pvalue)

                  f"{d.latency_ms.min():.2f} to {d.latency_ms.max():.2f} ms")
        out[c] = o
    return out

figs2de-control-stable (count half)¶

In control animals stimulated without behavioural training, activation density within 200 um and the number of activated neurons do not change from early to late weeks.

The control survey files store each ROI's binary activation per stimulation channel and current; the number of activated ROIs per channel and current is their sum. The 800 um limit of the count cannot be applied for the same reason; all activated ROIs are counted. Weeks are counted from each control animal's first imaging session (common method). In control animals stimulated without behavioural training, neither PL nor NPL responses change in modulation, time to maximum firing rate or PL peak spike probability.

The paper says only that the controls had similar stimulation parameters, but its code runs the control units through the behavioural response classes with a 20 ms pulse window (processing/control/postprocessing/create_session_responses.py) and tests them at 5 uA with its own filters (python/fig_s7/generate_figure.py: P < 0.05, z > 0, baseline at least 0.5 Hz, more than 5 trains, more than 15 pulse-window spikes, weeks below 5). How the analysis differs from the paper's. Thresholds are refitted with the Python port of psignifit; the dataset stores none. The movement-onset threshold is taken from hit trials, as miss trials have no response time. Pulse-locking follows the paper's code, with pulses placed 10 ms apart from the train onsets, as no pulse times are stored; the call is random, and the claims that rest on it near a threshold (fig5d, fig5e, fig5h) are shown under three other seeds. The hit-miss PSTH bin width and smoothing are not in the paper or its code; two widths were run. The stimulation contact is placed as the paper's code places it, not by the electrode table. The control analyses follow the paper's control code, whose timing file is not public; its 700 ms baseline holds the previous burst for most bursts, and a baseline free of stimulation is shown as a variant. Control trials are numbered from burst_index_in_trial, as the stored trial_index restarts in each recording block. Cell types are the stored labels, which the files describe as the trough-to-peak classification; the rule applied to the stored mean waveform is shown as a variant.

What was found about the dataset. The 46 sessions of weeks 0 to 4 match the paper's count, and the ephys response counts are close to the paper's, but the unit total (795 in weeks 0 to 4) is below the paper's 973. Behavioural files give no stimulation-site position in the imaging volume and no activation calls, and the planar ROIs are segmented per session with no identity across sessions, so no behavioural imaging claim can be tested. The stored stim_channel does not index the electrode table's channel_name, though both are described as Ripple channel numbers. The control files use 3 bursts of 10 pulses at 50 Hz, where the paper says the controls had similar stimulation parameters. In the control files trial_index, described as the trial index within the session, restarts in each recording block. Most miss trials carry no response time, Mouse 6 has no catch trials, and cell types are spelled differently in Mouse 6.

Daste, Pierré et al. (2025), passive odor experiments, from dandiset 000785¶

Paper: Daste, Pierré et al., "Projection-specific Routing of Odor Information in the Olfactory Cortex", bioRxiv preprint doi:10.64898/2025.12.12.694045 (version 1). The claims file (claims/000785/10.64898-2025.12.12.694045.yaml) was written from the preprint's full text flattened from its JATS XML: main text, Methods and supplementary legends, without the contents of Tables 2 to 8.

Dataset: DANDI:000785, version 0.260520.1603 (doi:10.48324/dandi.000785/0.260520.1603). The paper cites no version. Two versions are published, 0.260519.1753 and 0.260520.1603; they hold the same 61 files with the same blobs (checked by asset path and blob id through the DANDI API before the analysis), so the most recent one is pinned. The files are streamed, never downloaded.

This notebook covers the counts of neurons and the passive experiments (identity, concentration and 30 Hz datasets). The Go/NoGo experiment and the tracked neurons are in reproduce_daste_2025_gng.ipynb.

dataset-neuron-counts¶

The passive identity dataset holds 81 OB-p, 84 mPFC-p and 1978 untagged neurons from 10 mice; the concentration dataset 87 OB-p, 102 mPFC-p and 2232 untagged neurons from 10 mice; the Go/NoGo dataset 7 mice (4 OB-p, 3 mPFC-p tagged) with, per session, 95 +/- 2 OB-p, 87 +/- 8 mPFC-p and 1690 +/- 35 untagged neurons.

Counts of suite2p cells by tag, as the code's load_experiment builds them: planes without a red cell are skipped (compute_dFF0). The count over all planes is shown beside it. For Go/NoGo the day of a session is its rank among the experiment's dates (the code's day_num), day 0 the passive day; "per session" is read as (a) the total over the mice of one task day, averaged over days 1 to 3, or (b) over days 0 to 3. The paper has 3 mPFC-p Go/NoGo mice and the dandiset 4, so the counts are given with all mice and without sub-668, the mPFC mouse without tracking identifiers.

    g = df.groupby("projection_area").agg(red=("n_red", "sum"), cells=(cellcol, "sum"), mice=("subject", "nunique"))

    X, t = s["X"][:, s["keep"]], s["t"]
    bm = (t >= -base) & (t < 0)
    resp = X[:, :, (t >= 0) & (t < 5)].mean(-1)
    if per_trial:
        mu, sd = X[:, :, bm].mean(-1), X[:, :, bm].std(-1, ddof=1)
    else:
        B = X[:, :, bm].reshape(X.shape[0], -1)
        mu, sd = B.mean(1)[:, None], B.std(1, ddof=1)[:, None]
    r = resp > mu + 2.33 * sd
    odors = s["trials"][s["keep"]].stim_name.to_numpy()
    if rule == "e":
        rel = r.mean(1) > 0.5
    else:
        rel = np.stack([r[:, odors == o].mean(1) > 0.5 for o in np.unique(odors)], 1).any(1)
    full = np.zeros((X.shape[0], len(s["trials"])), np.int8)
    full[:, s["keep"]] = r * (1 + rel[:, None])         # 0 none, 1 responsive unreliable, 2 responsive reliable
    return full

def windows_of(width, t, a=-5.0, b=15.0):
    edges = np.arange(a, b + 1e-9, width)
    wins = [(lo, lo + width) for lo in edges[:-1]]
    keep = [w for w in wins if ((t >= w[0]) & (t < w[1])).any()]
    return keep, len(wins) - len(keep)

def anova2(Y, A, B):
    """Type II two-way ANOVA with interaction for every column of Y (trials x cells)."""
    a = pd.get_dummies(pd.Categorical(A), drop_first=True).to_numpy(float)
    b = pd.get_dummies(pd.Categorical(B), drop_first=True).to_numpy(float)
    ab = np.einsum("ti,tj->tij", a, b).reshape(len(A), -1)
    one = np.ones((len(A), 1))
    def rss(M):
        beta, *_ = np.linalg.lstsq(M, Y, rcond=None)
        return ((Y - M @ beta) ** 2).sum(0)
    r_a, r_b = rss(np.hstack([one, a])), rss(np.hstack([one, b]))
    r_ab = rss(np.hstack([one, a, b]))
    full = np.hstack([one, a, b, ab])
    r_full = rss(full)
    df_res = len(A) - np.linalg.matrix_rank(full)
    out = {}
    for name, ss, df in [("identity", r_b - r_ab, a.shape[1]), ("concentration", r_a - r_ab, b.shape[1]),
                         ("interaction", r_ab - r_full, ab.shape[1])]:
        F = (ss / df) / (r_full / df_res)
        out[name] = stats.f.sf(F, df, df_res)
    return out

    wins, _ = windows_of(width, t_co, -2.0, 15.0)
    rng = np.random.default_rng(seed)
    three = np.zeros((n_rep, len(wins)))

How the analysis differs from the paper's. Normalization, cell selection and trial segmentation follow the paper's code; the figure analyses are not in the code and follow the Methods and the claims file's readings. The binarization was run under both readings of the window placement, which give the same outcomes here. Decoding uses 5-fold stratified cross-validation with a new fold split and cell sample in each repeat. The transformer and MLP claims were not run.

What was found about the dataset. The stated imaging rate is wrong in 21 files (30, 50 or 100 Hz where the timestamps give 4.51 to 4.52 Hz). With the code's rule of skipping planes without red cells, the OB-p and mPFC-p counts of the identity and concentration experiments match the paper's exactly, the untagged counts are 2.1% (1937 against 1978) and 4.5% (2132 against 2232) lower, and the 30 Hz counts match exactly; over all planes the identity untagged count is 2328 against the paper's 1978.

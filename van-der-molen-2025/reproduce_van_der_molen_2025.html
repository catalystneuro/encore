Reproducing van der Molen, Spaeth, Chini et al. (2025) from dandiset 001603¶

Paper. van der Molen T, Spaeth A, Chini M, et al. (2025). Preconfigured neuronal firing sequences in human brain organoids. Nature Neuroscience. doi:10.1038/s41593-025-02111-0. The claims file was written from the NIH author manuscript in PubMed Central (PMC12912721.1) with the publisher's Supplementary Information; this attempt read the same text.

Dandiset. DANDI:001603, version 0.260923.0623. The paper cites no version of the dandiset. This is the only published version and the most recent one; the draft has the same 111 assets and size, so the published version is pinned.

What is used. The sorted files only: each holds a 1 ms binary spike matrix (processing/curated_binning/t_spk_mat, the input of the paper's code), and most also a units table. Recordings are cut to the code's lengths (180 s for HO1 to HO4, slices and primary cultures; 600 s for HO5 to HO8 and murine organoids). The raw _ecephys files are not read.

Method sources. The claims file (its opening comment and each criterion), and where it is silent, the paper's Methods and Supplementary Methods and the code it links (github.com/braingeneers/Protosequences at e9a79c4), cited in sequences.py and below.

Shuffles. The paper normalises to 100 Okun-swap shuffles per recording. This notebook uses 10 per recording, and 3 for the pairwise cross-correlations and the shuffled burst similarity, to fit the runtime limit (a deviation; the shuffle mean is the reference, and its noise is small next to the effects tested). Every shuffle made all the swaps requested (data check).

Bursts. Peaks at 700 ms minimum distance (Methods); where a peak in the tail of a long burst gives a second, overlapping burst, only the burst with the higher peak is kept, which is what the Methods' increase of the distance "up to 2000 ms" for long-burst recordings is for (an assumption on which recordings it applies to; 2000 ms for every recording is shown as a variant).

Statistics. Mixed models are fitted by REML with a random intercept, and fixed effects and contrasts are tested with t on Satterthwaite degrees of freedom, as lmerTest does (sequences.lmm).

Every matrix count is at most the units-table count (several spikes in one 1 ms bin count once): True

The spike matrices are 1 ms bins (the file's description says so); where a units table exists, each unit's matrix count is at most its spike count in the table, the difference being spikes that fall in the same millisecond, and the table's last spike lies within the matrix length. Some units tables hold a single NaN for units with no spikes. The species field says Rattus norvegicus for Pr1 to Pr4 (Yuan et al., E18 Wistar rat) and Mus musculus for Pr5 to Pr8; the paper calls all primary cultures murine. All files share one clock per recording: there is no trial table, and every measure here is computed from the spike matrix alone, so a check of alignment between streams does not apply.

def run(args):
    name, rec, n_shuf, n_pair, sim, seed, light = args
    m = sq.load_matrix(first.loc[rec].asset_id, sq.keep_seconds(name))
    t0 = time.time()
    r = sq.analyse(name, m, seed, n_shuf=n_shuf, n_shuf_pair=n_pair, similarity=sim, light=light)
    if rec == name:
        # d2 (supp27-d2-near-critical): intact, one per-unit shuffle, and the AR fit check
        rng = np.random.default_rng(seed + 500)
        x = sq.bin_pop(m)
        vp, vn = sq.ar_yule_walker(x)
        xs = sq.bin_pop(sq.shuffle_each_unit(m, rng))
        r["d2"] = dict(d2=sq.d2_distance(vp), d2_shuffled=sq.d2_distance(sq.ar_yule_walker(xs)[0]),
                       **sq.ar_fit_check(x, vp, vn, rng))
    r["secs"] = time.time() - t0
    return rec, r

from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score


def burst_corr_vectors(seg):
    """Per burst, the lower triangle of the unit-by-unit correlation of the -250 to 500 ms rates
    (numpy corrcoef; undefined correlations set to 0, as the code's nanmax with the identity)."""
    U = seg.shape[0]
    tri = np.tril_indices(U, -1)
    out = []
    for b in range(seg.shape[1]):
        with np.errstate(invalid="ignore", divide="ignore"):
            c = np.corrcoef(seg[:, b, :])
        c = np.nan_to_num(c, nan=0.0)
        out.append(c[tri])
    return np.array(out)


def kneedle(ks, sse):
    """Knee of a decreasing convex curve: the point farthest below the chord (Satopaa et al.)."""
    x = (np.array(ks) - ks[0]) / (ks[-1] - ks[0])
    y = (np.array(sse) - min(sse)) / (max(sse) - min(sse))
    return ks[int(np.argmax((1 - x) - y))]

How the analysis differs from the paper's. 10 shuffles per recording (3 for pairwise correlations and shuffled similarity; 5 and 2 under the second recording length) where the paper uses 100; burst-only rates that do not hold the inverse ISI across the gap between bursts (the code's rates are shown for fig4f); overlapping bursts merged at 700 ms where the paper raises the peak distance for some recordings; mixed models fitted here by REML with Satterthwaite t tests in place of the paper's R; MATLAB smoothing replaced by its scipy counterparts (Gaussian with standard deviation one fifth of the window); the shuffles cover the analysed segment (the code shuffles the first 180 s); d2 from a Python port of the code of Sooter et al., with one shuffle per recording and an AR fit check whose rule the paper does not give.

What was found about the dataset. The 31 main recordings (8 human organoids, 9 murine organoids, 6 slices, 8 primary cultures) are in the dandiset as sorted files with 1 ms spike matrices, and HO1 has the 46 bursts of Fig. 1C. The HO2 and HO3 longitudinal recordings are deposited two or three times. The baseline sorted file of MO12 and all murine organoid longitudinal recordings are missing. Units carry positions but no identifier linking them across recordings of one organoid; the 0 h and 4 h recordings of HO2 and HO3, and the baseline and gabazine recordings of MO10, MO11 and MO14, have identical ordered positions. Pr1 to Pr4 are labelled rat, the paper calls them murine. With the stated burst detection, four murine organoids have no burst (their highest peaks reach 3.0 to 3.7 times the RMS), so the paper's murine organoid parameters are not given.

Partial outcomes. One rule is applied to every claim. Where the criterion defines a partial outcome, it decides.

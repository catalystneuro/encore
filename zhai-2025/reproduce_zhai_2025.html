Clocks¶

Each check contrasts the response in the window the analysis uses with a window of the same length where no response is expected.

  • Somatic: the spike counts against the commanded step (negative steps should give no spikes).
  • Dendritic: the area of (G - G0)/R0 from 0.95 to 1.5 s (current injections at about 1 s) against the same length from 2.5 s.
  • Sr2+-oEPSC: events from 40 to 400 ms after the flash, from the flash time in the optogenetic pulses table, against 500 to 860 ms.
  • GRAB-ACh3.0: the mean fluorescence in the 1 s after the trial table's stimulus time against the 1 s before it.

Somatic excitability¶

link-somatic-cells¶

The dandiset's somatic current-step recordings are those behind the paper's somatic excitability figures, and the spike counts computed from them agree with the paper's per-cell tables.

Spike counts as in the paper's script: upward crossings of 0 mV over the sweep; rheobase the first positive step with a spike. When a cell holds a step twice, the first sweep is used (an assumption; the last is shown as a variant). Each dandiset cell is compared with every row of the paper's table for its group over the steps from 20 to 300 pA present in both.

def by_group(df, ct, conds, col):
    return [df[(df.cell_type == ct) & (df.condition == c)][col].to_numpy(float) for c in conds]

def show_mw(label, a, b, la, lb):
    r = zhai.mw(a, b)
    print(f"{label}: {la} n={r['n1']} median {r['median1']:.3f}; {lb} n={r['n2']} median {r['median2']:.3f}; "
          f"Mann-Whitney U={r['U']:.1f}, P={r['p']:.4g}")
    return r

def per_date(df, ct, conds, col):
    d = df[(df.cell_type == ct) & df.condition.isin(conds)]
    return d.groupby(["condition", "date"])[col].agg(["size", "median"]).round(3)

def step_medians(cells, ct, conds):
    out = {}
    for c in conds:
        d = cells[(cells.cell_type == ct) & (cells.condition == c)]
        steps = sorted({s for x in d.counts for s in x})
        out[c] = {s: float(np.median([x[s] for x in d.counts if s in x])) for s in steps if 20 <= s <= 300}
    return pd.DataFrame(out).T

def dendritic_link(cells, by_ordinal=False):
    rows = []
    for sheet, ct, cond, pg in DEN_MAP:
        P = T[sheet]
        P = P[(P.iloc[:, 1] == pg[0]) & (P.iloc[:, 2] == pg[1])] if isinstance(pg, tuple) else P[P.iloc[:, 1] == pg]
        vals = P.iloc[:, -1].to_numpy(float)
        ids = P.iloc[:, 0].astype(str).tolist()
        D = cells[(cells.cell_type == ct) & (cells.condition == cond)].sort_values(["date", "cell"]).reset_index(drop=True)
        D["ordinal"] = D.groupby("date").cumcount()  # the cell's place among the group's analysed cells of the day
        for i, d in D.iterrows():
            if sheet.startswith("Fig 6D"):
                letter = "abcdefgh"[int(d.ordinal)] if by_ordinal else "abcdefgh"[int(d.cell) - 1]
                pid = f"{d.date[4:8]}{d.date[:4]}_{letter}"
                pv = vals[ids.index(pid)] if pid in ids else np.nan
            else:
                pid = ids[i] if i < len(ids) else None
                pv = vals[i] if i < len(vals) else np.nan
            rows.append(dict(sheet=sheet[:6], group=str(pg), date=d.date, cell=d.cell, n_pairs=d.n_pairs,
                             n_data=len(D), n_paper=len(P), paper_id=pid, ordinal=int(d.ordinal) + 1, index=d["index"], paper=pv,
                             nearest=vals[np.argmin(np.abs(vals - d["index"]))]))
    L = pd.DataFrame(rows)
    L["rel_diff"] = (L["index"] - L.paper).abs() / L.paper
    L["rel_diff_nearest"] = (L["index"] - L.nearest).abs() / L.nearest
    return L

link-sr-cells¶

The dandiset's Sr2+-oEPSC recordings are cells of the paper's Figures 2 and 4, and their events agree with the paper's per-cell values.

Events are found with the detector in zhai.detect_events (a stand-in for TaroTools; see the helper's docstring): from 40 to 400 ms after the flash, peaks of inward current whose prominence exceeds five SD of the noise. The paper's identifiers are the date followed by a letter (the dSPN table writes the date as MMDDYYYY, the iSPN table as YYYYMMDD); the letter is the cell number of the file. The paper's event count per cell is its frequency times 3.6 s (10 sweeps of 0.36 s), which is what its frequencies imply.

def sr_cells(sw, amp_col="amps", n_col="n_events", max_sweeps=None, last=False):
    if max_sweeps:
        g = sw.sort_values("sweep_start").groupby(["path", "cell"])
        sw = g.tail(max_sweeps) if last else g.head(max_sweeps)
    c = sw.groupby(["cell_type", "date", "cell", "condition"]).agg(n_sweeps=(n_col, "size"), n_events=(n_col, "sum"),
                                                                      amps=(amp_col, "sum")).reset_index()
    c["mean_amp"] = c.amps.apply(lambda x: float(np.mean(x)) if len(x) else np.nan)
    c["freq_hz"] = c.n_events / (c.n_sweeps * 0.36)
    c["key"] = c.date + c.cell.apply(lambda k: "abcdefgh"[k - 1])
    return c.drop(columns="amps")

def paper_sr():
    P = []
    for ct, a, f in [("dSPN", "Fig 2H_dSPN Sr-oEPSC amp", "Fig 2I_dSPN Sr-oEPSC freq"), ("iSPN", "Fig 4G_iSPN Sr-oEPSC amp", "Fig 4H_iSPN Sr-oEPSC freq")]:
        x = T[a].set_axis(["id", "group", "paper_amp"], axis=1).merge(T[f].set_axis(["id", "group", "paper_freq"], axis=1))
        x["ct"] = ct
        P.append(x)
    P = pd.concat(P, ignore_index=True)
    P["id"] = P.id.astype(str)

def sr_link(c):
    M = c.merge(paper_sr(), on="key", how="outer", indicator=True)

    M["within25"] = (M.amp_rel.abs() <= 0.25) & (M.n_rel.abs() <= 0.25)

How the analysis differs from the paper's: spikes, rheobase, the dendritic index and the GRAB areas follow the paper's scripts, but from the files' data (the GRAB ROI is the 50 um circle computed from the movies; background images are not shared, which cancels in the normalised area). Sr2+-oEPSC events come from a stand-in detector, not TaroTools with visual checking. The AIM group effect is the between-mouse F of the mixed design. Eight claims rest on the paper's own tables, as the claims file says. After the first verification round the red-channel background of the dendritic index was corrected (55, where 161 had been subtracted from both channels), the last-sweep variant of the somatic measures was made to take the last sweep, and the Sr2+ claims gained the last-10 and nearest-run sweep variants; no outcome changed. After the second round every somatic test was also run under the last sweep of a repeated step (cell somatic-last-sweep).

What was found about the dataset: it holds every cell of the paper's off-state, on-state and drug groups for somatic, dendritic and Sr2+ recordings, and every GRAB region; the control and 6-OHDA patch-clamp recordings, the open-field data and the confocal images are not in it. 33 of 123 somatic cells do not match the paper's spike counts exactly. One dendritic cell lacks the pair of sites the paper used, which changes the outcome of fig1i-dspn-dendritic-sch-lower (P = 0.066 with it, 0.027 without it). The Figure 8 AIM scores are the lab's sheets and differ from the published figure. Two Sr2+ cells hold more sweeps than the paper used, and several GRAB regions hold more trials than the two the Methods give and lack a full calibration trial.

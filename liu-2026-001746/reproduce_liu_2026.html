Reproducing Liu, Huang, Shen, Shao, Jing et al. (2026) from dandiset 001746¶

Paper: Liu, Huang, Shen, Shao, Jing et al. (2026). An atlas of primate insular cortex reveals a signal-processing strategy in von Economo neurons. Nature Cell Biology 28, 1742-1757. doi:10.1038/s41556-026-02009-4. The claims file was written from the version of record in Europe PMC (PMC13457102): main text, legends, Methods; it names the Supplementary Information as not read. This attempt also had the Supplementary Information PDF (Supplementary Figs. 1 to 17); the Supplementary Tables are not in it.

Dataset: DANDI:001746, version 0.260825.0222, 462 NWB files, one Patch-seq cell each (current-clamp step sweeps). The paper cites no version of the dandiset. This is the only published version, and the draft lists the same 462 files and size (printed below), so it is pinned.

Outside inputs. The 10x excitatory neurons with their clusters, Ext.h5ad of the h5ad archive of GEO GSE319557, streamed for fig7c. From the paper's code repository RFLiu2021/AIC_proj at commit 44cd8a6dfbb1f1ce363d73742e4f3652086b0f9d: the cell table metaInfo_ephysio_patchSeq.csv (cell type, VEN subtype and transcriptomic cluster per file, which the files lack), the per-cell feature table Ins_patchseq_ephs.xlsx and per-cell phase peak indices PeakIdx_Fig5e.xlsx (reference values for checks that do not decide), NeuronPeakIdx_summary.mat (the 62 AIS distances of Fig. 4i), and the morphological feature table morphFeatMatrix.xlsx. Feature extraction follows the Methods, with details the Methods leave open taken from the paper's MATLAB package PatchAnaLab 1.0 (doi:10.5281/zenodo.19995355), as the helper aic.py says for each.

In every file the voltage falls at the stimulus onset and rises at its offset, so the voltage and stimulus series share one clock. In some files a change of similar size appears 100 ms before the onset (counted above); in the 600 ms protocol this is outside the step and is consistent with a test pulse or spontaneous activity before it. It does not move the step. The paper's code finds the step in the voltage within fixed sample windows; its onset lies within a few samples of the stimulus onset in most files, and the analysis uses the stimulus onset.

Feature comparisons between the six projection neuron groups¶

The groups are formed as calFDR_ephsio.m forms them, from the table's cluster and expert type, on the files with a transcriptomic type. The tests are two-sided Wilcoxon rank-sum tests with Benjamini-Hochberg FDR over the features of each comparison (calFDR_ephsio.m). The claims file makes the family the 39 features of Ins_patchseq_ephs.xlsx, those the Methods define computed as defined there. Nineteen of them (phase areas and perimeters, ISI phase ratios, slopes of FR and first ISI, amplitude CV and Fano factor, AHP latency and others) are defined neither in the Methods nor in PatchAnaLab, so they cannot be computed from the recordings; their values are taken from the code's table by cell ID (234 of the 237 grouped cells are in it), and the FDR over the 39 features (q39) decides. The 20 features the Methods name form the variant family (q_F20; for the ISI CV and Fano factor, which are not among them, these 20 and the two ISI measures). q39_upper is the bound on the FDR over 39 features that holds whatever the 19 other p-values are, shown as a check.

def upper39(p):
    """Upper bound of the BH-adjusted p-value of each known feature in a 39-feature family."""
    p = pd.Series(p).dropna()
    r = p.rank(method="first")
    bound = (p * 39 / r).clip(upper=1)
    return pd.Series({k: bound[p >= p[k]].min() for k in p.index})

def compare(df, a_groups, b_groups, features=None):
    """Rank-sum tests of a against b for every feature, with the FDR readings described above."""
    a, b = df[df.group.isin(a_groups)], df[df.group.isin(b_groups)]
    feats = sorted(set(F20 + IN39 + EXTRA + X19), key=(F20 + IN39 + EXTRA + X19).index)
    rows = {}
    for f in feats:
        x, y = a[f].astype(float).dropna(), b[f].astype(float).dropna()
        p = stats.mannwhitneyu(x, y, alternative="two-sided").pvalue if len(x) > 1 and len(y) > 1 else np.nan
        rows[f] = {"n_a": len(x), "n_b": len(y), "median_a": x.median(), "median_b": y.median(), "p": p}
    t = pd.DataFrame(rows).T
    t["q_F20"] = np.nan
    t.loc[F20, "q_F20"] = aic.bh(t.loc[F20, "p"].astype(float))
    q22 = aic.bh(t.loc[F20 + ["ISI_CV", "ISI_Fano"], "p"].astype(float))
    t.loc[["ISI_CV", "ISI_Fano"], "q_F20"] = q22[-2:]
    t["q39_upper"] = upper39(t.loc[IN39, "p"].astype(float))
    t["q39"] = np.nan
    t.loc[IN39 + X19, "q39"] = aic.bh(t.loc[IN39 + X19, "p"].astype(float))
    for var, base in {"tau_code": "tau_methods", "Rm_code": "Rm_methods", "tau_sweep_median": "tau_methods"}.items():  # a variant in its base's place
        t.loc[var, "q39_upper"] = upper39(t.loc[[var if f == base else f for f in IN39], "p"].astype(float))[var]
        fam = [var if f == base else f for f in IN39 + X19]
        t.loc[var, "q39"] = aic.bh(t.loc[fam, "p"].astype(float))[fam.index(var)]
        fam = [var if f == base else f for f in F20]
        t.loc[var, "q_F20"] = aic.bh(t.loc[fam, "p"].astype(float))[fam.index(var)]
    t["F39"] = np.where(t.q39 < 0.05, "sig", "ns")
    t.loc[~t.index.isin(IN39 + ["tau_code", "Rm_code", "tau_sweep_median"]), "F39"] = "-"
    if features is not None:
        t = t.loc[features]
    return t

def readings(df, target, features):
    """Reading (a): target against the other five pooled; (b): against each other group."""
    others = [g for g in aic.GROUPS if g != target]
    out = []
    t = compare(df, [target], others, features)
    t.insert(0, "against", "other five pooled")
    out.append(t)
    for g in others:
        t = compare(df, [target], [g], features)
        t.insert(0, "against", g)
        out.append(t)
    r = pd.concat(out)
    r.index.name = "feature"
    return r.reset_index()

def medians(df, features):
    return df.groupby("group")[features].median().reindex(aic.GROUPS)

The Methods put the recordings without RNA on a MultiClamp 700B with pClamp and the Patch-seq recordings on a HEKA amplifier with PatchMaster ("Patch-seq recording"). In the files the device follows the recording year (mostly Axon for the 2018 subjects and HEKA for the 2022 ones), and both devices hold typed and untyped cells, so the device does not mark the recordings without RNA. The groups are unevenly spread over the devices (L5 IT FEZF2 93 of 125 Axon files, L2/3 IT HPCAL1 6 of 30). Half-width and tau are longer in the Axon files in every group, in the computed values and in the code's own table (half-width 3.13 against 2.08 ms, tau 41 against 26 ms). Bringing Axon files to the HEKA rate leaves half-width and tau unchanged and changes the phase peak index, so the half-width and tau difference is one of recording conditions, not of sampling rate, while the phase peak index also depends on the rate.

fig3e-phase-peak-index and fig3d-saddle-phase-plane¶

VENs have lower phase peak indices than any PC group.

The AP phase-plane plots of VENs show a more prominent biphasic shape than those of PCs, with the AIS phase decaying before the SD phase in a saddle-like shape.

The index is read automatically (helper docstring) on the maximal-rate sweep, (a) on its first AP and (b) as the median over its APs. Kruskal-Wallis over the six groups, then Dunn's test with Bonferroni and with Sidak correction. The code's per-cell values (PeakIdx_Fig5e.xlsx, read by hand) are compared, without deciding. An AP whose rising phase has neither a second maximum nor a shoulder gets the lowest dV/dt of its rising phase as its AIS value (the Methods' "point with the lowest derivative value"), so it counts as the least saddle-like; the synthetic APs below show the three cases, and the variant _x leaves such APs out.

def dunn_table(df, col):
    d = df.dropna(subset=[col])
    kw = stats.kruskal(*[d[d.group == g][col] for g in aic.GROUPS])
    out = {"KW H": kw.statistic, "KW p": kw.pvalue}
    for corr in ["bonferroni", "sidak"]:
        pt = sp.posthoc_dunn(d, val_col=col, group_col="group", p_adjust=corr)
        for g in aic.GROUPS:
            if g != "VEN":
                out[f"{corr} VEN vs {g}"] = pt.loc["VEN", g]
    return d.groupby("group")[col].agg(["count", "median"]).reindex(aic.GROUPS), out

rng = np.random.default_rng(0)
def synth_ap(kind, fs):
    ts = np.arange(0, 0.006, 1 / fs)
    bump = lambda t0, w, h: h * np.exp(-0.5 * ((ts - t0) / w) ** 2)
    dv = {"biphasic": bump(0.0012, 0.00015, 150) + bump(0.0018, 0.0002, 250),
          "shoulder": bump(0.0013, 0.0002, 120) + bump(0.0017, 0.0002, 250),
          "monophasic fast": bump(0.0016, 0.0003, 300),
          "monophasic slow": bump(0.0024, 0.0006, 150)}[kind]  # mV/ms
    v = -50 + np.cumsum(dv) / fs * 1000
    thr = int(np.flatnonzero(dv > 0.02 * dv.max())[0])
    return v, thr, int(np.argmax(v[: int(np.argmax(dv)) + int(0.002 * fs)]))

Result: fig3e blocked (methods underspecified). The automatic reading the criterion fixes would give partially reproduced, but on the analysis below it does not measure the saddle shape on these recordings, and its outcome turns on a detail the paper does not give. On the first AP of the maximal-rate sweep the VEN median index is the lowest (0.037; next L2/3 IT HPCAL1 0.083), Kruskal-Wallis p = 0.0016, and Dunn's test separates VENs from L5 ET (Bonferroni p = 0.003, Sidak 0.003) and from no other group (L6 PC 0.062). On the median over the sweep's APs the VEN median is again the lowest (0.081; next L5 IT FEZF2 0.111), Kruskal-Wallis p = 0.0015, and Dunn's test separates VENs from L5 ET only (p = 0.009 under both). APs whose AIS phase is not resolved are on average 3% or less of a group's APs, but they are the first AP of 5 of 30 L2/3 IT HPCAL1 cells, 3 of 125 L5 IT FEZF2, 3 of 29 VEN and 3 of 18 L5 ET. Leaving them out keeps the VEN medians the lowest (0.030 and 0.081) and changes the first-AP Dunn result: VENs are then separated from IT RORB, L5 ET and L6 PC. The outcome rests on the prominence guard: at 0.02 of the maximal dV/dt the median-AP reading no longer gives VENs the lowest median (0.200 against 0.173 for L5 IT FEZF2) and on the first AP Dunn's test separates no group (lowest p, L5 ET, 0.053 Sidak and 0.055 Bonferroni), which the criterion would not call partially reproduced; at 0.10 the VEN median is the lowest under both readings and VENs are separated from L5 ET on the first AP and from IT RORB on the median.

The shoulder branch reads 195 of the 237 first APs, and it does not measure the shoulder on these recordings. On synthetic APs without noise it gives 0.21 for an AP with a shoulder and 0.81 for one without an AIS phase; with Gaussian noise of 0.02 to 0.05 mV at 50 kHz, a slow-rising AP without an AIS phase gets a median index of 0.003 to 0.011, below 0.1 in 76% to 98% of trials, and the shoulder AP falls to 0.018 at 0.05 mV. At 25 kHz the AP without an AIS phase falls the same way from 0.05 mV, while the shoulder AP keeps its index. The recordings are in this range: the white noise before the step is 0.023 mV (median) in the 50 kHz Axon files and 0.30 mV in the 25 kHz HEKA files. In the recorded first APs read through this branch, the index rises with the time between the AIS value and the dV/dt maximum (Spearman 0.75), and in VENs the AIS value lies a median 0.16 ms before the maximum at 0.92 of it, at 0.9 or more of it in 55% of VEN cells (8% to 38% in the PC groups), as the noise places it in the synthetic test. On the 28 first APs with two resolved maxima, where the branch does not enter, the groups do not differ (Kruskal-Wallis p = 0.54). The code's hand-read values for 233 cells give the paper's result (VEN median 0.117, the lowest; Dunn p of 0.001 or less against every PC group, both corrections), and the automatic index agrees with them only loosely (Spearman 0.39 first AP, 0.20 median). The index also depends on the sampling rate (Axon files brought to 25 kHz change it, median 0.088 to 0.168), and within one device VENs are not significantly lower than the other groups pooled (Axon p = 0.08, HEKA p = 0.10). The paper placed the peaks by hand and gives no rule an automatic reading could follow, and the outcome changes with the choices this reading makes, so no automatic reading has a defensible basis. The claim is blocked, methods underspecified, with fig3d-saddle-phase-plane and fig4i-peak-index-ais-distance-real, which use the same index.

Limits of this analysis. The fall under noise holds for the slow-rising AP: a fast-rising AP without an AIS phase keeps a high index at 0.02 and 0.03 mV (0.666 and 0.698) and falls to 0.006 only from 0.05 mV. Among shoulder-branch cells the index does not correlate with the noise (Spearman 0.07), and the HEKA noise of 0.30 mV is above the 0.1 mV the synthetic test reaches. The p = 0.54 on two resolved maxima comes from groups of 1 to 10 cells and has little power; VENs still have the lowest median there (0.006). The criterion fixes an automatic reading and reports a disagreement with the hand-read values as a deviation, so blocking goes beyond its letter, on the grounds that the fixed reading does not measure what it stands for; a reader should confirm this.

How the analysis differs from the paper's. The features are computed from the deposited traces
with the Methods' definitions and PatchAnaLab's details, not taken from the paper's feature table;
they match it closely for the AP measures (about 97% of cells within 10%), rheobase, latency and
the first-sweep tau. The Methods' tau (averaged over all hyperpolarizing sweeps) is about 26% longer
than the table's, which holds the code's first-sweep tau. Of the claims file's FDR family (39
features), 19 features are defined nowhere in the paper or its package; their values are taken
from the paper's feature table, as an assumption. The phase peak index is read automatically,
where the paper clicked the peaks by hand; it agrees with the hand-read values only loosely, and
the hand-read values give the paper's results for Fig. 3e and 4i where the automatic ones give
them in part or not at all, and these claims are blocked. Groups come from the cell table, which differs from the paper's feature
table for two cells. The transcriptomic distances use the 500 genes that the Methods' gene
selection picks in the 10x data, with two other rankings as variants. No outcome rests on these
two choices: the variants give the same outcomes. Two outcomes rest on assumptions: the cell
table link (its row 235 read as the row of s172) and l5et-vs-l5it-sag-rm-rate (the outcome common to
both sag readings, where the criterion gives no rule for their disagreement).

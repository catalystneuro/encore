Sadeghi et al. (2019): neural claims (CRCNS bst-2)¶

Paper: Sadeghi M, Zhai X, Stevenson IH, Escabi MA (2019). A neural ensemble correlation code for sound category identification. PLoS Biol 17(10):e3000449, doi:10.1371/journal.pbio.3000449. The claims file (claims/sadeghi-2019.yaml) was written from the version of record (PMC6788721) with its supplement.

Dataset: CRCNS bst-2 (doi:10.6080/K03X84V3), read from the public bucket crcnsarchive at bst-2/live/data.tar.gz. CRCNS data sets are not versioned, so the version is recorded as unversioned (dataset crcns:bst-2/unversioned); the paper cites the data set's DOI and no version, and this is the only copy the bucket holds (last modified 2026-02-11). The MD5 sums from bst-2/live/checksums.md5 for the files read: data.tar.gz 916ae724cd3334a16a4396b861e4abe0; docs/crcns_bst-2_data_description.pdf 81457299a36f12a18f2eb8afa5ef1862; docs/FigureData.pdf d0a76ae42a544a60c02912762be2127b. The data description (version 0.6, 26 August 2019) and its figure list were read first.

def width_at(curve, tau, frac):
    """Full width (ms) of the contiguous region around the peak where curve >= frac * peak,
    with linear interpolation of the crossings."""
    i0 = int(np.argmax(curve))
    thr = frac * curve[i0]
    def cross(step):
        i = i0
        while 0 <= i + step < len(curve) and curve[i + step] >= thr:
            i += step
        if not (0 <= i + step < len(curve)):
            return tau[i]
        a, b = curve[i], curve[i + step]
        return tau[i] + (tau[i + step] - tau[i]) * (a - thr) / (a - b)
    return cross(1) - cross(-1)


def side_peak(curve, tau, min_lag=10.0):
    """Lag (ms) of the largest local maximum at positive lags beyond min_lag."""
    m = tau > min_lag
    c, t = curve[m], tau[m]
    loc = [i for i in range(1, len(c) - 1) if c[i] > c[i - 1] and c[i] >= c[i + 1]]
    if not loc:
        return np.nan, np.nan
    j = max(loc, key=lambda i: c[i])
    return t[j], c[j]

At the example paradigm 1 site, stimulus-driven temporal correlations are fast for crowd, water and fire (3.0, 3.0 and 3.9 ms wide at 50% of maximum; 5.9, 6.9 and 11.8 ms at 10%), the bird chorus has a sharp peak (5.9 ms half width) and a slow component (161.2 ms at 10%), and the snake has a 7.9 ms half width, 20.6 ms at 10%, and a periodic pattern of about 50 ms period at high-frequency sites.

Stimulus-driven (shuffled) temporal correlations c_kk(tau), lags within 100 ms. The lag step is 0.49 ms at the files' rate. Channel order is not documented in the data set, so "upper eight channels" is run as channels 9 to 16 and, as a variant, 1 to 8; reading (b) of the period (best frequency above 2 kHz) needs best frequencies, which the data set lacks.

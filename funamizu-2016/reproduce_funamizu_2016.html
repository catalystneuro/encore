Method details used throughout and where they come from are in the docstring of funamizu.py. Two choices forced by the data are standard ones: the files hold a lick frequency (1/inter-lick interval, capped at 10 Hz, held between licks) instead of lick times, so a lick count is the integral of that frequency and a lick onset is a change of it (its form is shown under lick-goal-correlation); and distance-aligned activity is interpolated at 0.42 cm bin centres.

    rows = []

        d = dict(session=np.full(n, i), roi=np.arange(n), area=r["meta"]["area"], layer=r["meta"]["layer"],

def classify(base, sw, km, seed=0, per_session=False):
    """Classes under one reading of O1 (base), O2 (sw) and O3 (km). k-means runs once on the
    after-reaching neurons pooled over sessions, or, with per_session, in each session apart
    (a variant: the paper does not say which)."""
    t = NT
    goal_lp = np.minimum(t[f"lp_goal_{base}"], t[f"lp_dist_{base}"])
    lick_lp = t[f"lp_lick_{base}"]
    start_sig = (t[f"lp_start_{base}"] < LT) | (t[f"lp_sdist{sw}_{base}"] < LT)
    goal_sig = goal_lp < LT
    lick_sig = lick_lp < LT
    goal_cls = goal_sig & ~(lick_sig & (lick_lp < goal_lp))          # the more significant alignment wins
    lick_cls = lick_sig & ~goal_cls
    task = start_sig | goal_sig | lick_sig
    before = goal_cls & ~t.peak_after
    aft = (goal_cls & t.peak_after).values
    after = np.zeros(len(t), bool); reward = np.zeros(len(t), bool)
    scopes = [aft] if not per_session else [aft & (t.session == i).values for i in range(len(R))]
    for sc in scopes:
        idx = np.flatnonzero(sc)
        if len(idx) < 2:
            after[idx] = True                                         # one neuron cannot be split; kept as after-reaching
            continue
        feat = PRE16[idx] if km == "a" else PRE16[idx].mean(1, keepdims=True)
        lab = KMeans(2, n_init=20, random_state=seed).fit_predict(np.nan_to_num(feat))
        if len(set(lab)) < 2:
            after[idx] = True; continue
        hi = np.argmax([np.nanmean(PRE16[idx][lab == c]) for c in (0, 1)])
        after[idx[lab == hi]] = True; reward[idx[lab != hi]] = True
    return pd.DataFrame(dict(task=task.values, goal_sig=goal_sig.values, lick=lick_cls.values, before=before.values,
                             after=after, reward=reward, gd=before.values | after))

CLS = {rd: classify(*rd) for rd in READINGS}
CLS_GD = {rd: CLS[rd] for rd in READINGS if rd[1] == "67"}           # O2 does not change goal-distance classes

Data check¶

What was loaded, and each check of the description against the data. The trial table's goal_distance_cm is the start-to-goal distance; VirtualMovement/move_scan column 0 is the forward position within the trial in units of 36/430 cm (it starts at 0 in every trial and reaches the trial's goal distance when the goal is reached); Speed/speed_x is forward speed in m/s after its conversion factor; Licking/lick_rate is a lick frequency in Hz. Imaging and behaviour share one 30.9 Hz clock: every series has the same number of frames, and the trial table's frames sum to that number. The behaviour streams follow the trial clock: the reward follows the frame where the position passes the goal by tens of milliseconds, and the trial records end about 8 s after the reward (the paper's ITI is 7 s). The imaging follows it too: the decoder, trained on dR/R against the goal distance of each frame, estimates distance far better than the flat prior (claim fig4-above-chance), which an offset between the clocks would prevent. The description says the files hold "sound on/off indicators"; the data hold only the start tone. sound_on_off is 1 in exactly one frame per trial, the first, as is any speaker of stimulus/presentation/speaker_on_matrix (printed below), and every row of speaker_presentations starts at a trial start and lasts one frame; the table has several rows per trial start, one per speaker id listed there, which is why it has 1,085 to 1,240 rows for 150 trials (the counts are printed below for every file). Sound and no-sound zones are therefore computed from the condition and the distance, as the Methods define them.

ZB = {"25.1-8.4": (F.DCENT > 8.4) & (F.DCENT <= 25.1), "8.4-0": F.DCENT <= 8.4}
def slopes_all(trace_reading):
    """Slope of each neuron's condition-averaged activity against approach (rise per cm toward the
    goal, equation 5), per condition and zone. Reading (a) the 0.42 cm bins, (b) after the 8.37 cm
    moving average of the classification."""
    y = COND if trace_reading == "a" else uniform_filter1d(np.nan_to_num(COND), F.SMOOTH_D, axis=2, mode="nearest")
    out = {}
    for z, m in ZB.items():
        x = F.DCENT[m]; yy = y[:, :, m]
        xc = x - x.mean()
        out[z] = -((yy - np.nanmean(yy, axis=2, keepdims=True)) * xc).sum(2) / (xc ** 2).sum()   # neurons x conditions
    return out

def trial_bins(v, width):
    """Per trial mean of a per-frame value v in goal-distance bins of the given width (cm)."""
    b = np.floor(FR.x.values / width).astype(int)
    df = pd.DataFrame(dict(session=FR.session, trial=FR.trial, state=FR.state, group=FR.group, b=b, v=v, x=FR.x))
    return df.groupby(["session", "trial", "state", "group", "b"], as_index=False)[["v", "x"]].mean()

def ppc_pm_bins(v, width, layer=2, conds=(0, 1, 2), err=None):
    tb = trial_bins(v, width)
    tb = tb[tb.group.isin([f"PPC L{layer}", f"PM L{layer}"]) & tb.state.isin(conds)]
    tb = tb[tb.v.notna()]                     # trials of sessions without goal-distance neurons under the reading
    grp = {k: g.v.values for k, g in tb.groupby(["state", "b", "group"])}
    out = []
    for c in conds:
        for b in sorted(tb.b.unique()):
            a = grp.get((c, b, f"PPC L{layer}"), np.zeros(0)); m = grp.get((c, b, f"PM L{layer}"), np.zeros(0))
            p, z = F.mwu(a, m)
            out.append(dict(condition=COND_NAMES[c], bin=f"{(b + 1) * width:.2f}-{b * width:.2f}", lo=b * width,
                            ppc=np.median(a) if len(a) else np.nan, pm=np.median(m) if len(m) else np.nan, z=z, p=p, n=f"{len(a)}, {len(m)}"))
    return pd.DataFrame(out)

def zone_slopes(v, against="x"):
    """Per trial and zone, slope of v on goal distance (decrease per cm of approach, equation 10),
    or on time (b1 of y = b0 + b1 t) when against='time'. Frames of a zone whose sound state
    differs from the zone's (the first 33 cm from the start) are left out."""
    df = pd.DataFrame(dict(session=FR.session, trial=FR.trial, state=FR.state, group=FR.group, zone=FR.zone, silent=FR.silent,
                           u=FR[against].values, v=v))
    df = df[(df.zone >= 0) & ~np.isnan(df.v)]
    zs = np.array([0, 1, 0, 1]); exp_silent = np.where(df.state == 1, zs[df.zone] == 1, np.where(df.state == 2, zs[df.zone] == 0, False))
    df = df[df.silent.values == exp_silent]
    df["uv"] = df.u * df.v; df["uu"] = df.u ** 2
    g = df.groupby(["session", "trial", "state", "group", "zone"])
    s = g.agg(n=("v", "size"), su=("u", "sum"), sv=("v", "sum"), suv=("uv", "sum"), suu=("uu", "sum")).reset_index()
    s = s[s.n >= 3]
    den = s.suu - s.su ** 2 / s.n
    s["slope"] = (s.suv - s.su * s.sv / s.n) / den.where(den > 1e-9)
    s["silent"] = np.where(s.state == 1, zs[s.zone] == 1, np.where(s.state == 2, zs[s.zone] == 0, False))
    return s

Single-basis regressions¶

For every neuron significant in goal-aligned activity under either baseline, unfiltered dR/R is fitted as y = b0 + b1 phi(variable), phi the Gaussian basis of equation (3) centred at the value of maximal averaged activity (Online Methods, Regression analysis). The width is profiled over a grid of 25 values from 0.5 to 200 (cm or dB), the least-squares fit at each, and the best grid value is then refined by a bounded scalar optimizer between its two neighbouring grid values, in place of an optimizer started from four initial values; the grid covers the four initial values of either reading of O6. Frames are those of O6, (a) and (b). The fits run in the loading step (funamizu.regressions).

How the analysis differs from the paper's: lick counts and onsets come from a lick frequency, not lick times; the task-relevance baseline (O1), the k-means feature (O3), the shift (O7) and the bins (O8) are readings, all run, and a claim whose readings disagree is blocked; k-means is pooled over sessions, with a per-session variant shown for the counts and the slope claims; the multi-basis regression (fig3b) and the SVM claims are not run, and the single-basis fits profile the width over a grid and refine it with a bounded optimizer.

What was found about the dataset: it holds the paper's 94 imaging sessions of 8 mice, with the session counts per mouse, area and layer and the 41,031 active ROIs exactly as reported, dR/R as defined in the Methods, and the first 150 trials of each session. It does not hold the muscimol experiment or the sound-mapping trials. The sound streams hold only the start tone, not the task sound the description implies; speaker_presentations lists the speakers on at each trial start, 6 to 26 rows per trial. Licks are stored as a capped, held frequency, not as events. The start-to-reward times (9.3 s) and the share of slow trials (0.48%) differ from the Methods (7.4 s, 2.71%).
